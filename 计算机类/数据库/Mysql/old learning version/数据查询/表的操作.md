# 表的创建

```sql
CREATE TABLE table_name (
    column1 datatype,
    column2 datatype,
    ...
);
```

一、命名规范

>关键字表名需用**反引号包裹 ** `order`

>Linux 环境表名区分大小写，Windows 不区分，全程统一小写避免兼容问题。

>表名小写，用下划线分隔，禁止中文、空格、特殊符号、SQL 关键字

例如
```sql
CREATE TABLE users (  
    id INT AUTO_INCREMENT PRIMARY KEY,  
    username VARCHAR(50) NOT NULL,  
    email VARCHAR(100) NOT NULL,  
    birthdate DATE,  
    is_active BOOLEAN DEFAULT TRUE  
);
```

# 表的删除

执行删除命令后所有数据都会消失

```sql
-- 删除表，如果存在的话
DROP TABLE IF EXISTS mytable;

-- 直接删除表，不检查是否存在
DROP TABLE mytable;

```


只是想删除表中的所有数据，但保留表的结构
这会清空表中的所有数据，但不会删除表本身

```sql
TRUNCATE TABLE table_name;
```

# 表的新数据插入

```sql
单行插入
INSERT INTO table_name (column1, column2, column3, ...)
VALUES (value1, value2, value3, ...);

多行插入
INSERT INTO table_name (column1, column2, column3, ...) VALUES
(value1, value2, value3, ...),
(value1, value2, value3, ...),
(value1, value2, value3, ...),
(value1, value2, value3, ...);
```

>如果数据是**字符型**，必须使用**单引号**或者**双引号**，如： 'value1', "value1"

```sql
INSERT INTO users (username, email, birthdate, is_active)
VALUES ('test', 'test@runoob.com', '1990-01-01', true);
```

可以把上面的简写为：

```sql
INSERT INTO users
VALUES (NULL,'test', 'test@runoob.com', '1990-01-01', true);
```

# 表旧数据的修改

基本语法

```sql
UPDATE table_name
SET column1 = value1  
WHERE condition;
```

- 可以同时更新一个或多个字段。

例如：
```sql
UPDATE studentsNEW SET stu_name='huang' WHERE stu_id=1;
UPDATE studentsNEW SET stu_name='shorter' WHERE stu_height<300;
UPDATE studentsNEW SET stu_id='1' WHERE stu_name='x';
UPDATE studentsNEW SET stu_height=stu_height+100 WHERE stu_age>3;
```

# 删除表的字段
```sql

ALTER TABLE 表名 DROP col1, DROP col2;
```

# 添加表的字段
```sql
--末尾新增 
ALTER TABLE 表名 ADD 字段名 类型 约束; 

--指定位置第一个 
ALTER TABLE 表名 ADD 字段名 类型 FIRST;
--指定位置某字段后面
ALTER TABLE 表名 ADD 字段名 类型 AFTER 已有字段;
-- 一次性加多字段 
ALTER TABLE 表名 ADD (字段名 字段类型, 字段名 字段类型);
```

# MODIFY 

>只能改(类型+约束)，不能修改字段名字
```sql
ALTER TABLE 表名 MODIFY 字段名 新类型 新约束; -- 示例：加大长度、加非空 
```


# CHANGE
 
>可以修改(数据类型 + 约束+字段名称 )

>固定格式：`CHANGE 旧字段名 新字段名 类型 约束`
```sql
ALTER TABLE 表名 CHANGE 旧名 新名 类型 约束;
 
-- 只改名、类型不变（类型原样抄写）
ALTER TABLE employee CHANGE birth birthday DATE; 

-- 只改类型、名字不变（新旧同名） 
ALTER TABLE employee CHANGE birthday birthday DATETIME;
```

可以**修改字段名称 + 数据类型 + 约束**，必须同时填写旧名、新名、类型三样，缺一不可
