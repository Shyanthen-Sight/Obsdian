语法:
```sql
CREATE DATABASE [IF NOT EXISTS] 库名 
CHARACTER SET 字符集
COLLATE 排序规则;
```

>其中字符集常用的是常用 ：**utf8mb4**

简单创建
```sql
CREATE DATABASE testdb;
```

## MySQL 重点注意
### 1. 命名规范

1. 库名只能由**字母、数字、下划线**组成
 
2. 不能用 SQL 关键字（如 user），非要用得加反引号 `` `库名` ``；
 
3. 区分大小写：Windows 不区分，Linux 严格区分，建议全程小写命名。

###  2.字符集与排序规则

4. 不要用旧 `utf8`，MySQL 的`utf8`只支持 3 字节，存不了 emoji、生僻字；统一用 **utf8mb4**

5. 排序推荐 `utf8mb4_unicode_ci`（兼容多语言、大小写不敏感）；

6. 建库不指定字符集，会继承服务器默认配置，后期改库改表非常麻烦。

### 3. IF NOT EXISTS 必加

  不加时，如果库已存在会直接抛错，程序批量执行 SQL 会中断崩溃。
