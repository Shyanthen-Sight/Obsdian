# Unit 1 Notices 通知 —— 知识点精讲与分析

> 对应《走进职场英语写作（第二版）》书中第 1–20 页。
> 本单元三种通知类型：紧急通知、预告通知、多种形式通知。核心训练点：祈使句给指令、"V-ing" 表行动方式、省略结构写短句、写简短标题、被动语态把非正式转正式。

---

## 一、单元定位与学习目标
通知（Notice）是职场中最常见、最简短的公开文体。它的本质是**"信息一次性触达，读者扫一眼就要看懂"**，因此本单元贯穿一条主线——**读者意识（reader awareness）**：写通知时永远假设读者时间紧、注意力散、甚至可能正在慌乱中（紧急情况）。

学完本单元你应能：
- 根据场合选择合适的通知形式（口头/图形/竖排/书信/邮件）；
- 用祈使句和 "V-ing" 形式写出清晰指令；
- 用省略结构压缩句子，写简短标题；
- 用被动语态把口语化通知改成正式通知。

## 二、PART 1 Emergency Notices 紧急通知（第 2–7 页）

### 1. 体裁认知
紧急通知（火灾、地震、设备报修等）的读者处于应激状态，**信息必须"一眼可读"**。这是它和普通通知最大的区别——普通通知可以委婉，紧急通知必须**指令化、命令化、无歧义**。

### 2. 核心写作技巧（Writing Skills）
- **清晰标题**：直接点明事件，如 `FIRE ACTION`、`EARTHQUAKE`，不要写成"关于……的通知"这种绕弯标题。
- **分场景副标题**：把行动按触发条件分组，例如：
  - `IF YOU DISCOVER A FIRE`（你发现火情时）
  - `ON HEARING THE ALARM`（听到警报时）
  - `IN THE EVENT OF AN EARTHQUAKE`（地震发生时）
- **用具体可感的词（concrete words）**：写 "use a fire extinguisher"、"move 50 meters away"，而不是 "do something about the fire"。
- **直接写 Dos and Don'ts**：该做什么、不该做什么，逐条列出。

### 3. 语言点讲解（Language Focus）

#### （1）连词后省略 "subject + be"
在从句中，当主语与主句一致或指代明确时，可省略 "主语 + be" 使句子紧凑：

> As (it is) announced in the notice, the fire drill will be held on Friday.

常见可省略连词：**if / even if / as if / as / unless / until / when / while / where / although / once**。

⚠️ 注意：省略只发生在**从句**中，不能在主句里省略。

#### （2）"V-ing" 表行动方式
在主句后用现在分词短语，表示**同一主语**紧接着要做的动作：

> Leave the building calmly, **using the nearest exit**.
> Please switch off your phones, **not making any noise**.

否定形式是 **not + V-ing**：

> Do not run around, **not pushing others**.（不要乱跑，不要推搡他人。）

### 4. 表达工具（Expressions in Use）
强调手段（emphatic devices）清单——紧急通知靠视觉强调让关键信息跳出来：
下划线 / 大写 / 颜色标注 / 编号 / 项目符号 / 星号 / 字体变化 / 斜体 / 粗体 / 对齐 / 行距。

### 5. 范文解析
- **Bridge No.139 报修通知** vs **Fire Action 火灾行动通知**：教材通过对比让你体会哪则"一眼可读"。火灾通知的标准三段：发现火情→听到警报→疏散。
- **地震通知草稿**：分 "During the earthquake" 和 "After the earthquake" 两阶段列行动清单。

### 6. 常见错误避坑
- ❌ 用完整长句写紧急指令（读者没时间读从句）；
- ❌ 标题模糊（"An Important Notice" 不如 "EVACUATION ROUTE"）；
- ❌ V-ing 逻辑主语与主句不一致（*Walking down the stairs, the alarm rang* —— 错误，因为 alarm 不能 walk）。

### 7. 过程写作任务（Project）
角色 Allen 第一天上班，经理 Johnson 让他观察办公楼隐患并写紧急通知。
- Step 1：记录表格（Places observed / Potential dangers / Measures to take）；
- Step 2：按合理顺序起草；
- Step 3：每句主语突出、用 V-ing、删 subject+be；
- Step 4：用强调手段润色排版。

## 三、PART 2 Upcoming Event Notices 预告通知（第 8–15 页）

### 1. 体裁认知

预告通知（会议、讲座、比赛、闭馆等）必须交代四要素：**what / when / where / who**。这是通知的"硬指标"，缺一个读者就要追问。

### 2. 核心写作技巧

#### （1）简短标题（brief forms）
标题用名词短语，省略冠词和助动词，制造电报式简洁感：
- ~~The new online registration is available~~ → **(The) New Online Registration (Is) Available**

#### （2）正式度分级与被动语态
通知风格分 formal / neutral / informal 三档。**被动语态是正式写作的标志**，作用是隐去主观人称（I / we），让通知显得客观、公事公办：

> I am going to hold a free lecture. → **A free lecture will be held**.

**非正式转正式四步法**：
1. 删除多余词；
2. 避免口语表达；
3. 合并短句；
4. 必要时改用被动语态。

要避免的口语痕迹：缩写（don't / can't）、句首 And、be going to、无信息量的 "Attention!"。

### 3. 语言点讲解（Language Focus）
- 被动语态结构 **be + V-ed**：只有 be 随时态变化（is / was / is being / will be / has been），过去分词 V-ed 不变。
- 连接词后省略 "subject + be"（同 PART 1）：As (it is) announced, …

### 4. 表达工具（Expressions in Use）
正式通知开场白：
- Please be informed that…（特此告知……）
- Please be reminded that…（敬请留意……）
- It is hereby announced that…（现宣布……）
- This is to notify that…（兹通知……）
- Please note that…（请注意……）

### 5. 范文解析
- **Notice Board A**：五则通知（OAC 会议取消、澄清说明、语言中心关闭、工作坊报名、学生工资单可取），训练你做 What/Who/Where/When 表格。
- **Notice Board B**：口译大赛、跨文化讲座、作业提交、Q&A 专场、春节图书馆闭馆。

### 6. 常见错误避坑
- ❌ 时间信息模糊："next month" / "this night" 必须改成具体日期；
- ❌ 主语用 "we" 太多，显得不正式；
- ❌ 标题带完整句子（标题写短语即可）。

### 7. 过程写作任务（Project）
Allen 在公司内网发布一周在线通知公告。要点：先收集信息写关键词，起草时回答全部 wh-questions，用被动避人称，给清晰标题与具体时间地点。

## 四、PART 3 Notices in Multiple Forms 多种形式的通知（第 16–20 页）

### 1. 体裁认知
同一条信息，因**对象和距离**不同，通知的"容器"也不同：
- **Graphic format 图形格式**：用关键词表格（Subject / Type / Date / Time / Venue / Sponsor）呈现，<font color="#c00000">快速易跟</font>；
- **Vertical format 竖排格式**：每行一个要点、行首常用介词，风格更正式，<font color="#c00000">用于讲座、庆典等重要场合</font>；
- 距离远的重要对象（市长、外地 VIP）则写成 **letter 或 e-mail**。

### 2. 核心写作技巧
- Graphic format = 关键词表，不写完整句；
- Vertical format = 句子拆成短行，<font color="#c00000">每行一个 key point，介词开头（At / On / In / From…）</font>。

### 3. 范文解析
- **Forum on Loss of Native Habitat** 图形通知；
- **Shakespeare Poems 讲座**竖排通知（Professor Andree, Lecture Hall, 6:30 p.m. Thursday 10 January）；
- **毕业典礼演讲邀请信**（书信体通知）。

### 4. 常见错误避坑
- ❌ 对重要场合用太随意的图形格式；
- ❌ vertical format 一行塞多个要点（每行只放一个信息点）。

### 5. 过程写作任务（Project）
角色公司秘书，为 HONS Group 开幕典礼（Dr Andrew Smith 主讲）分别通知三类对象：
- 员工 → 表格形式；
- 本市市长 → vertical format；
- 外地 VIP 客户 → 书信形式。
这是本单元的综合应用：**形式由对象决定**。

## 五、单元速记卡

| 要点 | 关键内容 |
|------|----------|
| 读者意识 | 读者时间紧，信息要一眼可读 |
| 紧急通知 | 指令化、具体词、Dos & Don'ts |
| 预告通知 | 必含 what/when/where/who |
| 标题 | 名词短语、省略冠词助动词 |
| 省略 | 从句中 "连词 + (主语+be)" |
| V-ing | 主句后表同一主语的紧随动作，否定 not+V-ing |
| 正式化 | 被动语态隐去 I/we，删口语，合并短句 |
| 形式选择 | 对象近/远、场合正式度决定图形/竖排/书信 |
