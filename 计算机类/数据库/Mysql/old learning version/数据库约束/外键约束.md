
## 建表时添加外键约束
```sql
create table 表名(
字段定义...
constraint 外键名称 foreign key (字段名) references 主表名 (主键字段) [属性]
);
```

## 修改创建外键约束
```sql
alter table 表名 add constraint 外键名 foreign key (外键字段) references 主表名(主键字段) [属性];
```

## 删除外键
```sql
alter table 表名 drop foreign key 外键名;
```

**参数说明**

**constraiant**：用于设置外键的==*约束名*==，可以省略

**foreign key**：用于==指定外键字段==

**reference**：用于==指定主表和主键==

**属性说明：**

**CASCADE**：主表删除或修改记录时，从表也会对==关联记录的外键字段进行修改==。

**RESTRICT**：删除或修改主表记录，子表中若有关联记录，则==不允许主表删除或修改==。

**SET NULL**：主表删除或修改主表记录时，==从表会将关联记录的外键字段设为null==。

**ON UPDATE CASCADE**：主表修改记录时，从表关联记录的==外键字段也会修改==。（将CASCADE改为RESTRICT，意思相反）

**ON DELETE CASCADE**：主表删除记录时，从表关联记录的==外键字段也会删除==。（将CASCADE改为RESTRICT，意思相反）
