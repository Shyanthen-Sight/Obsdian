## 零、为什么要有这两类关系

关系千千万，但**数学里真正"到处都在用"的只有两类**：

- **等价关系**：把"按某种标准认为**相同**（可以互相替换）"这件事形式化。
  - 例：整数按"除以 3 的余数"分组；三角形按"相似"分组；人按"同一天生日"分组。
  - 关键词：**分类、归类、看作一样**。
- **偏序关系**：把"按某种标准**比较大小 / 谁包含谁 / 谁更精细**"形式化。
  - 例：实数的小于等于 `≤`；集合的包含 `⊆`；正整数的整除 `∣`；任务之间的"必须先做完"依赖。
  - 关键词：**层级、次序、先后、粗细**。

> 🧠 **一句话总纲**：等价关系回答"**谁和谁是一伙的**"；偏序关系回答"**谁在谁上面**"。
> 前者把集合**切碎成几堆**，后者把集合**排成一个有层级的骨架**。

这两类关系分别是 4.3 节三条性质的**特定组合**：

| 关系类型 | 自反 | 对称 | 反对称 | 传递 |
| --- | --- | --- | --- | --- |
| 等价关系 | ✓ | ✓ | — | ✓ |
| 偏序关系 | ✓ | — | ✓ | ✓ |

==注意：等价关系要"对称"，偏序关系要"反对称"，它们是对称性上的两极。== 传递性和自反性是二者共有的地基。

## 一、等价关系

### 1.1 定义

设 `R` 是集合 `A` 上的二元关系。若 `R` 同时满足：

1. **自反性**：`∀x∈A`，有 `<x,x>∈R`；
2. **对称性**：`∀x,y∈A`，若 `<x,y>∈R` 则 `<y,x>∈R`；
3. **传递性**：`∀x,y,z∈A`，若 `<x,y>∈R` 且 `<y,z>∈R`，则 `<x,z>∈R`。

则称 `R` 为 `A` 上的**等价关系**。习惯上把等价关系记作 `~`，把 `<x,y>∈~` 写成 `x ~ y`，读作"**x 等价于 y**"。

> 🧠 **口诀**：**自、对、传** —— "自己跟自己一样，你跟我一样我就跟你一样，你跟我一样、我跟他一样，你就跟他一样"。

### 1.2 典型例子

| 例子 | 集合 `A` | 关系 `R` | 为什么是等价关系 |
| --- | --- | --- | --- |
| 恒等关系 | 任意 `A` | `I_A = {<x,x> ∣ x∈A}` | 每个元素只和自己相关，三性质全部平凡成立 |
| 全域关系 | 任意 `A` | `E_A = A×A` | 所有元素两两相关，三性质成立 |
| 模 n 同余 | `Z`（整数集） | `x ≡ y (mod n)` ⟺ `n ∣ (x−y)` | 自反：`n∣0`；对称：`n∣(x−y) ⟹ n∣(y−x)`；传递：`n∣(x−y), n∣(y−z) ⟹ n∣(x−z)` |
| 奇偶同组 | `Z` | `x ~ y` ⟺ `x, y` 同奇偶 | 即 `n = 2` 的同余 |
| 三角形相似 | 某平面上的三角形集 | `△₁ ~ △₂` ⟺ 两三角形相似 | 相似的三个条件（SSS/AA 等）保证自、对、传 |
| 号码同首 | 手机号集合 | 前缀相同 | 长度固定时三性质成立 |
| 回路连通 | 无向图顶点 | `u ~ v` ⟺ `u, v` 之间有路径 | 自反（平凡路）；对称（无向）；传递（路径拼接） |

> ⚠️ **易错**：`≤` 是自反、传递，但**不对称**（`2≤3` 却 `3≰2`），所以 `≤` **不是**等价关系。—— 对称是等价关系的命门。

## 二、等价类 `[x]_R`

### 2.1 定义

设 `~` 是 `A` 上的等价关系，`x∈A`。令

```
[x]_R = { y | y∈A 且 <x,y>∈R } = { y | x ~ y }
```

称 `[x]_R` 为 **`x` 关于 `R` 的等价类**（equivalence class），`x` 称为该等价类的**代表元**。

直观理解：==把所有"和 `x` 互相等价"的元素捡进同一个袋子里，这个袋子就是 `[x]_R`。==

### 2.2 四条基本性质

**性质 1（非空）**：`[x]_R ≠ ∅`。
证明：由自反性 `<x,x>∈R`，所以 `x∈[x]_R`，故非空。∎

**性质 2（成员身份）**：`x∈[x]_R`，即每个元素都在自己的等价类里。

**性质 3（相等判据）**：`[x]_R = [y]_R ⟺ x ~ y`。

> 这是等价类**最有用的一条**：判断两个等价类是否相等，不必比较两个集合，只要检验代表元是否等价。

**性质 4（要么相等，要么不交）**：若 `[x]_R ≠ [y]_R`，则 `[x]_R ∩ [y]_R = ∅`。

证明（性质 4）：反设 `[x]_R ∩ [y]_R ≠ ∅`，则 `∃z∈A` 使 `z∈[x]_R` 且 `z∈[y]_R`，即 `x ~ z` 且 `y ~ z`。由对称性 `z ~ y`，再由传递性 `x ~ y`。由性质 3 得 `[x]_R = [y]_R`，与假设矛盾。故二者不相交。∎

**性质 5（覆盖整个 A）**：`⋃_{x∈A} [x]_R = A`。
证明：显然 `⋃[x]_R ⊆ A`（每个等价类都是 `A` 的子集）；又对任意 `a∈A`，有 `a∈[a]_R`，故 `A ⊆ ⋃[x]_R`。两边互相包含，相等。∎

> 🧠 **一句话记牢**：==等价类是一堆堆互不重叠、又刚好铺满 `A` 的"拼图块"。==

### 2.3 等价类与代表元

- 同一个等价类中可以有很多代表元：`[x]_R = [y]_R` 时 `x, y` 都叫代表元。
- 不同代表元算出来的类，可能是同一个类（性质 3）。
- 习惯上从每个类里挑一个元素作代表，写出来的类会"看起来不重复"。

## 三、商集 `A/R` 与划分

### 3.1 商集

令

```
A/R = { [x]_R | x∈A }
```

即**所有等价类组成的集合**，称为 `A` 关于 `R` 的**商集**（quotient set）。

> ⚠️ **易错**：`[x]_R` 是**元素（一个子集）**，而 `A/R` 是**集合的集合**。层次差一级，写题时别把 `[x]_R` 与 `A/R` 混为一谈。
> 例：`A = {1,2,3,4}`，`~` 按奇偶分组。则 `[1]_R = [3]_R = {1,3}`，`[2]_R = [4]_R = {2,4}`，而 `A/R = { {1,3}, {2,4} }`（只有 **2** 个元素）。

### 3.2 划分

设 `A` 是非空集合，`π = {S₁, S₂, …, Sₖ}` 是 `A` 的一些子集组成的集合。若满足：

1. 每个块**非空**：`Sᵢ ≠ ∅`；
2. 两两**不相交**：`Sᵢ ∩ Sⱼ = ∅`（`i ≠ j`）；
3. 并**覆盖 A**：`⋃_{i=1}^{k} Sᵢ = A`。

则称 `π` 是 `A` 的一个**划分**（partition），每个 `Sᵢ` 称为 `π` 的一个**划分块**。

### 3.3 核心定理

> ==**定理**：集合 `A` 上的等价关系与 `A` 的划分一一对应。==

**证（两个方向的构造）**：

- **由关系到划分**：给定 `A` 上的等价关系 `R`，取其商集 `A/R`。由第 2.2 节的性质 4、5，`A/R` 中每个类非空、两两不交、并恰为 `A`，所以 **`A/R` 是 `A` 的一个划分**。
- **由划分到关系**：给定 `A` 的划分 `π`，定义关系
  ```
  R = { <x,y> | x, y 属于 π 的同一个划分块 }
  ```
  验证三性质：
  - 自反：`x` 与自己在同一块；
  - 对称：同块关系本身是对称的；
  - 传递：若 `x, y` 同块、`y, z` 同块，则由"块之间不交"知这两块必须是同一块，故 `x, z` 同块。
  故 `R` 是等价关系，且它的商集恰好是 `π`。

两个构造互为逆运算，且唯一，故一一对应。∎

> 🧠 **记忆钩子**：==等价关系 ⟷ 划分，是**同一件事的两种说法**==：一个说"用哪些对子判等价"，一个说"最后分成哪几堆"。
> 给了划分，就能写出"同块即等价"的等价关系；给了等价关系，就能用商集切出划分。

## 四、偏序关系

### 4.1 定义

设 `R` 是 `A` 上的二元关系。若 `R` 满足：

1. **自反性**：`∀x∈A`，`<x,x>∈R`；
2. **反对称性**：`∀x,y∈A`，若 `<x,y>∈R` 且 `<y,x>∈R`，则 `x = y`；
3. **传递性**：`∀x,y,z∈A`，若 `<x,y>∈R` 且 `<y,z>∈R`，则 `<x,z>∈R`。

则称 `R` 为 `A` 上的**偏序关系**（partial order），记作 `≼`，并把 `<A, ≼>` 称为一个**偏序集**（poset）。

把 `<x,y>∈≼` 写成 `x ≼ y`，读作"`x` 小于等于 `y`"或"`x` 排在 `y` 前"。

> ⚠️ **两个提醒**：
> 1. 符号 `≼` 是**抽象**的，具体含义取决于场景（`≤`、`⊆`、`∣` 都可）。
> 2. 反对称**不等于**"反对立"，也不是"不对称"。`3 ≤ 3` 成立，`3 ≼ 3` 也成立 —— 自反与反对称并不冲突。

### 4.2 典型例子

| 偏序集 | 集合 `A` | 关系 `≼` | 说明 |
| --- | --- | --- | --- |
| 实数偏序 | `R`（实数） | `≤` | 最直观的"大小" |
| 幂集偏序 | `P(S)` | `⊆` | "包含得多"就"更大" |
| 整除偏序 | `Z⁺`（正整数） | `x ∣ y` | 自反：`x∣x`；反对称：`x∣y, y∣x ⟹ x=y`；传递：`x∣y, y∣z ⟹ x∣z` |
| 子群偏序 | 某群的所有子群 | 子群包含 | 同 `⊆` |
| 字符串前缀 | 字符串集 | `s` 是 `t` 的前缀 | 字典序的雏形 |
| 任务依赖 | 任务集 | "a 必须先于 b" | 常见于项目管理/拓扑排序 |

> ⚠️ **易错**：`⊂`（真包含，即严格包含）**不是**偏序关系！它**不自反**（`A ⊄ A`）。要构成偏序，必须用 `⊆`。
> 同理 `x < y` 也不是偏序，`x ≤ y` 才是。

### 4.3 可比与不可比

在偏序集 `<A, ≼>` 中，对 `x, y∈A`：

- 若 `x ≼ y` 或 `y ≼ x`，称 `x` 与 `y` **可比**（comparable）；
- 若二者都不成立，称 `x` 与 `y` **不可比**（incomparable），记作 `x ∥ y`。

> 关键差异：==偏序允许"不可比"存在——这正是它比全序"偏"的地方。==
> 例：在 `<Z⁺, ∣>` 中，`2` 与 `3` 不可比（2 不整除 3，3 也不整除 2）。在幂集 `<P(S), ⊆>` 中，`{a}` 与 `{b}` 不可比。

## 五、哈斯图（Hasse 图）

### 5.1 为什么要画

偏序集的关系图（有向图）边太多、自环太多，直接画看不清结构。**哈斯图**去掉所有"冗余信息"，只保留"骨架"。

### 5.2 三条化简规则

从关系图出发，依次做：

1. **去掉所有自环**：因为自反性是偏序的默认属性，无需画出（`<x,x>` 全部省略）。
2. **去掉由传递性可推出的边**：若 `x ≼ y`、`y ≼ z`，则 `x ≼ z` 一定成立，这一条边是多余的，去掉。**只保留"紧挨着的"（覆盖）关系**。
   - 定义：若 `x ≼ y` 且 `x ≠ y`，且**不存在** `z` 使 `x ≼ z ≼ y`（`z` 与 `x, y` 都不同），则称 `y` **覆盖** `x`，`x ⋖ y` 画一条边。
3. **按偏序方向分层摆放**：约定"小的在下、大的在上"（或反向，全图统一即可），把方向信息用**上下位置**表示，于是箭头也可以省掉。

> 🧠 **口诀**：**去自环、去多余、定方向**。留下的边 = 覆盖关系。

### 5.3 画法步骤（实用流程）

1. 写出集合 `A` 与关系 `≼`（或用覆盖关系）。
2. 找出所有**极小元**放在最底层。
3. 找出每个元素"**直接盖住**"它的元素（覆盖关系），连边。
4. 逐层向上排：只被极小元覆盖的放第二层，依次上推。
5. 检查：每条向上路径都对应一个"链"，不可比的元素水平分开摆放。

### 5.4 例一：`<{1,2,3,4,6,12}, ∣>` 的哈斯图

覆盖关系：`1⋖2, 1⋖3, 2⋖4, 2⋖6, 3⋖6, 4⋖12, 6⋖12`。

分层（文字版）：

```
第 4 层（顶）:        12
                     /  \
第 3 层:            4    6
                    |   / \
第 2 层:            2  ...  3
                     \  |  /
第 1 层（底）:         1
```

用缩进+表格更清楚：

| 层 | 元素 |
| --- | --- |
| 第 1 层（底） | `1` |
| 第 2 层 | `2`, `3` |
| 第 3 层 | `4`, `6` |
| 第 4 层（顶） | `12` |

连边（覆盖）：`1—2`、`1—3`、`2—4`、`2—6`、`3—6`、`4—12`、`6—12`。

> 注意 `2` 与 `3` 同层不可比，`4` 与 `6` 同层不可比。

### 5.5 例二：幂集 `P({a,b,c})` 的哈斯图

按包含关系 `⊆`：

| 层 | 元素 |
| --- | --- |
| 第 1 层（底） | `∅` |
| 第 2 层 | `{a}`, `{b}`, `{c}` |
| 第 3 层 | `{a,b}`, `{a,c}`, `{b,c}` |
| 第 4 层（顶） | `{a,b,c}` |

覆盖关系：相邻两层中"差一个元素"的两个集合之间连边。这是一个著名的**布尔格**结构，每一层的元素个数正好是 `C(3,k)`：1, 3, 3, 1。

> 🧠 ==幂集按 `⊆` 的哈斯图 = 一个"分层的立方体骨架"==，层数与集合的基数对应，非常整齐。

## 六、偏序集中的特殊元素（本节最易混）

设 `<A, ≼>` 是偏序集，`B ⊆ A`。

### 6.1 六类元素总表

| 名称 | 定义（关键：看待比较的是谁） | 是否唯一 | 是否必存在 |
| --- | --- | --- | --- |
| **最大元** `max B` | `b∈B`，且 `∀x∈B`，`x ≼ b`（**B 中人人 ≤ 它**） | 若存在则**唯一** | 不一定 |
| **最小元** `min B` | `b∈B`，且 `∀x∈B`，`b ≼ x` | 若存在则**唯一** | 不一定 |
| **极大元** | `b∈B`，且 **B 中不存在** `x` 使 `b ≺ x`（比它大的） | 可多个 | 有限时必有 |
| **极小元** | `b∈B`，且 **B 中不存在** `x` 使 `x ≺ b`（比它小的） | 可多个 | 有限时必有 |
| **上界** | `b∈A`（注意可**不在 B**！），且 `∀x∈B`，`x ≼ b` | 可多个 | 不一定 |
| **下界** | `b∈A`，且 `∀x∈B`，`b ≼ x` | 可多个 | 不一定 |
| **上确界** `sup B` | 上界集合的**最小元**（最小上界） | 若存在则唯一 | 不一定 |
| **下确界** `inf B` | 下界集合的**最大元**（最大下界） | 若存在则唯一 | 不一定 |

（这里 `b ≺ x` 表示 `b ≼ x` 且 `b ≠ x`。）

### 6.2 三组关键辨析

**(1) 最大元 vs 极大元**

- 最大元要求"**跟 B 中所有元素都可比且最大**"；极大元只要求"**B 中找不到比它更大的**"，**允许它和其他元素不可比**。
- ==最大元一定是极大元，反之不成立。==
- 例子：`<{2,3,6,12}, ∣>` 取 `B = {2,3,6,12}`。`12` 最大元也是极大元；`2,3` 不是极大元（`2≼6`）。但取 `B = {2,3}`：`2, 3` 都**是极大元**（彼此不可比，谁也没有更大者），却**没有最大元**（不可比，不存在"人人都 ≤ 它"的元素）。

> ⚠️ **判最大元/最小元的必杀技**：先检查 `B` 中有没有**不可比的一对**；只要有，就**不可能**有最大元或最小元（因为最大元必须与所有人可比）。==不可比出现 ⟹ 最大/最小元不存在；但极大/极小元仍可能有多个。==

**(2) 上界 vs 上确界**

- 上界在 `A` 中找，**可以在 `B` 之外**；上确界是"上界里最小的那个"。
- 上界可能有很多个；上确界存在则**唯一**。
- 例：`<R, ≤>`，`B = (0,1)`（开区间）。上界有 `1, 2, 100, …`，**上确界 `sup B = 1`**，但 `1 ∉ B`（题中 `B` 无最大元）。这体现出**上确界不必属于 `B`，最大元必须属于 `B`**。
- 例：`<Q, ≤>`（有理数），`B = {x∈Q | x² < 2}`。`B` 有上界（如 2），但在 `Q` 中**没有上确界**（`√2` 不在 `Q`）——说明==在偏序集中上确界不一定存在，取决于所在的"A"==。

> ⚠️ **一句话刺刀**：==最大元必须在 B 里，上确界可以在 B 外；上确界是"上界中的最小者"。==

**(3) 极大元一定存在吗？**

- **有限**偏序集：极大元和极小元**必定存在**（沿着链一直往上走，有限步必停）。
- **无限**偏序集：不一定。例 `<Z, ≤>` 中 `B = Z` 无极大元也无最大元。
- 最大/最小元则**无论有限无限都不保证存在**。

### 6.3 综合例题（判断六类元素）

设 `A = {1,2,3,4,6,12}`，偏序为整除 `∣`，取 `B = {2,3,6}`（`≼` 即 `∣`）。

| 概念 | 结果 | 理由 |
| --- | --- | --- |
| `max B` | **6** | `2∣6`、`3∣6`，6 是 B 中人人 ≤ 的元素 |
| `min B` | **不存在** | `2` 与 `3` 不可比，没有"人人 ≥ 它"的元素 |
| 极大元 | **6** | B 中无比 6 更大者 |
| 极小元 | **2, 3** | 2 与 3 互相不可比，二者都无比自己更小者 |
| 下界 | 只有 **1** | A 中能整除 2 和 3 的元素只有 1 |
| 上界 | **6, 12** | 6 和 12 都被 2、3 整除 |
| `inf B` | **1** | 下界只有 1，故最大下界 = 1 |
| `sup B` | **6** | 上界 {6,12} 中最小者为 6 |

> 观察：此处 `max B = sup B = 6`，`inf B = 1`（`1 ∉ B`，说明下确界可以在 B 外），而 `min B` 不存在。
> 🧠 **规律**：==当 `max B` 存在时，`sup B = max B`；否则 `sup B` 只能是 B 外的元素或不存在。==

## 七、全序关系（线序）

### 7.1 定义

设 `<A, ≼>` 是偏序集。若 `A` 中**任意两个元素都可比**，即 `∀x,y∈A`，`x ≼ y` 或 `y ≼ x`，则称 `≼` 为 **A 上的全序关系**（total order），也叫**线序关系**，`<A, ≼>` 称为**全序集**（或线序集）。

### 7.2 全序 vs 偏序

| 特征 | 偏序 | 全序 |
| --- | --- | --- |
| 自反 + 反对称 + 传递 | ✓ | ✓ |
| 任意两元素可比 | 不一定 | **必然** |
| 哈斯图形状 | 可能"分叉成一片" | **一条链**（每个元素最多一个直接上方、一个直接下方） |
| 例子 | `<P(S), ⊆>`、`<Z⁺, ∣>` | `<R, ≤>`、`<{1,2,4,8}, ∣>` |

> 反例对比：`<P({a,b}), ⊆>` 中 `{a}` 与 `{b}` 不可比，所以**不是**全序；但 `<{1,2,4,8}, ∣>` 中任意两个都能互相整除比较，是**全序**（哈斯图是一条竖线 `1—2—4—8`）。

### 7.3 良序（点到为止）

若 `<A, ≼>` 是全序集，且 `A` 的**任意非空子集都有最小元**，则称 `≼` 为 **A 上的良序关系**。

- `<N, ≤>`（自然数）是良序集。
- `<Z, ≤>`（整数）**不是**良序集：整数集本身（或 `{…,−2,−1,0}`）没有最小元。
- `<R, ≤>` 也**不是**良序集。

> 良序 = 全序 + "任何非空子集都踩着地（有最小元）"。数学归纳法能成立，理论上就靠自然数的良序性。

## 八、典型例题

### 例 1（判定等价关系并求商集）

设 `A = {1,2,3,4,5}`，`R = {<x,y> | x,y∈A, x−y 是 3 的倍数}`。判断 `R` 是否为等价关系，并求 `A/R`。

**解**：`x−y` 是 3 的倍数即 `x ≡ y (mod 3)`，同余关系是等价关系（见 1.2 节），三性质成立。

按 `mod 3` 分组：
- 余 1：`{1,4}`
- 余 2：`{2,5}`
- 余 0：`{3}`

故 `A/R = { {1,4}, {2,5}, {3} }`。

### 例 2（由划分求等价关系）

设 `A = {a,b,c,d}`，划分 `π = { {a,b}, {c}, {d} }`。写出对应的等价关系。

**解**：同块即相关。`{a,b}` 内部：`<a,a>,<a,b>,<b,a>,<b,b>`；`{c}`：`<c,c>`；`{d}`：`<d,d>`。
故
```
R = { <a,a>,<a,b>,<b,a>,<b,b>,<c,c>,<d,d> }
```

### 例 3（求特殊元素并画哈斯图）

`A = {1,2,3,4,6,12}`，`≼` 为 `∣`。取 `B = {2,4,6,12}`。求 `max B`、`min B`、极大/极小元、上/下界、`sup B`、`inf B`。

**解**：

- 可比性：`2∣4∣12`，`2∣6∣12`，但 `4` 与 `6` 不可比。
- `max B`：`12`（人人 ≤ 12），**存在且唯一**。
- `min B`：`2`（`2` ≤ `4,6,12`），存在且唯一。
- 极大元：`12`；极小元：`2`。
- 上界：`12`（A 中只有 12 能被 2,4,6 全部整除）；`sup B = 12`。
- 下界：`1, 2`（都整除 B 中所有元素）；`inf B = 2`。

（哈斯图同 5.4 节，B 取的是其中一部分元素。）

### 例 4（判定全序）

判断 `<{1,2,3,6}, ∣>` 是否为全序集。

**解**：检查每一对：`1∣2,1∣3,1∣6,2∣6,3∣6` 均可比；但 `2` 与 `3` 互不整除 —— **不可比**。故**不是**全序集（只是偏序集），其哈斯图中 `2` 与 `3` 分叉。

## 练习题

**🟢 基础**

1. 判断下列关系是否为等价关系，并说明理由：
   (a) `A = Z`，`x ~ y ⟺ x−y 是偶数`；
   (b) `A = Z`，`x ~ y ⟺ x·y > 0`；
   (c) `A = {1,2,3}`，`R = {<1,1>,<2,2>,<3,3>,<1,2>,<2,1>}`。

2. 设 `A = {1,2,3,4,5,6}`，`R` 为"模 3 同余"。求每个元素的等价类，并写出商集 `A/R`。

3. 判断下列是否为 `A` 上的偏序关系：
   (a) `A = R`，`x ≼ y ⟺ x ≤ y`；
   (b) `A = Z`，`x ≼ y ⟺ x ∣ y`（整除）；
   (c) `A = P({a,b})`，`x ≼ y ⟺ x ⊂ y`（真包含）。

**🟡 进阶**

4. 设 `A = {1,2,3,4,6,8,12,24}`，偏序为整除 `∣`。画出哈斯图，并指出所有极大元与极小元。

5. 划分 `π = { {1,2,3}, {4,5}, {6,7,8,9} }` 是集合 `A = {1,2,…,9}` 的划分。写出对应的等价关系 `R`，并说明 `[4]_R` 与 `A/R`。

6. 设 `<A, ≼>` 中 `B = {x∈R | 1 < x < 2}`（实数开区间）。求 `B` 的上界、下界、`sup B`、`inf B`，并说明 `max B`、`min B` 是否存在。

7. 判断 `<{1,3,9,27}, ∣>` 与 `<P({a,b}), ⊆>` 哪个是全序集，哪个不是，并各画一个哈斯图说明。

**🔴 挑战**

8. 证明：在偏序集 `<A, ≼>` 中，若 `B ⊆ A` 的最大元存在，则最大元唯一；并证明此时 `sup B = max B`。

9. 设 `f: A → B` 是任意函数，在 `A` 上定义 `x ~ y ⟺ f(x) = f(y)`。证明 `~` 是 `A` 上的等价关系，并说明商集 `A/~` 与 `f` 的"原像族"之间的关系。

---

# 参考答案与详细解析

**1.**
(a) **是**等价关系。自反：`x−x=0` 是偶数；对称：`x−y` 与 `y−x` 同为偶/奇；传递：偶数 + 偶数仍为偶数。
(b) **不是**。`x·y>0` 不自反：`x=0` 时 `0·0=0 ≯ 0`；也对 `x ≠ 0` 需 `x²>0` 成立，但零元素破坏自反。故不是等价关系。
(c) **是**等价关系。`I_A ⊆ R` 保证自反；`<1,2>` 与 `<2,1>` 成对出现，对称；无需要传递的新组合出错，传递成立。

**2.** 按 `mod 3` 分组：
- `[1]_R = [4]_R = {1,4}`
- `[2]_R = [5]_R = {2,5}`
- `[3]_R = [6]_R = {3,6}`
商集 `A/R = { {1,4}, {2,5}, {3,6} }`。

**3.**
(a) **是**偏序（自反、反对称、传递）。
(b) **不是**（在 `Z` 上）。整除在 `Z` 上**不反对称**：`2∣(−2)` 且 `(−2)∣2`，但 `2 ≠ −2`。==若把 `A` 换成 `Z⁺`（正整数），则是偏序。==
(c) **不是**。真包含 `⊂` **不自反**（`x ⊄ x`），故不是偏序；`⊆` 才是。

**4.** `A = {1,2,3,4,6,8,12,24}`，覆盖关系：
`1⋖2, 1⋖3, 2⋖4, 2⋖6, 3⋖6, 4⋖8, 4⋖12, 6⋖12, 8⋖24, 12⋖24`。

分层：

| 层 | 元素 |
| --- | --- |
| 第 1 层 | `1` |
| 第 2 层 | `2`, `3` |
| 第 3 层 | `4`, `6` |
| 第 4 层 | `8`, `12` |
| 第 5 层 | `24` |

- 极小元：`1`（唯一，也是最小元）。
- 极大元：`24`（唯一，也是最大元）。
（`8` 与 `12` 不可比，同层。）

**5.** 同块即等价，`R` = 各块内部的完全关系：
```
R = ( {1,2,3}×{1,2,3} ) ∪ ( {4,5}×{4,5} ) ∪ ( {6,7,8,9}×{6,7,8,9} )
```
`[4]_R = {4,5}`，`A/R = { {1,2,3}, {4,5}, {6,7,8,9} } = π`。

**6.** 在 `<R, ≤>` 中：
- 上界：所有 `≥ 2` 的实数，即 `[2, +∞)`；`sup B = 2`（最小上界）。
- 下界：所有 `≤ 1` 的实数，即 `(−∞, 1]`；`inf B = 1`。
- `max B`、`min B` 均**不存在**（开区间端点 `1, 2` 不属于 `B`，`B` 中无最大/最小者）。
> 要点：==`sup B`/`inf B` 可以不在 `B` 内；`max B`/`min B` 必须在 `B` 内。==

**7.**
- `<{1,3,9,27}, ∣> **是**全序集：任意两个都能互相整除比较，哈斯图为一条竖线 `1—3—9—27`。
- `<P({a,b}), ⊆>` **不是**全序集：`{a}` 与 `{b}` 不可比。哈斯图：

```
第 2 层（顶）:        {a,b}
                    /      \
第 1 层:         {a}      {b}
                    \      /
第 0 层（底）:         ∅
```

**8.** 证明：
- **唯一性**：设 `b₁, b₂` 都是 `B` 的最大元。因 `b₁` 是最大元且 `b₂∈B`，有 `b₂ ≼ b₁`；因 `b₂` 是最大元且 `b₁∈B`，有 `b₁ ≼ b₂`。由**反对称性**得 `b₁ = b₂`。故最大元唯一。
- **`sup B = max B`**：设 `b = max B`。因 `∀x∈B, x ≼ b`，故 `b` 是 `B` 的一个**上界**。又任何上界 `u` 都满足 `b ≼ u`（因 `b∈B`，上界必须 ≥ B 中所有元素）。故 `b` 是上界中最小的，即 `sup B = b`。∎
> 对偶结论：`min B` 存在时 `inf B = min B`。

**9.** 证明：
- 自反：`f(x) = f(x)`，故 `x ~ x`。
- 对称：`f(x) = f(y) ⟹ f(y) = f(x)`，故对称。
- 传递：`f(x) = f(y)` 且 `f(y) = f(z) ⟹ f(x) = f(z)`。
故 `~` 是等价关系。

商集关系：每个等价类 `[x]_~ = { a∈A | f(a) = f(x) }` 恰是某个像点 `f(x)` 的**原像** `f⁻¹(f(x))`。故 ==`A/~` 就是"把所有落在同一像值的元素合成一堆"得到的划分，块数与 `f` 的值域大小相同。== 这正是"等价关系 = 划分"定理的一个漂亮应用。

## 附一：等价关系 / 偏序关系速查

**等价关系三性质**：自反 ✓、对称 ✓、传递 ✓。记作 `~`。

**等价类与商集**

| 概念 | 记号 | 含义 |
| --- | --- | --- |
| 等价类 | `[x]_R` | `{y ∣ x ~ y}`，非空，且 `x∈[x]_R` |
| 相等判据 | `[x]_R = [y]_R ⟺ x ~ y` | 比较代表元即可 |
| 不相交律 | `[x] ≠ [y] ⟹ [x]∩[y] = ∅` | 类的分裂性 |
| 商集 | `A/R = {[x]_R ∣ x∈A}` | 所有等价类组成的集合 |
| 划分 | `π` | 非空、两两不交、并 = `A` |
| 核心定理 | 等价关系 ⟷ 划分 | 一一对应 |

**哈斯图画法三步**：① 去自环；② 去传递推出的边（只留覆盖关系）；③ 按偏序方向分层摆放。

**六类特殊元素对照**

| 元素 | 在哪个集合里找 | 条件 | 唯一性 | 存在性 |
| --- | --- | --- | --- | --- |
| 最大元 | `B` 内 | 人人 ≤ 它 | 唯一 | 不一定 |
| 最小元 | `B` 内 | 人人 ≥ 它 | 唯一 | 不一定 |
| 极大元 | `B` 内 | B 中无人比它大 | 可多个 | 有限必有 |
| 极小元 | `B` 内 | B 中无人比它小 | 可多个 | 有限必有 |
| 上界 | `A` 内（可出 `B`） | 人人 ≤ 它 | 可多个 | 不一定 |
| 下界 | `A` 内（可出 `B`） | 人人 ≥ 它 | 可多个 | 不一定 |
| 上确界 `sup B` | `A` 内 | 上界中最小者 | 唯一 | 不一定 |
| 下确界 `inf B` | `A` 内 | 下界中最大者 | 唯一 | 不一定 |

**三条必背辨析**

1. ==最大元必是极大元，极大元未必是最大元。==（最大元要求与所有元素可比）
2. ==`B` 中只要出现不可比的一对，最大元与最小元必不存在。==
3. ==`max B` 存在 ⟹ `sup B = max B`；`min B` 存在 ⟹ `inf B = min B`。反向不成立。==

**全序 / 良序**

- 全序 = 偏序 + 任意两元素可比；哈斯图是一条链。
- 良序 = 全序 + 任意非空子集有最小元。`<N, ≤>` 良序，`<Z, ≤>`、`<R, ≤>` 非良序。
