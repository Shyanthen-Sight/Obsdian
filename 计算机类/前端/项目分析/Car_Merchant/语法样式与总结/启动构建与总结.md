# 启动构建与总结

> [!abstract] 一句话
> 开发时 `npm install` → `npm run dev` 即可跑起来；`npm run build` 同时做类型检查和 Vite 构建。全文最后把整个项目概括成一条主线：==`main.ts` 起步 → `App.vue` 导航 + 路由出口 → `Rent_page.vue` 管状态 → 子组件收事件，Vue 自动更新页面==。

---

## 一、如何启动和构建项目

在项目目录下执行：

```powershell
cd C:\Users\Shyanthen\Desktop\Vue\vue_class\homework\Car_Merchant\Car_Merchant
npm install
npm run dev
```

开发服务器启动后，在浏览器打开终端显示的地址，通常是：

```text
http://localhost:5173
```

### 1.1 类型检查和构建

```powershell
npm run type-check
npm run build
```

项目中的 `build` 脚本同时执行类型检查和 Vite 构建：

```json
{
  "scripts": {
    "build": "run-p type-check \"build-only {@}\" --",
    "type-check": "vue-tsc --build",
    "build-only": "vite build"
  }
}
```

### 1.2 代码格式化

```powershell
npm run format
```

### 1.3 代码检查

```powershell
npm run lint
```

## 二、总结

Car Merchant 的核心结构可以概括为：

```text
main.ts
  ↓ 注册 Vue、Router、Pinia
App.vue
  ↓ 公共导航 + 路由出口
router/index.ts
  ↓ 根据 URL 选择页面
Rent_page.vue
  ↓ 管理车辆数据和业务状态
子组件
  ├─ VehicleToolbar：收集筛选条件
  ├─ VehicleGrid：展示并选择车辆
  ├─ AddVehicleModal：收集新车信息
  ├─ DeleteVehicleModal：验证删除操作
  └─ SuccessToast：展示操作结果
```

最重要的数据流原则是：

```text
父组件通过 props 把数据传给子组件
子组件通过 emit 把操作通知父组件
父组件修改状态
Vue 根据响应式状态自动更新页面
```

最重要的 Vue 语法包括：

```text
ref        创建响应式状态
computed   创建派生状态
watch      监听状态变化
v-if       条件渲染
v-for      列表渲染
v-model    表单双向绑定
:prop      动态属性绑定
@event     事件监听
defineProps 接收父组件数据
defineEmits 发出子组件事件
router-view 显示当前路由页面
router.push 程序化跳转路由
```
