## 零、一阶逻辑的符号表

**核心观念**：一阶逻辑 = 命题逻辑 ＋ 个体／谓词／量词。命题逻辑的**一切联结词、永真式、等值式全部保留**，只是"原子命题"被换成了"原子公式"。

| 类别 | 符号 | 说明 |
| :--- | :--- | :--- |
| **个体常元符号** | a, b, c, … | 代表一个确定个体 |
| **个体变元符号** | x, y, z, … | 代表任意个体，可被量词约束 |
| **函数符号** | f, g, h, … | 如 `f(x)` 表示 x 的父亲 |
| **谓词符号** | P, Q, R, … | 一元表性质，n 元表关系 |
| **联结词** | ¬ ∧ ∨ → ↔ | 与命题逻辑**完全相同** |
| **量词符号** | ∀ ∃ | 一阶逻辑新增 |
| **技术符号** | ( ) , | 分组与分隔 |

> **⚠️ 与命题逻辑的关键差别**：一阶逻辑的符号表里**没有"命题变元"**。这里的 `P` 是**谓词符号**而非命题变元（只有 0 元谓词才退化成命题）。
> 因此 C1 里"用真值表判永真"的那套，在一阶逻辑里**不能照搬**（见第八节 8.2）。

## 一、项与原子公式

### 1.1 项（term）

**递归定义**：

1. **个体常元符号**是项；
2. **个体变元符号**是项；
3. 若 `f` 是 n 元函数符号，`t₁, …, tₙ` 是项，则 `f(t₁, …, tₙ)` 是项；
4. 只有有限次应用 1–3 得到的才是项。

**直觉**：==项是"指称个体"的表达式==——它"算出一个东西"，本身**没有真假**。

| 是项 ✔ | 不是项 ✘ |
| :--- | :--- |
| `a`、`x`、`y` | `P(x)`（这是公式，不是项） |
| `f(x)`、`g(a, y)` | `x ∧ y`（∧ 只连接公式） |

### 1.2 原子公式（atomic formula）

若 `P` 是 n 元谓词符号，`t₁, …, tₙ` 是项，则 ==`P(t₁, …, tₙ)` 是原子公式==。

**要点**：原子公式是**最小的完整公式**，不能再拆。0 元谓词（命题）也可看作原子公式。

- ✔ `P(x)`、`Q(a, f(x))`、`R(x, y, z)`
- ✘ `P(x) ∧ Q(y)`（这是复合公式，最高层联结词是 ∧）

## 二、合式公式（谓词公式）

### 2.1 递归定义

1. **原子公式**是合式公式；
2. 若 A 是合式公式，则 `¬A` 是；
3. 若 A、B 是合式公式，则 `(A ∧ B)`、`(A ∨ B)`、`(A → B)`、`(A ↔ B)` 是；
4. 若 A 是合式公式，x 是个体变元，则 `∀xA`、`∃xA` 是；
5. 只有**有限次**应用以上各条得到的符号串才是合式公式。

### 2.2 配套概念

| 概念 | 含义 |
| :--- | :--- |
| **子公式** | 由公式的某一部分构成、且本身合式的公式 |
| **最高层联结词** | 最后一步使用的联结词，决定公式的"主结构" |

**最高层联结词的判定**：从外往里找**最外层的、未被括号包住的**联结词。

- `∀x(P(x) → Q(x))`：无最外层联结词，最高层是**∀x**（量词）
- `P(x) → ∀xQ(x)`：最高层是 **→**
- `¬P(a) ∧ ∃yQ(y)`：最高层是 **∧**
- `¬(P(a) ∧ ∃yQ(y))`：最高层是 **¬**

### 2.3 识别练习

| 符号串               | 是否合式 | 理由                                     |
| :---------------- | :--: | :------------------------------------- |
| `∀x(P(x) → Q(x))` |  ✔   | 标准形式                                   |
| `P(x) ∧ ∃yQ(y)`   |  ✔   | ∧ 两侧都是合式公式                             |
| `∀xP`             | 视约定  | 若 `P` 是 0 元谓词则 ✔；本课程一般要求写 `P(x)` 或空元形式 |
| `x → P(x)`        |  ✘   | `x` 是**项**不是公式，→ 两侧必须都是公式              |
| `∀x ∧ P(x)`       |  ✘   | ∧ 左侧必须是完整公式，`∀x` 后没跟公式                 |
| `P(x, )`          |  ✘   | 谓词的元数与实参个数不符                           |

> **⚠️ 记住**：==**项填槽，公式有真值。**== 凡是"能算出个体"的（a, x, f(x)）都只能放在谓词的槽里，不能直接拿联结词连接。

## 三、辖域、指导变元、约束出现、自由出现

这一节是 [[2.3 一阶逻辑等值式与前束范式]] 换名规则的**全部基础**，必须练到机械正确。

### 3.1 四个定义

| 术语          | 定义                                    |
| :---------- | :------------------------------------ |
| **指导变元**    | 量词后面紧跟的那个个体变元（`∀x`、`∃y` 里的 x、y）       |
| **辖域**（作用域） | 该量词**后面紧邻的那个公式**（有括号则到括号结束）           |
| **约束出现**    | 变元的某次出现，落在**相应指导变元的辖域内**，且与指导变元**同名** |
| **自由出现**    | 不是约束出现的出现                             |

### 3.2 判定流程（三步走）

1. 把公式里**所有量词、指导变元、各自辖域**圈出来；
2. 对**每一个变元的每一次出现**问：它落在这个"同名量词"的辖域内吗？
3. 在 ⇒ **约束出现**；不在 ⇒ **自由出现**。

> **⚠️ 关键**：同一个符号（如 x）在同一个公式里可以**两种身份并存**。

### 3.3 例：`∀x(P(x) → ∃yQ(x, y))`

```
∀x ( P(x) → ∃y Q(x, y) )
│  │        │  │
│  │        │  └── Q(x, y) 是 ∃y 的辖域
│  │        └───── ∀x 的辖域是整个 (P(x) → ∃yQ(x, y))
│  └────────────── 指导变元 x
└───────────────── 指导变元
```

- `P(x)` 的 **x**：在 ∀x 辖域内、与指导变元同名 ⇒ **约束出现**
- `Q(x, y)` 的 **x**：仍在 ∀x 辖域内（∀x 的辖域延伸到整个括号）⇒ **约束出现**
- `Q(x, y)` 的 **y**：在 ∃y 辖域内 ⇒ **约束出现**
- 结论：**全部约束，无自由变元 ⇒ 闭式**

### 3.4 例：`P(x) → ∀xQ(x)`（"同名不同命"）

- 第一个 **x**（在 `P(x)` 里）：不在任何量词辖域内 ⇒ **自由出现**
- 第二个 **x**（在 `∀xQ(x)` 里）：在 ∀x 辖域内 ⇒ **约束出现**

> ==**同名 ≠ 同一个变元。**== 公式里的"自由 x"和"约束 x"是**两个互不相关的对象**——这正是 [[2.3 一阶逻辑等值式与前束范式]] 中换名／代替规则存在的理由。

### 3.5 例：`∃xP(x) ∧ Q(x)`（被 ∧ 截断的辖域）

- ∃x 的辖域**只有 `P(x)`**，∧ 的右支**不被罩住**
- `P(x)` 的 x ⇒ **约束**；`Q(x)` 的 x ⇒ **自由**

> **⚠️**：辖域是"量词后紧邻的**那一个**公式"。这一条最容易被"整行扫描"的眼睛漏掉，也是 2.3 例 5（第 5 题）失分的原因。

### 3.6 易错提醒

| 陷阱 | 说明 |
| :--- | :--- |
| 只看符号、不管辖域 | `∃yQ(x, y)` 里的 x **不一定**约束——要看外层有没有 `∀x`／`∃x` 罩着 |
| 忽略 ∧、∨、→ 截断辖域 | `∃xP(x) ∧ Q(x)`、`∀xP(x) → Q(x)` 中右支都是自由的 |
| 内外层量词同名 | `∀x(P(x) → ∃xQ(x))` 中内层 ∃x 会**遮蔽**外层 ∀x，需谨慎（2.3 要求先换名） |
| 以为括号可随便省 | 省略要按优先顺序 `¬ > ∧ > ∨ > → > ↔`；**拿不准就加括号** |

## 四、闭式

**定义**：==不含自由出现的公式称为**闭式**（封闭公式）。==

| | 闭式 | 含自由变元的公式 |
| :--- | :--- | :--- |
| 真值 | 给定**解释**即有确定真值 | 必须再给**赋值**（指定每个自由变元取哪个个体） |
| 例 | `∀x∃yP(x, y)`、`P(a) ∧ ∀xQ(x)` | `P(x)`、`P(x) → ∀xQ(x)` |

**注意**：个体**常元**不影响封闭性——`P(a)` 里 a 是常元，`P(a) ∧ ∀xQ(x)` 仍是**闭式**。

**闭包（把非闭式变成闭式）**：

- **全称闭包**：把每个自由变元用 ∀ 量词加在前面（`P(x)` → `∀xP(x)`）
- **存在闭包**：用 ∃ 加（`P(x)` → `∃xP(x)`）

> **考试提醒**：判"永真式／矛盾式"时，题目给的公式**通常是闭式**；若含自由变元，要先想清楚它说的是"对所有赋值都成立"还是"存在赋值成立"。

## 五、两个改名技巧：换名与代替

本节只讲"**是什么**"；"**怎么用**"在 [[2.3 一阶逻辑等值式与前束范式]] 第五节（三条规则）与求前束范式时反复练。

### 5.1 换名规则（约束变元改名）

**内容**：把某量词辖域内某一**约束出现**的个体变元，连同该量词的**指导变元**一起，换成**该辖域内未曾出现过**的个体变元符号，其余部分不变 ⇒ 所得公式与原公式**等值**。

**三条操作要点**：

1. 指导变元**和**辖域内的同名约束出现**必须同时改**；
2. **新名不能在该量词辖域内出现过**（否则造成**变元捕获**）；
3. **自由出现不动**。

**例**：`∀x(P(x) ∧ ∃xQ(x))` ⇒ 把内层 ∃x 改名 ⇒ `∀x(P(x) ∧ ∃yQ(y))` ✔

> ⚠️ 注意 `Q` 是**一元**的，不能写成 `∃yQ(x, y)`；新名 y 在内层辖域内未出现 ✔

### 5.2 代替规则（自由变元代替）

**内容**：把公式中某个**自由出现**的个体变元，用公式中**未曾出现过**的个体变元符号**处处**代替 ⇒ 所得公式与原公式**等值**。

**例**：`P(x) → ∀xQ(x)` 中，第一个 x 自由、第二个 x 约束。用 z 代替**自由出现**的 x ⇒ `P(z) → ∀xQ(x)` ✔（仍等值）

### 5.3 一句话对比

> ==**换名动约束（指导变元 + 辖域内同名出现一起改）；代替动自由（处处改）；两者的新名字都必须"没见过"。**==

### 5.4 ⚠️ 为什么必须换名（2.3 的伏笔）

```
∃xF(x) ∨ ∀xG(x)        两个量词指导变元同名，但辖域各自独立
```

若不换名直接合并，写成 `∃x(F(x) ∨ ∀xG(x))`，内层 ∀x 与外层 ∃x **同名却不同辖域**，公式含义已说不清。
正确做法是两个量词**各换一个名**（如 `∃uF(u) ∨ ∀vG(v)`）再处理。

更隐蔽的是"自由变元被捕获"：

```
∀xF(x, y) ∨ ∃yG(x, y)      y 在 F(x,y) 中自由，又撞上 ∃y
```

直接合并会写成 `∀x∃y(F(x, y) ∨ G(x, y))`——**F 里的自由 y 被 ∃y 抓走了**，含义被破坏。
⇒ 必须先把 `∃yG(x, y)` 换成 `∃zG(x, z)`。

> 这就是 [[2.3 一阶逻辑等值式与前束范式]] 反复强调"**求前束范式第 3 步必须先换名**"的根本原因。

## 六、解释 I

### 6.1 定义

**解释（赋值）I** 由四部分构成，其中 D 是**非空**个体域：

==I = ( D,  个体常元的指派,  函数符号的指派,  谓词符号的指派 )==

| 成分 | 内容 |
| :--- | :--- |
| **个体域 D** | 非空集合，变元的一切取值来源 |
| **常元指派** | 每个常元 a ↦ D 中一个元素 ā |
| **函数指派** | 每个 n 元函数符号 f ↦ 一个具体函数 Dⁿ → D |
| **谓词指派** | 每个 n 元谓词符号 P ↦ Dⁿ 上的一个具体**关系** |

> **⚠️ 解释必须给全**：常元、函数、谓词**一个都不能漏**。漏掉谓词的指派就没法算真值。

### 6.2 完整示例

**解释 I**：D = {1, 2, 3}；a = 1；`P(x)`："x 是奇数"；`Q(x, y)`："x < y"。

**先把谓词具化成真值表**：

```
P(1) = 1    P(2) = 0    P(3) = 1

Q(x, y)：x < y
         y=1  y=2  y=3
  x=1  [  0    1    1  ]
  x=2  [  0    0    1  ]
  x=3  [  0    0    0  ]
```

**求 `∀x(P(x) → ∃yQ(y, x))` 在 I 下的真值**：

- x = 1：P(1) = 1；`∃yQ(y, 1)` = "存在 y < 1" ⇒ y=1,2,3 全为 0 ⇒ **假**
  ⇒ 蕴含式 **1 → 0 = 假** ✘
- x = 2：P(2) = 0 ⇒ 蕴含式 **0 → … = 真** ✔
- x = 3：P(3) = 1；`∃yQ(y, 3)` = "存在 y < 3" ⇒ y = 1 满足 ⇒ **真**
  ⇒ 蕴含式 **1 → 1 = 真** ✔

有一个个体使公式为假 ⇒ **整个公式在 I 下为假**。

### 6.3 同一公式，换个解释真值就变

考虑 `∃x∀yQ(x, y)`（"存在一个最大的数"，`Q(x, y)`：x ≥ y）：

| 解释 | 个体域 D | 真值 | 原因 |
| :--- | :--- | :-: | :--- |
| I₁ | {1, 2, 3} | **真** | 3 ≥ 一切 |
| I₂ | 自然数集 N | **假** | 无最大自然数 |

> ==**个体域和谓词一换，真值可能整个翻过来。**== 这就是 2.1 第三节说"个体域不同真值可能完全不同"的落地示例。

### 6.4 赋值 σ

**赋值 σ**：对公式中**所有自由变元**指定 D 中元素。记 `(I, σ)` 为"解释 + 赋值"。

| 公式 | 需要什么才能谈真值 |
| :--- | :--- |
| 闭式（如 `∀x∃yP(x, y)`） | 只需**解释 I** |
| 含自由变元（如 `P(x)`） | **I 和 σ 都要给** |

> **记忆**：==**I 解释"符号的含义"（D、函数、谓词）；σ 只解决"自由变元取哪个个体"。**==

## 七、真值的递归计算

**思路**：一阶公式的真值是**由里往外**递归定义的。

1. **原子公式** `P(t₁, …, tₙ)`：先把每个项在 `(I, σ)` 下算成 D 中元素，再看这个 n 元组是否属于 P 所指派的**关系**。
2. **¬ ∧ ∨ → ↔**：与命题逻辑**完全相同的真值表**。
3. **量词**：
   - `∀xA(x)` 为真 ⟺ 对 D 中**每一个** d，`A(d)`（把 x 指派为 d）为真；
   - `∃xA(x)` 为真 ⟺ D 中**存在**某个 d 使 `A(d)` 为真。

**计算示例**：I：D = {1, 2}，P(1) = 1, P(2) = 0；Q(1,1) = 1, Q(1,2) = 0, Q(2,1) = 0, Q(2,2) = 1。求 `∃x(P(x) ∧ Q(x, x))`。

```
x = 1：P(1) ∧ Q(1,1) = 1 ∧ 1 = 1     ✔
x = 2：P(2) ∧ Q(2,2) = 0 ∧ 1 = 0
⇒ ∃x 找到至少一个真 ⇒ 公式为 真
```

> **有限域技巧**：D 有限时，`∀` 展开为 ∧ 连乘、`∃` 展开为 ∨ 连加，公式**退化为命题公式**，真值表与等值演算照用（见 [[2.1一阶逻辑基本概念]] 第三节"有限域桥"）。

## 八、公式的类型

### 8.1 三种类型

| 类型 | 别称 | 定义 | 例 |
| :--- | :--- | :--- | :--- |
| **永真式** | 逻辑有效式 | 在**一切解释**和**一切赋值**下都为真 | `∀xP(x) → ∃xP(x)` |
| **矛盾式** | 不可满足式 | 在一切解释和一切赋值下都为假 | `∀xP(x) ∧ ∃x¬P(x)` |
| **可满足式** | —— | **存在**某个解释和赋值使它为真 | `∃xP(x)`、`∀xP(x)` 都算 |

**三者关系**：

```
永真式   ⊂   可满足式          （永真式一定可满足）
矛盾式   ∩   可满足式 = ∅      （矛盾式必不可满足）

¬A 永真  ⟺  A 矛盾
A 永真   ⇒   A 可满足（反之不然）
```

**有限域判定法**：取 D 为有限集合（常用 D = {1, 2}），用 ∧／∨ 展开 ⇒ 得到命题公式 ⇒ 真值表或等值演算。

**⚠️ 不可判定性**：==一阶逻辑公式的永真性是**不可判定**的==（Church–Turing 定理）——**不存在**一个算法，能对任意一阶公式都在有限步内判定它是否永真。相比之下命题逻辑可用真值表机械判定，这是根本性的升级。

> **考场上怎么办**：
> ① **限域枚举**——D 取 {1, 2} 逐一展开（最常用）；
> ② **半可判定**——若它真是永真式，用等值演算／证明**总能找到**一个证明；
> ③ 判"**不是**永真式"只需**构造一个反例解释**。

### 8.2 ⭐ 代换实例：两个方向的差别

**定理**：==命题逻辑的每个**重言式**，把命题变元代换成一阶公式后，所得都是**一阶永真式**。==

**但反之不成立**：

```
∀xP(x) → ∃xP(x)        一阶永真，却不是任何重言式的代换实例
```

**为什么**：它的永真性依赖"**个体域非空**"这一**一阶特有**事实——命题逻辑里没有"非空论域"这个结构，自然没有对应重言式。

> **记忆**：==**重言式的代换实例 ⊂ 一阶永真式**，包含是**严格**的。==
> 推论：**用真值表"证明"一阶永真式是不可靠的**——真值表只能在**有限、已确定的解释**下算真值，不能替代"对任意解释成立"的证明。

### 8.3 与 2.3 的衔接

**等值式与永真式的关系**：

```
A ⇔ B   ⟺   A ↔ B 是永真式（逻辑有效式）
```

一阶逻辑的 `⇔` 比命题逻辑的 `⇔` 要求**更强**：不只要在一切**赋值**下真，还要在**一切个体域、一切解释**下真。
这正是 [[2.3 一阶逻辑等值式与前束范式]] 反复强调"**B 中不含被移出的变元 x**"的根本原因——稍微违反，换一个解释就破功。

## 九、易错点速查表

| 易错点 | 正解 |
| :--- | :--- |
| 把一阶逻辑的 `P` 当命题变元 | `P` 是**谓词符号**；一阶逻辑符号表**不含命题变元** |
| 项与公式混用 | 项"指称个体"（a, x, f(x)）；公式"有真值"（P(x), A∧B）。`x → P(x)` 不是合式公式 |
| 判约束／自由时只看符号不圈辖域 | 必须**逐个量词圈辖域**再逐次出现判定 |
| 漏掉与、或、蕴含截断辖域 | `∃xP(x) ∧ Q(x)` 中右支自由；`∀xP(x) → Q(x)` 中 `Q(x)` 自由 |
| 认为同一符号就是同一变元 | 同名可变身份：`P(x) → ∀xQ(x)` 中前后两个 x 互不相干 |
| 换名只改指导变元 | 指导变元**和**辖域内同名约束出现要**同时改** |
| 换名／代替的新名乱取 | 新名必须在相应范围内**未出现过**，否则**变元捕获** |
| 忽略个体域非空 | `∀xP(x) → ∃xP(x)` 的永真性完全依赖 **D ≠ ∅** |
| 解释没给全 | I 必须给全**常元、函数、谓词**的指派 |
| 闭式与含自由变元公式混谈 | 闭式给解释即定真值；含自由变元还要给**赋值 σ** |
| 用真值表证明一阶永真式 | 一阶永真性**不可判定**；真值表只能在**有限确定的解释**下算真值 |
| 以为"重言式代换实例"就是全部永真式 | 严格包含：`∀xP(x) → ∃xP(x)` 就不是代换实例 |
| 把"可满足"当"永真" | 可满足只要求**存在**解释使其真；永真要求**一切**解释下真 |

## 十、练习题

### 第 1 题 🟢
指出下列公式中量词的指导变元、辖域，并指出各变元是**约束出现**还是**自由出现**：

(1) `∀x(P(x) → Q(x))`
(2) `∃xP(x) ∧ Q(x)`
(3) `∀x(P(x) → ∃yQ(x, y))`
(4) `∀xP(x, y) ∨ ∃yQ(y)`

(1) `P(a)`
(2) `∀xP(x)`
(3) `∃xQ(x, a)`
(4) `∀x(P(x) → ∃yQ(y, x))`

### 第 4 题 🟡
用换名规则或代替规则，把下列公式化为"变元不重名"的**等值**公式：

(1) `∀x(P(x) ∧ ∃xQ(x))`
(2) `P(x) → ∀xQ(x)`
(3) `∀xF(x, y) ∨ ∃yG(x, y)`

### 第 5 题 🟡

### 第 6 题 🔴

判断 `∃x∀yQ(x, y) → ∀y∃xQ(x, y)` 是否为一阶永真式。若是，给出证明；若否，给出反例解释。

# 参考答案与详细解析

## 第 1 题

**(1) `∀x(P(x) → Q(x))`**

- 指导变元：**x**；辖域：整个 `(P(x) → Q(x))`
- `P(x)`、`Q(x)` 中的 x 都在辖域内 ⇒ **全部约束出现**，无自由变元（**是闭式**）

**(2) `∃xP(x) ∧ Q(x)`**

- 指导变元：**x**；辖域：**只有 `P(x)`**（∧ 的右支**不在**辖域内！）
- `P(x)` 的 x ⇒ **约束出现**
- `Q(x)` 的 x ⇒ **自由出现**　←　本题考点

**解析**：辖域是"量词后紧邻的**那一个**公式"。同一个 x 在这里**半边约束、半边自由**。

**(3) `∀x(P(x) → ∃yQ(x, y))`**

- ∀x：指导变元 x，辖域 `(P(x) → ∃yQ(x, y))`
- ∃y：指导变元 y，辖域 `Q(x, y)`
- `P(x)` 的 x：在 ∀x 辖域内 ⇒ **约束**
- `Q(x, y)` 的 x：在 ∀x 辖域内（虽不在 ∃y 辖域内）⇒ **约束**
- `Q(x, y)` 的 y：在 ∃y 辖域内 ⇒ **约束**
- ⇒ **全部约束，无自由变元（闭式）**

**(4) `∀xP(x, y) ∨ ∃yQ(y)`**

- ∀x：指导变元 x，辖域 `P(x, y)`
- ∃y：指导变元 y，辖域 `Q(y)`
- `P(x, y)` 的 **x**：在 ∀x 辖域内 ⇒ **约束**
- `P(x, y)` 的 **y**：**不在**任何量词辖域内（∀x 只管 x；∃y 的辖域只有 `Q(y)`）⇒ **自由出现**
- `Q(y)` 的 y：在 ∃y 辖域内 ⇒ **约束**
- ⇒ **y 既有自由出现又有约束出现**——这正是 [[2.3 一阶逻辑等值式与前束范式]] 例 4 必须先换名的原因。

---

## 第 2 题

**(1)** `∀x∃yP(x, y)` ⇒ **是闭式**（x、y 都被约束）。

**(2)** `∀xP(x) → Q(x)` ⇒ **不是**。∀x 的辖域只有 `P(x)`，`Q(x)` 里的 x **自由**。

**(3)** `P(a) ∧ ∀xQ(x)` ⇒ **是闭式**。`a` 是**个体常元**不是变元；x 被 ∀x 约束。==常元不影响封闭性。==

---

## 第 3 题

**先把解释具化**：

- D = {1, 2, 3}，a = 1
- `P(x)`（x 是奇数）：P(1) = 1，P(2) = 0，P(3) = 1
- `Q(x, y)`（x < y）：

```
         y=1  y=2  y=3
  x=1  [  0    1    1  ]
  x=2  [  0    0    1  ]
  x=3  [  0    0    0  ]
```

**(1)** `P(a)` = P(1) = **真**

**(2)** `∀xP(x)`：P(1) = 1 ✔、P(2) = 0 ✘ ⇒ **假**

**(3)** `∃xQ(x, a)` = `∃xQ(x, 1)` = "存在 x < 1"：x=1,2,3 全为 0 ⇒ **假**

**(4)** `∀x(P(x) → ∃yQ(y, x))`：

- x = 1：P(1) = 1；`∃yQ(y, 1)` = "存在 y < 1" ⇒ 全 0 ⇒ **假** ⇒ 蕴含 **0** ✘
- x = 2：P(2) = 0 ⇒ 蕴含 **1** ✔
- x = 3：P(3) = 1；`∃yQ(y, 3)` = "存在 y < 3" ⇒ y = 1 满足 ⇒ **真** ⇒ 蕴含 **1** ✔

**一处为假 ⇒ 公式在 I 下为假。**

**解析**：`∀` 展开为 ∧，==只要**有一个个体**让公式为假，∀ 整句就假==。

---

## 第 4 题

**(1) `∀x(P(x) ∧ ∃xQ(x))`**

内层 ∃x 与外层 ∀x **同名但辖域不同**。把**内层**改名（新名 y 须在内层辖域内未出现）：

```
⇔ ∀x(P(x) ∧ ∃yQ(y))                        （换名规则）
```

**答案**：`∀x(P(x) ∧ ∃yQ(y))`

> ⚠️ `Q` 是**一元**的，不能写成 `∃yQ(x, y)`。

**(2) `P(x) → ∀xQ(x)`**

第一个 x **自由**，第二个 x **约束**。用**代替规则**：把自由出现的 x 用公式中未出现的 z 处处代替：

```
⇔ P(z) → ∀xQ(x)                             （代替规则）
```

**答案**：`P(z) → ∀xQ(x)`（与原式等值）

**(3) `∀xF(x, y) ∨ ∃yG(x, y)`**

`y` 在 `F(x, y)` 中是**自由出现**，又撞上 `∃y` 的指导变元 ⇒ 必须把 **∃y 换名**为 z（z 在 `G(x, y)` 内未出现）：

```
⇔ ∀xF(x, y) ∨ ∃zG(x, z)                     （换名规则）
```

**答案**：`∀xF(x, y) ∨ ∃zG(x, z)`

**解析**：若不换名就直接做辖域扩张，会得到 `∀x∃y(F(x, y) ∨ G(x, y))`，**F 里的自由 y 被 ∃y 捕获了**，含义被破坏。这就是 [[2.3 一阶逻辑等值式与前束范式]] 例 4 的第一步。

---

## 第 5 题

**公式**：`∀xP(x) → ∃xP(x)`

**为什么永真**：设任意解释 I，**个体域 D ≠ ∅**。

- **情形一**：`∀xP(x)` 在 I 下为**假** ⇒ 蕴含式前件假 ⇒ 整式为**真**；
- **情形二**：`∀xP(x)` 在 I 下为**真** ⇒ D 中每个 d 都使 P(d) 真。取 D 中**任一**元素 d₀（==D 非空保证取得到==），则 P(d₀) 真 ⇒ `∃xP(x)` 真 ⇒ 后件真 ⇒ 整式为**真**。

两种情形都为真 ⇒ **永真式** ✔

**是否重言式的代换实例**：**不是**。

它的形式是 `A → B`，而 A、B **不同**（`∀xP(x)` 与 `∃xP(x)`）；重言式里没有"同一个谓词分别经 ∀、∃ 得到的两个公式必然满足 A ⇒ B"这样的结构。它之所以真，靠的是"**个体域非空**"这一**一阶逻辑特有**的事实。

> **结论**：==重言式的代换实例 ⊂ 一阶永真式==，本题给出严格包含的具体反例。

---

## 第 6 题

取 D = {1, 2}，令 `P(1) = 1, P(2) = 0`；`Q(1) = 0, Q(2) = 1`。

- `∃xP(x)`：P(1) = 1 ⇒ **真**
- `∃xQ(x)`：Q(2) = 1 ⇒ **真**
- ⇒ 前提（合取）= **真**
- `∃x(P(x) ∧ Q(x))`：x=1 得 1∧0 = 0；x=2 得 0∧1 = 0 ⇒ **假**

⇒ 存在解释使**前提真、结论假**，**不能推出** ✔

**解析**：这正是 [[2.3 一阶逻辑等值式与前束范式]] 3.3 节"∃ 对 ∧ **不分配**"的反例，只是换了个出场方式。==`∃x(P∧Q) ⇒ ∃xP ∧ ∃xQ`，反之不成立。==

---

## 第 7 题

**答：是一直永真式** ✔

**证明**：设任意解释 I，假设 `∃x∀yQ(x, y)` 在 I 下为**真**。
则存在 d₀ ∈ D，使**对所有** y ∈ D 都有 `Q(d₀, y)` 为真。

现任取 y ∈ D，取 x = d₀，则 `Q(d₀, y)` 为真 ⇒ 对**每个** y 都存在这样的 x ⇒ `∀y∃xQ(x, y)` 为**真**。

故 `∃x∀yQ(x, y) → ∀y∃xQ(x, y)` 在 I 下为真。I 任意 ⇒ **永真式** ✔

**反向不成立**（`∀y∃xQ(x, y) → ∃x∀yQ(x, y)` **不是**永真式）：

取 D = 自然数集 N，`Q(x, y)`：x > y。

- `∀y∃xQ(x, y)`：对每个自然数 y，存在更大的 x（N 无上界）⇒ **真**
- `∃x∀yQ(x, y)`：需存在一个自然数 x 大于**所有**自然数 ⇒ **假**

⇒ 前件真而结论假，**反向不成立** ✔

**解析**：这叫==**量词顺序的单调性**：`∃∀ ⇒ ∀∃`==。"有一个 x 通吃所有 y"当然能推出"每个 y 各自都有合适的 x"。这正是 [[2.3 一阶逻辑等值式与前束范式]] 3.4 节的量词顺序等值式。

## 附一：本篇核心定义一览

**语法部分**

- **符号表**：常元、变元、函数、谓词、联结词、量词、技术符号（**不含命题变元**）
- **项**：常元／变元是项；`f(t₁,…,tₙ)` 是项
- **原子公式**：`P(t₁,…,tₙ)`
- **合式公式**：5 条递归定义
- **四个语法概念**：指导变元、辖域、约束出现、自由出现
- **闭式**：无自由出现的公式

**语义部分**

- **解释 I**：`I = (D, 常元指派, 函数指派, 谓词指派)`，**D ≠ ∅**
- **赋值 σ**：给**自由变元**指定 D 中元素
- **真值递归**：原子公式 → 联结词（同命题逻辑）→ 量词（∀ 全查、∃ 抽查）
- **公式类型**：永真式（逻辑有效式）／矛盾式（不可满足式）／可满足式

**重要定理**

- 命题逻辑**重言式的代换实例**都是一阶永真式（**反之不然**）
- 一阶逻辑的永真性**不可判定**（半可判定）
- `A ⇔ B ⟺ A ↔ B 永真`

**两条改名规则（本节只作陈述，用法见 2.3 第五节）**

- **换名规则**：动**约束**变元（指导变元 + 辖域内同名出现一起改），新名须**该辖域内未出现**
- **代替规则**：动**自由**变元（处处替换），新名须**公式中未出现**

## 附二：易混概念对照

| 容易混的一对 | 区别 |
| :--- | :--- |
| **项 vs 公式** | 项"指称个体"（a, x, f(x)）；公式"有真值"（P(x), A∧B） |
| **原子公式 vs 合式公式** | 原子公式是最小的合式公式；合式公式 = 原子公式 + 联结词／量词递归生成 |
| **指导变元 vs 约束出现** | 指导变元是量词后那**一个**符号；约束出现是变元**每一次**落在辖域内的出现 |
| **约束出现 vs 自由出现** | 看是否落在"**同名**量词"的辖域内——同名也可能一个约束一个自由 |
| **闭式 vs 含自由变元的公式** | 前者给**解释**即定真值；后者还要给**赋值 σ** |
| **换名 vs 代替** | 换名动**约束**变元（连同指导变元，辖域内改）；代替动**自由**变元（处处改）。共同点：新名必须"没见过" |
| **解释 I vs 赋值 σ** | I 解释"**符号的含义**"（D、函数、谓词）；σ 只解决"**自由变元取哪个个体**" |
| **永真式 vs 重言式** | 重言式是命题逻辑概念（真值表全 1）；一阶永真式要求**一切解释**下真。==重言式代换实例 ⊂ 一阶永真式（严格）== |
| **可满足 vs 永真** | 可满足只要求"**存在**"解释使其真；永真要求"**一切**"解释下真 |
| **有限域判定 vs 一般判定** | 有限域可展开为命题公式、**可判定**；一般一阶逻辑**不可判定** |
| **常元 vs 变元（对封闭性的影响）** | 常元**不影响**闭式性（`P(a)` 是闭式）；自由变元会破坏闭式性 |
