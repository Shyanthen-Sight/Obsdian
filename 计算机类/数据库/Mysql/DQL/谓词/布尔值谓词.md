# 布尔值谓词 —— `IS TRUE` / `IS FALSE` / `IS UNKNOWN`

> [!abstract] 一句话
> `IS TRUE`、`IS FALSE`、`IS UNKNOWN` 用来==**显式判断一个表达式的逻辑值**==，结果永远是 `TRUE` 或 `FALSE`，不会返回 `UNKNOWN`。
> 它们和 `= TRUE` 的关键区别：==**`NULL = TRUE` 是 UNKNOWN，而 `NULL IS TRUE` 是 FALSE**==。

> [!info] 与其它笔记的分工
> 逻辑组合见 [[逻辑谓词]]；判空见 [[空值谓词]]；`<=>` 见 [[安全等于]]。
> 本篇讲布尔测试谓词的语义、真值表、与 `= TRUE` 的区别和实用场景。

---

## 一、语法

```sql
expr IS TRUE
expr IS NOT TRUE
expr IS FALSE
expr IS NOT FALSE
expr IS UNKNOWN
expr IS NOT UNKNOWN
```

```sql
SELECT (1 = 1) IS TRUE;       -- 1
SELECT (1 = 2) IS FALSE;      -- 1
SELECT (NULL = 1) IS UNKNOWN; -- 1
SELECT (NULL = 1) IS NULL;    -- 1（UNKNOWN 在 MySQL 里就是 NULL）
```

> [!note] `IS UNKNOWN` 与 `IS NULL`
> 对布尔表达式来说，`IS UNKNOWN` 和 `IS NULL` 是等价的：
> ```sql
> SELECT (NULL = 1) IS UNKNOWN;  -- 1
> SELECT (NULL = 1) IS NULL;     -- 1
> ```
> `IS UNKNOWN` 语义更贴合三值逻辑；`IS NULL` 更通用。

---

## 二、真值表

设 `expr` 的逻辑值有三种：

| `expr` 的值 | `IS TRUE` | `IS NOT TRUE` | `IS FALSE` | `IS NOT FALSE` | `IS UNKNOWN` | `IS NOT UNKNOWN` |
| --- | --- | --- | --- | --- | --- | --- |
| TRUE | **TRUE** | FALSE | FALSE | TRUE | FALSE | TRUE |
| FALSE | FALSE | **TRUE** | **TRUE** | FALSE | FALSE | TRUE |
| UNKNOWN | FALSE | **TRUE** | FALSE | **TRUE** | **TRUE** | FALSE |

> [!important] 三条最常用的结论
> 1. `NULL IS TRUE` → **FALSE**（不是 UNKNOWN）；
> 2. `NULL IS NOT TRUE` → **TRUE**；
> 3. `NULL IS UNKNOWN` → **TRUE**。

---

## 三、和 `= TRUE` 的根本区别

```sql
-- expr 为 NULL 时
SELECT NULL = TRUE;        -- NULL（UNKNOWN）
SELECT NULL IS TRUE;       -- 0（FALSE）
SELECT NULL IS NOT TRUE;   -- 1（TRUE）
```

| 表达式 | `expr = TRUE` | `expr IS TRUE` |
| --- | --- | --- |
| `expr = TRUE` | TRUE | TRUE |
| `expr = FALSE` | FALSE | FALSE |
| `expr = UNKNOWN` | **UNKNOWN** | **FALSE** |
| 在 `WHERE` 中 | UNKNOWN 行被丢弃 | FALSE 行被丢弃，结果确定 |

> [!danger] `WHERE (col = 1) = TRUE` 和 `WHERE col = 1` 一样，都丢 NULL
> 因为 `NULL = 1` 得 UNKNOWN，`UNKNOWN = TRUE` 仍得 UNKNOWN。
> 想让 NULL 行"明确地不通过"而不是"未知"，用 `IS TRUE`：
> ```sql
> WHERE (col = 1) IS TRUE
> ```
> 但注意：这**不会**把 NULL 行变成通过，只是把 UNKNOWN 变成 FALSE。结果集通常一样，区别在语义和后续组合。

---

## 四、什么时候真的需要它

### 4.1 明确区分"假"和"未知"

```sql
-- 统计：条件为真 / 为假 / 未知 各多少行
SELECT
    SUM((score >= 60) IS TRUE)    AS pass_cnt,
    SUM((score >= 60) IS FALSE)   AS fail_cnt,
    SUM((score >= 60) IS UNKNOWN) AS unknown_cnt
FROM exam;
```

如果写 `SUM(score >= 60)`，UNKNOWN 会被 `SUM` 忽略，你只得到"通过数"；写 `COUNT(*) - ...` 才能推出未知数。
用 `IS TRUE/FALSE/UNKNOWN` 可以把三类**显式拆开**。

### 4.2 在 `CASE` 里处理三值

```sql
SELECT
    CASE
        WHEN (score >= 60) IS TRUE    THEN '及格'
        WHEN (score >= 60) IS FALSE   THEN '不及格'
        WHEN (score >= 60) IS UNKNOWN THEN '缺考'
    END AS result
FROM exam;
```

> [!tip] 这是 `CASE` 里最稳的三值分支写法
> `CASE WHEN score >= 60 THEN ... WHEN score < 60 THEN ... ELSE ... END` 也能工作，但 `IS TRUE/FALSE/UNKNOWN` 把"未知"显式写出来，意图更清楚。

### 4.3 布尔列/表达式的可读性

```sql
-- is_active 是 TINYINT(1)，可能有 NULL
SELECT * FROM user WHERE is_active IS TRUE;
-- 只取明确为 1 的行；NULL 和 0 都不取
```

对比：

```sql
SELECT * FROM user WHERE is_active = 1;   -- NULL 行被 UNKNOWN 丢弃，结果一样
SELECT * FROM user WHERE is_active;       -- 只取非 0 非 NULL
```

> [!note] 结果可能一样，语义不同
> `is_active = 1` 和 `is_active IS TRUE` 在 `WHERE` 里结果通常相同。
> 但如果你在 `SELECT` 里输出、或在 `CASE` 里组合，`IS TRUE` 的"永不 UNKNOWN"更有优势。

---

## 五、`IS FALSE` 与 `NOT`

```sql
-- 这两条不一样
WHERE NOT (col = 1)      -- col 为 NULL 时：UNKNOWN → 行被丢弃
WHERE (col = 1) IS FALSE -- col 为 NULL 时：FALSE → 行被丢弃（结果一样）
```

结果集通常一样，因为两者最终都只保留"明确不满足"的行。但语义上：

- `NOT (col = 1)`：否定一个可能未知的条件；
- `(col = 1) IS FALSE`：明确断言"这个条件为假"。

> [!warning] 不要以为 `IS FALSE` 能捞回 NULL 行
> NULL 行的条件是 UNKNOWN，不是 FALSE。`IS FALSE` 对 UNKNOWN 返回 FALSE，所以 NULL 行仍然不通过。
> 要包含 NULL 行，必须显式 `OR col IS NULL`。

---

## 六、与 `IS NULL` 的选择

| 需求 | 写法 |
| --- | --- |
| 判断列是否为 NULL | `col IS NULL` |
| 判断布尔表达式是否为 UNKNOWN | `expr IS UNKNOWN` |
| 判断布尔表达式是否为 TRUE | `expr IS TRUE` |
| 判断布尔表达式是否为 FALSE | `expr IS FALSE` |
| 判断"非 NULL" | `col IS NOT NULL` |
| 判断"非 UNKNOWN" | `expr IS NOT UNKNOWN` |

```sql
-- 对布尔表达式，这两条等价
WHERE (a > b) IS UNKNOWN
WHERE (a > b) IS NULL

-- 对普通列，用 IS NULL 更自然
WHERE name IS NULL
```

> [!tip] 可读性优先
> 普通列判空 → `IS NULL`。
> 布尔表达式三值分支 → `IS TRUE` / `IS FALSE` / `IS UNKNOWN`。

---

## 七、常见错误合集

> [!failure] 以为 `NULL IS TRUE` 是 UNKNOWN
> 它是 **FALSE**。布尔测试谓词永远返回 TRUE/FALSE。

> [!failure] 以为 `IS FALSE` 能查出不满足含 NULL 条件的行
> NULL 行是 UNKNOWN，不是 FALSE。仍然不通过。

> [!failure] 用 `= TRUE` 判断布尔表达式
> 遇到 NULL 会得 UNKNOWN，被 `WHERE` 丢弃。需要明确三值时用 `IS TRUE`。

> [!failure] 把 `IS UNKNOWN` 用在普通列上
> `name IS UNKNOWN` 语法上可跑（等价 `name IS NULL`），但语义别扭。普通列用 `IS NULL`。

> [!failure] 在 `CASE` 里漏掉 UNKNOWN 分支
> 没有 `ELSE` 时，UNKNOWN 会落到 `ELSE NULL`，结果可能不符合预期。显式写 `IS UNKNOWN` 分支。

---

## 八、速查表

| 需求 | 写法 |
| --- | --- |
| 表达式明确为真 | `expr IS TRUE` |
| 表达式明确为假 | `expr IS FALSE` |
| 表达式为未知 | `expr IS UNKNOWN` |
| 表达式不为真（含未知） | `expr IS NOT TRUE` |
| 表达式不为假（含未知） | `expr IS NOT FALSE` |
| 表达式不为未知 | `expr IS NOT UNKNOWN` |
| 普通列判空 | `col IS NULL` |
| 三值统计 | `SUM(expr IS TRUE)` 等 |
