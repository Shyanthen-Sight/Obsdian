```sql
select 列，列，函数
from 表名
[where condition] 
[order by 排序列1 asc|desc，排序列2 asc|desc]
```

asc是升序（默认值），desc是降序

若满足多种排序条件，先满足排序1，再满足排序2


```sql
SELECT * FROM employee ORDER BY salary DESC;
```
