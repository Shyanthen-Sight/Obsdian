## 一、前置概念：从简单式到范式

**约定**：以下始终设命题公式中共有 n 个命题变元，并**按固定顺序**排列，如 p, q, r。

| 概念             | 定义                  | 举例（n = 3）           |
| :------------- | :------------------ | :------------------ |
| **文字**         | 命题变元本身或其否定          | p、¬q                |
| **简单合取式**（短语）  | 有限个文字的**合取**        | ¬p ∧ q ∧ r          |
| **简单析取式**（子句）  | 有限个文字的**析取**        | ¬p ∨ q ∨ r          |
| **析取范式 (DNF)** | ==有限个简单合取式的**析取**== | (¬p ∧ q) ∨ (p ∧ ¬r) |
| **合取范式 (CNF)** | ==有限个简单析取式的**合取**== | (¬p ∨ q) ∧ (p ∨ ¬r) |

**两个容易混的点**：

1. **范式不是唯一的**。p ∨ q 和 (p ∧ q) ∨ (p ∧ ¬q) ∨ (¬p ∧ q) 都是析取范式且互相等值——所以要引入"主"范式来保证唯一。
2. **范式 ≠ 主范式**。上面表格里的 DNF / CNF 只要求"是简单式的析取 / 合取"，**不要求**每个简单式里把变元补全。==主范式则要求每个简单式都是极小项 / 极大项（即**变元必须补齐**）。==

## 二、极小项与极大项

### 2.1 定义

- **极小项（布尔合取式）**：n 个变元的某个==**简单合取式**==中，若==**每个变元与其否定不同时出现**，且**二者之一必出现且仅出现一次**==，则称该式为极小项，记作 mᵢ。
- **极大项（布尔析取式）**：n 个变元的某个==**简单析取式**==中，若==每个变元与其否定不同时出现，且二者之一必出现且仅出现一次==，则称该式为极大项，记作 Mᵢ。

由定义立刻可知：==n 个变元共有 **2ⁿ 个极小项**和 **2ⁿ 个极大项**==。

### 2.2 下标编码规则

把变元出现的形式按顺序翻译成二进制位：

|            | 变元以**本身**形式出现（如 p） | 变元以**否定**形式出现（如 ¬p） |
| :--------- | :----------------: | :-----------------: |
| **极小项 mᵢ** |      记 **1**       |       记 **0**       |
| **极大项 Mᵢ** |      记 **0**       |       记 **1**       |

得到的二进制数转成十进制，就是下标 i。

> **一句话记法**：极**小**项"顺着抄"（1 = 变元自己）；极**大**项"反着来"（1 = 变元的否定）。
> **更强的记法**：mᵢ **只在**赋值 i 下为**真**；Mᵢ **只在**赋值 i 下为**假**。（这句能直接推出编码规则，建议优先记这句。）

### 2.3 n = 3 时的完整对照表（p, q, r）

| i | 二进制 | 极小项 mᵢ | 极大项 Mᵢ |
|:---:|:---:|:---|:---|
| 0 | 000 | ¬p ∧ ¬q ∧ ¬r | p ∨ q ∨ r |
| 1 | 001 | ¬p ∧ ¬q ∧ r | p ∨ q ∨ ¬r |
| 2 | 010 | ¬p ∧ q ∧ ¬r | p ∨ ¬q ∨ r |
| 3 | 011 | ¬p ∧ q ∧ r | p ∨ ¬q ∨ ¬r |
| 4 | 100 | p ∧ ¬q ∧ ¬r | ¬p ∨ q ∨ r |
| 5 | 101 | p ∧ ¬q ∧ r | ¬p ∨ q ∨ ¬r |
| 6 | 110 | p ∧ q ∧ ¬r | ¬p ∨ ¬q ∨ r |
| 7 | 111 | p ∧ q ∧ r | ¬p ∨ ¬q ∨ ¬r |

**验证"只在一种赋值下取特定值"**：取 i = 5（二进制 101，即 p = 1, q = 0, r = 1）：
- m₅ = p ∧ ¬q ∧ r → 1 ∧ 1 ∧ 1 = **1**（真）；
- M₅ = ¬p ∨ q ∨ ¬r → 0 ∨ 0 ∨ 0 = **0**（假）。

### 2.4 三条关键性质

1. **唯一取值性**：mᵢ 在 2ⁿ 种赋值中恰有一种为真；Mᵢ 恰有一种为假。
2. **互补关系**：¬mᵢ ⟺ Mᵢ，且 ¬Mᵢ ⟺ mᵢ。（否定一个极小项，得到的等值式正是**同下标**的极大项。这条是第六节方法的依据。）
3. **全体之积 / 之和**：
   - m₀ ∨ m₁ ∨ … ∨ m_{2ⁿ−1} ⟺ 1（永真）
   - M₀ ∧ M₁ ∧ … ∧ M_{2ⁿ−1} ⟺ 0（永假）

## 三、主析取范式与主合取范式

| 名称        | 定义                  | 简记            |
| :-------- | :------------------ | :------------ |
| **主析取范式** | ==由**极小项**构成的析取范式== | ∑m(i₁, i₂, …) |
| **主合取范式** | ==由**极大项**构成的合取范式== | ∏M(j₁, j₂, …) |

**存在唯一性定理**：==任何命题公式都存在与之**等值**的主析取范式和主合取范式==；且在等值意义下**唯一**（不计极小项 / 极大项的书写顺序）。

> 所以：==**两个公式等值 ⟺ 它们的主析（或合）取范式相同==（极小项下标集合一致）。** 这是主范式最大的用处。

## 四、求法一：真值表法 🟢

### 步骤

1. 列出公式真值表（2ⁿ 行）；
2. **成真行 → 写极小项**：该行变元取 1 的写本身、取 0 的写否定，合取起来；把所有成真行析取，得主析取范式；
3. **成假行 → 写极大项**：规则与上一步**相反**（取 0 的写本身、取 1 的写否定），析取起来；把所有成假行合取，得主合取范式。

### 例 1 🟢 求 P = p → q 的主范式

|  p  |  q  | P = p → q | 对应的项 |
| :-: | :-: | :-------: | :--- |
|  0  |  0  |   **1**   | m₀   |
|  0  |  1  |   **1**   | m₁   |
|  1  |  0  |   **0**   | M₂   |
|  1  |  1  |   **1**   | m₃   |

**主析取范式**（取成真行）：
P ⟺ m₀ ∨ m₁ ∨ m₃ = (¬p ∧ ¬q) ∨ (¬p ∧ q) ∨ (p ∧ q) ⟺ **∑m(0, 1, 3)**

**主合取范式**（取成假行）：
P ⟺ M₂ = ¬p ∨ q ⟺ **∏M(2)**

**验算**：两个下标集合互补（{0,1,3} ∪ {2} = {0,1,2,3}），符合第六节的规律 ✔

> 真值表法的优点是不需要动脑，缺点是变元一多（3 个以上）行数就爆炸。考场推荐用它**验算**手算结果。

## 五、求法二：等值演算法 🟡

### 步骤

**第 1 步｜消去 → 和 ↔**
- A → B ⟺ ¬A ∨ B
- A ↔ B ⟺ (A → B) ∧ (B → A)

**第 2 步｜否定词内移（De Morgan 律）**
- ¬(A ∧ B) ⟺ ¬A ∨ ¬B
- ¬(A ∨ B) ⟺ ¬A ∧ ¬B
- ¬¬A ⟺ A

**第 3 步｜化成普通范式**（用分配律）
- 求主**析取**式用：A ∧ (B ∨ C) ⟺ (A ∧ B) ∨ (A ∧ C)
- 求主**合取**式用：A ∨ (B ∧ C) ⟺ (A ∨ B) ∧ (A ∨ C)
- 途中配合使用幂等律（A ∨ A ⟺ A）、交换律、结合律、吸收律（A ∨ (A ∧ B) ⟺ A）

**第 4 步｜补全缺失的变元**（这一步是从"范式"升级为"主范式"的关键）

设简单式 A 中**不含**变元 p，则：
- 简单合取式补齐：A ⟺ A ∧ (p ∨ ¬p) ⟺ (A ∧ p) ∨ (A ∧ ¬p)
- 简单析取式补齐：A ⟺ A ∨ (p ∧ ¬p) ⟺ (A ∨ p) ∧ (A ∨ ¬p)

**第 5 步｜去重**：重复出现的极小项 / 极大项用幂等律合并为一个。

### 例 2 🟡 求 P = (p → q) ∧ (q → r) 的主析取范式

**第 1 步** 消去蕴含：
P ⟺ (¬p ∨ q) ∧ (¬q ∨ r)

**第 3 步** 分配律展开：
(¬p ∨ q) ∧ (¬q ∨ r) ⟺ (¬p ∧ ¬q) ∨ (¬p ∧ r) ∨ (q ∧ ¬q) ∨ (q ∧ r)

其中 q ∧ ¬q ⟺ 0，是矛盾式，直接划掉：
P ⟺ (¬p ∧ ¬q) ∨ (¬p ∧ r) ∨ (q ∧ r)

**第 4 步** 补全变元（每一项都缺一个变元）：
- ¬p ∧ ¬q 缺 r → (¬p ∧ ¬q ∧ r) ∨ (¬p ∧ ¬q ∧ ¬r) = m₁ ∨ m₀
- ¬p ∧ r 缺 q → (¬p ∧ q ∧ r) ∨ (¬p ∧ ¬q ∧ r) = m₃ ∨ m₁
- q ∧ r 缺 p → (p ∧ q ∧ r) ∨ (¬p ∧ q ∧ r) = m₇ ∨ m₃

**第 5 步** 合并去重：
P ⟺ m₀ ∨ m₁ ∨ m₃ ∨ m₇ = **∑m(0, 1, 3, 7)**

**主合取范式**（用第六节的下标互补法直接写）：
P ⟺ **∏M(2, 4, 5, 6)**

**真值表验算** ✔

| p q r | p → q | q → r | P |
|:---:|:---:|:---:|:---:|
| 0 0 0 | 1 | 1 | **1** → m₀ |
| 0 0 1 | 1 | 1 | **1** → m₁ |
| 0 1 0 | 1 | 0 | 0 → M₂ |
| 0 1 1 | 1 | 1 | **1** → m₃ |
| 1 0 0 | 0 | 1 | 0 → M₄ |
| 1 0 1 | 0 | 1 | 0 → M₅ |
| 1 1 0 | 1 | 0 | 0 → M₆ |
| 1 1 1 | 1 | 1 | **1** → m₇ |

### 例 3 🟡 求 P = ¬(p → q) ∨ r 的主析取范式

**第 1、2 步** 先算 ¬(p → q)：因为 p → q ⟺ ¬p ∨ q，所以
¬(p → q) ⟺ ¬(¬p ∨ q) ⟺ p ∧ ¬q

于是 P ⟺ (p ∧ ¬q) ∨ r

**第 4 步** 补全变元：
- p ∧ ¬q 缺 r → (p ∧ ¬q ∧ r) ∨ (p ∧ ¬q ∧ ¬r) = m₅ ∨ m₄
- r 缺 p、q → (p ∧ q ∧ r) ∨ (p ∧ ¬q ∧ r) ∨ (¬p ∧ q ∧ r) ∨ (¬p ∧ ¬q ∧ r) = m₇ ∨ m₅ ∨ m₃ ∨ m₁

**第 5 步** 合并去重：
P ⟺ **∑m(1, 3, 4, 5, 7)**，其主合取范式为 ∏M(0, 2, 6)

> **要点**：一个"单项"（比如单独的 r）补齐两个缺失变元时，会变成 2² = 4 个极小项——这就是 r 一项贡献了 m₁、m₃、m₅、m₇ 的原因。

## 六、求法三：由主析取范式直接写主合取范式 🟢

由性质 ¬mᵢ ⟺ Mᵢ 可得：

> 若 P ⟺ ∑m(i₁, i₂, …, i_k)，则
> **P ⟺ ∏M(全部下标中除去 i₁, i₂, …, i_k 后剩下的那些)**

因为 ¬(m_{i₁} ∨ … ∨ m_{i_k}) ⟺ ¬m_{i₁} ∧ … ∧ ¬m_{i_k} ⟺ M_{i₁} ∧ … ∧ M_{i_k}，而"取补集"恰好对应"取否定"。

**操作要点**：n 个变元时全部下标是 {0, 1, …, 2ⁿ − 1}，共 2ⁿ 个。先列出这个全集，再划掉主析取范式里出现过的下标，剩下的就是主合取范式的下标。

### 例 4 🟢

| 已知 | n | 全集 | 补集 = 主合取范式下标 |
|:---|:---:|:---|:---|
| P ⟺ ∑m(0, 1, 3, 7) | 3 | {0,1,2,3,4,5,6,7} | {2,4,5,6} → ∏M(2, 4, 5, 6) |
| P ⟺ ∑m(2, 3, 4, 6) | 3 | {0,1,2,3,4,5,6,7} | {0,1,5,7} → ∏M(0, 1, 5, 7) |

反向同样成立：由 ∏M 求 ∑m 也是取补集。

> ⚠️ 这个"补集"操作**只在主范式之间**成立。把普通析取范式当成主析取范式去取补集，结果是错的。

## 七、三种方法对比与选择

| 方法 | 适用场景 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **真值表法** | 变元 ≤ 3；用于**验算** | 机械、不易错 | 变元多时行数爆炸（2ⁿ 行） |
| **等值演算法** | 变元 ≥ 3、含 → ↔ 的复杂公式 | 不用枚举，考场首选 | 步骤多，补全变元时易漏项 |
| **下标互补法** | 已有一个主范式，要求另一个 | 一行搞定 | 不能从普通公式直接开始 |

**实战建议**：等值演算法求出主析取范式 → 用下标互补法写出主合取范式 → 有时间为难的时候用真值表抽查两行。

## 八、主范式的三大应用

1. **判断两个公式是否等值**：分别求主析取范式，若极小项下标集合相同 ⟺ 等值。
   例：p → q 与 ¬q → ¬p 都是 ∑m(0, 1, 3)，故等值（逆否命题与原命题等价）。
2. **判断公式类型**：
   - 主析取范式含**全部** 2ⁿ 个极小项 ⟺ 公式为**永真式**（重言式）；此时主合取范式不含任何极大项（空合取式，约定记作 **1**）。
   - 主合取范式含**全部** 2ⁿ 个极大项 ⟺ 公式为**永假式**（矛盾式）；此时主析取范式不含任何极小项（空析取式，约定记作 **0**）。
   - 其余情形为**可满足式**（非重言式）。
3. **求成真赋值 / 成假赋值**：
   - 主析取范式中**出现的**极小项下标 → 对应的赋值使公式为**真**；
   - 主合取范式中**出现的**极大项下标 → 对应的赋值使公式为**假**。

# 参考答案与详细解析

## 第 1 题
二进制 5 = **101**，按 p, q, r 顺序：1 → 写本身，0 → 写否定。

- **极小项 m₅ = p ∧ ¬q ∧ r**，它只在赋值 (p=1, q=0, r=1) 下为**真**；
- **极大项 M₅ = ¬p ∨ q ∨ ¬r**，它只在赋值 (p=1, q=0, r=1) 下为**假**。

**解析**：注意两者的编码方向相反——同一个下标 5，m₅ 里 r 是**正**的，M₅ 里 r 是**反**的。检验方法：把 p=1, q=0, r=1 代入，m₅ = 1∧1∧1 = 1，M₅ = 0∨0∨0 = 0 ✔

## 第 2 题
**主析取范式**：p ∨ q 缺变元，用 p ∨ q ⟺ (p ∧ q) ∨ (p ∧ ¬q) ∨ (¬p ∧ q) 补齐：
P ⟺ (p ∧ ¬q) ∨ (¬p ∧ q) ∨ (p ∧ q) = **∑m(1, 2, 3)**

**主合取范式**：n = 2，全集 {0, 1, 2, 3}，补集为 {0}：
P ⟺ **∏M(0) = p ∨ q**

**解析**：p ∨ q 本身就是合取范式（且恰好是极大项 M₀），所以主合取范式就是它自己。而主析取范式必须"拆开"，得到三个极小项。

## 第 3 题

| p | q | P = p ↔ q | 对应的项 |
|:---:|:---:|:---:|:---|
| 0 | 0 | **1** | m₀ |
| 0 | 1 | **0** | M₁ |
| 1 | 0 | **0** | M₂ |
| 1 | 1 | **1** | m₃ |

**主析取范式**：P ⟺ m₀ ∨ m₃ = (¬p ∧ ¬q) ∨ (p ∧ q) = **∑m(0, 3)**
**主合取范式**：P ⟺ M₁ ∧ M₂ = (p ∨ ¬q) ∧ (¬p ∨ q) = **∏M(1, 2)**

**验算**：(p ∨ ¬q) ∧ (¬p ∨ q) 展开得 (p ∧ ¬p) ∨ (p ∧ q) ∨ (¬q ∧ ¬p) ∨ (¬q ∧ q) ⟺ (p ∧ q) ∨ (¬p ∧ ¬q) ✔

**解析**：等价联结词 ↔ 等价于"同真同假"，所以成真行只有 00 和 11 两行。

## 第 4 题
P ⟺ (p ∧ q) ∨ (¬p ∧ r)

**第 4 步** 补全变元（n = 3，缺的变元都是 r 或 q）：
- p ∧ q 缺 r → (p ∧ q ∧ r) ∨ (p ∧ q ∧ ¬r) = m₇ ∨ m₆
- ¬p ∧ r 缺 q → (¬p ∧ q ∧ r) ∨ (¬p ∧ ¬q ∧ r) = m₃ ∨ m₁

合并：**P ⟺ ∑m(1, 3, 6, 7)**
主合取范式（补集 {0, 2, 4, 5}）：**P ⟺ ∏M(0, 2, 4, 5)**
= (p ∨ q ∨ r) ∧ (p ∨ ¬q ∨ r) ∧ (¬p ∨ q ∨ r) ∧ (¬p ∨ q ∨ ¬r)

**真值表验算** ✔

| p q r | p ∧ q | ¬p ∧ r | P |
|:---:|:---:|:---:|:---:|
| 0 0 0 | 0 | 0 | 0 → M₀ |
| 0 0 1 | 0 | 1 | **1** → m₁ |
| 0 1 0 | 0 | 0 | 0 → M₂ |
| 0 1 1 | 0 | 1 | **1** → m₃ |
| 1 0 0 | 0 | 0 | 0 → M₄ |
| 1 0 1 | 0 | 0 | 0 → M₅ |
| 1 1 0 | 1 | 0 | **1** → m₆ |
| 1 1 1 | 1 | 0 | **1** → m₇ |

## 第 5 题
P ⟺ (p ∨ ¬q) ∧ r

**先求主析取范式**（分配律）：
P ⟺ (p ∧ r) ∨ (¬q ∧ r)

补全变元（n = 3）：
- p ∧ r 缺 q → (p ∧ q ∧ r) ∨ (p ∧ ¬q ∧ r) = m₇ ∨ m₅
- ¬q ∧ r 缺 p → (p ∧ ¬q ∧ r) ∨ (¬p ∧ ¬q ∧ r) = m₅ ∨ m₁

合并：P ⟺ **∑m(1, 5, 7)**

**下标互补**：n = 3 的全集 {0,…,7}，补集 = {0, 2, 3, 4, 6}
**主合取范式：P ⟺ ∏M(0, 2, 3, 4, 6)**

写成具体形式（注意编码方向与极小项相反）：
= (p ∨ q ∨ r) ∧ (p ∨ ¬q ∨ r) ∧ (p ∨ ¬q ∨ ¬r) ∧ (¬p ∨ q ∨ r) ∧ (¬p ∨ ¬q ∨ r)

**真值表验算** ✔

| p q r | p ∨ ¬q | r | P |
|:---:|:---:|:---:|:---:|
| 0 0 0 | 1 | 0 | 0 → M₀ |
| 0 0 1 | 1 | 1 | **1** → m₁ |
| 0 1 0 | 0 | 0 | 0 → M₂ |
| 0 1 1 | 0 | 1 | 0 → M₃ |
| 1 0 0 | 1 | 0 | 0 → M₄ |
| 1 0 1 | 1 | 1 | **1** → m₅ |
| 1 1 0 | 1 | 0 | 0 → M₆ |
| 1 1 1 | 1 | 1 | **1** → m₇ |

## 第 6 题
n = 3，全集 {0, 1, 2, 3, 4, 5, 6, 7}，划掉 {2, 3, 4, 6}，剩余 {0, 1, 5, 7}：

**P ⟺ ∏M(0, 1, 5, 7)**
= (p ∨ q ∨ r) ∧ (p ∨ q ∨ ¬r) ∧ (¬p ∨ q ∨ ¬r) ∧ (¬p ∨ ¬q ∨ ¬r)

**解析**：写 M₀ = p ∨ q ∨ r：下标 0 的二进制是 000，极大项中"0 写本身、1 写否定"，三个 0 全是本身形式。
写 M₁ = p ∨ q ∨ ¬r：001 的最低位是 1，对应 r 写否定。
写 M₅ = ¬p ∨ q ∨ ¬r：101 的最高位、最低位是 1，对应 p、r 写否定。
写 M₇ = ¬p ∨ ¬q ∨ ¬r：111 三位全为 1，全部写否定。

## 第 7 题
**结论：等值。**

**求 p → (q → r)**：
- 用蕴涵等值式换掉 → 会引入 ¬ 作用在复合式上，这里改用等值的"形式转换"更稳妥：
  p → (q → r) ⟺ ¬p ∨ (¬q ∨ r) ⟺ ¬p ∨ ¬q ∨ r

这是三个文字的析取，正好是极大项 M₆（二进制 110：1 写否定 → ¬p, ¬q；0 写本身 → r）。
所以 **p → (q → r) ⟺ ∏M(6) ⟺ ∑m(0, 1, 2, 3, 4, 5, 7)**

**求 (p ∧ q) → r**：
(p ∧ q) → r ⟺ ¬(p ∧ q) ∨ r ⟺ ¬p ∨ ¬q ∨ r

同一个式子！所以 **(p ∧ q) → r ⟺ ∏M(6) ⟺ ∑m(0, 1, 2, 3, 4, 5, 7)**

两式主析取范式的极小项下标集合完全相同（都是 {0,1,2,3,4,5,7}），故**等值**。

**解析**：这其实是一个常用的逻辑等值式——**"输出律 / 移出律"**：p → (q → r) ⟺ (p ∧ q) → r。用主析取范式判定等值是最规范的证法：求范式 → 比较下标集合。

## 第 8 题
P ⟺ (p → q) ∧ (q → r) ∧ (r → p)
⟺ (¬p ∨ q) ∧ (¬q ∨ r) ∧ (¬r ∨ p)

这个式子表示"p, q, r 循环蕴涵"，直观上当三者取值相同时成立。用真值表法最稳：

| p q r | p → q | q → r | r → p | P |
|:---:|:---:|:---:|:---:|:---:|
| 0 0 0 | 1 | 1 | 1 | **1** → m₀ |
| 0 0 1 | 1 | 1 | 0 | 0 → M₁ |
| 0 1 0 | 1 | 0 | 1 | 0 → M₂ |
| 0 1 1 | 1 | 1 | 1 | **1** → m₃ |
| 1 0 0 | 0 | 1 | 1 | 0 → M₄ |
| 1 0 1 | 0 | 1 | 0 | 0 → M₅ |
| 1 1 0 | 1 | 0 | 1 | 0 → M₆ |
| 1 1 1 | 1 | 1 | 1 | **1** → m₇ |

**主析取范式：P ⟺ ∑m(0, 3, 7)**，主合取范式 P ⟺ ∏M(1, 2, 4, 5)

**结论**：既不含全部 8 个极小项（不是重言式），也不含全部 8 个极大项（不是矛盾式），所以 P 是**可满足式**，其成真赋值为 (0,0,0)、(0,1,1)、(1,1,1)——恰好是三变元取值全相同的三种情况。

## 附一：常见易错点速查表

| 易错点 | 正解 |
|:---|:---|
| 极小项 / 极大项的编码方向搞反 | mᵢ 在赋值 i 下为**真**；Mᵢ 在赋值 i 下为**假**。极**小**项顺抄，极**大**项反抄 |
| 不先约定变元顺序就开始编码 | 必须先固定顺序（如约定 p, q, r），顺序不同下标全变 |
| 把普通析取范式当主析取范式 | 主范式要求每个简单式都把变元**补齐**，缺一个变元就要乘 (p ∨ ¬p) 展开 |
| 补全变元时只写一半 | A ∧ (p ∨ ¬p) 要展开成 **(A ∧ p) ∨ (A ∧ ¬p)** 两项，不能只留一项 |
| 忘记去掉矛盾项 q ∧ ¬q | 该式为 0，应直接划掉；同理 q ∨ ¬q 为 1，在合取中可直接划掉 |
| 主合取范式写成同下标的 m | mᵢ 与 Mᵢ 下标相同但**含义相反**，由 ∑m 求 ∏M 必须取**补集** |
| 计算补集时用错全集 | n 个变元的全集是 {0, 1, …, 2ⁿ − 1}，共 **2ⁿ** 个下标 |
| 极小项个数数错 | 每个极小项恰含 n 个文字，共 2ⁿ 个 |
| 永真式 / 永假式的特例没记 | 永真：主合取范式为**空**（记作 1）；永假：主析取范式为**空**（记作 0） |
| 用主范式判断等值却只比较"长得像不像" | 要比较**极小项下标集合**是否相同，形式上可以写得完全不同 |

## 附二：核心公式一览

**转换类**
- A → B ⟺ ¬A ∨ B
- A ↔ B ⟺ (A → B) ∧ (B → A) ⟺ (A ∧ B) ∨ (¬A ∧ ¬B)

**De Morgan 律**
- ¬(A ∧ B) ⟺ ¬A ∨ ¬B
- ¬(A ∨ B) ⟺ ¬A ∧ ¬B

**分配律**
- A ∧ (B ∨ C) ⟺ (A ∧ B) ∨ (A ∧ C)　← 用于求主析取范式
- A ∨ (B ∧ C) ⟺ (A ∨ B) ∧ (A ∨ C)　← 用于求主合取范式

**补全变元**
- A ⟺ A ∧ (p ∨ ¬p)　← 合取式补齐
- A ⟺ A ∨ (p ∧ ¬p)　← 析取式补齐

**互补与对偶**
- ¬mᵢ ⟺ Mᵢ，¬Mᵢ ⟺ mᵢ
- 若 P ⟺ ∑m(S)，则 P ⟺ ∏M(全集 ∖ S)

**常用等值式**
- 幂等律：A ∨ A ⟺ A，A ∧ A ⟺ A
- 吸收律：A ∨ (A ∧ B) ⟺ A，A ∧ (A ∨ B) ⟺ A
- 输出律：p → (q → r) ⟺ (p ∧ q) → r
- 逆否律：p → q ⟺ ¬q → ¬p
