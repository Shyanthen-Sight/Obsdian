**建表时创建**
```sql
create table 表名称(
字段名 数据类型,
check(表达式),
字段名 数据类型 not null default 默认值
);
```

**建表后修改**
```sql
alter table 表名 add constraint 约束名 check(表达式);
```

**删除约束**
```sql
alter table 表名 drop constraint 约束名;
```

**查询约束**
```sql
SELECT * FROM 
INFORMATION_SCHEMA.TABLE_CONSTRAINTS 
WHERE TABLE_SCHEMA = '苦命' 
AND TABLE_NAME = '表名';
```
