## 零、为什么从集合开始

在动笔定义集合之前，先回答一个"凭什么"的问题。

**一、集合是现代数学的基础语言。** 数学里几乎每一个对象——数、点、函数、关系、概率事件——最终都可以用集合来构造。把"一堆对象"打包成一个整体，是数学抽象的第一步。有了整体，才能谈"两个整体之间的映射"，才能谈"在整体上做运算"。

**二、本章为第 4 章的关系与函数铺路。** 关系是笛卡尔积的子集，函数是特殊的二元关系；而笛卡尔积本身又是集合。也就是说，第 4 章所有的定义，其字母表都来自本章。本节没学明白，第 4 章会寸步难行。

**三、逻辑与集合是"一枚硬币的两面"。** 对照下表可以看出这种同构：

| 一阶逻辑                  | 集合论            |
| :-------------------- | :------------- |
| 谓词 `P(x)`             | 元素 `x` 是否属于集合  |
| `P(x) → Q(x)` 恒真       | `A ⊆ B`        |
| `P(x) ↔ Q(x)` 恒真       | `A = B`        |
| `∃x P(x)`             | 集合非空           |
| 空谓词（恒假）               | 空集 `∅`         |

> **记忆钩子**：==**子集定义 `A ⊆ B` 就是把一阶逻辑句子 `∀x(x ∈ A → x ∈ B)` 原封不动搬过来**==。以后凡是要证"包含关系"，思路就是"证一个全称蕴含式"——这是整章的通用套路。

## 一、集合的定义与表示

### 1.1 康托尔的朴素定义

**定义（朴素／直观）**：集合是一些**确定的、彼此不同的**对象汇成的**整体**。这些对象称为集合的**元素**（或成员）。

这里有三个关键词，缺一不可：

1. **确定的**——任给一个对象，都能判断它属不属于这个集合（不会"说不清"）；
2. **彼此不同的**——同一对象不能在一个集合里出现两次；
3. **整体**——我们关心的是"打包之后"这个对象，而不是里面的零件。

> ⚠️ **为什么要写"朴素"两个字？** 康托尔的定义依赖"任意一堆对象都能构成集合"这一直觉。1901 年罗素指出，若允许这样造句，"所有不包含自身的集合"也会构成一个集合 `R`，于是 `R ∈ R` 与 `R ∉ R` 同时被推出，产生矛盾（**罗素悖论**）。现代数学因而改用**公理化集合论**（ZF 系统），把"集合"当作**不加定义的原始概念**，只用公理约束它的行为。本书不深入公理化，知道"集合是原始概念、靠公理刻画"即可。

### 1.2 元素与属于关系

- 若对象 `x` 是集合 `A` 的元素，记作 `x ∈ A`，读作"`x` 属于 `A`"；
- 否则记作 `x ∉ A`，读作"`x` 不属于 `A`"。

> **约定**：本章用大写字母 `A, B, C, …` 表示**集合**，小写字母 `a, b, c, x, y, …` 表示**元素**。符号 `∈` 与 `∉` 只用于"元素—集合"之间：==`∈` 的**左边是大写还是小写**，是判断一句话是否合法的第一道关卡==。

### 1.3 集合的三种表示法

| 表示法       | 形式                 | 特点                  | 例                       |
| :-------- | :----------------- | :------------------ | :---------------------- |
| **列举法**（外延法） | `A = {a, b, c}`     | 把元素一一列出，元素少时用      | `A = {1, 3, 5, 7}`      |
| **描述法**（谓词法） | `A = {x \| P(x)}`   | 用**元素满足的条件**刻划，元素多时用 | `A = {x \| x 是小于 8 的奇数}` |
| **文氏图**    | 一个封闭曲线圈出的区域        | 直观、不精确，用于辅助推理       | 见下方说明                   |

**描述法要点**：`A = {x | P(x)}` 中的竖线读作"使得"，整体意思是"所有使 `P(x)` 为真的 `x` 组成的集合"。这里的 `P(x)` 就是一个**谓词**——描述法在一阶逻辑里对应的公式是 `∀x(x ∈ A ↔ P(x))`。

> **口诀**：==**"竖线左边定范围，竖线右边定条件"**==。例如 `{x | x ∈ N 且 x < 5}` 中，左边 `x` 指明"从全总个体域里挑"，右边的 `x ∈ N 且 x < 5` 才是筛选条件。

**文氏图（Venn 图）**：用一个矩形代表**全集** `E`，矩形内的封闭曲线（通常是圆）代表集合，曲线内部画点表示元素。文氏图**只能辅助理解、不能代替证明**——图形无法表达"任意 `x`"这样的全称断言。

**几个用列举法写出的例子**：

- 小于 5 的自然数：`{0, 1, 2, 3, 4}`
- 拉丁字母表前三位：`{a, b, c}`
- 方程 `x^2 = 1` 的实根：`{-1, 1}`

### 1.4 元素的三条性质

| 性质       | 含义                        | 后果举例                                  |
| :------- | :------------------------ | :------------------------------------ |
| **确定性**   | 任一对象与集合的关系非此即彼            | "很大的数"不构成集合（"很大"不确定）                  |
| **互异性**   | 集合中元素**不重复**，重复写也只算一个      | `{1, 1, 2} = {1, 2}`                  |
| **无序性**   | 元素**不分先后**，写出来的次序无关       | `{1, 2, 3} = {3, 1, 2}`               |

> ⚠️ **易错警告**：由互异性与无序性，==`{1, 2} = {2, 1}` 是**同一个集合**==，不要像数列那样区分次序。若真要区分次序，那是下一章的"有序对／笛卡尔积"，不是集合。同理 `{1, 1}` 与 `{1}` 是同一个集合。

## 二、集合之间的关系

### 2.1 外延公理：集合由元素唯一决定

**外延公理**：两个集合相等，当且仅当它们的元素完全相同：

```
A = B  ⟺  ∀x (x ∈ A ↔ x ∈ B)
```

这条公理是**一切集合等式证明的总纲**：==要证 `A = B`，就去证"`∀x(x ∈ A ↔ x ∈ B)`"；实际做法是拆成两个方向 `A ⊆ B` 与 `B ⊆ A`==。

### 2.2 子集与真子集

**定义（子集）**：设 `A, B` 是集合。若 `B` 的每一个元素都是 `A` 的元素，则称 `B` 是 `A` 的**子集**，记作 `B ⊆ A`（也读作"`A` 包含 `B`"）。用逻辑符号写出：

```
B ⊆ A  ⟺  ∀x (x ∈ B → x ∈ A)
```

**定义（真子集）**：若 `B ⊆ A` 且 `B ≠ A`，则称 `B` 是 `A` 的**真子集**，记作 `B ⊂ A`（有的书写作 `B ⫋ A`）。

**"不包含"的写法**：`B ⊄ A` 表示 `B` 不是 `A` 的子集，即

```
B ⊄ A  ⟺  ∃x (x ∈ B ∧ x ∉ A)
```

> **记忆钩子**：`⊆` 的定义是**全称蕴含**，它的否定是**存在合取**。==**"每一个都……" 的否定是 "存在一个不……"**==——这正是 C2 里学过的量词否定律 `¬∀x(...) → ∃x¬(...)`。要用好子集证明，先要背熟这条否定。

**子集举例**（设 `N` 为自然数集，`R` 为实数集）：

- `{1, 2} ⊆ {1, 2, 3}`；且 `{1, 2} ⊂ {1, 2, 3}`（真子集）
- `N ⊆ R`（每个自然数都是实数）
- `A ⊆ A` 对任何集合 `A` 成立

### 2.3 包含关系的三条性质

设 `A, B, C` 为任意集合，则包含关系 `⊆` 满足：

| 性质        | 公式                              | 证明思路                     |
| :-------- | :------------------------------ | :----------------------- |
| **自反性**   | `A ⊆ A`                         | 任取 `x ∈ A`，当然有 `x ∈ A`    |
| **反对称性**  | `(A ⊆ B ∧ B ⊆ A) → A = B`       | 由外延公理：双向包含即元素全同          |
| **传递性**   | `(A ⊆ B ∧ B ⊆ C) → A ⊆ C`       | 任取 `x ∈ A`，经 `B` 传到 `C`   |

> **记忆钩子**：==包含关系 `⊆` 是一个**偏序**（第 4 章会正式命名）==：在"集合的集合"上，它满足自反、反对称、传递。这就是为什么 `⊆` 用起来像"小于等于"。

### 2.4 证明 `A ⊆ B` 的标准套路

**套路（务必背熟）**：

```
证 A ⊆ B：
  任取 x ∈ A          （"任取"二字不能省，它对应 ∀x）
  …（推理链条）…
  得 x ∈ B
  由 x 的任意性，∀x(x ∈ A → x ∈ B) 成立，即 A ⊆ B   ∎
```

**证 `A = B` 的套路**：分别证 `A ⊆ B` 与 `B ⊆ A`，再由外延公理得 `A = B`。

> ⚠️ **易错警告**：初学时最容易犯的错是"**只证了一个方向**"就宣布相等；或者第二步里偷偷把 `x` 换成了**具体的**某个元素（"取 `x = 1`"）——那就只证了"对 `x = 1` 成立"，不是对**任意** `x` 成立。

## 三、特殊集合

### 3.1 空集 `∅`

**定义**：不含任何元素的集合称为**空集**，记作 `∅`。即 `∅ = {x | x ≠ x}`（右边这个条件永远假，故没有任何元素满足）。

**性质 1（唯一性）**：空集只有一个。**证明**：设 `∅₁` 与 `∅₂` 都是空集。由性质 2（见下），空集是任何集合的子集，故 `∅₁ ⊆ ∅₂` 且 `∅₂ ⊆ ∅₁`；由外延公理得 `∅₁ = ∅₂`。∎

**性质 2（`∅` 是任何集合的子集）**：对任意集合 `A`，有 `∅ ⊆ A`。**证明**：

```
按定义，需证 ∀x(x ∈ ∅ → x ∈ A)。
任取 x，考察蕴含式 "x ∈ ∅ → x ∈ A"：
  由于 ∅ 不含任何元素，"x ∈ ∅" 恒为假；
  蕴含式的前件为假 ⟹ 整个蕴含式为真。
故对任意 x 该蕴含式成立，即 ∅ ⊆ A。   ∎
```

> **记忆钩子**：==**"前件为假的蕴含式恒真"**——这是 C1 命题逻辑里 `→` 的真值表结论，在这里第一次真正派上用场==。空集的这两条性质，全靠这一个逻辑事实撑着。

> ⚠️ **易错警告**：`∅ ⊆ A` 对**任何** `A` 成立（包括 `A = ∅`），但"`A ⊆ ∅` 对任何 `A` 成立"是**错的**——`A ⊆ ∅` 只在 `A = ∅` 时成立。不要因为"空集最小"就双向乱套。

### 3.2 全集 `E` 与单元素集

**全集**：在讨论某个具体问题时，事先约定的、包含所讨论的一切对象的集合，记作 `E`（也常用 `U`）。==**全集是相对的**==：在"整数问题"里 `E` 可以取 `Z`，在"全班同学问题"里 `E` 就是全班同学的集合——换一个问题，`E` 就换一个。

**单元素集**：只含一个元素的集合，如 `{a}`。注意 `{a}` 与元素 `a` 是**两回事**：`a ∈ {a}` 成立，而 `a = {a}` **不**成立（除非 `a` 本身是个恰好等于 `{a}` 的集合，但那会引起悖论，公理化系统里禁止）。

### 3.3 幂集 `P(A)`

**定义**：设 `A` 是集合。`A` 的**所有子集**构成的集合称为 `A` 的**幂集**，记作 `P(A)`（也写作 `2^A`）：

```
P(A) = { S | S ⊆ A }
```

**例**：

| `A`             | `P(A)`                                        | `\|P(A)\|` |
| :-------------- | :-------------------------------------------- | :--------- |
| `∅`             | `{∅}`                                         | `1`        |
| `{a}`           | `{∅, {a}}`                                    | `2`        |
| `{a, b}`        | `{∅, {a}, {b}, {a, b}}`                       | `4`        |
| `{a, b, c}`     | 8 个子集                                        | `8`        |

> ⚠️ **易错警告**：==`P(∅) = {∅}` 而**不是** `∅`==！因为 `∅` 也是 `∅` 的一个子集，所以幂集里必含这个元素。同理 `|P(∅)| = 1`，不是 `0`。写幂集时永远记着"先写 `∅`，再写各个单元素集，再写更大的……最后写 `A` 自己"。

**幂集的包含性质**：`A ⊆ B ⟺ P(A) ⊆ P(B)`。证明留作练习题。

### 3.4 `|P(A)| = 2^n` 的三种证法

**定理**：若 `|A| = n`（`n` 为自然数），则 `|P(A)| = 2^n`。

这个结论极其重要，下面给出三条互相独立的证明思路——考试里至少要求会两种。

**证法一：按子集大小分类（组合计数）**。`A` 的含 `k` 个元素的子集有 `C(n, k)` 个（`k = 0, 1, …, n`）。由二项式定理，

```
|P(A)| = C(n,0) + C(n,1) + … + C(n,n) = (1 + 1)^n = 2^n
```

**证法二：数学归纳法（结构归纳）**。

- **基始**：`n = 0` 时 `A = ∅`，`P(∅) = {∅}`，`|P(∅)| = 1 = 2^0`，成立。
- **归纳步**：设 `n` 时成立。取 `|A| = n + 1`，固定 `a ∈ A`，令 `B = A \ {a}`，则 `|B| = n`。`A` 的子集分两类：**不含 `a` 的**恰好是 `B` 的全部子集，有 `2^n` 个；**含 `a` 的**必形如 `S ∪ {a}`（`S ⊆ B`），也与 `B` 的子集一一对应，有 `2^n` 个。两类不交且穷尽，故 `|P(A)| = 2^n + 2^n = 2^{n+1}`。∎

**证法三：特征函数（0-1 串配对）**。给 `A` 的每个子集 `S` 配一个"身份证"：对 `A = {a₁, …, aₙ}` 中每个 `aᵢ`，若 `aᵢ ∈ S` 记 `1`，否则记 `0`，得到一个长 `n` 的 0-1 串。这个对应是**一一的**：不同的子集给出不同的串，每个串也都能还原出唯一子集。长 `n` 的 0-1 串共有 `2^n` 个，故 `|P(A)| = 2^n`。∎

> **记忆钩子**：==**"幂集大小 = 2 的元素个数次幂"**——名字里的 `2^A` 就是这么来的==。二项式证法偏"数数"，归纳证法偏"结构"，特征函数证法偏"对应"，三条路通向同一个结论。

## 四、`∈` 与 `⊆` 的严格区别

这是全章最容易被出成判断题的地方，值得单独一节。

### 4.1 一句话区分

| 符号   | 读作      | 左端是什么   | 右端是什么   | 例子                |
| :--- | :------ | :------ | :------ | :---------------- |
| `∈`  | 属于      | **元素**  | **集合**  | `1 ∈ {1, 2}`      |
| `⊆`  | 包含于（子集） | **集合**  | **集合**  | `{1} ⊆ {1, 2}`    |

==**`∈` 描述"个体与整体"，`⊆` 描述"整体与整体"**==。判断一句写法合不合法，先看 `∈`／`⊆` 左边那个东西是不是集合。

### 4.2 经典辨析串

设 `∅` 是空集，用它"制造"一串集合：

| 命题              | 真假  | 理由                              |
| :-------------- | :-- | :------------------------------ |
| `∅ ∈ {∅}`       | **真** | `{∅}` 的唯一元素就是 `∅`               |
| `∅ ⊆ {∅}`       | **真** | 空集是任何集合的子集                      |
| `∅ ∈ ∅`         | **假** | `∅` 没有任何元素，谈不上"属于"              |
| `∅ ⊆ ∅`         | **真** | 空集是（空集自己的）子集                    |
| `{∅} ≠ ∅`       | **真** | `{∅}` 含一个元素，`∅` 不含元素，故两者不等       |
| `{∅} ⊆ {∅}`     | **真** | 任何集合是自身的子集                      |
| `{∅} ∈ {∅}`     | **假** | `{∅}` 的元素只有 `∅`，而 `{∅} ≠ ∅`      |
| `{∅} ⊆ {{∅}}`   | **假** | `{∅}` 的元素是 `∅`，而 `∅ ∉ {{∅}}`     |
| `{∅} ∈ {{∅}}`   | **真** | `{{∅}}` 的唯一元素就是 `{∅}`            |

> **口诀**：==**"`∈` 看内容，`⊆` 看元素个个数"**——`a ∈ A` 问的是"`a` 在不在 `A` 的清单里"；`B ⊆ A` 问的是"`B` 清单里的每一项是否都在 `A` 清单里"==。

### 4.3 `∈` 不具有传递性

包含关系 `⊆` 具有传递性，但 `∈` **没有**。反例：

```
设 A = {a}，B = {A} = {{a}}。
则 a ∈ A，A ∈ B，但 a ∉ B（B 的唯一元素是 A，不是 a）。
```

即 `a ∈ A` 且 `A ∈ B` 推不出 `a ∈ B`。==**"属于的属于"不等于"属于"**==——这正是"集合可以套娃"带来的现象，也是 `∈` 与 `⊆` 不能混用的根本原因。

## 五、集合的基数与常用数集

### 5.1 基数（元素个数）

**定义**：有限集合 `A` 中元素的**个数**称为 `A` 的**基数**（或势），记作 `|A|`（有的书写作 `card A`）。

- `|∅| = 0`；`|{∅}| = 1`；`|{∅, {∅}}| = 2`
- 若 `A` 有 `n` 个元素，称 `A` 为**有限集**；否则为**无限集**。
- 例：`|{1, 2, 3}| = 3`，`|N|` 为无穷（记作 `ℵ₀`，点到这里为止）。

> ⚠️ **易错警告**：`|{∅}| = 1` 而 `|∅| = 0`——==**括号里有没有那个 `∅`，差了个 1**==。这正是"`P(∅) = {∅}` 而不是 `∅`"的同源陷阱。

### 5.2 常用数集记号（约定）

| 记号              | 名称                       | 例                    |
| :-------------- | :----------------------- | :------------------- |
| `N`             | 自然数集（本书取含 `0` 的约定）      | `{0, 1, 2, 3, …}`    |
| `N+` 或 `N*`     | 正整数集                     | `{1, 2, 3, …}`       |
| `Z`             | 整数集                      | `{…, -2, -1, 0, 1, 2, …}` |
| `Z+`            | 正整数集                     | `{1, 2, 3, …}`       |
| `Q`             | 有理数集                     | `1/2, -3, 0.25, …`   |
| `R`             | 实数集                      | `√2, π, 1, …`        |
| `C`             | 复数集                      | `1 + i, -i, …`       |

包含链：`N ⊂ Z ⊂ Q ⊂ R ⊂ C`（除 `N ⊆ Z` 视 `0` 的约定而定，本书按上表取 `N ⊆ Z`）。

> ⚠️ **易错警告**：==**不同教材对 `N` 是否含 `0` 的约定不同**==。本书约定 `0 ∈ N`，于是 `N = Z⁺ ∪ {0}`，`N⁺ = Z⁺`。做题时若题目另作约定，以题目为准；同题内必须前后一致，否则 `N ⊆ Z` 之类的包含链会自相矛盾。

### 5.3 可数与不可数（点到为止）

- 能与 `N` 建立一一对应的无限集称为**可数集**（如 `Z`、`Q` 都是可数的）；
- 不能的称为**不可数集**（如 `R` 不可数）。

本课程只需知道"有限／无限"的分界，以及可数、不可数这两个词对应的现象，不要求展开证明。

## 六、例题

**例 1（元素归属判断）** 判断正误：`{1, 2} ∈ {1, 2, 3}`。

**解**：假。`{1, 2, 3}` 的元素是 `1, 2, 3` 三个**数**，其中并没有 `{1, 2}` 这个**集合**。而 `{1, 2} ⊆ {1, 2, 3}` 才是真的。

> 要点：看 `∈` 左边是元素 `1` 还是集合 `{1, 2}`。

**例 2（三种表示法互化）** 用列举法表示 `A = {x | x ∈ N 且 x^2 < 10}`。

**解**：满足 `x ∈ N` 且 `x^2 < 10` 的自然数有 `0, 1, 2, 3`，故 `A = {0, 1, 2, 3}`。

**例 3（幂集与基数）** 设 `A = {a, b}`，写出 `P(A)` 并求 `|P(A)|`。

**解**：`A` 的子集按大小排：`∅`（0 元）、`{a}`、`{b}`（1 元）、`{a, b}`（2 元）。故

```
P(A) = {∅, {a}, {b}, {a, b}}，  |P(A)| = 2^2 = 4
```

**例 4（证明包含关系）** 证明：若 `A ⊆ B` 且 `B ⊆ C`，则 `A ⊆ C`。

**证明**：

```
任取 x ∈ A。
由 A ⊆ B 得 x ∈ B；
再由 B ⊆ C 得 x ∈ C。
由 x 的任意性，∀x(x ∈ A → x ∈ C)，即 A ⊆ C。   ∎
```

**例 5（证明集合相等）** 证明：`∅` 是唯一的空集。（即 3.1 性质 1，此处作为等式证明的模板再演一遍。）

**证明**：设 `∅₁, ∅₂` 均为空集。由"空集是任何集合的子集"：`∅₁ ⊆ ∅₂` 且 `∅₂ ⊆ ∅₁`。由外延公理，双向包含蕴含相等，故 `∅₁ = ∅₂`。∎

**例 6（`∈` 与 `⊆` 辨析）** 指出下列各式的真假：`∅ ∈ {∅}`、`∅ ⊆ {∅}`、`{∅} ∈ {{∅}}`。

**解**：三个都**真**。第一个见 4.2；第二个由"空集是任何集合的子集"；第三个因为 `{{∅}}` 的唯一元素恰是 `{∅}`。

# 参考答案与详细解析

## 第 1 题

**(1)** `12` 的正因数是 `1, 2, 3, 4, 6, 12`，都属于 `N`，故

```
A = {1, 2, 3, 4, 6, 12}
```

**解析**：列举法要"数全"。易漏 `1` 和 `12` 本身。

**(2)** `2, 4, 6, 8, 10` 都是 `N` 中的**偶数**且**不超过 10**，故

```
B = {x | x ∈ N 且 x 是偶数且 x ≤ 10}
```

**解析**：描述法允许有多种写法（如 `{2k | k ∈ N 且 1 ≤ k ≤ 5}` 也对）。只要条件能唯一圈定这五个数即可。

**(3)** `{1, 2} ∈ {1, 2, 3}` 为**假**，因为右端的元素是数 `1, 2, 3`，不含集合 `{1, 2}`；`{1, 2} ⊆ {1, 2, 3}` 为**真**，因为 `1, 2` 都在右端中。==这是 `∈` 与 `⊆` 最经典的一组对照==。

## 第 2 题

`A = {1, 2, 3}` 的子集按元素个数分类：

| 元素个数 | 子集                       |
| :--- | :----------------------- |
| 0    | `∅`                      |
| 1    | `{1}`、`{2}`、`{3}`        |
| 2    | `{1, 2}`、`{1, 3}`、`{2, 3}` |
| 3    | `{1, 2, 3}`              |

共 `2^3 = 8` 个。**真子集**是除去 `A` 自身后的 7 个。

**解析**：==**真子集个数 = 子集个数 − 1 = 2^n − 1**==，因为唯一被排除的只有"集合自己"。此外还有"非空子集个数 = `2^n − 1`"、"非空真子集个数 = `2^n − 2`"，三者别记混。

---

## 第 3 题

**(1) 真。** `{∅}` 的唯一元素就是 `∅`，故 `∅ ∈ {∅}`。

**(2) 真。** 空集是任何集合的子集，取"任何集合"为 `∅` 自身即可。

**(3) 假。** `∅` 不含任何元素，`0` 也不例外。

**(4) 假。** `{∅}` 含一个元素（即 `∅`），`∅` 不含元素，二者基数不同（`1 ≠ 0`），故不等。

**解析**：四个小题覆盖了 `∈`／`⊆`／空集／单元素集的全部常见混淆点。==记忆锚点：`0`、`∅`、`{∅}` 的基数依次是 `0, 0, 1`；`∅` 与 `{∅}` 一真一假的关键就在于"有没有那层花括号"。==

---

## 第 4 题

`A = {a, b, c}`，按大小枚举子集：

```
P(A) = { ∅,
         {a}, {b}, {c},
         {a, b}, {a, c}, {b, c},
         {a, b, c} }
|P(A)| = 2^3 = 8
```

再求 `|P(P(∅))|`。先算内层：`P(∅) = {∅}`，其基数为 `1`；于是 `|P(P(∅))| = 2^1 = 2`。

**解析**：==**逐层用公式 `|P(X)| = 2^{|X|}`**==，不要试图把 `P(P(∅))` 展开写出来（那是 `P({∅}) = {∅, {∅}}`，确实只有 2 个元素，可自行验证）。

---

## 第 5 题

**证明**：需证 `∀x(x ∈ ∅ → x ∈ A)`。

```
任取 x。
若 x ∈ ∅：由空集定义，∅ 不含任何元素，故 "x ∈ ∅" 恒为假；
蕴含式 "x ∈ ∅ → x ∈ A" 的前件为假，整个蕴含式为真。
由 x 的任意性，∀x(x ∈ ∅ → x ∈ A) 成立，即 ∅ ⊆ A。   ∎
```

**解析**：本题的证明**没有用到 `A` 的任何信息**——这正是"对任意 `A` 都成立"的原因。==证明的核心是命题逻辑的真值表结论："`假 → 任何` 恒真"。==

---

## 第 6 题

**证明（⇒）**：设 `A ⊆ B`。任取 `S ∈ P(A)`，则 `S ⊆ A`；由 `A ⊆ B` 及 `⊆` 的传递性，`S ⊆ B`，即 `S ∈ P(B)`。故 `P(A) ⊆ P(B)`。

**证明（⇐）**：设 `P(A) ⊆ P(B)`。注意到 `A ∈ P(A)`（因为 `A ⊆ A`）；由 `P(A) ⊆ P(B)` 得 `A ∈ P(B)`，即 `A ⊆ B`。

综上，`A ⊆ B ⟺ P(A) ⊆ P(B)`。∎

**解析**：=="先证整体包含，再用 `A ∈ P(A)` 这一条把幂集关系'降'回原集合关系"==，是幂集证明的固定套路。请特别注意：`A ∈ P(A)` 恒成立（`A` 是 `A` 自己的子集），但 `A ∈ A` 通常**不**成立。

---

## 第 7 题

逐个判断：

- **`A ∈ P(B)`：成立。** `P(B)` 由 `B` 的所有子集组成，而 `A = {a, b} ⊆ {a, b, c} = B`，故 `A` 是 `B` 的子集，即 `A ∈ P(B)`。
- **`A ⊆ P(B)`：不成立。** `A` 的元素是 `a, b`（个体），而 `P(B)` 的元素是集合（如 `∅, {a}, …`）。==元素 `a` 不是集合，不可能属于 `P(B)`==，故 `A ⊄ P(B)`。
- **`{A} ⊆ P(B)`：成立。** `{A}` 的唯一元素是 `A`，而上面已证 `A ∈ P(B)`，故 `{A}` 的每个元素都在 `P(B)` 中，即 `{A} ⊆ P(B)`。

**解析**：本题把"同一对集合 `A, B`，在不同花括号层次下结论完全不同"摆在一起，是 `∈`／`⊆` 辨析的终极版。==判断的关键枢纽：**先问"左端那个东西的元素是什么类型"**——是 `a`（个体）就不可能 `⊆` 进去，是 `{a, b}`（集合）才可能。==

---

## 第 8 题

`A = {∅, {∅}}`，其元素是 `∅` 与 `{∅}` 两个，故 `|A| = 2`。

`A` 的全部子集（共 `2^2 = 4` 个）：

```
P(A) = { ∅, {∅}, {{∅}}, {∅, {∅}} }
|P(A)| = 2^2 = 4
```

判断：

- **`∅ ∈ A`：真。** `A` 的第一个元素就是 `∅`。
- **`{∅} ⊆ A`：真。** `{∅}` 的唯一元素是 `∅`，而 `∅ ∈ A`，故 `{∅} ⊆ A`。
- **`{{∅}} ∈ P(A)`：真。** `{{∅}}` 是 `A` 的子集（其唯一元素 `{∅}` 属于 `A`），故 `{{∅}} ∈ P(A)`。

**解析**：==本题的 `A = {∅, {∅}}` 正是 3.1 里提到过的"基数为 2 的集合"，把它当做一个"标准模型"背下来，很多 `∅` 相关的判断题都能立刻找到例子（或反例）。== 另外注意区分：`{{∅}} ∈ P(A)` 为真，而 `{{∅}} ∈ A` 为**假**（`A` 的元素只有 `∅` 和 `{∅}`）——不要滑过去了。

## 附一：定义与易混速查

**一、基础定义一览**

| 概念       | 记号与定义                          |
| :------- | :----------------------------- |
| 属于／不属于   | `x ∈ A` ／ `x ∉ A`               |
| 子集       | `B ⊆ A ⟺ ∀x(x ∈ B → x ∈ A)`     |
| 不包含      | `B ⊄ A ⟺ ∃x(x ∈ B ∧ x ∉ A)`     |
| 真子集      | `B ⊂ A ⟺ B ⊆ A ∧ B ≠ A`         |
| 集合相等     | `A = B ⟺ ∀x(x ∈ A ↔ x ∈ B)`     |
| 空集       | `∅ = {x \| x ≠ x}`，无元素           |
| 全集       | `E`，相对概念，随问题而变                 |
| 幂集       | `P(A) = {S \| S ⊆ A}`，也记 `2^A`   |
| 基数       | `\|A\|`，有限集的元素个数               |

**二、三条核心结论（必背）**

- `|P(A)| = 2^n`（`n = |A|`）；真子集个数 `2^n − 1`；非空子集个数 `2^n − 1`。
- `∅ ⊆ A` 对任何 `A` 成立；`∅` 唯一。
- `A ⊆ B ⟺ P(A) ⊆ P(B)`。

**三、`∈` vs `⊆` 一图流**

| 情形            | `∈` 成立？ | `⊆` 成立？ |
| :------------ | :----- | :----- |
| `1` 与 `{1, 2}`   | ✅     | ❌（`1` 是元素，不是集合） |
| `{1}` 与 `{1, 2}` | ❌     | ✅     |
| `∅` 与 `{∅}`      | ✅     | ✅     |
| `∅` 与 `∅`        | ❌     | ✅     |
| `{∅}` 与 `{∅}`    | ❌     | ✅     |

**四、包含关系的三条性质**

| 性质    | 表达式                        |
| :---- | :-------------------------- |
| 自反    | `A ⊆ A`                     |
| 反对称   | `A ⊆ B ∧ B ⊆ A ⟹ A = B`    |
| 传递    | `A ⊆ B ∧ B ⊆ C ⟹ A ⊆ C`    |

**五、易混清单**

- `∈` 左端是**元素**，`⊆` 两端都是**集合**——最核心的一条。
- `∅ ∈ {∅}` 真，`∅ ⊆ {∅}` 真，`{∅} ≠ ∅`。
- `P(∅) = {∅}`，不是 `∅`；`|P(∅)| = 1`，不是 `0`。
- `∈` **没有**传递性（`a ∈ A` 且 `A ∈ B` 推不出 `a ∈ B`），`⊆` 有传递性。
- 证 `A ⊆ B` 必须"任取 `x ∈ A`"，不能代具体值。
- 证 `A = B` 必须**双向**包含，只证一边不算数。
- `N` 是否含 `0` 视约定而定；本书取含 `0`。
- "`A ⊆ ∅`"只在 `A = ∅` 时成立，别与"`∅ ⊆ A` 恒成立"弄反。
