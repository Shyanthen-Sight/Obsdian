## Unit 1　Let's Be Friends!

> [!info] 语法重点：be 动词 + 人称代词主格

### 一、be 动词搭配（背表格）

**人称代词主格（7 个）**：I / you / he / she / it / we / they

| 主语                                    | be 动词 |
| :-------------------------------------- | :------ |
| I                                       | **am**  |
| you（你 / 你们）                        | **are** |
| he / she / it、单数名词、**不可数名词** | **is**  |
| we / they、复数名词、并列主语           | **are** |

- **不可数名词**：water, milk, bread, tea, rice, meat, coffee, fruit, news, health, English

### 二、句型变换（三步走）

1. **否定句**：be 动词后加 not —— He is not / isn't from England.
2. **一般疑问句**：be 动词提到句首 —— Are you Li Ming? — Yes, I am. / No, I'm not.
3. **特殊疑问句**：疑问词 + be + 主语 —— What's your name?（= What is）

- **特殊疑问词**：what 什么 / who 谁（主格）/ whose 谁的 / which 哪一个 / when 何时 / where 何地 / why 为什么（答用 because）/ how 怎样

### 三、并列主语，be 怎么选（三条原则）

| 连接词 / 句型                                        | 原则         | be 跟谁                  |
| :--------------------------------------------------- | :----------- | :----------------------- |
| and、both...and                                      | **并列原则** | 整体当复数 → are / were |
| either...or、neither...nor、not only...but also、or  | **就近原则** | 离 be 最近的             |
| as well as、together with、besides、but、rather than | **就远原则** | 最前面的真主语           |
| there be                                             | **就近原则** | 紧跟 be 的第一个名词     |

**例句（各抄一句）**

- You and I **are** good friends.
- Neither you nor he **is** wrong.
- Tom, as well as his friends, **is** coming.
- There **is** a pen and two books on the desk.

> [!info] 参见
> There be 句型在 **Unit 3** 会完整展开，这里先掌握「就近」这一条。

> [!warning] 易错（红笔标记）
> - 不可数名词作主语一律 is，**in the two bottles / on the plate 只是修饰语**，不能决定 be：The water **in the two bottles is** not enough. ✅
> - be 动词的否定、疑问**不借助 do / does**：He **isn't** happy. ✅　He **doesn't** happy. ❌
> - 主格只作主语（放动词前），不能放动词、介词后。
> - 问句主语 you → 答句换成 I：Are you...? — Yes, **I** am.

## Unit 2　Meet My Family!

> [!info] 语法重点：物主代词 + 名词复数 + 名词所有格

### 一、形容词性物主代词（后面必须接名词）

| 人称 | 形容词性物主代词          |
| :--- | :------------------------ |
| I    | **my**（我的）            |
| you  | **your**（你的 / 你们的） |
| he   | **his**（他的）           |
| she  | **her**（她的）           |
| it   | **its**（它的）           |
| we   | **our**（我们的）         |
| they | **their**（他们的）       |

### 二、名词性物主代词（后面不能再接名词）

| 人称 | 名词性物主代词  |
| :--- | :-------------- |
| I    | **mine**        |
| you  | **yours**       |
| he   | **his**（不变） |
| she  | **hers**        |
| it   | **its**（不变） |
| we   | **ours**        |
| they | **theirs**      |

- **名词性 = 形容词性 + 名词**：This is **my** book. = This book is **mine**.
- **高频句型** `a / an + 名词 + of + 名词性物主代词`：a friend of **mine**、a classmate of **his**.

### 三、名词复数变化

| 规则                                          | 例子                                                                                                                      |
| :-------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------ |
| 一般 + s                                      | book → books                                                                                                             |
| s, x, ch, sh 结尾 + es                        | box → boxes, watch → watches, brush → brushes                                                                          |
| **o 结尾看「生命」**：有生命 + es，无生命 + s | 有生命：tomato → tomatoes, potato → potatoes, hero → heroes；无生命：photo → photos, piano → pianos, radio → radios |
| 辅音字母 + y，变 y 为 i + es                  | baby → babies, family → families                                                                                        |
| f / fe 结尾，变 f / fe 为 v + es              | knife → knives, leaf → leaves, wolf → wolves                                                                           |
| 不规则                                        | child → children, man → men, woman → women, foot → feet, tooth → teeth                                               |

> [!note] 例外
> 不以 f / fe 变 v，直接加 -s：roof → roofs, chief → chiefs, safe → safes

### 四、名词所有格

- **单数名词 + 's**：Tom's book
- **复数以 s 结尾 + '**：the students' classroom
- **复数不以 s 结尾 + 's**：Children's Day
- **两人共有**：只在最后一人加 's —— Lucy and Lily's room
- **各自拥有**：两人后都加 's —— Lucy's and Lily's rooms

> [!warning] 易错（红笔标记）
> - **its**（它的）≠ **it's**（= it is）
> - 妇女节是 **Women's** Day（不是 Woman's）
> - 不用所有格的地方别乱加 's：give flowers to our **teachers** ✅

## Unit 3　Our Colorful School Life

> [!info] 语法重点：可数 / 不可数名词 + There be + 一般现在时

### 一、可数与不可数

- **可数名词**：an apple → two apples
- **不可数名词没有复数**，用量词短语表数量：
  - a glass of water → two **glasses** of water
  - a piece of bread → two **pieces** of bread
- **常见不可数**：water, milk, bread, rice, meat, juice, tea, coffee, money, advice, information, homework

### 二、There be 句型

- **结构**：`There is / are + 主语 + 地点状语`（意为「某地有某物」）
- **就近原则**：be 由紧跟它的第一个名词决定
  - There **is** some milk and two apples on the table.
  - There **are** two apples and some milk on the table.

> [!note] There be 与 have 的区别
> - **There be** = 某地有
> - **have / has** = 某人（物）有

### 三、一般现在时

- **用法**：经常性、习惯性的动作或客观事实。
- **第三人称单数变化**：

| 规则                         | 例子                                     |
| :--------------------------- | :--------------------------------------- |
| 一般 + s                     | work → works, play → plays             |
| s, x, ch, sh, o 结尾 + es    | watch → watches, go → goes, do → does |
| 辅音字母 + y，变 y 为 i + es | study → studies, fly → flies           |
| 元音字母 + y，直接 + s       | play → plays, buy → buys               |
| 不规则                       | have → has, be → is                    |

- **否定 / 疑问借 do / does**：

| 主语                       | 助动词   | 否定句             | 一般疑问句              |
| :------------------------- | :------- | :----------------- | :---------------------- |
| I / you / we / they / 复数 | **do**   | don't + 动词原形   | Do + 主语 + 动词原形?   |
| he / she / it / 单数       | **does** | doesn't + 动词原形 | Does + 主语 + 动词原形? |

> [!tip] 记忆口诀
> **助动词看主语，实义动词回原形——does / doesn't 一出现，后面动词变成原形。**

## Unit 4　Fun in the Sun!

> [!info] 语法重点：人称代词宾格 + 现在进行时

### 一、人称代词（主格 → 宾格）

| 主格 | 宾格     |
| :--- | :------- |
| I    | **me**   |
| you  | **you**  |
| he   | **him**  |
| she  | **her**  |
| it   | **it**   |
| we   | **us**   |
| they | **them** |

**用法位置**

| 位置                | 用格 | 例句                          |
| :------------------ | :--- | :---------------------------- |
| 动词后作宾语        | 宾格 | Please help **me**.           |
| 介词后作宾语        | 宾格 | This is for **us**.           |
| be 后作表语（口语） | 宾格 | — Who is it? — It's **me**. |
| 作主语              | 主格 | **He** and **I** are friends. |

### 二、现在进行时

- **构成**：`主语 + am / is / are + 动词-ing + 其他`
- **含义**：此时此刻或现阶段**正在进行**的动作
- **标志词**：now, look, listen, at the moment, right now, these days
- **动词 -ing 变化**：
  - 一般 + ing：play → playing
  - 不发音 e 结尾，去 e + ing：make → making, write → writing
  - 重读闭音节末尾只有一个辅音字母，双写 + ing：run → running, sit → sitting

### 三、不用进行时的状态动词（重要）

| 类别        | 动词                                          | 例句                      |
| :---------- | :-------------------------------------------- | :------------------------ |
| 心理 / 情感 | like, love, hate, want, hope                  | I **like** this song. ✅  |
| 认知 / 感觉 | know, understand, remember, forget, see, hear | I **know** the answer. ✅ |
| 拥有 / 属于 | have（有）, belong to                         | He **has** a new bike. ✅ |

> [!tip] 记忆口诀
> **「喜欢、讨厌、想、知道、看见、听见、有」——状态不是动作，一律不加 -ing。**

> [!warning] 易错（红笔标记）
> - **have 作「有」不用进行时，作「吃、喝、玩」可以用**：We **are having** lunch now. ✅
> - look / listen 在句首是**提醒词**，后面必须用进行时：**Look!** The children **are playing** football.
> - 介词后用宾格：for **you and me** ✅　for you and ❌
> - 主语是复数别漏 are：His parents **are talking**. ✅
