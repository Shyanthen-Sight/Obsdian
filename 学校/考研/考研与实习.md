# 考研与实习双目标规划

> 制定日期：2026-09-15（大二上 · 第 1 周）
> 本人：计算机科学与技术 · 大二上
> 考试时间轴：**考研初试 = 2028 年 12 月** | 大二下 = 2027 年春 | 大二暑假 = 2027 年 7–8 月

---

## 〇、一句话结论

> **两个目标不冲突，但不能同时"用力"。正确做法是：把大二下到暑假用作实习的唯一窗口，大三上开学无条件切回考研主线。**
>
> 底层逻辑：大二到考研还有 **2 年 3 个月**，时间绰绰有余；而实习这件事存在**硬窗口**（大三后就没空实习了），考研不存在窗口限制（随时可以开始，越晚开始越吃亏）。所以先吃掉有窗口限制的那件事。

**三条重要结论：**

1. **两校都考数一 + 英一。** 这是天大的好消息——数学和英语的复习**100% 通用**，你可以到 2028 年 9 月再看情况做最终抉择，前面的投入一点都不浪费。
2. **专业课按西南大学标准准备，等于同时覆盖重邮。** 808 = 数据结构 + 操作系统，802 = 数据结构。按 808 复习，两校通吃，还保留了以后换学校的自由度。
3. **重邮的自命题是双刃剑。** 只考一门数据结构，看起来轻松，但正因为吸引了一批"不想考 408"的考生，2026 年学硕线 264、专硕线 330 的落差说明**报考热度波动极大**。不要把 264 当成你的目标，**初试目标定 340+**。

> ⚠️ 分数线数据来自考研机构与资讯网站汇总，机构口径存在出入（如同一年份 260 / 308 两个版本），**备考前必须去重邮研究生院官网（yjs.cqupt.edu.cn）拉近三年真题与录取名单核对**。

## 二、冲突分析：到底哪里会打架

### 2.1 结论先行

| 时间段               | 是否冲突        | 原因                         |
| ----------------- | ----------- | -------------------------- |
| 大二上（现在）           | ❌ 不冲突       | 考研还没启动，实习还没开始，两个目标都需要"打地基" |
| 大二下（2027 春）       | ⚠️ 轻度冲突     | 只有一种情况会冲突：专业课挂科 / 绩点崩盘     |
| 大二暑假（2027.7–8）    | ⚠️ 轻度冲突     | 可能挤掉考研基础阶段的 2 个月（影响可控）     |
| **大三上（2027.9 起）** | 🔴 **严重冲突** | 这是考研全科铺开的黄金期，任何实习都会致命      |
| 大三下 / 大四上         | 🔴 **不可调和** | 必须二选一，且只能选考研               |

**所以真正的问题不是"要不要实习"，而是"实习必须在大三上开学前 100% 结束"。**

### 2.2 五个被低估的冲突点（深度分析）

#### ① 最大的冲突不在"时间"，而在"心态惯性"

实习留下的真实伤害不是占用的那两个月，而是：**拿到工资、被同事叫"同学"、熟悉了工作节奏之后，很难再回到自习室坐 10 小时。** 社区里大量"边实习边考研"失败的案例，都是败在这一条，不是败在时间不够。

**应对：** 实习开始前就和家里、和自己讲清楚——这是**一次性体验**，不是职业转向。8 月底离职是不可谈判的硬约束。

#### ② 保研的诱惑会悄悄偷走你的两年

双非院校推免比例通常 **1%–3%**（少数专业更少）。如果你现在的成绩排名不在**专业前 5%**，请**立刻放弃保研幻想**，把全部精力投向考研。摇摆两年"我要不要冲保研"，最后大概率两头空——保研要绩点+竞赛+科研三条腿，和考研、实习的用力方向完全不同。

**行动：** 这周就去教务处查你们专业近三年的推免名额和最低排名，把数字写在这条笔记下面。

#### ③ 培养方案会决定你的冲突强度（必须核实）

**去教务处查你们 2026 级（或你所在年级）的培养方案，重点看大二下开了哪些课：**
- 如果大二下同时有**操作系统 + 计算机组成原理 + 概率论** → 冲突强度 🔴 高，实习必须压到暑假，学期内不动
- 如果大二下以选修课为主 → 冲突强度 🟢 低，可以学期内做兼职实习

#### ④ 大厂暑期实习"不招大二"是硬门槛

腾讯、华为等大厂的暑期实习**明确要求毕业年份**（如 2028 届、2029 届），大二基本被筛掉。你能投的是：
- **日常实习**（全年滚动、门槛低、看重"及时到岗"）
- **小厂 / 中厂 / 本地公司**（更愿意带低年级）
- **远程实习 / 导师横向项目**（含金量看能不能讲出东西）

**这反而是好事——它把目标二的期望值锚定在合理位置，不会让你为了"大厂"三个字投入超额的准备时间。**

#### ⑤ 大二实习其实是考研的**对冲**，不是对立面

如果考研失败（客观概率存在），一份大二+大三的实习经历能让你走春招时**不至于裸奔**。反过来，考研失败且零实习零项目，才是真正的困境。

**所以目标二的定位应该是：低成本保险，不是第二事业。**

## 三、目标一：考研规划（篇幅更长，因为它是首选）

### 3.1 择校策略：把"重邮"当主攻，"西南大学"当期权

```
梯度设计
├─ 主攻（80% 精力）：重庆邮电大学 计算机科学与技术（学硕）
│   └─ 理由：招生规模大（~170人）、自命题只有数据结构一门、
│            重庆本地就业认可度高（通信+计算机交叉）、上岸概率最高
├─ 进阶（按 100% 标准准备，自然覆盖）：西南大学 计信院
│   └─ 理由：数一英一相同 + 808 包含数据结构与操作系统 = 复习内容完全覆盖 802
└─ 保底（不确定时的退路）：重邮专硕 085404 / 本校
    └─ 注意：重邮专硕 2026 线 330，比学硕难，别默认"专硕好考"
```

**关键决策点：2028 年 9 月（大四上开学）前必须敲定学校。** 在那之前，数学、英语、数据结构、操作系统全都通用，不必焦虑。

### 3.2 分阶段规划

#### 🟢 阶段 0：大二上（2026.09 – 2027.01）——地基期

| 科目 | 具体任务 | 验收标准 |
|---|---|---|
| 校内课程 | 数据结构、高数、线代、离散**必须 85+** | GPA 稳住，为可能的保研留后路 |
| 数据结构 | 不只是应付考试：手写链表/栈队列/二叉树/图/八大排序 | 能白板写出代码 + 分析复杂度 |
| 英语 | 每天 30 min：背单词（词汇量 5500 目标）+ 每周精读 1 篇外刊 | 期末前词汇量 ≥ 4000 |
| 项目 | 做 **1 个能写进简历的工程项目** | 有 Git 仓库、README、能跑起来、能讲清架构 |

> 💡 数学建模的那套 MATLAB 能力不要丢，它是很好的复试谈资，但**不能作为唯一的项目**——技术岗面试官想看的是软件工程能力，不是建模脚本。

#### 🟡 阶段 1：寒假（2027.01 – 2027.02）——启动期

- 定下技术方向（**建议后端 Java/Go 或测试开发**，理由见 4.2）
- 背单词进入第二阶段（考研核心词 5500）
- 做出**第一版简历**（哪怕只有项目 + 竞赛 + 课程）
- 开始 LeetCode：目标寒假结束刷完 **Hot 100 中的简单+中等**

#### 🟠 阶段 2：大二下（2027.02 – 2027.07）——双线并行期

| 线 | 任务 |
|---|---|
| 实习线 | 3–5 月为投递高峰（4–5 月集中投、6 月面试多）；优先重庆本地日常实习 |
| 学业线 | 专业课一节都不能松，尤其**操作系统**（西南大学 808 的考点）|
| 考研线 | 只做两件事：**英语单词不断 + 数学跟着校内课学扎实**，不启动系统复习 |

#### 🔴 阶段 3：大三上（2027.09 – 2028.01）——**全面转入考研**

| 科目 | 任务 |
|---|---|
| 数学一 | 一轮基础走完（高数 + 线代 + 概率论），跟一位老师全程 |
| 专业课 | 数据结构二轮深化 + 操作系统（覆盖 808，顺带覆盖 802） |
| 英语一 | 单词第三轮 + 长难句 + 早年真题阅读 |
| 政治 | 不启动（大四上再开始，永远不晚） |
| 实习 | **止损：完全清零**，最多保留远程/周末的零星任务 |

#### 🔥 阶段 4-6：大三下 → 大三暑假 → 大四上（2028.02 – 2028.12）

- **大三下**：数学强化（660/1000 题）+ 专业课强化 + 英语真题精做
- **大三暑假**：全科冲刺，真题套卷，专业课背诵
- **大四上**：9 月核对最新招生简章（**重点看 802/808 是否改考 408**）、10 月报名、11–12 月模考、12 月应试

### 3.3 目标分数设定

| 科目 | 目标分 | 说明 |
|---|---|---|
| 数学一 | 110–125 | 决定成败的一科 |
| 英语一 | 65–75 | 单词量是唯一变量 |
| 政治 | 65–70 | 后期投入即可 |
| 专业课（802/808） | 120–130 | 自命题有规律，真题为王 |
| **总分** | **340–360** | 高于重邮近年录取均分，留出波动余量 |

## 四、目标二：大二下实习规划

### 4.1 定位：一次"低成本、高信息量"的探索

**目的不是转正、不是赚钱、不是攒大厂 title**，而是三件事：
1. 确认自己喜不喜欢上班（这个信息**只有做过才知道**）
2. 把简历从"零实习"变成"有一段实习"
3. 为考研失败留一条退路

### 4.2 方向选择：选和考研重叠度最高的

| 方向 | 与考研重叠度 | 推荐度 |
|---|---|---|
| **后端开发（Java / Go）** | 高（操作系统、网络、数据结构全是考点） | ⭐⭐⭐⭐⭐ |
| **测试开发** | 中高（八股偏软，门槛相对低） | ⭐⭐⭐⭐ |
| 客户端 / 前端 | 低（八股方向与考研关系小） | ⭐⭐ |
| 算法 / AI | 极高但门槛极高（大二基本不可能） | ⭐ |

> **原则：实习准备过程本身要能反哺考研。** 后端方向的八股（操作系统、计算机网络、数据库）和数据结构算法题，和 802/808 的考点是同一批知识。

### 4.3 投递战术（时间线精确到月）

```
2027.02 – 2027.03  简历定稿（1 项目 + 建模竞赛 + 课程）
                   开始投递重庆本地中小厂练手
2027.04 – 2027.05  集中投递窗口（岗位最多、反馈最好）
                   BOSS直聘 / 实习僧 / 牛客 / 官网 / 学校就业网
2027.06           面试密集期（小厂练手 → 中厂正式）
2027.06 底 – 07 初 入职
2027.07 – 2027.08  在职（约 6–8 周）
2027.08.31         硬性离职线 ← 不可谈判
2027.09            回到学校，考研模式启动
```

**投递渠道优先级：**
1. 学校就业网 / 学院实习群（**最高优先级**，竞争者仅为同校同学）
2. 导师 / 学长学姐内推（效率最高）
3. 重庆本地企业直投（腾讯云智研发在重庆有日常实习批次，实习薪资 4000–6000 元/月区间；此外渝北、两江新区软件企业密集）
4. BOSS 直聘 / 实习僧（海投，做好被无视的准备）
5. 远程实习（无本地机会时的兜底）

**心态校准：** 大二投 100 份收 3 个面试是正常水平，收到 1 个日常实习 offer 就算成功。**别把"进大厂"设为成功标准。**

### 4.4 止损规则（写死，不许讨价还价）

| 触发条件 | 动作 |
|---|---|
| 8 月 31 日 | 无条件离职，不接续期、不接长期兼职 |
| 大三上开学后 | 清零所有工作，最多保留远程零星任务 |
| 实习期间 | 每天必须保持 30 min 英语 + 数学不断档 |
| 如果要"转正" | 直接拒绝——你的主线是考研，不是这份工作 |
| 如果实习严重挤压学期课程 | 学期内立即停，只保留暑假档 |

## 八、核心原则（贴在墙上）

1. **考研是主线，实习是保险。** 任何时候两者冲突，砍实习。
2. **大二不二选一，只做重叠部分。** 数学 + 数据结构 + 英语 + 一个项目，四项对两个目标都有用。
3. **实习的窗口期在大三上之前，考研的窗口期在毕业之前。** 先吃有窗口的那件事。
4. **数一英一通用 → 选校可以拖到 2028 年 9 月。** 不要现在纠结学校，现在纠结的每一年都是浪费。
5. **8 月 31 日是硬线。** 写在这里，就是用来防止未来的自己讨价还价的。
