# Unit 6 Data Reports: Charts 图表数据报告 —— 知识点精讲与分析

> 对应书中第 111–144 页。三个部分：曲线图 Curve Charts、柱状图 Bar Charts、饼状图 Pie Charts。核心训练点：数据报告三段结构、改写四法、趋势描述句型、main clause + explanatory information、约数/倍数/分数、cautious words、时态选择。

---

## 一、单元定位

图表作文（data report）不是把图表数字挨个抄一遍，而是**把数据读成一个故事**：总体趋势是什么、主要特征有哪些、原因和启示是什么。本单元是全教材语言密度最高的单元之一。

通用三段结构（三种图都适用）：
- **Introduction**：图表基本信息 + overall trend（总体趋势）；
- **Body**：按对象/曲线分若干段，每段 topic sentence + supportive specifics（细节数据）；
- **Conclusion**：major features——findings / causes / implications / predictions，不重复数字、不举例。

---

## 二、PART 1 Curve Charts 曲线图（第 112–125 页）

### 1. 认知
曲线图展示某事物**随时间的动态变化**（上升、下降、波动、峰值）。

### 2. 写作技巧
- **写引言段**：先把坐标轴/标题信息改写成一句，再给 overall trend；
- **改写四法（Rephrasing）**：①同义词/反义词替换；②写得更概括或更具体；③短语↔从句互转；④改变词性；
- **总体趋势句**：一句话点出共同特征 + 例外/附加信息；
- **Body 段落**：topic sentence + supportive specifics；
- **写结论**：简述 findings / causes / implications / predictions。

### 3. 核心句式：main clause + explanatory information
主句之后用从句/名词短语/V-ing短语/介词短语/形容词短语**解释主句**，而不是给新信息。这是让报告句子"有层次"的关键结构。

### 4. 表达工具

**基本信息句型**：
- The curve chart shows / presents / displays / demonstrates… over the period from… to…
- The bar chart illustrates…
- The pie chart presents the proportion / ratio / percentage / distribution of…
- The table gives a breakdown / distribution of…

**趋势描述两套句型**：
- There be + Adj. + Noun + Prep.(value) + Prep.(time)
  - 形容词：slow / slight / gentle / gradual / stable / moderate / dramatic / sudden / quick / sharp / significant / considerable / consistent
  - 名词：decline / decrease / drop / fall / increase / rise / climb / peak / level-off / bottom
- Subject + Verb + Adv. + Prep.
  - 例：declined gradually to… / increased dramatically to…

**因果路标（Cause-and-effect Signposts）**：
- 副词：thus / hence / consequently / therefore / accordingly
- 名词：consequence / reason / result
- 动词：cause / lead / attribute
- 介词：because of / due to
- 连词：since / for

### 5. 范文解析
Monthly Income Received by Males and Females in City A（2011–2015）完整报告；郊区人口比例（1900 约 12% → 2000 约 52%）；Milk Consumption Per Capita, City B 1991–2001。

### 6. 过程写作任务（Project）
在人事办公室，为 Mr Smith 写过去四周员工每日准时情况 data report（用于月度奖金与制度改进）。Introduction 给 global trend，Body 每段一个典型特征加细节澄清，Conclusion 给 findings/原因/解决方案，≥150 词、Times New Roman。

## 三、PART 2 Bar Charts 柱状图（第 126–133 页）

### 1. 认知
柱状图专门用于**比较分组数据**，展示主类别下子组的复杂信息。

### 2. Grouping the Data（重点）
写作前先给数据分组，从不同维度找异同、聚焦主要特征、找关键点（最忙/最大/最高）。两种组织方式：
- **按时间分组**：1990 组 / 2010 组，组内按城市比；
- **按对象分组**：City A / B / C，组内按年份比；
即 **group-by-group** 与 **point-to-point** 两种比较模式。

### 3. Approximations 约数（重点）
- about / or so / approximately / more than / less than / around / nearly / almost / just over / just under / well over / well under
- 例：997,625 → nearly one million；about one-third ≈ 33.56%；just over a quarter ≈ 26%。

### 4. 范文解析
Life Expectancy, Okston/Roland/Kasenford（1990 & 2010）：1990 年 Kasenford 最高 72.52，2010 年 Roland 77.64 反超，Okston 增速最快；货运总量柱状图（Railway/Highway/Water/Air，1990/2000/2010）段落排序。

### 5. 过程写作任务（Project）
市场研究员，在线调查本市最受欢迎的三个在线交流网站并分析原因。Introduction 给主题+共同特征，Body 分组组织、按重要性排序、用 group-by-group 或 point-to-point 比较，Conclusion 重述发现+原因+启示+预测，≥150 词。

## 四、PART 3 Pie Charts 饼状图（第 134–144 页）

### 1. 认知
饼状图展示**部分与整体的关系**，是**静态信息**（不像曲线图展示动态变化）。

### 2. 按优先级组织信息
从**最重要 → 较重要 → 最不重要**展开段落，而不是按图上扇形顺序机械描述。

### 3. 多图处理（Dealing with More than One Chart）
两图以上先弄清关系：
- 数据类型相似 → 可互相比较；
- 数据类型不同 → 一图解释/支撑另一图（如 preferred houses vs types lived in vs house price-to-income ratio）。

### 4. Cautious Words 谨慎用词（重点）
避免绝对化断言词：**definitely / clearly / undoubtedly / absolutely / never / should**。改用：
- tend to / be (less) likely to / seem / appear / data show that / suggest
- 用 that / those 指代前文名词避免重复。

### 5. 时态选择（Language Focus，重点）
时态取决于图表所示时间：
- 出现过去年份 → 过去时；
- 出现未来年份 → 将来时；
- 无时间标注 → 一般现在时；
- 引言性表述与作者判断也用现在时。

### 6. 表达工具
表示"占比"的词：**account for / make up / represent / constitute / comprise / occupy**。

### 7. 范文解析
Popular Types of Houses in City A（Semi-detached 30% / Bungalows 25% / Detached 25% / Flats 17% / Terraced 3%）；学生手机品牌双饼图（2010 vs 2012：Nokia 40%→15%、Apple 15%→35%、Samsung 20%→25%、Huawei 15%→10%）；大学生休闲活动双饼图（2002 vs 2012）。

### 8. 过程写作任务（Project）
社会观察者，就父母对"二孩政策"态度做调查，找影响生育二孩决定的主要因素，小组合作写 data report，建两张以上图表。自查六问：段落连贯、按优先级、细节澄清、cautious 词、因果表达、定语从句避免重复；≥150 词、Times New Roman、single-spaced。

## 五、单元速记卡

| 要点 | 关键内容 |
|------|----------|
| 三段结构 | Introduction(基本信息+总趋势)→Body(topic sentence+细节)→Conclusion(findings/原因/启示) |
| 改写四法 | 同义替换 / 概括具体化 / 短语从句互转 / 改变词性 |
| 趋势句型 | There be + 形+名+介词时间；或 主+动+副+介词 |
| 曲线图 | 随时间动态变化 |
| 柱状图 | 分组比较，group-by-group 或 point-to-point |
| 饼状图 | 部分与整体，静态，按优先级排序 |
| 约数 | nearly / approximately / just over / well under… |
| 占比词 | account for / make up / represent / constitute / comprise |
| 谨慎词 | tend to / seem / appear / suggest，避免 definitely |
| 时态 | 过去年用过去时，未来年用将来时，无时间用现在时 |
