
# 双绞线（Twisted Pair，TP）

### 一、双绞线基础定义

双绞线把**两根绝缘铜导线两两绞合**在一起的传输线缆，绞合结构**抵消电磁干扰**，是局域网最主流布线

双绞线分为外部**有屏蔽双绞线**和**无屏蔽双绞线**

**STP 屏蔽双绞线（sheilded TP）

线外包裹金属屏蔽箔，抗强电磁干扰，工厂、高压设备旁才用，成本高

**UTP 非屏蔽双绞线（Unshield TP）

无金属屏蔽层，造价低、易施工，机房、家用、校园网全用这个

    cat=category(级别)
- Cat3（三类）：老式百兆，现在淘汰
- Cat5（五类）：最高 100Mbps
- Cat5e（超五类）：主流百兆 / 千兆
- Cat6（六类）：稳定千兆，支持短距离万兆
- Cat6a（超六类）：万兆稳定长距离

### 二、结构

一根成品网线里有**4 对双绞线**（8 根芯线）：

橙白 - 橙、绿白 - 绿、蓝白 - 蓝、棕白 - 棕，对应水晶头 T568A/T568B 线序

- T568B（日常通用接法）：橙白、橙、绿白、蓝、蓝白、绿、棕白、棕

- T568A：绿白、绿、橙白、蓝、蓝白、橙、棕白、棕


# 光纤（Optical Fiber）

- **传输原理**：以光信号传递数据，核心是纤芯 + 包层，利用光的全反射传导光束。
- **分类**
    
    - 单模光纤Single-Mode Fiber（SMF）：
         芯细，激光光源，传输距离远、速率高，多用于主干长距离通信；
    - 多模光纤Multi-Mode Fiber（MMF）：
         芯粗，LED 光源，距离短，多用于楼宇、机房内网。
    
- **核心优势**
    
    **完全不受电磁干扰**、信号衰减小、带宽极高、无漏电窃听风险；
    
- **缺点**
    
    质地脆易折断，切割熔接工艺复杂，成本高于双绞线；
    
- **适用场景**：跨城骨干网、机房长距离高速互联、宽带入户。

# 同轴电缆（Coaxial Cable）

1. **结构**：中心铜芯导线→绝缘层→金属屏蔽网→外层保护皮，同心同轴结构。
2. **传输信号**：电信号，屏蔽层大幅抵御电磁干扰。
3. **两类规格**

- 粗同轴（10BASE5）：传输距离长，早期以太网主干，笨重昂贵；
- 细同轴（10BASE2）：布线轻便，老式局域网总线拓扑。

4. **优缺点**
    
    优势：抗干扰比普通双绞线强；
    
    劣势：布线不灵活、成本偏高、现在基本被双绞线、光纤淘汰。
5. **现存用途**：有线电视（闭路电视 CATV）、部分射频监控线路。
