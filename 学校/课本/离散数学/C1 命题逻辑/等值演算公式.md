## 零、先分清三种符号

| 符号  | 名称      | 属于哪一层             | 含义                          |
| :-: | :------ | :---------------- | :-------------------------- |
| `↔` | 等价联结词   | **对象语言**（公式内部的运算） | A ↔ B 本身是一个命题公式，有真值         |
| `⇔` | 等值（等价式） | **元语言**（公式之间的关系）  | A ↔ B 是**重言式**，读作"A 与 B 等值" |
| `⇒` | 重言蕴含    | **元语言**           | A → B 是**重言式**，读作"A 重言蕴含 B" |

**定义**：设 A、B 为命题公式，若 A ↔ B 是重言式，则称 A 与 B **等值**，记作 A ⇔ B。

**判断两式等值的三条路**：真值表法（A ↔ B 全为 1）｜等值演算法（用本页公式推）｜主范式法（主析取范式完全相同）。

**运算符优先顺序**：`¬` > `∧` > `∨` > `→` > `↔`；同级左结合，但 `→` 习惯按右结合理解；拿不准就加括号。

## 一、等值演算的两条规则

1. **代入规则**：若 A ⇔ B，把 A、B 中某个命题变元**处处**用同一个公式 C 替换，所得两式仍等值。
   （"处处"是关键词：不能只换一处。）
2. **替换规则（置换规则）**：若 A ⇔ B，而公式 C 中含有子公式 A，把 C 中 A 的**某些出现**（不必全部）替换为 B 得 C′，则 C ⇔ C′。

> 一句话区分：**代入换变元、必须全换；替换换子式、可以只换一处。**

## 二、==16 组基本等值式==

### 2.1 与 ¬、∧、∨ 有关的（第 1–11 组）

|  #  | 名称       | 等值式                                                               |
| :-: | :------- | :---------------------------------------------------------------- |
|  1  | 双重否定律    | ¬¬A ⇔ A                                                           |
|  2  | 幂等律      | A ∨ A ⇔ A ； A ∧ A ⇔ A                                             |
|  3  | 交换律      | A ∨ B ⇔ B ∨ A ； A ∧ B ⇔ B ∧ A                                     |
|  4  | 结合律      | (A ∨ B) ∨ C ⇔ A ∨ (B ∨ C) ； (A ∧ B) ∧ C ⇔ A ∧ (B ∧ C)             |
|  5  | 分配律      | A ∨ (B ∧ C) ⇔ (A ∨ B) ∧ (A ∨ C) ； A ∧ (B ∨ C) ⇔ (A ∧ B) ∨ (A ∧ C) |
|  6  | ==德摩根律== | ¬(A ∨ B) ⇔ ¬A ∧ ¬B ； ¬(A ∧ B) ⇔ ¬A ∨ ¬B                           |
|  7  | 吸收律      | A ∨ (A ∧ B) ⇔ A ； A ∧ (A ∨ B) ⇔ A                                 |
|  8  | 零律       | A ∨ 1 ⇔ 1 ； A ∧ 0 ⇔ 0                                             |
|  9  | 同一律      | A ∨ 0 ⇔ A ； A ∧ 1 ⇔ A                                             |
| 10  | 排中律      | A ∨ ¬A ⇔ 1                                                        |
| 11  | 矛盾律      | A ∧ ¬A ⇔ 0                                                        |

### 2.2 与 →、↔ 有关的（第 12–16 组）

|  #  | 名称      | 等值式                       |
| :-: | :------ | :------------------------ |
| 12  | 蕴含等值式   | A → B ⇔ ¬A ∨ B            |
| 13  | 等价等值式   | A ↔ B ⇔ (A → B) ∧ (B → A) |
| 14  | 假言易位    | A → B ⇔ ¬B → ¬A           |
| 15  | 等价否定等值式 | A ↔ B ⇔ ¬A ↔ ¬B           |
| 16  | 归谬论     | (A → B) ∧ (A → ¬B) ⇔ ¬A   |

> **结构性提示**：第 2–11 组中每个"∨ 版"和"∧ 版"互为**对偶**（见第四章），所以真正要记的只有 10 条；第 12–16 组是 5 条。合计 16 组。

### 2.3 常元 0 / 1 的边角公式

- ¬0 ⇔ 1，¬1 ⇔ 0
- A → 0 ⇔ ¬A，A → 1 ⇔ 1，0 → A ⇔ 1，1 → A ⇔ A
- A ↔ 1 ⇔ A，A ↔ 0 ⇔ ¬A，1 ↔ A ⇔ A，0 ↔ A ⇔ ¬A
- A → A ⇔ 1，A ↔ A ⇔ 1
- 0 ∨ A ⇔ A，1 ∧ A ⇔ A（同一律的另一半）

## 三、由基本等值式导出的常用公式

| 名称 | 等值式 |
|:---|:---|
| 蕴含的否定 | ¬(A → B) ⇔ A ∧ ¬B |
| 蕴含的多种形态 | A → B ⇔ ¬A ∨ B ⇔ ¬B → ¬A ⇔ ¬(A ∧ ¬B) |
| 等价的多种形态 | A ↔ B ⇔ (A → B) ∧ (B → A) ⇔ (A ∧ B) ∨ (¬A ∧ ¬B) ⇔ (¬A ∨ B) ∧ (A ∨ ¬B) |
| 等价的否定 | ¬(A ↔ B) ⇔ A ↔ ¬B ⇔ ¬A ↔ B ⇔ (A ∧ ¬B) ∨ (¬A ∧ B) |
| 蕴含对 ∧ 的分配 | A → (B ∧ C) ⇔ (A → B) ∧ (A → C) |
| 蕴含对 ∨ 的分配 | A → (B ∨ C) ⇔ (A → B) ∨ (A → C) |
| 前件为 ∨ | (A ∨ B) → C ⇔ (A → C) ∧ (B → C) |
| 前件为 ∧ | (A ∧ B) → C ⇔ A → (B → C) |
| 输出律 / 输入律 | A → (B → C) ⇔ (A ∧ B) → C |
| 吸收变体 ① | A ∨ (¬A ∧ B) ⇔ A ∨ B |
| 吸收变体 ② | A ∧ (¬A ∨ B) ⇔ A ∧ B |
| 德摩根推广 | ¬(A₁ ∨ … ∨ Aₙ) ⇔ ¬A₁ ∧ … ∧ ¬Aₙ ； ¬(A₁ ∧ … ∧ Aₙ) ⇔ ¬A₁ ∨ … ∨ ¬Aₙ |
| 分配律推广 | A ∨ (B₁ ∧ … ∧ Bₙ) ⇔ (A ∨ B₁) ∧ … ∧ (A ∨ Bₙ) ； A ∧ (B₁ ∨ … ∨ Bₙ) ⇔ (A ∧ B₁) ∨ … ∨ (A ∧ Bₙ) |
| 幂等推广 | A ∨ A ∨ … ∨ A ⇔ A ； A ∧ A ∧ … ∧ A ⇔ A |

## 四、对偶原理

**对偶式**：设公式 A 中只含 `¬`、`∧`、`∨`、`0`、`1`，把 `∧` 与 `∨` 互换、`0` 与 `1` 互换（变元与 `¬` 不动），所得公式 A\* 称为 A 的对偶式。

| 定理 | 内容 |
|:---|:---|
| 定理一（等值式成对） | 若 A ⇔ B，则 A\* ⇔ B\* |
| 定理二（对偶与否定） | ¬A(p₁, …, pₙ) ⇔ A\*(¬p₁, …, ¬pₙ) |

**用途**：第二章 2–11 组中每组的左右两行互为对偶——记住一行就能免费得到另一行（"∨ 换成 ∧、0 换成 1"）。

## 五、与主范式相关的公式

- **互补关系**：¬mᵢ ⇔ Mᵢ，¬Mᵢ ⇔ mᵢ，mᵢ ⇔ ¬Mᵢ（同下标）。
- **极小项两两互斥**：mᵢ ∧ mⱼ ⇔ 0（i ≠ j）；**极大项两两互斥**：Mᵢ ∨ Mⱼ ⇔ 1（i ≠ j）。
- **全体极小项析取为真**：⋁ᵢ mᵢ ⇔ 1；**全体极大项合取为假**：⋀ᵢ Mᵢ ⇔ 0。
- **由主析取范式写主合取范式**（下标互补）：若 A ⇔ ⋁_{i∈I} mᵢ，则 A ⇔ ⋀_{j∉I} Mⱼ。
- **三类公式的判定**：

| 公式类型 | 等值刻画 | 主范式刻画 |
|:---|:---|:---|
| 重言式 | A ⇔ 1 | 主析取范式含**全部** 2ⁿ 个极小项 |
| 矛盾式 | A ⇔ 0 | 主合取范式含**全部** 2ⁿ 个极大项 |
| 可满足式 | A ⇏ 0 | 主析取范式至少含 1 个极小项 |
| A 与 B 等值 | A ↔ B ⇔ 1 | A、B 的主析取范式**完全相同** |

## 六、联结词完备集

**完备集**：能表示所有命题公式的联结词集合。

- 常见完备集：`{¬, ∧}`、`{¬, ∨}`、`{¬, →}`、`{↑}`（与非）、`{↓}`（或非）。
- **与非**：A ↑ B ⇔ ¬(A ∧ B)；**或非**：A ↓ B ⇔ ¬(A ∨ B)。
- 用单一联结词表示：

| 目标 | 用 ↑（与非）表示 | 用 ↓（或非）表示 |
|:---|:---|:---|
| ¬A | A ↑ A | A ↓ A |
| A ∧ B | ¬(A ↑ B) ⇔ (A ↑ B) ↑ (A ↑ B) | (A ↓ A) ↓ (B ↓ B) |
| A ∨ B | (A ↑ A) ↑ (B ↑ B) | ¬(A ↓ B) ⇔ (A ↓ B) ↓ (A ↓ B) |

- ⚠️ `{∧, ∨}` **不是**完备集（无法表示 ¬）。

## 七、单向蕴含式

| 名称    | 推理定律                                    |
| :---- | :-------------------------------------- |
| 附加    | A ⇒ A ∨ B                               |
| 化简    | A ∧ B ⇒ A                               |
| 假言推理  | A ∧ (A → B) ⇒ B                         |
| 拒取式   | ¬B ∧ (A → B) ⇒ ¬A                       |
| 析取三段论 | ¬A ∧ (A ∨ B) ⇒ B                        |
| 假言三段论 | (A → B) ∧ (B → C) ⇒ A → C               |
| 等价三段论 | (A ↔ B) ∧ (B ↔ C) ⇒ A ↔ C               |
| 构造性二难 | (A → B) ∧ (C → D) ∧ (A ∨ C) ⇒ B ∨ D     |
| 破坏性二难 | (A → B) ∧ (C → D) ∧ (¬B ∨ ¬D) ⇒ ¬A ∨ ¬C |

> 这些是**重言蕴含**，只保证一个方向（前件为真时后件必真），反向不一定成立，**不能写成 ⇔**。这是本章最常见的扣分点。

## 八、一页速记

**16 组清单**：双重否定 · 幂等 · 交换 · 结合 · 分配 · 德摩根 · 吸收 · 零律 · 同一律 · 排中 · 矛盾 · 蕴含等值 · 等价等值 · 假言易位 · 等价否定 · 归谬论。

**记忆钩子**：

- **德摩根**："否定进去，∨ ∧ 互换"。
- **分配律**："∨ 对 ∧ 可分配，∧ 对 ∨ 也可分配"——这点与算术不同（算术里只有乘法对加法分配）。
- **蕴含**：A → B 记作"¬A 或 B"；它的否定是"A 且 ¬B"（不是"¬A 或 B"）。
- **假言易位**：即"原命题与其逆否命题等值"。
- **对偶**：每条 ∨ 定律免费附赠一条 ∧ 定律，只需记住一半。
- **常错**：把 `⇔`（等值，双向）与 `⇒`（蕴含，单向）混用；把 `↔` 写进等值演算的推演链里当元符号用。
