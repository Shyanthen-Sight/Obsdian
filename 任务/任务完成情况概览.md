# 未完成任务

> 自动汇总 每日任务 与 每周安排 文件夹中所有未完成的任务（不含 templates 中的任务模板）

```tasks
not done
(path includes 每日任务) OR (path includes 每周安排)
path does not include templates
sort by path
group by filename
```
---
# 最近完成

> 最近 20条完成记录（每日任务 + 每周安排），按完成时间倒序

```tasks
done
(path includes 每日任务) OR (path includes 每周安排)
path does not include templates
sort by done reverse
limit to 20
```
