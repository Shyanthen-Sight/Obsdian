# 测试

容器化项目最容易出现的测试问题是“本地 mock 通过，真实依赖挂掉”：Mock 的 PostgreSQL 不会校验 SQL 方言，内存版 Redis 不支持你用的 Lua 脚本，消息队列的确认语义也和假实现不一样。把依赖换成真容器，能提前暴露这类差异。

单元测试不必进容器，它们该在几百毫秒内跑完，依赖纯函数和接口。容器主要解决集成测试和端到端测试里的“真实依赖”和“环境一致”。

## Testcontainers

Testcontainers 在测试进程里管理容器生命周期：用例开始时拉镜像、启动、拿到随机端口，结束时销毁。以 Node 为例：

```js
import { PostgreSqlContainer } from '@testcontainers/postgresql';

let pg;
beforeAll(async () => {
  pg = await new PostgreSqlContainer('postgres:16-alpine')
    .withDatabase('app_test')
    .withUsername('app')
    .withPassword('app')
    .start();
  process.env.DATABASE_URL = pg.getConnectionUri();
}, 60_000);

afterAll(async () => {
  await pg?.stop();
});
```

`getConnectionUri()` 返回带随机宿主端口的连接串，多个测试文件并行也不会撞端口。首次启动要等镜像拉取和初始化，超时给足。本地反复跑可以加 `.withReuse()`，CI 里别开，避免状态残留。Ryuk 容器负责在测试进程异常退出后清理，别把它随便关掉。

Java 的 JUnit 5、Python 的 testcontainers-python、Go 的 testcontainers-go 都是同一套思路，区别只在容器对象的声明方式。

## compose 起一套集成环境

依赖多、启动顺序复杂时，compose 更直观：

```yaml
services:
  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_PASSWORD: test
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U postgres"]
      interval: 2s
      timeout: 3s
      retries: 20
  redis:
    image: redis:7-alpine
  test:
    build: .
    depends_on:
      db:
        condition: service_healthy
      redis:
        condition: service_started
    environment:
      DATABASE_URL: postgres://postgres:test@db:5432/postgres
      REDIS_URL: redis://redis:6379
    command: npm run test:integration
```

跑的时候用独立项目名，避免污染开发环境：

```bash
docker compose -p ci -f compose.test.yaml up \
  --build --abort-on-container-exit --exit-code-from test
docker compose -p ci -f compose.test.yaml down -v
```

`--abort-on-container-exit` 让任一容器退出就停整套，`--exit-code-from test` 把测试容器的退出码当作命令退出码，CI 才能判断红绿。`-p ci` 隔离网络和卷，`down -v` 清数据卷；不清理的话，下次可能读到残留。

## 怎么选

Testcontainers 适合“测试代码自己声明依赖”，生命周期跟着测试框架走，本地和 CI 行为一致，代价是每个进程都要管容器。compose 适合“一整套服务一起起”，配置直观，但清理和退出码要自己处理，并行时容易抢端口。

两种方式都要固定版本，`postgres:16-alpine` 而不是 `latest`。数据库初始化用 migration 而不是 dump，测试才和部署一致。要更快的隔离可以把数据目录放 `tmpfs`，但别拿它测持久化。
