# 空值谓词 —— `IS NULL` / `IS NOT NULL`

> [!abstract] 一句话
> `IS NULL` / `IS NOT NULL` 是==**唯一可靠的判空方式**==，结果永远是 `TRUE` 或 `FALSE`，不会返回 `UNKNOWN`。
> 记住一条：==**`= NULL` 永远查不出数据**==，因为任何与 NULL 的普通比较都是 UNKNOWN。

> [!info] 与其它笔记的分工
> 普通比较见 [[比较谓词]]；NULL 安全相等 `<=>` 见 [[安全等于]]。
> 本篇系统讲 NULL 的语义、判空写法、NULL 在聚合/排序/分组/约束中的行为。

---

## 一、NULL 是什么

> [!danger] NULL 不是 0，也不是空字符串
> `NULL` 表示"**未知 / 没有值**"。
> - `0` 是一个确定的数值；
> - `''` 是一个确定的空字符串；
> - `NULL` 是"不知道有没有值"。

```sql
SELECT NULL = 0;      -- NULL（UNKNOWN，不是 0）
SELECT NULL = '';     -- NULL（UNKNOWN）
SELECT NULL = NULL;   -- NULL（UNKNOWN，不是 1）
SELECT NULL + 1;      -- NULL
SELECT CONCAT('a', NULL); -- NULL（整个结果变 NULL）
```

> [!important] 三值逻辑
> 任何与 NULL 参与的算术或普通比较，结果都是 **UNKNOWN**。
> `WHERE` 只保留 TRUE，所以 NULL 行在大多数条件里会**静默消失**。

---

## 二、正确的判空写法

```sql
-- ✅ 唯一可靠的两种写法
SELECT * FROM student WHERE name IS NULL;
SELECT * FROM student WHERE name IS NOT NULL;

-- ✅ MySQL 函数形式（等价于 IS NULL）
SELECT * FROM student WHERE ISNULL(name);

-- ✅ NULL 安全等于（等价于 IS NULL）
SELECT * FROM student WHERE name <=> NULL;
```

```sql
-- ❌ 永远 Empty set，哪怕表里真有 name 为 NULL 的行
SELECT * FROM student WHERE name = NULL;
SELECT * FROM student WHERE name <> NULL;
SELECT * FROM student WHERE name != NULL;
```

> [!failure] 为什么 `= NULL` 永远为空
> `name = NULL` 对每一行都求值为 UNKNOWN；`WHERE` 只保留 TRUE，所以一行都不返回。
> 这不是"没有 NULL 行"，而是"**没有任何行能通过这个条件**"。

## 三、NULL 的传播规则

### 3.1 算术与函数

```sql
SELECT 1 + NULL;              -- NULL
SELECT NULL * 0;              -- NULL（不是 0！）
SELECT ABS(NULL);             -- NULL
SELECT UPPER(NULL);           -- NULL
SELECT CONCAT('a', NULL);     -- NULL
SELECT CONCAT_WS('-', 'a', NULL, 'b'); -- 'a-b'（CONCAT_WS 跳过 NULL）
```

> [!warning] `NULL * 0` 不是 0
> 未知值乘以 0，结果仍然是"未知"。
> 聚合函数通常会忽略 NULL，但算术不会。

### 3.2 比较

| 表达式 | 结果 |
| --- | --- |
| `NULL = NULL` | UNKNOWN |
| `NULL <> NULL` | UNKNOWN |
| `NULL > 1` | UNKNOWN |
| `NULL BETWEEN 1 AND 2` | UNKNOWN |
| `NULL LIKE '%'` | UNKNOWN |
| `NULL IN (1, 2)` | UNKNOWN |
| `NULL IS NULL` | **TRUE** |
| `NULL <=> NULL` | **TRUE** |

### 3.3 逻辑运算

| 表达式 | 结果 |
| --- | --- |
| `NULL AND TRUE` | UNKNOWN |
| `NULL AND FALSE` | **FALSE** |
| `NULL OR TRUE` | **TRUE** |
| `NULL OR FALSE` | UNKNOWN |
| `NOT NULL` | UNKNOWN |

> [!tip] 口诀
> **`AND` 遇假即为假，`OR` 遇真即为真**，其余涉及 UNKNOWN 的组合多半还是 UNKNOWN。
> 详见 [[逻辑谓词]] 与 [[计算机类/数据库/Mysql/sql运算符/逻辑运算符|逻辑运算符]]。

## 四、NULL 在聚合函数中的行为

| 函数 | 对 NULL 的处理 |
| --- | --- |
| `COUNT(*)` | 数**所有行**，包括含 NULL 的行 |
| `COUNT(col)` | **不数 NULL**，只数非 NULL 值 |
| `SUM(col)` | 忽略 NULL；全是 NULL 时返回 NULL |
| `AVG(col)` | 忽略 NULL；分母是非 NULL 个数 |
| `MAX(col)` / `MIN(col)` | 忽略 NULL；全是 NULL 时返回 NULL |
| `GROUP_CONCAT(col)` | 忽略 NULL |

```sql
-- 表中有 5 行，其中 2 行 remark 为 NULL
SELECT COUNT(*), COUNT(remark) FROM `order`;
-- COUNT(*) = 5，COUNT(remark) = 3
-- 两者之差 = NULL 行数
```

> [!important] `COUNT(*)` 与 `COUNT(col)` 的差值就是 NULL 行数
> ```sql
> SELECT COUNT(*) - COUNT(remark) AS null_cnt FROM `order`;
> ```
> 这是统计 NULL 数量最直接的写法。

### 4.1 `AVG` 的分母陷阱

```sql
-- salary: 10000, 20000, NULL
SELECT AVG(salary) FROM emp;   -- 15000，不是 10000
```

`AVG` 的分母是**非 NULL 个数（2）**，不是总行数（3）。
如果业务要求"NULL 按 0 算"，必须显式转换：

```sql
SELECT AVG(IFNULL(salary, 0)) FROM emp;   -- 10000
```

> [!warning] 统计口径要先定清楚
> "平均工资"到底排不排除没填工资的人？这是业务问题，不是 SQL 问题。
> 默认的 `AVG` 会排除 NULL，往往和业务预期不一致。

## 五、NULL 在分组、排序、去重中的行为

### 5.1 `GROUP BY`

所有 NULL 会被分到**同一组**：

```sql
SELECT dept_id, COUNT(*) FROM emp GROUP BY dept_id;
-- dept_id 为 NULL 的员工会归为一个 NULL 组
```

### 5.2 `ORDER BY`

MySQL 中 `NULL` 被视为**最小值**：

```sql
SELECT * FROM emp ORDER BY dept_id ASC;
-- NULL 排在最前

SELECT * FROM emp ORDER BY dept_id DESC;
-- NULL 排在最后
```

> [!tip] 想让 NULL 固定排最后
> ```sql
> ORDER BY (dept_id IS NULL), dept_id;
> ```
> `dept_id IS NULL` 为 0/1，先按"是否 NULL"排，再按值排。

### 5.3 `DISTINCT`

`DISTINCT` 把多个 NULL 视为**相同**，只保留一个：

```sql
SELECT DISTINCT dept_id FROM emp;
-- 多个 NULL 只出现一次
```

### 5.4 `UNIQUE` 约束

标准 SQL 中 NULL 不等于 NULL，所以**唯一索引允许多个 NULL**：

```sql
CREATE TABLE t (
    email VARCHAR(100) UNIQUE
);
INSERT INTO t VALUES (NULL), (NULL);   -- ✅ 允许
```

> [!note] 这是特性，不是 bug
> 如果业务要求"NULL 也只能有一个"，需要把列设为 `NOT NULL`，或用其他方式约束。

## 六、NULL 与 `CHECK` 约束

```sql
CREATE TABLE student (
    age INT CHECK (age >= 0)
);
```

插入 `NULL` 会**通过**检查，因为 `NULL >= 0` 是 UNKNOWN，而 `CHECK` 只拒绝 FALSE。

> [!danger] `CHECK` 不会拦住 NULL
> 想禁止 NULL，必须同时写 `NOT NULL`：
> ```sql
> age INT NOT NULL CHECK (age >= 0)
> ```

## 七、把 NULL 转成可比较的值

```sql
SELECT IFNULL(name, '匿名') FROM student;              -- 两参
SELECT COALESCE(name, nickname, '匿名') FROM student;  -- 多参，返回第一个非 NULL
SELECT IF(gender IS NULL, '未知', gender) FROM student;
SELECT NULLIF(gender, '') FROM student;                -- 相等时返回 NULL
```

| 函数 | 作用 |
| --- | --- |
| `IFNULL(a, b)` | `a` 为 NULL 时返回 `b`，否则返回 `a` |
| `COALESCE(a, b, c, ...)` | 返回第一个非 NULL |
| `NULLIF(a, b)` | `a = b` 时返回 NULL，否则返回 `a` |
| `ISNULL(a)` | 判断是否为 NULL，返回 1/0 |

> [!warning] 过滤层不要随便转换
> ```sql
> -- ❌ 索引失效，而且把"未知"和"空串"混为一谈
> WHERE IFNULL(name, '') = ''
> ```
> - **展示层**：可以转，避免前端拿到 `null`；
> - **过滤层**：不要转，直接用 `IS NULL`；
> - **统计层**：先明确口径，再决定 `IFNULL` 还是忽略 NULL。

## 八、NULL 与索引

```sql
-- ✅ 通常可以走索引
SELECT * FROM student WHERE name IS NULL;
SELECT * FROM student WHERE name IS NOT NULL;
```

- B+ 树索引会记录 NULL 值的位置，`IS NULL` 通常可以走索引；
- `IS NOT NULL` 的选择性取决于 NULL 占比，NULL 很少时可能全表更快；
- `col = NULL` 用不上索引，因为它根本不是有效条件（永远 UNKNOWN）。

> [!tip] 复合索引中的 NULL
> 复合索引 `(a, b)` 中，`a IS NULL` 仍可能使用索引；但 `b IS NULL` 单独查询通常用不上（不满足最左前缀）。
> 具体看 `EXPLAIN`。

## 九、常见错误合集

> [!failure] `= NULL` / `<> NULL`
> 永远空集。用 `IS NULL` / `IS NOT NULL`。

> [!failure] `NOT IN` 子查询含 NULL
> 结果必空。见 [[IN谓词]]。

> [!failure] 以为 `COUNT(col)` 会数 NULL
> 它跳过 NULL。用 `COUNT(*)` 或 `COUNT(*) - COUNT(col)` 统计。

> [!failure] 以为 `AVG` 把 NULL 当 0
> 它忽略 NULL，分母是非 NULL 个数。需要按 0 算时用 `IFNULL`。

> [!failure] `CHECK` 能拦住 NULL
> `CHECK` 只拒绝 FALSE，NULL 产生的 UNKNOWN 会通过。要加 `NOT NULL`。

> [!failure] 在过滤条件里用 `IFNULL` 包列
> 索引失效，还混淆语义。判空直接用 `IS NULL`。

> [!failure] 拼接字符串时忽略 NULL
> `CONCAT('a', NULL)` 整个结果是 NULL。需要跳过 NULL 时用 `CONCAT_WS`。

## 十、速查表

| 需求 | 写法 |
| --- | --- |
| 判断为 NULL | `col IS NULL` |
| 判断非 NULL | `col IS NOT NULL` |
| 函数形式判空 | `ISNULL(col)` |
| NULL 安全相等 | `col <=> NULL` |
| 统计 NULL 行数 | `COUNT(*) - COUNT(col)` |
| NULL 当 0 参与聚合 | `SUM(IFNULL(col, 0))` / `AVG(IFNULL(col, 0))` |
| 展示层默认值 | `IFNULL(col, '默认')` / `COALESCE(...)` |
| NULL 排最后 | `ORDER BY (col IS NULL), col` |
| 禁止 NULL | 列加 `NOT NULL` |

> 3. `CHECK (age >= 0)` 能阻止插入 NULL 吗？为什么？

> **NULL 是"未知"，不是 0 也不是空串；判空只能用 `IS NULL` / `IS NOT NULL`；比较遇 NULL 得 UNKNOWN；聚合忽略 NULL，`COUNT(*) - COUNT(col)` 就是 NULL 行数；`CHECK` 拦不住 NULL，要加 `NOT NULL`。**
