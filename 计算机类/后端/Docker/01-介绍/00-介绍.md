# 介绍

Docker 这条线绕不开三个问题：容器是什么，为什么需要它，它和虚拟机差在哪。这三问答不清，后面的命令就只能靠背。

## 这一阶段在讲什么

[[01-容器|容器]] 给出核心心智模型：容器是被命名空间和 cgroups 限制住的进程，不是缩小版虚拟机。[[02-为什么用容器|为什么用容器]] 把收益和代价放在一起看，避免为了容器而容器。[[03-虚拟机与容器|虚拟机与容器]] 划清隔离边界，解释什么时候该用谁。[[04-Docker 与 OCI|Docker 与 OCI]] 说明镜像格式和运行时为什么能跨工具通用。

可以用一个很小的实验验证前面的说法：

```bash
docker run --rm alpine sh -c 'echo pid=$$; ps -ef; uname -r'
```

容器里 `ps` 只能看到自己的一两个进程，`uname -r` 显示的却和宿主机一样。两行输出就说明了"进程隔离、内核共享"。

## 学完的标准

- 能说清镜像和容器的关系，以及删掉容器后数据去了哪
- 能解释容器为什么比虚拟机启动快
- 知道哪些场景不适合容器，比如需要独立内核或强隔离的多租户
- 看到 `Exited (137)` 时知道先查 OOM 还是信号
