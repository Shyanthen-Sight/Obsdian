## 五、各单元语法知识

> 语法集中在每单元第 5 课时 Grammar in Use，全部绑定单元话题。

### Unit 1 My Dream Job —— 一般将来时

**核心结构：**

```text
will + 动词原形
be (am/is/are) going to + 动词原形
```

**要点：**

- `will`：客观将来、临时决定、口头承诺
- `be going to`：事先计划好的、有迹象表明将要发生
- 否定：`won't` / `be not going to`；疑问：`will` / `be` 提前

**例句：** `I will study hard.` / `I'm going to be a dancer.`

---

### Unit 2 The World of Art —— 复合不定代词/副词 + 感叹句

**核心结构：**

```text
some-/any-/no-/every- + -one/-body/-thing   （复合不定代词）
somewhere / anywhere / nowhere / everywhere  （不定副词）
What (+ a/an) + 形容词 + 名词 (+ 主 + 谓)!
How + 形容词/副词 (+ 主 + 谓)!
```

**要点：**

- `some-` 系列用于肯定句（及期待肯定回答的疑问句）；`any-` 系列用于否定句和疑问句；`no-` 表否定；`every-` 表"每一个"
- 复合不定代词作主语时谓语用单数；形容词修饰时后置（如 `something interesting`）
- 感叹句：`What + a/an + adj. + 可数名词单数!`；`How + adj./adv.!`

**例句：** `What a wonderful painting!` / `Art can be about something beautiful.`

---

### Unit 3 Sound Body, Sound Mind —— 否定前缀 + need 的用法（情态动词）

**核心结构：**

```text
non- / dis- / un- / mis- / in- / im- + 词根   （否定前缀构词）
needn't do sth.           （need 作情态动词：不必做某事）
need to do / don't need to do   （need 作实义动词）
```

**要点：**

- 否定前缀加在单词前构成否定意义的新词，是扩大词汇量的重要手段
- `need` 作情态动词：无人称、时态、数的变化，常用于否定句和疑问句（`needn't do`）
- `need` 作实义动词：有人称和数的变化，后接不定式（`need to do` / `don't need to do`）
- 语境关联：`can/can't`（能力）、`must/mustn't`（义务）等情态动词在健康话题中运用

**例句：** `You needn't worry about him.` / `I need to get some sleep now.`

---

### Unit 4 Changing and Growing —— 后缀 -ful/-less + 过去进行时

**核心结构：**

```text
- ful（充满……的）   hope → hopeful
- less（无……的）    care → careless
was / were + doing（过去进行时）
```

**要点：**

- 后缀 `-ful` / `-less` 把名词或动词变成形容词，两者互为反义（如 careful / careless）
- 过去进行时：表示过去某一时刻或某一阶段正在进行的动作
- 时间标志词：`at that time`、`at 8 o'clock yesterday`、`while` 等
- 否定：`wasn't/weren't + doing`；疑问：`Was/Were + 主语 + doing?`

**例句：** `I was reading at 8 o'clock last night.` / `They were playing basketball when it started to rain.`

---

### Unit 5 Amazing Places —— 后缀 -y + 动词不定式 to do

**核心结构：**

```text
名词/动词 + -y → 形容词     rain → rainy, cloud → cloudy, sun → sunny
to do 不定式：作宾语 / 宾语补足语 / 目的状语
```

**要点：**

- 后缀 `-y` 构成形容词（注意拼写：辅音 + y 结尾时变 y 为 i，如 `sun → sunny`）
- 不定式作宾语：`want / plan / hope / decide / learn to do`
- 不定式作宾补：`tell / ask / want sb. to do`
- 不定式作目的状语：`in order (not) to do`

**例句：** `I want to visit the Great Wall.` / `My mother told me to clean my room.`

---

### Unit 6 Earth and Beyond —— 形容词比较级/最高级 + 后缀 -ness

**核心结构：**

```text
A + be + 比较级 + than + B
A + be + the + 最高级 + in / of 范围
形容词 + -ness → 名词     kind → kindness, sad → sadness
```

**要点：**

- 比较级：两者比较，表"更……"；最高级：三者及以上比较，表"最……"
- 变化规则：单音节加 `-er/-est`；多音节加 `more/most`；不规则变化（`good → better → best`、`bad → worse → worst` 等）
- 常用结构：`one of + the + 最高级 + 复数名词`（最……之一）
- 后缀 `-ness` 把形容词变成名词（注意辅音 + y 结尾变 y 为 i，如 `happy → happiness`）

**例句：** `Jupiter is larger than Saturn.` / `Jupiter is the largest planet in the solar system.`

## 六、语法学习建议

1. **构词法是暗线（性价比之王）**：U3–U6 连续四个单元学习词缀（否定前缀 → -ful/-less → -y → -ness），背单词时主动做"词根 + 前后缀"拆解，可以成倍扩大词汇量。

2. **时态两条线**：U1 一般将来时（向前看，谈规划）+ U4 过去进行时（向后看，讲故事），正好覆盖"未来计划"和"过去正在发生"两大叙事场景，写作时配合使用。

3. **语法全部"话题化"**：U1 用将来时谈职业、U6 用比较级对比行星。复习时把语法例句背进单元话题里（比如用比较级描述"地球 vs 火星"），比孤立刷语法题更贴合新教材的考试方向。

4. **以单元为单位复习**：每单元做四件事——梳理话题词汇、复述主题阅读、练习当周思维策略、完成单元项目产出。
