## 一、核心规则

1. `AUTO_INCREMENT` **只能用于整数类型**：`TINYINT / SMALLINT / INT / BIGINT`
2. 必须依附在**主键 PRIMARY KEY** 或唯一 UNIQUE 字段上（实际开发只和主键搭配）
3. 一张表**只能有 1 个自增字段**
4. 默认从 `1` 开始自增，插入 NULL / 不赋值时自动填充递增值

## 二、建表时添加自增（两种写法）

### 1. 列级写法（最常用）

```sql
CREATE TABLE 表名 (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20)
);
```
### 2. 表级主键 + 列级自增（复合主键场景）

复合主键只能给其中一个整数字段加自增：

```sql
CREATE TABLE score (
    id INT AUTO_INCREMENT,
    sid INT,
    score INT,
    PRIMARY KEY(id, sid)
);
```

### 自定义自增起始值

建表末尾用 `AUTO_INCREMENT=N` 指定初始值：
```sql
CREATE TABLE user (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(20)
) AUTO_INCREMENT = 1000; -- 第一条数据从1000开始
```

## 三、建表后给已有字段添加 / 移除自增

### 1. 添加自增（修改字段属性）

```sql
ALTER TABLE 表名 MODIFY 字段名 INT PRIMARY KEY AUTO_INCREMENT;
```

示例：

```sql
ALTER TABLE emp3 MODIFY id INT PRIMARY KEY AUTO_INCREMENT;
```

### 2. 删除自增（仅去掉自增，主键保留）


```sql
ALTER TABLE 表名 MODIFY 字段名 INT PRIMARY KEY;
```

### 3. 修改自增起始值

```sql
ALTER TABLE 表名 AUTO_INCREMENT = 200;
```

⚠️ 注意：只能设置**比当前最大值更大**的数字，设更小的值不生效。

---

## 四、插入数据用法

自增字段无需手动传值，三种写法等效：

```sql
-- 写法1：省略自增字段
INSERT INTO user(name) VALUES('张三');

-- 写法2：给自增字段传NULL
INSERT INTO user(id,name) VALUES(NULL,'李四');

-- 写法3：手动指定数字（会改变下一次自增基数）
INSERT INTO user(id,name) VALUES(50,'王五');
```
