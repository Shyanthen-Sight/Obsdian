# 模板语法详解

> [!abstract] 一句话
> 这份笔记把项目里用到的 Vue 模板语法逐个过一遍：==插值 `{{ }}`、条件 `v-if`、列表 `v-for`、属性绑定 `:`、事件 `@`、修饰符 `.prevent / .self / .enter`、表单 `v-model`==，以及模板里偶尔需要写的 TypeScript 类型断言。

---

## 一、Vue 模板语法详解

### 1.1 插值表达式 `{{ }}`

```vue
<span>{{ car.name }}</span>
```

双大括号用于把 JavaScript 数据渲染到页面。

可以使用简单表达式：

```vue
{{ cars.length }}
{{ car.mileage.toLocaleString() }}
{{ activeFilterCount > 0 ? 'Active' : 'None' }}
```

> [!tip] 模板里别写复杂逻辑
> 不建议在模板中写复杂业务逻辑，复杂逻辑应该放到 `computed` 或方法中。

### 1.2 `v-if`

```vue
<div v-if="cars.length > 0">
```

条件为假时，元素不会被创建。

配合 `v-else`：

```vue
<div v-if="cars.length > 0">
  车辆列表
</div>
<div v-else>
  没有匹配车辆
</div>
```

### 1.3 `v-for`

```vue
<article
  v-for="car in cars"
  :key="car.id"
>
```

`v-for` 遍历车辆数组。

`:key` 用于帮助 Vue 识别每一个列表项。列表中应该使用稳定且唯一的值：

```vue
:key="car.id"
```

> [!warning] 别用数组下标当 key
> 不建议直接使用数组下标，因为删除和排序时可能造成 DOM 复用错误。

### 1.4 `v-bind` 简写

完整写法：

```vue
<img v-bind:src="car.image" v-bind:alt="car.name" />
```

简写：

```vue
<img :src="car.image" :alt="car.name" />
```

项目中大量使用：

```vue
:disabled="selectedCarId === null"
:class="{ selected: selectedCarId === car.id }"
:visible="isAddModalOpen"
```

### 1.5 动态 class

```vue
:class="{ selected: selectedCarId === car.id }"
```

含义是：

```text
条件为 true  → 添加 selected 类
条件为 false → 不添加 selected 类
```

导航栏中还使用了数组形式：

```vue
:class="[
  'icon',
  { rotated: iconRotated, flipped: isRentPage }
]"
```

这表示固定类 `icon` 和条件类 `rotated`、`flipped` 同时存在。

### 1.6 `v-on` 和事件简写

完整写法：

```vue
<button v-on:click="addCar">Add</button>
```

简写：

```vue
<button @click="addCar">Add</button>
```

项目中的常见事件：

```vue
@click="goToRentPage"
@submit.prevent="submit"
@mouseenter="icon_rotate"
@mouseleave="icon_reset"
@keydown.enter="emit('select', car.id)"
```

### 1.7 事件修饰符

#### `.prevent`

```vue
@submit.prevent="submit"
```

阻止表单默认提交和页面刷新。

#### `.self`

```vue
@click.self="close"
```

只有点击事件绑定元素自身时才执行。

点击弹窗内容区域不会关闭弹窗，点击背景区域才会关闭。

#### `.enter`

```vue
@keydown.enter="emit('select', car.id)"
```

只有按下 Enter 键时触发。

### 1.8 `v-model`

普通输入框：

```vue
<input v-model="name" />
```

选择框：

```vue
<select v-model="type">
```

数字转换：

```vue
<input v-model.number="dailyPrice" />
```

### 1.9 `v-bind` 与 TypeScript 类型断言

模板中：

```vue
@input="emit(
  'update:minBudget',
  Number(($event.target as HTMLInputElement).value)
)"
```

`$event.target` 的通用类型不一定能直接访问 `.value`，因此使用：

```ts
$event.target as HTMLInputElement
```

告诉 TypeScript：这个事件目标就是一个 HTML 输入框。
