## UNIT 1：Notices（通知）—— 书中第 1–20 页

**单元总目标**：用多种形式写通知；用祈使句（imperative sentence）给指令；用 "V-ing" 形式指示行动方式；用省略结构（ellipsis）写简洁句；写简短标题（brief forms）；给明确信息写清晰通知；用被动语态把非正式风格转为正式。

### PART 1：Emergency Notices（紧急通知）—— 书中第 2–7 页

1. **核心知识**：紧急通知向公众传达应急措施（emergency measures）的指令性信息，须**简短清晰**；读者在紧急情况下时间有限、可能紧张，信息必须一眼可读（读者意识）。
2. **Writing Skills**：
- 用清晰标题呈现紧急状况（如 Fire Action）；
- 用副标题（If you discover a fire / On hearing the alarm / In the event of an earthquake / In case of a fire）；
- 用具体可感知的词（concrete words，如 use an extinguisher、50 meters away）；
- 直接告知 Dos and Don'ts；
- 指导人们如何操作。
3. **Language Focus**：
- 连词后 "subject + be" 常省略以使句子紧凑（仅发生在从句中），可省略的连词：if /even if /as if /as/unless /until/when /while/where /although/once；
- "V-ing" 形式用于主句后指示同一主语的恰当行动，否定形式为 "not + V-ing"。
4. **Expressions in Use**：可省略 "subject + be" 的连词群；强调手段（emphatic devices）清单：underlining /capitalizing/colour code /numbering/bullet points /asterisks/setting typeface /italics/bold /aligning text /line spacing。
5. **写作任务**：
- Task 1 对比两则通知（Bridge No.139 撞桥报修 vs Fire Action 火灾行动）判断哪则更易理解并说明理由；
- Task 2 划出连词并删除 "subject + be"；
- Task 3 用 "V-ing" 改写 4 句紧急行动指令；
- Task 4 用 "not + V-ing" 合并 4 组句子；
- Task 5 把地震通知草稿重组、润色、排版并勾选所用强调手段。
6. **范文 / 样例主题**：Bridge No.139 报修通知；Fire Action 火灾行动通知（IF YOU DISCOVER A FIRE / ON HEARING THE FIRE ALARM）；"In the event of an earthquake" 草稿（During / After the earthquake 两阶段行动清单）。
7. **练习类型**：阅读理解勾选 + 说理、连词识别与省略改写、V-ing 改写、not+V-ing 合并、草稿重组排版。
8. **过程写作（Project）**：角色 Allen 首日上班，经理 Johnson 要求观察办公楼潜在危险并写紧急通知。Step 1 观察记录（Places observed / Potential dangers / Measures to take）；Step 2 按合理顺序起草；Step 3 主语突出开头、用 V-ing、删 subject+be；Step 4 用强调手段润色。

### PART 2：Upcoming Event Notices（即将发生事项通知）—— 书中第 8–15 页

1. **核心知识**：涉及职场常规事务（如会议）的预告通知，必须点明 **what / when / where / who**。
2. **Writing Skills**：
- 标题宜用简短名词短语，冠词与助动词常省略（如 (The) New Online Registration / (Is) Available）；
- 写作风格分 formal /neutral/informal，被动语态是正式写作特征（避免 I/we 等主观代词，例 I am going to hold a free lecture → A free lecture will be held）；
- 正式写作避免口语（缩写、句首 And、be going to、无信息的 Attention!），非正式转正式四步：删多余词 / 避口语 / 合并短句 / 必要时用被动。
3. **Language Focus**：被动语态 "be + V-ed" 中仅 "be" 随时态变化（is /was/is being /will be /has been），V-ed 不变；"subject + be" 常在连接词后省略（As (it is) announced, …）。
4. **Expressions in Use**：Please be informed that… / Please be reminded that… / It is hereby announced that… / This is to notify that… / Please note that…
5. **写作任务**：
- Task 1 读 Notice Board A 五则通知完成 What/Who/Where/When 表格；
- Task 2 删多余部分改写 4 个标题；
- Task 3 为 Notice Board B 五则通知写标题（口译大赛、跨文化讲座、作业提交、Q&A 专场、春节图书馆闭馆）；
- Task 4 把模糊信息（we /next month /this night 等）具体化；
- Task 5 观察地点日期排列并划出介词；
- Task 6 主动改被动（5 句）；
- Task 7 删可省略的 subject+be；
- Task 8 选及物动词造被动句；
- Task 9 四则非正式通知改正式风格。
6. **范文 / 样例主题**：Notice Board A（OAC Meeting Canceled、Clarification、Language Center Closed、Language Workshop Registration、Student Paychecks Available）；Notice Board B（口译大赛等 5 则）。
7. **练习类型**：信息提取表格、标题简写、模糊信息具体化、介词识别、被动语态改写、省略改写、非正式转正式。
8. **过程写作（Project）**：Allen 在公司内网为一周发布在线通知公告。Step 1 收集信息写关键词；Step 2 按关键词起草（须回答 wh-questions）；Step 3 避啰嗦口语、用被动避人称代词、给清晰标题与具体信息；Step 4 查语法拼写标点、选强调手段。

### PART 3：Notices in Multiple Forms（多种形式的通知）—— 书中第 16–20 页

1. **核心知识**：通知可有**图形格式（graphic format）**—— 以关键词图表呈现，更清晰易跟；**竖排格式（vertical format）**—— 风格更正式，用于讲座 / 庆典等重要活动，句子拆成短行、每行一个要点、行首常用介词；收发双方距离远时也可作 **letters 或 e-mails** 送达。
2. **Writing Skills**：graphic format 用关键词表格（Subject/Type/Date/Time/Venue/Sponsor）；vertical format 每行一个 key point、介词引导。
3. **Language Focus / Expressions in Use**：本部分未设独立板块。
4. **写作任务**：
- Task 1 读讲座便条完成 graphic notice 表格（Cross-cultural Studies 讲座，Professor Lenard）；
- Task 2 把书信通知（邀请 Mr Johnson 在毕业典礼演讲）改写为 vertical format；
- Task 3 把 graphic notice（Forum on Loss of Native Habitat）改写为书信形式。
5. **范文 / 样例主题**：Forum on Loss of Native Habitat 图形通知；Shakespeare Poems 讲座竖排通知（Professor Andree, Lecture Hall, 6:30 p.m. Thursday 10 January）；毕业典礼演讲邀请信。
6. **练习类型**：便条→图形表格、信函↔竖排 / 图形互转改写。
7. **过程写作（Project）**：角色公司秘书，就 HONS Group 开幕典礼（Dr Andrew Smith 主讲）分别通知**员工（表格形式）、本市市长（vertical format）、外地 VIP 客户（书信）**。Step 1 搞清 what/when/where/who (m)、按对象选形式；Step 2 分写三种通知；Step 3 检查 wh-questions、信息明确、简明；Step 4 查语法、字体对齐、拼写标点。

## UNIT 2：Business E-mails and Letters（商务电子邮件与信函）—— 书中第 21–52 页

**单元总目标**：理解商务书信基本结构；用 full block style 写信；遵循 **5C principles**；写清晰 subject lines；用 specifics 阐明信息；用正式与非正式表达；用直接与间接表达；用 reader-centred 策略处理负面信息；写 complaint letters 解决问题；遵循 **RRRG/RRRRG** 规则写致歉信。

### PART 1：Basics of Business E-mails and Letters（基础）—— 书中第 22–33 页

1. **核心知识**：邮件与书信是职场主要沟通手段，共享特征并遵循同一 **5C 规则**：
- **Clarity**（首段直奔主题、分段清晰）；
- **Conciseness**（用最少的词给完整信息）；
- **Concreteness**（展示具体日期 / 数字 / 姓名）；
- **Courtesy**（reader-centred、尊重对方）；
- **Correctness**（信息、语法、标点正确）。
- 书信三段结构：Introduction（目的、提及上次联系）→ Body（详细信息）→ Conclusion（待采取行动与联系方式）。
2. **Writing Skills**：
- **Full block style**—— 不缩进、全文左对齐，heading 与 closing 用 open punctuation；称呼语匹配（知姓名用 Dear…+ Yours sincerely；不知姓名用 Dear Sir or Madam / To whom it may concern + Yours faithfully）；
- 三种格式：Full Block / Modified Block / Semi-block；
- 日期写法 "day + month + year" 且月份拼写单词（20 September 2001）；
- subject lines 应具体相关、简短；
- "General + Specific" Statement Pattern—— 笼统信息后同句内补具体细节；
- 介词可串联大量信息实现简洁；
- **Writing in an Indirect Way**—— 拒绝、请求、提不同意见等敏感问题用间接方式以免尴尬；
- 商务信函中 we 比 I 更常用（代表公司、客户受重视）；
- 邮件即便随意也不用网聊缩写（COS/4U）、未公认 acronym、全大写 / 小写、不完整句。
3. **Language Focus**：本部分以 Writing Skills 承载句法点（概括 + 具体、介词串联、间接表达），无独立深色 Language Focus 框。
4. **Expressions in Use**：**Useful Abbreviations**——asap / rsvp / c/o / atten / cc / bcc / enc / PS / re / sub / ref / rgds。
5. **写作任务**：
- Task 1 把商务信 18 个信息点与 A–R 结构部分配对；
- Task 2 辨认三种格式；
- Task 3 选正确日期写法；
- Task 4 选 salutation-closing 组合；
- Task 5 按 full block style 校对草稿信；
- Task 6 两封打乱信段落排序（发票通知信、延迟交货致歉信）；
- Task 7 比较 subject line 优劣；
- Task 8 "概括 + 具体" 合并改写 5 句；
- Task 9 介词填空；
- Task 10 判断 12 句 Formal/Neutral/Informal 风格；
- Task 11 判断 Direct/Indirect；
- Task 12 用给定句式间接改写；
- Task 13 改写口语化邮件（Jason Wang 索要织带图片）。
6. **范文 / 样例主题**：FOSKOL WHOLESALE HOUSE INC 致 Mr Alex Waston 关于睡衣订单折扣的完整商务信；Soft Machionstyle Inc 介绍 SJ41 新型电机的草稿信；发票通知信与延迟交货致歉信；KUNI CORPORATION 还价信。
7. **练习类型**：结构配对、格式辨认、日期 / 称呼选择、草稿校对、段落排序、句型合并、介词填空、风格判断、邮件改写。
8. **过程写作（Project）**：角色销售经理 James McGregor 的助理，代复 KUNI CORPORATION 还价信（SJ-41 裤子要求 10% 折扣）。Step 1 列出留言要点与应对策略；Step 2 按 Letter heading / Subject / 三段正文 / Complimentary closing / Signature 结构起草（full block）；Step 3 按 5C 逐条修订；Step 4 至少 100 词、约一页 A4、Times New Roman、排版整洁。

### PART 2：Refusal Letters（拒绝信）—— 书中第 34–39 页

1. **核心知识**：拒绝信用于回绝他人要求；关键策略是 **reader-centred**—— 先给正面信息（positive message）再给负面信息（negative message）以柔化打击。
2. **Writing Skills**：
- **Reasons for Using Buffers**：促进相互理解 / 树立道德专业形象 / 避免损害客户关系；**Types of Buffer**：Appreciation（感激）、Compliment（赞赏）、Empathy（共情）；
- while/although 从句用于拒绝并同时引入替代方案；
- 被动语态在负面信息中更佳，使读者聚焦问题本身而回避当事人（The post you applied for cannot be provided this time）；
- **Reader-centred writing**（you-attitude /reader-friendly writing）—— 读者更关心 "能得到什么" 而非 "我们能给什么"。
3. **Language Focus**：无独立深色板块；常用句式：We are well aware of… / We know… / We are fully aware that… / While/Although… / We regret to inform you that… / We would appreciate it if…。
4. **Expressions in Use**：未设独立板块。
5. **写作任务**：
- Task 1 把 Buffers / 拒绝理由 / 替代方案与谢绝演讲邀请信配对；
- Task 2 用 buffers 拒绝 3 个情形（同事借电脑、VIP 客户要产品机密、供应商要求不走招标）；
- Task 3 共情句式改写 5 句；
- Task 4 用 while/although 合并 3 组短句（戒指退款改优惠券、无货寄另一款、不提供折扣）；
- Task 5 主动改被动 4 句；
- Task 6 reader-centred 改写 5 句；
- Task 7 勾选更有说服力的句子。
6. **范文 / 样例主题**：Daniel Houston 谢绝演讲邀请并推荐同事 Professor Daniel Levine 的信。
7. **练习类型**：功能配对、缓冲句写作、共情改写、合并、主被动转换、说服力比较。
8. **过程写作（Project）**：角色 IT 协会会长，日程已满须回绝 CCIT 2015 会议邀请。Step 1 列出 buffers 与拒绝理由；Step 2 起草；Step 3 检查是否用 We understand/know/are fully aware 及 While/Although；Step 4 校对语法、专业排版。

### PART 3：Complaint Letters（投诉信）—— 书中第 40–45 页

1. **核心知识**：投诉信表达恼怒不满，目的是要求对方采取行动改变不可接受局面。
2. **Writing Skills——Rules for Writing Complaint Letters**：
- **Credible**（具体信息：品名、序列号、购买地点、日期、问题）；
- **Reasonable**（主张投诉正当）；
- **Constructive**（明确要求：退款、期限、发票号、联系方式）；
- **Tactful**（坚定但礼貌，避免辱骂）。
3. **Language Focus**：无独立深色板块。
4. **Expressions in Use**：
- 描述问题词汇 ——breakage /polluted/delayed order /late delivery /inferior quality /faulty packing /improper packing /be underpaid /damaged goods /non-conforming products /poor service-management /leaking pipe /unbearable noise /overtime work /careless handling in transit；
- 要求解决的句式 ——Unless…, we will… / If…, we will… / Otherwise… / Not…until…；
- appreciate 词族（appreciate /appreciative/appreciated /appreciation）。
5. **写作任务**：
- Task 1 读 Complaint Letter 1（KL-1330 冰箱噪声大要求退款 ¥7,000）把 A–C 功能与 3 段配对；
- Task 2 按四规则勾选比较两封投诉信；
- Task 3 用具体信息填空完成投诉信模板（10 空）；
- Task 4 形容词选词填空（8 句）；
- Task 5 unless/if/otherwise 填空；
- Task 6 appreciate 词族填空。
6. **范文 / 样例主题**：Complaint Letter 1（冰箱退款）；Complaint Letter 2（Mr Laurence 拒收到货损坏的 A561 货物，要求补救否则取消订单）。
7. **练习类型**：功能配对、四规则比较、模板填空、选词填空、词族填空。
8. **过程写作（Project）**：角色 X Furniture Company 客户，Order FNG908 到货严重损坏（6 座椅损坏、4 书桌破裂、2 床零件缺失）要求立即换货。Step 1 用 7 条具体信息解释问题（地点日期数量 / 缺陷原因 / 已采取行动 / 客户权利 / 损失理由 / 要求 / 附件：发票、签收单、损坏清单）；Step 2 起草；Step 3 组织段落、选语气、避免信息重叠；Step 4 查语法拼写、行距页边距、full block style。

### PART 4：Apology Letters（致歉信）—— 书中第 46–52 页

1. **核心知识**：致歉信承认错误并在道歉时提供必要补偿；说 sorry 不一定真做错，有时是缓和关系的方式。
2. **Writing Skills——Rules (RRRRG)**：
- **Regret**（直接表达歉意）；
- **Reason**（客观陈述原因）；
- **Remedy**（明确如何及何时补救）；
- **Responsibility**（承担全部或部分责任）；
- **Guarantee**（保证不再发生）。（扉页目标中写作 RRRG，正文为五条规则。）
3. **Language Focus**：**现在完成时**常用于致歉信，表明已关注问题并采取补救行动（We have entered a replacement order to be shipped to you at once）。
4. **Expressions in Use**：
- 致歉介词搭配 ——regret that… /deep regret that… /sorry for… /sorry that… /sorry to hear… /apologize for… /apology for…；
- Guarantee 表达 ——assure /ensure/do everything in our power to ensure /guarantee/make every attempt to ensure /promise/strive to provide。
5. **写作任务**：
- Task 1 读致歉信勾选所用规则；
- Task 2 用给定词适当形式完成 6 句；
- Task 3 按 RRRRG 顺序排列句子；
- Task 4 组织成三段致歉信；
- Task 5 that/for/to 填空；
- Task 6 动词形式填空（现在完成时）；
- Task 7 划出表达 guarantee 的 7 个句子。
6. **范文 / 样例主题**：电视到货损坏立即换新的致歉信；White William 转来的 VIP 客户 Mr Emblem 投诉邮件（100 台空调、300 台冰箱延迟 20 天，公司政策不允许全额退款）。
7. **练习类型**：规则勾选、选词填空、句子排序、段落组织、介词填空、动词形式填空。

### PART 1：Curriculum Vitaes (CVs)—— 书中第 54–67 页

## UNIT 4：Agendas and Minutes（会议议程与会议记录）—— 书中第 75–92 页

**单元总目标**：为正式会议写 agenda 与 minutes；理解 Robert's Rules of Order；识别正式会议；识别演讲要点；用引导词（introductory words）复述信息。

### PART 1：Agendas（议程）—— 书中第 76–83 页

1. **核心知识**：议程是会议前的简要时间表与讨论事项清单；会前帮与会者准备，会中聚焦主题、引导会议、控制时间。**Robert's Rules of Order** 正式会议通用顺序 9 步：

   1. Welcome, call to order and roll call；
   2. Reading and approval of prior minutes；
   3. Reports of officers/boards/standing committees（先 Treasurer's report）；
   4. Reports of special committees（motion→seconded→voted）；
   5. Special orders；
   6. Unfinished business（old business）；
   7. New business（"Is there any new business?"）；
   8. Next meeting date；
   9. Adjournment。

   - 三类会议：**Formal meetings**（年会 / 董事会，严格按规则、motion 需动议 / 附议 / 表决、agenda 与 minutes 作法律文件存档）、**Semi-formal meetings**（部门决策会，多数商务会议属此类）、**Informal meetings**（周会 / 研讨 / 工作坊，不需表决）。
   - 清晰议程 8 要素：type of meeting /title/duration /main speakers /location/item numbers /subject of each item /timeline。

2. **Writing Skills**：正式议程遵循 Robert's Rules 编号；非正式议程（研讨会）可按 "时间 + 主题 + facilitator" 表格式布局。
3. **Language Focus**：正式会议术语 ——call to order（宣布开会）、regrets（缺席致歉）、approval of the prior minutes（通过上次纪要）、adoption of the agenda（通过议程）、adjournment（闭会）；主持用语："I call this meeting to order." / "Will the secretary please do a roll call?" / "Hearing no objection, this meeting is now adjourned."
4. **Expressions in Use**：未设独立板块；主持句型散见于 Task 3。

### PART 2：Minutes（会议记录）—— 书中第 84–92 页

1. **核心知识**：纪要是正式会议的书面记录，聚焦 motions made /issues discussed /decisions reached /actions to take；帮助核对客观性并准备下次会议。三种类型：
- **Minutes of narration（叙述式）**—— 讨论与决定的摘要，含间接引语与发言人姓名，清晰信息量大，最常用；
- **Minutes of resolution（决议式）**—— 只记决议结果与待办，常以 "Be it resolved that" 开头，简洁；
- **Verbatim minutes（逐字式）**—— 逐字记录，啰嗦但可作法律文件，用于法律记录或重要演讲。
- 记纪要 5 原则：**Impartial / Factual / Concise / Simple / Formal**（避免缩写、口语、俚语）。
2. **Writing Skills**：三种纪要类型辨别与选用；5 原则；时态规则；用 introductory verbs 复述发言。

4. **Expressions in Use——Introductory Verbs for Recapping**：accept / add / admit / announce / argue / believe / clarify / comment / conclude / consider / decide / emphasize / estimate / explain / focus on / highlight / indicate / insist / introduce / mention / persuade / present / propose / recommend / refer / remark / remind / reply / request / respond / stress / suggest / summarize / warn。

### PART 1：Problem-solving Memos—— 书中第 94–101 页

1. **核心知识**：Memos 是简短、专业、内部、可存档检索并作法律证据的文书，文风直接简洁。
- **Heading 头栏**：To（用职务头衔 official designation，不用 Mr./Dr.；多人按字母或职位顺序）、From、Ref（作者 / 打字员首字母，如 RT/ST）、Cc、Date（月份用单词或缩写，不用阿拉伯数字）。

3. **Language Focus**：无独立深色板块；heading 职务称呼、时间 / 数字用法融入 Writing Skills 与 Task。

- Writing a Body Paragraph——topic sentence + supportive specifics；

- 基本信息句型 ——The curve chart shows/presents/displays/demonstrates… over the period from… to…；The bar chart illustrates…；The pie chart presents the proportion/ratio/percentage/distribution of…；The table gives a breakdown/distribution of…；
- 趋势描述两套句型 ——There be + Adj. + Noun + Prep.(value) + Prep.(time)（slow/slight/gentle/gradual/stable/moderate/dramatic/sudden/quick/sharp/significant/considerable/consistent + decline/decrease/drop/fall/increase/rise/climb/peak/level-off/bottom）与 Subject + Verb + Adv. + Prep.（declined gradually to… /increased dramatically to…）；
- **Cause-and-effect Signposts**——Adv.: thus/hence/consequently/therefore/accordingly；Noun: consequence/reason/result；Verb: cause/lead/attribute；Prep.: because of/due to；Conj.: since/for。

## UNIT 7：Survey Reports（调查报告）—— 书中第 145–170 页

**单元总目标**：写 Introduction 说明主题与目的并设定研究问题；写 Literature Review 厘清概念并聚焦比较前人研究；写 Methodology 描述工具、参与者与流程；用 exemplification /quotation/rephrasing 展开 Findings；写 Discussion 分析原因并与前人研究比较评价；写 Conclusion 验证假设、承认局限、给出建议。

**体裁核心知识**：survey report 是事实 + 数据支撑的调查结果总结；高度结构化逻辑框架：**Introduction → Literature Review → Methodology → Findings → Discussion → Conclusion → Recommendation → Bibliography**。

### PART 1：Introduction and Literature Review—— 书中第 146–157 页

1. **核心知识 / 组织结构**：
- **Introduction 六要素**——Research subject、Research purpose、Research scope、Research criteria、Research hypotheses、Research questions；功能句类型：Giving context/background、Clarifying the necessity of a survey、Stating a general purpose、Raising research questions or hypotheses、Indicating the scope、Providing an overview of the structure。
- **Literature Review 六要素**——Defining key concepts、Comparing subjects/methods/findings in previous research、Reviewing main theories、Identifying main issues or gaps。
2. **Writing Skills**：
- Stating the Necessity—— 通过指出研究领域的 gap/problem/controversy 交代必要性；
- Setting a Research Goal—— 先写总体目标再细化成可测量的 objectives/research questions；
- Writing a Hypothesis—— 预测变量间关系，须 accessible 且 provable；
- **Rules for Writing a Literature Review**——Being selective / Being critical / Being relevant / Being synthesized；
- **Methods for Organizing**——Theme-focused / Chronological / Method-focused / Multi-method；
- Adjectives in a Literature Review（用形容词表作者判断立场）；
- Definitions—— 四种定义法：Elaboration（自己的话解释）、Quotation（引他人原话）、Comparison（比较各家定义）、Exemplification（举例说明）；
- **Tenses in a Literature Review**—— 研究具普适性且重要→一般现在时；仍在进行且直接相关→现在完成时；已完成且较次要→一般过去时（过去时叙述事件与前人结果，现在时讨论观点 / 展示发现）。
3. **Language Focus**：时态规则（见上）；研究问题 / 假设表述；引出 gap / 不确定性的词汇（no single study、lack of、much uncertainty、it is not clear、a major problem、fail to、only、little）。
4. **Expressions in Use**：
- Expressions for Literature Review——A key issue in … is …；There is an extensive acknowledgement of …, but much uncertainty still exists about …；Although multiple methods for … are widely used …, the majority of the studies to date …；Most of the previous research emphasized …；Multiple research methods have been used in the previous research on …；
- Expressions for Definitions——Sb. defines it as … / It refers to … / The term means that … / It is defined as … / As defined in /below/herein /by/above … 等 14 个定义句型。
5. **写作任务**：

- Task 4 为研究目的选最佳 research question；
- Task 5 把 hypothesis 改写为 research question 与 report title（service quality、price fairness 与 customer satisfaction）；
- Task 6 判断 5 段文献综述的组织方法；
- Task 7 划线标出表作者判断的形容词；
- Task 8 判断 4 个定义所用定义法；
- Task 9 用给定句型定义 Repeat business / Customer loyalty / Service accessibility / Product quality；
- Task 10 据参考文献（McColl-Kennedy & Schneider, 2000）回查范文引用；

### PART 2：Methodology—— 书中第 158–165 页

### PART 3：Discussion and Conclusion—— 书中第 166–170 页

1. **核心知识**：Discussion 是报告核心 —— 通过阐明意义、分析原因、将发现与假设对比来评价 findings；Conclusion 陈述 implications、limitations、recommendations 等。Discussion 功能句类型：Results of the present study、Elaboration of the meanings、Rephrasing of the findings、Comparison with the previous studies、Possible causes of the result、Comparison with the hypothesis。
2. **Writing Skills**：

- Comparison（对比）—— 识别差异、发现特点、得出洞见；
- Exemplification—— 解释概念、澄清事实、论证观点或支持 topic sentence；
- **The Conclusion**—— 验证假设（verify hypotheses）、展示启示（implications）、承认局限（limitations）、提出进一步研究建议（suggest further research）。
3. **Language Focus**：今昔研究对比句型（the same as /be similar to /differentiate from /rather than /the same /similarity and difference /as in /tend to）。
