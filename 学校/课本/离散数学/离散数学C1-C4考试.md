**最容易被扣分的地方**

1. 符号混用：`↔` 是公式里的联结词，`⇔` 是公式间"等值"的元语言记号，`⇒` 是"重言蕴含"。等值演算的推演链里只能出现 `⇔`。
2. 单向蕴含当等值用：9 条推理定律（附加、化简、假言推理…）**只有单向**，写成 `⇔` 直接扣分。
3. 求主范式时漏写变元：出现过的命题变元必须**全部**补齐，不能只写一部分（如漏了 `r` 就变成别的公式的范式）。
4. 蕴含的否定写错：`¬(A→B) ⇔ A∧¬B`，不是 `¬A∨B`。

**最容易被扣分的地方**

1. ==特性谓词配错==：全称量词配 `→`，存在量词配 `∧`。写反成 `∀x(P(x)∧Q(x))` 或 `∃x(P(x)→Q(x))` 是全章第一大错。
2. 个体域不是全总域时，不写特性谓词却直接套模板。
3. 量词顺序随意调换（`∀x∃yA` 只能推出 `∃y∀xA`，反向不成立）。
4. 化前束范式时忘了先**换名**，导致量词左移后把自由变元"捕获"了。

| 序号 | 考点 | 常见题型 | 概率 | 定位（笔记） |
| :-: | :--- | :--- | :-: | :--- |
| 1 | `∈` 与 `⊆` 辨析 | 判断"属于 / 包含"，`P(∅)`、`\|P(A)\|=2ⁿ` | ★★★★ | [[3.1 集合的基本概率]]（∈/⊆、空集、幂集三种证法） |
| 2 | 五种运算 | `∪ ∩ − ~ ⊕` 的计算与化简 | ★★★ | [[3.2 集合的基本运算]]（五运算 + 优先级 + 运算律总表） |
| 3 | ==恒等式证明== | 用元素法或恒等变形法证明集合等式 | ★★★★★ | [[3.2 集合的基本运算]]（证明三法）｜ [[例题分析]] 题型三 |
| 4 | ==容斥原理== | 有限集计数、'至少'/'恰好'型应用题 | ★★★★★ | [[3.3 集合中元素的计数]]（容斥 + 恰好 k 个 + lcm + φ(n)） |
| 5 | 文氏图七分块 | 三集合互不重叠区域的计数 | ★★★ | [[3.3 集合中元素的计数]] §七分块 ｜ [[例题分析]] 题型四 |

**最容易被扣分的地方**

1. 把 `∈` 写成 `⊆`：`a∈{a,b}` 对，`a⊆{a,b}` 错（当 `a` 不是集合时）。
2. `P(∅)={∅}` 而**不是** `∅`；`|P(A)|=2^{|A|}` 而不是 `|A|`。
3. 证明集合等式只画文氏图不写推导——文氏图只能辅助，不能当证明。
4. 容斥公式里 `|A∪B∪C|` 的第三项符号写成减号（应为**加** `|A∩B∩C|`）。
5. 整除计数用 `lcm` 而不是乘积：`|A∩B|` 对应"同时被 5 和 6 整除"，要除 `lcm(5,6)=30`。

**最容易被扣分的地方**

1. ==复合方向==：本书约定 `S∘R` 表示**先 R 后 S**（`(g∘f)(x)=g(f(x))`）。方向搞反，整题归零。
2. `R⁰ = I_A`（不是空集）；`R²=R∘R`。
3. 反自反 ≠ 非自反；对称 ≠ 反对称的对立面（可以既对称又反对称，当且仅当 `R⊆I_A`）。
4. `t(R)` 忘了"多步连通"，只算 `R²` 不够，要一路算到 `Rⁿ`。
5. 等价类 `[x]` 是**集合**，商集 `A/R` 是**集合的集合**，层次差一级。
6. 最大元必须在 `B` 内，上确界可以在 `B` 外；极大元可多个，最大元若存在必唯一。
7. `f⁻¹(y)` 是**原像集合**，不等于反函数；只有双射才有反函数。

# 二、知识点总结

## （一）第 1 章 命题逻辑

### 1. 底层符号：三层语言别混

| 符号 | 名称 | 层次 | 含义 |
| :-: | :--- | :--- | :--- |
| `↔` | 等价联结词 | 对象语言 | `A↔B` 本身是一个公式，有真值 |
| `⇔` | 等值 | 元语言 | `A↔B` 是重言式 |
| `⇒` | 重言蕴含 | 元语言 | `A→B` 是重言式（单向） |

优先级：`¬` > `∧` > `∨` > `→` > `↔`。

### 2. 16 组基本等值式（必背）

| # | 名称 | 等值式 |
| :-: | :--- | :--- |
| 1 | 双重否定 | `¬¬A ⇔ A` |
| 2 | 幂等 | `A∨A ⇔ A`；`A∧A ⇔ A` |
| 3 | 交换 | `A∨B ⇔ B∨A`；`A∧B ⇔ B∧A` |
| 4 | 结合 | `(A∨B)∨C ⇔ A∨(B∨C)`；`(A∧B)∧C ⇔ A∧(B∧C)` |
| 5 | 分配 | `A∨(B∧C) ⇔ (A∨B)∧(A∨C)`；`A∧(B∨C) ⇔ (A∧B)∨(A∧C)` |
| 6 | ==德摩根== | `¬(A∨B) ⇔ ¬A∧¬B`；`¬(A∧B) ⇔ ¬A∨¬B` |
| 7 | 吸收 | `A∨(A∧B) ⇔ A`；`A∧(A∨B) ⇔ A` |
| 8 | 零律 | `A∨1 ⇔ 1`；`A∧0 ⇔ 0` |
| 9 | 同一律 | `A∨0 ⇔ A`；`A∧1 ⇔ A` |
| 10 | 排中律 | `A∨¬A ⇔ 1` |
| 11 | 矛盾律 | `A∧¬A ⇔ 0` |
| 12 | ==蕴含等值== | `A→B ⇔ ¬A∨B` |
| 13 | 等价等值 | `A↔B ⇔ (A→B)∧(B→A)` |
| 14 | 假言易位 | `A→B ⇔ ¬B→¬A` |
| 15 | 等价否定 | `A↔B ⇔ ¬A↔¬B` |
| 16 | 归谬论 | `(A→B)∧(A→¬B) ⇔ ¬A` |

**两条演算规则**：代入规则（换变元，**必须处处换**）；替换规则（换子公式，**可以只换一处**）。

**必背导出公式**

| 名称    | 公式                                |
| :---- | :-------------------------------- |
| 蕴含的否定 | `¬(A→B) ⇔ A∧¬B`                   |
| 蕴含四形态 | `A→B ⇔ ¬A∨B ⇔ ¬B→¬A ⇔ ¬(A∧¬B)`    |
| 等价的否定 | `¬(A↔B) ⇔ (A∧¬B)∨(¬A∧B)`          |
| 输出律   | `A→(B→C) ⇔ (A∧B)→C`               |
| 吸收变体  | `A∨(¬A∧B) ⇔ A∨B`；`A∧(¬A∨B) ⇔ A∧B` |

**对偶原理**：`∧↔∨`、`0↔1` 互换得对偶式；`A⇔B ⟹ A*⇔B*`。第 2–11 组的"∨ 版"与"∧ 版"互为对偶，只需记一半。

### 3. 极小项与极大项

设变元为 `p₁,…,pₙ`，共 `2ⁿ` 个极小项 `m₀…m_{2ⁿ−1}`、`2ⁿ` 个极大项 `M₀…M_{2ⁿ−1}`。

| 概念       | 定义                             | 编码规则                                           |
| :------- | :----------------------------- | :--------------------------------------------- |
| 极小项 `mᵢ` | `n` 个变元（或其否定）的**合取**，每个变元恰出现一次 | 变元取 **0** 时配 `¬p`，取 **1** 时配 `p`；真值为 1 的赋值即为下标 |
| 极大项 `Mᵢ` | `n` 个变元的**析取**，每个变元恰出现一次       | 变元取 **1** 时配 `¬p`，取 **0** 时配 `p`；真值为 0 的赋值即为下标 |

**关键关系**：`¬mᵢ ⇔ Mᵢ`；`mᵢ∧mⱼ ⇔ 0`（`i≠j`）；`Mᵢ∨Mⱼ ⇔ 1`（`i≠j`）；`⋁mᵢ ⇔ 1`；`⋀Mᵢ ⇔ 0`。

**下标互补**：若 `A ⇔ ⋁_{i∈I} mᵢ`，则 `A ⇔ ⋀_{j∉I} Mⱼ`。

**主范式三求法**

| 方法 | 做法 | 适用 |
| :--- | :--- | :--- |
| 真值表法 | 列真值表，取成真行写极小项相或（或取成假行写极大项相与） | 变元少（≤3） |
| 等值演算法 | 用等值式化成"极小项之或" | 式子有结构 |
| 下标互补法 | 先求一种范式，另一种直接用补集下标 | 两种都要 |

**公式类型判定**

| 类型 | 等值刻画 | 主析取范式 | 主合取范式 |
| :--- | :--- | :--- | :--- |
| 重言式 | `A ⇔ 1` | 含**全部** `2ⁿ` 个极小项 | 不含极大项 |
| 矛盾式 | `A ⇔ 0` | 不含极小项 | 含**全部** `2ⁿ` 个极大项 |
| 可满足式 | `A ⇏ 0` | 至少 1 个极小项 | — |

### 4. 联结词完备集

`{¬,∧}`、`{¬,∨}`、`{¬,→}`、`{↑}`、`{↓}` 都是完备集；==`{∧,∨}` 不是==（无法表示否定）。

| 目标 | 用 ↑ 表示 | 用 ↓ 表示 |
| :--- | :--- | :--- |
| `¬A` | `A↑A` | `A↓A` |
| `A∧B` | `(A↑B)↑(A↑B)` | `(A↓A)↓(B↓B)` |
| `A∨B` | `(A↑A)↑(B↑B)` | `(A↓B)↓(A↓B)` |

### 5. 推理定律（9 条，全部**单向** `⇒`）

| 名称    | 形式                            |
| :---- | :---------------------------- |
| 附加    | `A ⇒ A∨B`                     |
| 化简    | `A∧B ⇒ A`                     |
| 假言推理  | `A∧(A→B) ⇒ B`                 |
| 拒取式   | `¬B∧(A→B) ⇒ ¬A`               |
| 析取三段论 | `¬A∧(A∨B) ⇒ B`                |
| 假言三段论 | `(A→B)∧(B→C) ⇒ A→C`           |
| 等价三段论 | `(A↔B)∧(B↔C) ⇒ A↔C`           |
| 构造性二难 | `(A→B)∧(C→D)∧(A∨C) ⇒ B∨D`     |
| 破坏性二难 | `(A→B)∧(C→D)∧(¬B∨¬D) ⇒ ¬A∨¬C` |

### 6. 推理有效性的四种判定 + 三条证明规则

**判定四法**：真值表法（前提合取 → 结论为重言式）｜等值演算法｜主析取范式法（前提合取的主析取范式含于结论）｜归谬法（前提 + `¬结论` 推出矛盾）。

**推理规则**

| 规则 | 内容 | 用法 |
| :--- | :--- | :--- |
| **P 规则** | 前提可直接引入 | 证明开头 |
| **T 规则** | 由前面若干公式推出新公式（用等值式或推理定律） | 中段推导，必须注明依据的序号与定律名 |
| **CP 规则** | 若要证 `A→B`，把 `A` 当附加前提，推出 `B` 后收工 | 结论是蕴含式时首选 |
| **反证法** | 把 `¬结论` 加入前提，推出矛盾（某式与其否定同时出现） | 结论是否定式或难推时 |

## （二）第 2 章 一阶逻辑

### 1. 四个基本概念

| 概念  | 含义                                     |
| :-- | :------------------------------------- |
| 个体词 | 独立存在的具体或抽象对象；个体常元 `a,b,c`，个体变元 `x,y,z` |
| 谓词  | 刻画个体性质或关系的词；`F(x)` 一元，`L(x,y)` 二元      |
| 量词  | `∀` 全称、`∃` 存在                          |
| 个体域 | 个体变元的取值范围；取"全总个体域"时用**特性谓词**缩回原范围      |

### 2. 符号化模板（==∀ 配 →，∃ 配 ∧==）

| 自然语言        | 模板                                |
| :---------- | :-------------------------------- |
| 所有的 S 都是 P  | `∀x(S(x)→P(x))`                   |
| 所有的 S 都不是 P | `∀x(S(x)→¬P(x))`                  |
| 有的 S 是 P    | `∃x(S(x)∧P(x))`                   |
| 有的 S 不是 P   | `∃x(S(x)∧¬P(x))`                  |
| 没有 S 是 P    | `¬∃x(S(x)∧P(x)) ⇔ ∀x(S(x)→¬P(x))` |
| 并非所有 S 都是 P | `¬∀x(S(x)→P(x)) ⇔ ∃x(S(x)∧¬P(x))` |

**易错连接词**：`仅当` → 后件；`除非` → `¬`；`A 除非 B` ⇔ `¬B→A`；`只有…才…` → 前件；`不都` = `¬∀`；`都不` = `∀¬`。

### 3. 辖域与变元

| 概念   | 含义                         |
| :--- | :------------------------- |
| 辖域   | 量词后紧跟的**最小**子公式            |
| 指导变元 | 量词后面那个变元（如 `∀x` 的 `x`）     |
| 约束出现 | 变元落在对应量词的辖域内               |
| 自由出现 | 变元不在任何约束它的量词辖域内            |
| 闭式   | **没有**自由出现的个体变元的公式（闭式必为命题） |


**换名规则**：约束变元可改名，但与辖域内其他约束无关的、以及自由出现的同名变元不得改，且改名后约束关系不变。
**代替规则**：自由变元可用项代替，需**处处**代替。

### 4. 解释与公式类型

**解释 I** 包含四件事：非空个体域 `D`；每个个体常元对应 `D` 中一个元素；每个函数常元对应 `D` 上一个函数；每个谓词常元对应 `D` 上一个谓词（真值确定的关系）。

**公式类型**

| 类型 | 定义 |
| :--- | :--- |
| 永真式（逻辑有效式） | 在任何解释和赋值下都为真 |
| 矛盾式（不可满足式） | 在任何解释和赋值下都为假 |
| 可满足式 | 至少存在一个解释和赋值使其为真 |

> 一阶逻辑公式的永真性==不可判定==（丘奇-图灵），只能具体判定，不能写通用算法。

### 5. 四组量词等值式

**(1) 量词否定**

`¬∀xA(x) ⇔ ∃x¬A(x)`；`¬∃xA(x) ⇔ ∀x¬A(x)`

**(2) 量词辖域收缩与扩张**（`B` 中不含 `x`）

| 式 | 等值于 |
| :--- | :--- |
| `∀x(A(x)∨B)` | `∀xA(x)∨B` |
| `∀x(A(x)∧B)` | `∀xA(x)∧B` |
| `∃x(A(x)∨B)` | `∃xA(x)∨B` |
| `∃x(A(x)∧B)` | `∃xA(x)∧B` |
| `∀x(A(x)→B)` | `∃xA(x)→B` |
| `∀x(B→A(x))` | `B→∀xA(x)` |
| `∃x(A(x)→B)` | `∀xA(x)→B` |
| `∃x(B→A(x))` | `B→∃xA(x)` |

**(3) 量词分配**（只有两条是等值式）

`∀x(A(x)∧B(x)) ⇔ ∀xA(x)∧∀xB(x)`
`∃x(A(x)∨B(x)) ⇔ ∃xA(x)∨∃xB(x)`

**单向蕴含**：`∀xA(x)∨∀xB(x) ⇒ ∀x(A(x)∨B(x))`；`∃x(A(x)∧B(x)) ⇒ ∃xA(x)∧∃xB(x)` —— 两者**反向都不成立**。

**(4) 量词顺序**

`∃x∀yA(x,y) ⇒ ∀y∃xA(x,y)`，==反向一般不等值==。

### 6. 前束范式（四步法）

**定义**：所有量词都在公式最前面，且辖域延伸到公式末尾，形如 `Q₁x₁Q₂x₂…QₙxₙM`，`M` 中无量词。

| 步 | 操作 | 依据 |
| :-: | :--- | :--- |
| ① | 消去 `→` 和 `↔` | `A→B ⇔ ¬A∨B`；`A↔B ⇔ (A→B)∧(B→A)` |
| ② | 否定号内移 | 德摩根 + 量词否定等值式 |
| ③ | **换名** | 约束变元改名，避免左移后捕获自由变元 |
| ④ | 量词左移 | 辖域扩张等值式 |

> 前束范式**不唯一**；若要求"母式"为合取范式，则称**前束合取范式**。

## （三）第 3 章 集合

### 1. 基本概念与三个高频陷阱

| 概念    | 要点                                        |
| :---- | :---------------------------------------- |
| 元素与集合 | `a∈A`：个体与整体；`A⊆B`：两个整体之间                  |
| 子集    | `A⊆B ⟺ ∀x(x∈A→x∈B)`                       |
| 真子集   | `A⊂B ⟺ A⊆B ∧ A≠B`                         |
| 空集    | `∅` 是**任何**集合的子集；`∅` 只有一个                 |
| 幂集    | `P(A) = {B ∣ B⊆A}`，`\|P(A)\| = 2^{\|A\|}` |
| 全集    | 事先约定的最大集合 `E`                             |

**三个陷阱**

1. `∅∈{∅}` 真，`∅⊆{∅}` 真，但 `∅={∅}` 假。
2. `P(∅)={∅}`（含 1 个元素），`|P(∅)|=1`，`P(P(∅))={∅,{∅}}`。
3. `{a}∈{a,{a}}` 真，同时 `{a}⊆{a,{a}}` 也真——同一对象可同时是元素和子集。

**`|P(A)|=2ⁿ` 的三种证法**：① 每个元素"在/不在"子集中，各 2 选，共 `2ⁿ`；② 按 `C(n,k)` 分类求和 `ΣC(n,k)=2ⁿ`；③ 对 `n` 归纳。

### 2. 五种运算

| 运算     |  记号   | 定义                          |
| :----- | :---: | :-------------------------- |
| 并      | `A∪B` | `{x ∣ x∈A∨x∈B}`             |
| 交      | `A∩B` | `{x ∣ x∈A∧x∈B}`             |
| 相对补（差） | `A−B` | `{x ∣ x∈A∧x∉B}`             |
| 绝对补    | `~A`  | `E−A`                       |
| 对称差    | `A⊕B` | `(A−B)∪(B−A) = (A∪B)−(A∩B)` |

优先级：`~` > `∩` > `∪`、`−`、`⊕`（同级从左到右）。

### 3. 运算律（对偶表，记一行得两行）

| 名称      | 并版                    | 交版                    |
| :------ | :-------------------- | :-------------------- |
| 幂等      | `A∪A=A`               | `A∩A=A`               |
| 交换      | `A∪B=B∪A`             | `A∩B=B∩A`             |
| 结合      | `(A∪B)∪C=A∪(B∪C)`     | `(A∩B)∩C=A∩(B∩C)`     |
| 分配      | `A∪(B∩C)=(A∪B)∩(A∪C)` | `A∩(B∪C)=(A∩B)∪(A∩C)` |
| ==德摩根== | `~(A∪B)=~A∩~B`        | `~(A∩B)=~A∪~B`        |
| 吸收      | `A∪(A∩B)=A`           | `A∩(A∪B)=A`           |
| 零律      | `A∪E=E`               | `A∩∅=∅`               |
| 同一律     | `A∪∅=A`               | `A∩E=A`               |
| 排中      | `A∪~A=E`              | `A∩~A=∅`              |
| 双重否定    | `~~A=A`               | —                     |
| 差补转换    | `A−B=A∩~B`            | —                     |
| 对称差     | `A⊕B=(A∪B)−(A∩B)`     | `A⊕B=(A−B)∪(B−A)`     |

### 4. 集合等式证明的两种正经写法

**元素法（万能）**：证 `A=B`，先证 `A⊆B`（任取 `x∈A`…推出 `x∈B`），再证 `B⊆A`。

**恒等变形法（快）**：从左边出发，一步步用运算律化成右边，每步注明所用定律。

**常用技巧**：`A−B=A∩~B`；`A⊕B=(A∪B)∩~(A∩B)`；把 `A⊆B` 转成 `A∩B=A` 或 `A∪B=B`。

> 文氏图只用于**发现**结论或**否定**错误等式（举反例），不能当证明。

### 5. 容斥原理

| 集合数 | 公式 |
| :-: | :--- |
| 2 | `\|A∪B\| = \|A\|+\|B\|−\|A∩B\|` |
| 3 | `\|A∪B∪C\| = \|A\|+\|B\|+\|C\|−\|A∩B\|−\|A∩C\|−\|B∩C\|+\|A∩B∩C\|` |
| n | `\|⋃Aᵢ\| = Σ\|Aᵢ\| − Σ\|Aᵢ∩Aⱼ\| + Σ\|Aᵢ∩Aⱼ∩Aₖ\| − … + (−1)^{n−1}\|A₁∩…∩Aₙ\|` |

**"不是"型**：`|~A∩~B∩~C| = |E| − |A∪B∪C|`。

**恰好 k 个**（记 `S_k` = 所有 `k` 重交集的大小之和）

| 目标 | 公式 |
| :--- | :--- |
| 恰好 1 个性质 | `N₁ = S₁ − 2S₂ + 3S₃` |
| 恰好 2 个性质 | `N₂ = S₂ − 3S₃` |

> 口诀：==奇加偶减==；元素被计入的次数要调成目标次数。

### 6. 计数中的两个进阶结论

- **整除计数**：`|A∩B|`（"同时被 a 和 b 整除"）用 ==lcm==，即 `⌊n/lcm(a,b)⌋`，不是 `⌊n/ab⌋`。
- **欧拉函数**：`1…n` 中与 `n` 互素的个数 `φ(n) = n∏(1 − 1/pᵢ)`，`pᵢ` 取遍 `n` 的全部**不同**素因子。

## （四）第 4 章 二元关系和函数

### 1. 有序对与笛卡尔积

**Kuratowski 定义**：`⟨x,y⟩ = {{x},{x,y}}`，保证 `⟨x,y⟩=⟨u,v⟩ ⟺ x=u ∧ y=v`。

| 性质 | 内容 |
| :--- | :--- |
| 元素个数 | `\|A×B\| = \|A\|·\|B\|` |
| 交换律 | ==不成立==（`A×B ≠ B×A`，除非空集或 `A=B`） |
| 结合律 | ==不成立== |
| 分配律 | `A×(B∪C) = (A×B)∪(A×C)`；对 `∩`、`−` 同样成立 |
| 合并律 | `(A×B)∩(C×D) = (A∩C)×(B∩D)` |
| ==不可合并== | `(A×B)∪(C×D) ≠ (A∪C)×(B∪D)`（会出现交叉搭配） |

**关系计数**：`|A|=m`、`|B|=n`，则从 `A` 到 `B` 的二元关系共 `2^{mn}` 个；`A` 上关系共 `2^{n²}` 个。

### 2. 关系的表示与基本运算

**三种表示**：集合（有序对清单）｜关系矩阵 `M_R=(mᵢⱼ)`，`mᵢⱼ=1 ⟺ ⟨aᵢ,aⱼ⟩∈R`｜关系图（有向图）。三者信息等价。

| 运算 | 定义 | 记忆 |
| :--- | :--- | :--- |
| `dom R` | `{x ∣ ∃y⟨x,y⟩∈R}` | 前件全体 |
| `ran R` | `{y ∣ ∃x⟨x,y⟩∈R}` | 后件全体 |
| `fld R` | `dom R ∪ ran R` | 域 |
| 逆 `R⁻¹` | `{⟨y,x⟩ ∣ ⟨x,y⟩∈R}` | 矩阵**转置**，图**反向** |
| 限制 `R↾A` | `{⟨x,y⟩ ∣ ⟨x,y⟩∈R ∧ x∈A}` | 掐前件 |
| 像 `R[A]` | `{y ∣ ∃x∈A⟨x,y⟩∈R}` | 只留从 A 出发的终点 |
| 复合 `S∘R` | `{⟨x,z⟩ ∣ ∃y(⟨x,y⟩∈R ∧ ⟨y,z⟩∈S)}` | ==先 R 后 S== |
| 幂 `Rⁿ` | `R¹=R`，`R^{n+1}=Rⁿ∘R`，==`R⁰=I_A`== | 走 n 步 |

**复合的矩阵算法**：`M_{S∘R} = M_R ⊙ M_S`（布尔乘法：先逐项与，再逐行或）。矩阵中不出现"2"。

**复合的性质**：满足结合律；==不满足交换律==；`(S∘R)⁻¹ = R⁻¹∘S⁻¹`（顺序反转）。

### 3. 五种性质（三重刻画必背）

| 性质 | 集合语言 | 关系矩阵 | 关系图 |
| :--- | :--- | :--- | :--- |
| 自反 | `∀x, ⟨x,x⟩∈R` | 主对角线**全 1** | 每点有自环 |
| 反自反 | `∀x, ⟨x,x⟩∉R` | 主对角线**全 0** | 无任何自环 |
| 对称 | `⟨x,y⟩∈R ⟹ ⟨y,x⟩∈R` | **对称矩阵** | 边成对出现 |
| 反对称 | `⟨x,y⟩∧⟨y,x⟩ ⟹ x=y` | 非对角位置 `mᵢⱼ` 与 `mⱼᵢ` 不同时为 1 | 两点间至多一条边 |
| 传递 | `⟨x,y⟩∧⟨y,z⟩ ⟹ ⟨x,z⟩` | ==`M² ≤ M`（逐位）== | — |

**代数刻画（做证明题的好工具）**

- 对称 `⟺ R = R⁻¹`
- 反对称 `⟺ R∩R⁻¹ ⊆ I_A`
- 传递 `⟺ R∘R ⊆ R ⟺ t(R)=R`

**两个"不"**：==反自反 ≠ 非自反==（非自反只要求至少一个对角元缺席）；==对称 ≠ 反对称的对立面==（`R⊆I_A` 时两者兼有）。

**保持性与不保持性**

| 运算 | 自反 | 反自反 | 对称 | 反对称 | 传递 |
| :--- | :-: | :-: | :-: | :-: | :-: |
| `R⁻¹` | 保 | 保 | 保 | 保 | 保 |
| `R∪S` | 保 | 保 | 保 | ==不保== | ==不保== |
| `R∩S` | 保 | 保 | 保 | 保 | 保 |
| `R−S` | ==不保== | ==不保== | 保 | 保 | ==不保== |
| `R∘S` | 保 | ==不保== | ==不保== | ==不保== | 保 |

### 4. 三种闭包

| 闭包 | 记号 | 构造公式 | 矩阵做法 | 图做法 |
| :--- | :-: | :--- | :--- | :--- |
| 自反闭包 | `r(R)` | `R ∪ I_A` | 对角线补 1 | 每点补自环 |
| 对称闭包 | `s(R)` | `R ∪ R⁻¹` | `M ∨ Mᵀ` | 边补反向 |
| 传递闭包 | `t(R)` | `R ∪ R² ∪ … ∪ Rⁿ`（`n=\|A\|`） | `M ∨ M² ∨ … ∨ Mⁿ` | 逐条找链补直连 |

**次序关系**（屈婉玲教材定理）

- `rs(R) = sr(R)`（自反与对称可换）
- `rt(R) = tr(R)`（自反与传递可换）
- ==`st(R) ⊆ ts(R)`，一般不等==

**Warshall 算法**（求 `t(R)`，`O(n³)`）

```
M ← M_R
for k = 1 to n:            # 中转点，必须最外层
    for i = 1 to n:
        if M[i][k] == 1:
            M[i] ← M[i] ∨ M[k]      # 第 i 行按位或第 k 行
```

> 记法：==拿"第 k 行"去更新"所有 `k` 列为 1 的行"==。`k` 必须在最外层，否则漏路径。

### 5. 等价关系与划分

| 概念 | 内容 |
| :--- | :--- |
| 等价关系 | 自反 + 对称 + 传递，记 `~` |
| 等价类 | `[x]_R = {y ∣ x~y}`，非空且 `x∈[x]_R` |
| 相等判据 | ==`[x]_R=[y]_R ⟺ x~y`==（比代表元，不比集合） |
| 不相交律 | `[x]≠[y] ⟹ [x]∩[y]=∅` |
| 商集 | `A/R = {[x]_R ∣ x∈A}`（**集合的集合**） |
| 划分 | 块非空 + 两两不交 + 并为 `A` |
| 核心定理 | ==等价关系 ⟷ 划分，一一对应== |

**由划分求关系**：`R = ⋃_{块 B∈π} (B×B)`。

**等价关系的关系矩阵形状**：沿主对角线排列的**全 1 方块**，块间全 0。

**常见等价关系**：`I_A`、`E_A`（全域）、模 `n` 同余、`x~y ⟺ f(x)=f(y)`（函数的核）、三角形相似、图的顶点连通。

**个数**：`|A|=n` 时等价关系个数 = Bell 数 `B_n`。`B₃=5`，`B₄=15`，`B₅=52`。

### 6. 偏序关系、哈斯图与六类特殊元素

**偏序** = 自反 + 反对称 + 传递，记 `<A, ≼>`。典型：`<R, ≤>`、`<P(S), ⊆>`、`<Z⁺, ∣>`。

> `⊂`（真包含）与 `<`（严格小于）==都不是==偏序——它们不自反。

**可比 / 不可比**：`x≼y` 或 `y≼x` 为可比；否则不可比，记 `x ∥ y`。偏序允许不可比，这正是"偏"的含义。

**哈斯图三规则**：① 去自环；② 去传递可推出的边（只留**覆盖关系** `x⋖y`：`x≺y` 且中间无 `z` 使 `x≺z≺y`）；③ 按"小的在下"分层摆放，省掉箭头。

**六类特殊元素**（设 `B⊆A`）

| 名称 | 在哪个集合找 | 条件 | 唯一性 | 存在性 |
| :--- | :--- | :--- | :--- | :--- |
| 最大元 `max B` | `B` 内 | `∀x∈B, x≼b` | 若存在则唯一 | 不一定 |
| 最小元 `min B` | `B` 内 | `∀x∈B, b≼x` | 若存在则唯一 | 不一定 |
| 极大元 | `B` 内 | `B` 中无比它更大的 | 可多个 | 有限必有 |
| 极小元 | `B` 内 | `B` 中无比它更小的 | 可多个 | 有限必有 |
| 上界 | `A` 内（==可不在 B==） | `∀x∈B, x≼b` | 可多个 | 不一定 |
| 下界 | `A` 内（==可不在 B==） | `∀x∈B, b≼x` | 可多个 | 不一定 |
| 上确界 `sup B` | `A` 内 | 上界中**最小**者 | 若存在则唯一 | 不一定 |
| 下确界 `inf B` | `A` 内 | 下界中**最大**者 | 若存在则唯一 | 不一定 |

**三条必背辨析**

1. ==最大元必是极大元，反之不成立==（最大元要求与全 `B` 可比）。
2. `B` 中出现不可比的一对，**不妨碍**最大元/最小元存在（只要有元素压住/托住所有人）。
3. ==`max B` 存在 ⟹ `sup B = max B`==；`min B` 存在 ⟹ `inf B = min B`。反向不成立。

**在 `<P(U), ⊆>` 中**：`sup B = ∪B`（并），`inf B = ∩B`（交）。
**在 `<Z⁺, ∣>` 中**：`sup` 对应 lcm 直觉，`inf` 对应 gcd 直觉。

**全序与良序**：全序 = 偏序 + 任意两元素可比（哈斯图是一条链）。良序 = 全序 + 任意非空子集有最小元（`<N,≤>` 良序，`<Z,≤>`、`<R,≤>` 非良序）。

### 7. 函数

**函数 = 关系 + 定义域取满 + 单值**。`f: A→B` 即 `f⊆A×B` 且 `dom f = A`、每个 `x` 唯一 `y`。

| 记号 | 含义 | 提醒 |
| :--- | :--- | :--- |
| `dom f` | 定义域 | 对函数而言 ==`= A`== |
| `ran f` | 值域 | `ran f ⊆ B`，==可以不等于 B== |
| `B` | 陪域 | ==陪域 ≠ 值域== |

**判定（图 / 矩阵）**：是函数 ⟺ 每点恰一条**出**边 ⟺ 每行恰一个 1。

| 类型 | 定义 | 等价说法 | 矩阵 | 入边 |
| :--- | :--- | :--- | :--- | :--- |
| 满射 | `ran f = B` | `∀y∈B, f⁻¹(y)≠∅` | 每列 ≥1 个 1 | 每点 ≥1 |
| 单射 | `f(x₁)=f(x₂) ⟹ x₁=x₂` | 不同输入不同输出 | 每列 ≤1 个 1 | 每点 ≤1 |
| 双射 | 满 ∧ 单 | `f⁻¹` 是函数 | 每行每列恰 1 个 1（置换矩阵） | 每点恰 1 |

**有限集三条结论**

```
|A| < |B|  ⟹  一定不满射
|A| > |B|  ⟹  一定不单射
|A| = |B|  ⟹  单射 ⟺ 满射 ⟺ 双射
```

**计数**（`|A|=m`，`|B|=n`）

| 类型 | 个数 |
| :--- | :--- |
| 全部函数 | `nᵐ` |
| 单射 | `P(n,m) = n(n−1)…(n−m+1)`（`m>n` 时为 0） |
| 满射 | `Σ_{k=0}^{n} (−1)^k C(n,k)(n−k)^m`（`m<n` 时为 0） |
| 双射 | `n!`（`m=n` 时） |

> 校验技巧：`m=n=3` 时满射公式得 `27−3·8+3·1=6`，与 `3!` 一致。

**像与原像**

- 像：`f(A′) = {f(x) ∣ x∈A′}`；`ran f = f(A)`。
- 原像：`f⁻¹(y) = {x∈A ∣ f(x)=y}`，==是集合，不是元素==，可能为空。
- `f(A′∩A″) ⊆ f(A′)∩f(A″)`，==一般不相等==（`f` 单射时才等）。
- `f(A′∪A″) = f(A′)∪f(A″)`（并永远保等号）。

**特殊函数**

| 名称 | 定义 | 满/单 |
| :--- | :--- | :--- |
| 常函数 | `f(x)=b₀` | 满仅当 `B={b₀}`；单仅当 `\|A\|=1` |
| 恒等函数 `I_A` | `I_A(x)=x` | 双射，复合单位元 |
| 特征函数 `χ_{A′}` | `E→{0,1}` | 一般既不单也不满 |
| 自然映射 `π` | `π(a)=[a]_R` | 满射；单 ⟺ `R` 是相等关系 |

### 8. 复合与反函数

**复合**：`(g∘f)(x) = g(f(x))`，==先 f 后 g==；前提 `ran f ⊆ dom g`。

**推演表**

| 已知 | 结论 | 反推 |
| :--- | :--- | :--- |
| `f`、`g` 都单射 | `g∘f` 单射 | — |
| `f`、`g` 都满射 | `g∘f` 满射 | — |
| `g∘f` 单射 | — | ==`f` 单射==（`g` 未必） |
| `g∘f` 满射 | — | ==`g` 满射==（`f` 未必） |

> 口诀：==单射向内找 `f`，满射向外找 `g`==。

**反函数四条恒等式**（`f: A→B` 双射）

`f⁻¹∘f = I_A`；`f∘f⁻¹ = I_B`；`I_B∘f = f`；`f∘I_A = f`；`(f⁻¹)⁻¹ = f`；`(g∘f)⁻¹ = f⁻¹∘g⁻¹`。

**可逆 ⟺ 双射**，且反函数唯一。

> `f⁻¹` 三重身份：**逆关系**（任何函数都有）｜**逆像符号** `f⁻¹(y)`（任何函数都有定义）｜**反函数**（只有双射才有）。这是本章最大的术语坑。

### 例 1　符号化（★基础）

把下列命题符号化：
(1) 只要不下雨，我就去跑步。
(2) 除非你道歉，否则我不原谅你。
(3) 我去跑步，仅当天气好。

**解**：设 `p`：下雨；`q`：我去跑步；`r`：天气好；`s`：你道歉；`t`：我原谅你。

(1) `¬p → q`（"只要…就…"是充分条件，前件为 `¬p`）
(2) `¬s → ¬t`（"P 除非 Q" ⇔ `¬Q→P`；"除非 Q，否则 R" ⇔ `¬Q→R`）
(3) `q → r`（"P 仅当 Q" ⇔ `P→Q`，`q` 是前件）

> 点评：==`只要` 引出后件的前件？不——"只要 A 就 B" 是 `A→B`；"仅当"才是 `B→A`==。三个连接词配错一个，整题归零。

### 例 3　等值演算（★★核心）

用等值演算证明 `(p→q)→(p→r) ⇔ p→(q→r)`。

**解**：

```
左边 = (p→q)→(p→r)
     ⇔ ¬(¬p∨q) ∨ (¬p∨r)          蕴含等值式
     ⇔ (p∧¬q) ∨ ¬p ∨ r            德摩根、双重否定
     ⇔ [ (¬p∨p) ∧ (¬p∨¬q) ] ∨ r   分配律（对 p∧¬q 与 ¬p 用）
     ⇔ [ 1 ∧ (¬p∨¬q) ] ∨ r        排中律
     ⇔ ¬p ∨ ¬q ∨ r                同一律、零律
右边 = p→(q→r)
     ⇔ ¬p ∨ (¬q∨r)                蕴含等值式（用两次）
     ⇔ ¬p ∨ ¬q ∨ r                结合律
左 = 右，故等值。∎
```

> 点评：等值演算的给分点在"**每步写出依据**"。只写一行结论不给理由，最多得一半分。

### 例 4　主析取范式与主合取范式（★★★核心）

求 `A = (p→q)∧r` 的主析取范式和主合取范式。

**解**：

`p→q ⇔ ¬p∨q`，故 `A ⇔ (¬p∨q)∧r`。

用分配律拆成极小项：

```
A ⇔ (¬p∧r) ∨ (q∧r)
  ⇔ (¬p∧r∧(q∨¬q)) ∨ (q∧r∧(p∨¬p))
  ⇔ (¬p∧q∧r) ∨ (¬p∧¬q∧r) ∨ (p∧q∧r) ∨ (¬p∧q∧r)
  ⇔ (¬p∧¬q∧r) ∨ (¬p∧q∧r) ∨ (p∧q∧r)
```

按 `p q r` 顺序（`¬p↔0`，`p↔1`）编码：`001 → m₁`，`011 → m₃`，`111 → m₇`。

**主析取范式**：`A ⇔ m₁ ∨ m₃ ∨ m₇`，即 `Σm(1,3,7)`。

**主合取范式**（下标互补，`{0,1,2,3,4,5,6,7}−{1,3,7} = {0,2,4,5,6}`）：

`A ⇔ M₀ ∧ M₂ ∧ M₄ ∧ M₅ ∧ M₆`，即 `ΠM(0,2,4,5,6)`。

> 点评：三个坑——① 拆极小项时漏补变元；② 编码时把 `¬p` 记成 1（应记 0）；③ 主合取范式写成"或"（应为"与"）。==验算：真值表里成真行只有 `001,011,111` 三行，与 `Σm(1,3,7)` 吻合。==

## （二）一阶逻辑例题

### 例 7　符号化（★★★★核心）

个体域为全总个体域。符号化：
(1) 所有的有理数都是实数。
(2) 有的有理数是整数。
(3) 没有不犯错误的人。
(4) 发光的不都是金子。

**解**：设 `R(x)`：x 是有理数；`S(x)`：x 是实数；`I(x)`：x 是整数；`P(x)`：x 是人；`F(x)`：x 会犯错误；`G(x)`：x 发光；`J(x)`：x 是金子。

(1) `∀x(R(x)→S(x))`
(2) `∃x(R(x)∧I(x))`
(3) `¬∃x(P(x)∧¬F(x))`，等价于 `∀x(P(x)→F(x))`
(4) `¬∀x(G(x)→J(x))`，等价于 `∃x(G(x)∧¬J(x))`

> 点评：==全称配 `→`、存在配 `∧`==，这是全章第一大铁律。写反的典型错误：`∀x(R(x)∧S(x))` 意思是"所有个体都是有理数且是实数"，与原意差得远。

### 例 8　辖域与变元分析（★★）

设公式 `∀x(F(x) ∧ ∃y G(x,y)) → H(x)`。指出各量词的辖域、指导变元，并判断各变元的出现性质及是否为闭式。

**解**：

- `∀x` 的辖域是 `F(x) ∧ ∃y G(x,y)`；指导变元 `x`。
- `∃y` 的辖域是 `G(x,y)`；指导变元 `y`。
- `F(x)` 中的 `x`：**约束**出现。
- `G(x,y)` 中的 `x`：**约束**出现（在 `∀x` 辖域内）；`y`：**约束**出现。
- `H(x)` 中的 `x`：==自由==出现（在 `∀x` 辖域之外）。
- 因存在自由变元 `x` ⟹ ==不是闭式==。

> 点评：同名变元在不同位置可以一自由一约束。==判断只看"是否落在对应量词的辖域内"，与符号是否同名无关。==

### 例 9　解释与真值（★★★）

个体域 `D={1,2}`，`F(x,y)` 解释为 `x+y=3`。求 `∀x∃yF(x,y)` 与 `∃y∀xF(x,y)` 的真值。

**解**：

- `∀x∃yF(x,y)`：`x=1` 时取 `y=2` 得 `1+2=3` ✓；`x=2` 时取 `y=1` 得 `2+1=3` ✓。故==真==。
- `∃y∀xF(x,y)`：需找一个固定的 `y` 使 `1+y=3` 且 `2+y=3` 同时成立，即 `y=2` 且 `y=1`，不可能。故==假==。

结论：此解释下 `∃y∀xF(x,y)` 为假而 `∀x∃yF(x,y)` 为真，==印证 `∃∀ ⇒ ∀∃` 但反向不成立==。

> 点评：求 `∃y∀x` 时，`y` 必须是**同一个值**通过所有 `x` 的检验；求 `∀x∃y` 时每个 `x` 可以配**不同的** `y`。这是两者唯一的差别，也是全部难度所在。

### 例 10　前束范式（★★★★核心）

求 `∀xF(x) → ∃xG(x)` 的前束范式。

**解**：

```
∀xF(x) → ∃xG(x)
⇔ ¬∀xF(x) ∨ ∃xG(x)                    ① 消蕴含
⇔ ∃x¬F(x) ∨ ∃xG(x)                    ② 否定内移（量词否定等值式）
⇔ ∃x¬F(x) ∨ ∃yG(y)                    ③ 换名（把后一个约束变元 x 改为 y）
⇔ ∃x(¬F(x) ∨ ∃yG(y))                  ④ 量词左移（辖域扩张）
⇔ ∃x∃y(¬F(x) ∨ G(y))                  ④ 再左移
```

**前束范式**：`∃x∃y(¬F(x) ∨ G(y))`。

> 点评：第 ③ 步换名是最容易被跳过、也最必须的一步。若直接写 `∃x(¬F(x)∨G(x))`，就把两个本来独立的量词合并了，语义完全改变。==前束范式不唯一，但每一步必须可验证。==

## （三）集合例题

### 例 11　`∈` 与 `⊆` 辨析（★★）

设 `A={∅,{∅}}`。判断下列各式真假：
(1) `∅∈A`　(2) `∅⊆A`　(3) `{∅}∈A`　(4) `{∅}⊆A`　(5) `{{∅}}⊆A`

**解**：

| 式 | 真假 | 理由 |
| :-: | :-: | :--- |
| (1) `∅∈A` | **真** | `∅` 是 `A` 列出的元素之一 |
| (2) `∅⊆A` | **真** | 空集是任何集合的子集 |
| (3) `{∅}∈A` | **真** | `{∅}` 是 `A` 列出的元素之一 |
| (4) `{∅}⊆A` | **真** | `{∅}` 的唯一元素 `∅` 属于 `A` |
| (5) `{{∅}}⊆A` | **真** | 其唯一元素 `{∅}` 属于 `A` |

**补充**：`|A| = 2`；`P(A) = {∅, {∅}, {{∅}}, A}`，`|P(A)| = 4 = 2²`。

> 点评：`∈` 问"在不在清单上"，`⊆` 问"每个成员是不是也在清单上"。两者可以同时为真，(3)(4) 就是例证。

### 例 12　集合等式证明（★★★★核心）

证明 `(A−B)−C = A−(B∪C)`。

**解**：

```
(A−B)−C = {x ∣ x∈A−B ∧ x∉C}
        = {x ∣ (x∈A ∧ x∉B) ∧ x∉C}
        = {x ∣ x∈A ∧ (x∉B ∧ x∉C)}
        = {x ∣ x∈A ∧ ¬(x∈B ∨ x∈C)}
        = {x ∣ x∈A ∧ x∉(B∪C)}
        = A−(B∪C)
```

（用了 `−` 的定义、`∧` 的结合律、德摩根律、`∪` 的定义。）∎

> 点评：==元素法的骨架是"从定义翻译到逻辑式，再用逻辑等值式变形，最后翻译回集合"==。中间不要跳步，`x∉B ∧ x∉C ⟺ x∉(B∪C)` 这步必须写出来。

### 例 13　容斥原理（★★★★核心）

求 `1…1000` 中不能被 `5`、`6`、`8` 整除的数的个数。

**解**：设 `A`、`B`、`C` 分别为被 5、6、8 整除的数集，全集 `E={1,…,1000}`。

```
|A| = ⌊1000/5⌋ = 200
|B| = ⌊1000/6⌋ = 166
|C| = ⌊1000/8⌋ = 125

|A∩B| = ⌊1000/lcm(5,6)⌋ = ⌊1000/30⌋ = 33
|A∩C| = ⌊1000/lcm(5,8)⌋ = ⌊1000/40⌋ = 25
|B∩C| = ⌊1000/lcm(6,8)⌋ = ⌊1000/24⌋ = 41

|A∩B∩C| = ⌊1000/lcm(5,6,8)⌋ = ⌊1000/120⌋ = 8
```

```
|A∪B∪C| = 200 + 166 + 125 − 33 − 25 − 41 + 8 = 400
|~A∩~B∩~C| = 1000 − 400 = 600
```

**答**：600 个。

> 点评：=="同时被 a、b 整除"必须用 lcm==。若写成 `⌊1000/(5×6)⌋=33` 恰好数值相同，但 `lcm(6,8)=24 ≠ 48`，一处用错就全错。

### 例 14　"恰好 k 个"（★★★★进阶）

某班 50 人，参加数学竞赛 30 人、物理 25 人、化学 20 人；数学物理都参加 15 人，数学化学都参加 12 人，物理化学都参加 8 人，三科都参加 5 人。求恰好参加一科、恰好参加两科的人数。

**解**：由题意 `S₁ = 30+25+20 = 75`；`S₂ = 15+12+8 = 35`；`S₃ = 5`。

```
恰好一科 N₁ = S₁ − 2S₂ + 3S₃ = 75 − 70 + 15 = 20
恰好两科 N₂ = S₂ − 3S₃ = 35 − 15 = 20
恰好三科 N₃ = S₃ = 5
一科都不参加 = 50 − (20+20+5) = 5
```

**答**：恰好一科 20 人，恰好两科 20 人。

> 点评：`S₂` 是"所有两两交集之和"，一个三科都参加的人在 `S₂` 里被算了 3 次，所以 `N₂ = S₂ − 3S₃`；在 `S₁` 里被算 3 次，公式里就减 `2S₂`、加 `3S₃` 来归零。==记住"被多算了几次就减几次"。==

### 例 15　欧拉函数（★★★进阶）

```

       = 180 × 1/2 × 2/3 × 4/5
       = 48
```

**答**：48 个。

### 例 16　笛卡尔积与关系计数（★★）

设 `A={1,2,3}`，`B={a,b}`。求 `|A×B|`、`|P(A×B)|`、`A` 上二元关系的个数、`A` 上等价关系的个数。

**解**：

- `|A×B| = 3×2 = 6`（`dom` 3 个，每个配 2 个后件）
- `|P(A×B)| = 2⁶ = 64`
- `A` 到 `B` 的关系：`2^{3×2}=2⁶=64` 个
- `A` 上关系：`2^{3×3}=2⁹=512` 个
- `A` 上等价关系 = 划分个数 = `B₃ = 5` 个

> 点评：==关系的个数总是指数 `2^{有序对总数}`==，因为每个有序对"在 / 不在"关系里各 2 选。等价关系个数是 Bell 数，不是 `2^{n²}`。

### 例 17　复合与幂（★★★）

`A={1,2,3}`，`R={⟨1,2⟩,⟨2,3⟩,⟨3,1⟩}`。求 `dom R`、`ran R`、`R⁻¹`、`R²`、`R³`、`R⁴`。

**解**：

- `dom R = ran R = {1,2,3}`
- `R⁻¹ = {⟨2,1⟩,⟨3,2⟩,⟨1,3⟩}`
- `R² = R∘R`（先 R 后 R）：`1→2→3` 得 `⟨1,3⟩`；`2→3→1` 得 `⟨2,1⟩`；`3→1→2` 得 `⟨3,2⟩`

  `R² = {⟨1,3⟩,⟨2,1⟩,⟨3,2⟩}`
- `R³ = R²∘R`：`1→3→1`、`2→1→2`、`3→2→3`，故 `R³ = {⟨1,1⟩,⟨2,2⟩,⟨3,3⟩} = I_A`
- `R⁴ = R³∘R = I_A∘R = R`

**答**：`R` 是 3-循环，周期为 3（`R³=I_A`，`R⁴=R`）。

> 点评：==`R⁰ = I_A`，不是 `∅`==。看到"每个元素前后件各出现一次"，先想它是循环之并，幂次直接按周期算。

### 例 18　五种性质判定（★★★★核心）

`A={1,2,3}`，逐条判定下列关系的五种性质：
`R₁={⟨1,1⟩,⟨2,2⟩,⟨3,3⟩,⟨1,2⟩}`；`R₂={⟨1,2⟩,⟨2,1⟩,⟨1,1⟩,⟨2,2⟩}`；`R₃={⟨1,2⟩,⟨2,3⟩,⟨1,3⟩}`；`R₄=∅`；`R₅=A×A`；`R₆={⟨1,2⟩,⟨2,1⟩}`。

**解**：

| 关系 | 自反 | 反自反 | 对称 | 反对称 | 传递 |
| :--- | :-: | :-: | :-: | :-: | :-: |
| `R₁` | ✓（三自环齐） | ✗ | ✗（有 `⟨1,2⟩` 无 `⟨2,1⟩`） | ✓ | ✓ |
| `R₂` | ✗（缺 `⟨3,3⟩`） | ✗（有自环） | ✓ | ✗（`⟨1,2⟩`与`⟨2,1⟩`） | ✓ |
| `R₃` | ✗ | ✓ | ✗ | ✓ | ✓ |
| `R₄=∅` | ✗ | ✓ | ✓ | ✓ | ✓ |
| `R₅=A×A` | ✓ | ✗ | ✓ | ✗ | ✓ |
| `R₆` | ✗ | ✓ | ✓ | ✗ | ✗（缺 `⟨1,1⟩`） |

**传递性复核**：`R₃` 只有 `⟨1,2⟩,⟨2,3⟩⟹⟨1,3⟩` 这一组，且 `⟨1,3⟩∈R₃`，故传递；`R₆` 中 `⟨1,2⟩∧⟨2,1⟩` 应得 `⟨1,1⟩`，但不在 `R₆` 里，故不传递。

> 点评：==`∅` 同时满足反自反、对称、反对称、传递四条==（`A≠∅` 时它不自反）。`A×A` 除反对称外全满足。判断顺序固定为"自反 → 反自反 → 对称 → 反对称 → 传递"，逐条给证据。

### 例 19　三种闭包（★★★★核心）

`A={1,2,3}`，`R={⟨1,2⟩,⟨2,3⟩}`。求 `r(R)`、`s(R)`、`t(R)`，并用 Warshall 算法验证 `t(R)`。

**解**：

- `r(R) = R ∪ I_A = {⟨1,2⟩,⟨2,3⟩,⟨1,1⟩,⟨2,2⟩,⟨3,3⟩}`
- `s(R) = R ∪ R⁻¹ = {⟨1,2⟩,⟨2,1⟩,⟨2,3⟩,⟨3,2⟩}`
- `t(R)`：`R² = {⟨1,3⟩}`，`R³ = ∅`，故 `t(R) = R∪R² = {⟨1,2⟩,⟨2,3⟩,⟨1,3⟩}`

**Warshall 验证**：初始矩阵（行列序 `1,2,3`）

```
0 1 0
0 0 1
0 0 0
```

- `k=1`：第 1 列全 0，不变。
- `k=2`：第 2 列第 1 行为 1 ⟹ `r₁ ← r₁ ∨ r₂ = (0,1,1)`。
- `k=3`：第 3 列第 1、2 行为 1 ⟹ `r₁ ← r₁∨r₃ = (0,1,1)`（不变），`r₂ ← r₂∨r₃ = (0,0,1)`（不变）。

终矩阵

```
0 1 1
0 0 1
0 0 0
```

即 `{⟨1,2⟩,⟨1,3⟩,⟨2,3⟩}`，与公式法一致。✓

> 点评：==`t(R)` 不是 `R∪R²` 就够了——这里恰好够，因为链最长 2 步==。一般要算到 `Rⁿ`（`n=|A|`）。Warshall 的 `k` 必须从 1 到 n 走最外层。

### 例 20　等价关系与商集（★★★★核心）

`A={1,2,3,4,5,6}`，`R={⟨x,y⟩ ∣ x≡y (mod 3)}`。判定 `R` 为等价关系，求各等价类与商集，并写出关系矩阵的块状结构。

**解**：`x−y` 被 3 整除。自反（`x−x=0`）、对称（差取反）、传递（两差相加）均成立 ⟹ 等价关系。

按 `mod 3` 分组：

```
[1] = [4] = {1,4}
[2] = [5] = {2,5}
[3] = [6] = {3,6}
A/R = { {1,4}, {2,5}, {3,6} }
```

关系矩阵（行列为 `1,2,3,4,5,6`）呈三个 `2×2` 全 1 方块沿对角线排列，块间全 0。

> 点评：==两个不同余数的类绝不相交，全体刚好铺满 `A`==——这就是"商集是划分"。写商集时注意它是**集合的集合**（`A/R` 只有 3 个元素，不是 6 个）。

### 例 21　偏序、哈斯图与六类特殊元素（★★★★★核心）

`A={1,2,3,4,6,12}`，`≼` 为整除 `∣`。画哈斯图，并对 `B={2,3,6}` 求六类特殊元素。

**解**：

**覆盖关系**：`1⋖2, 1⋖3, 2⋖4, 2⋖6, 3⋖6, 4⋖12, 6⋖12`

**分层**

| 层 | 元素 |
| :-: | :--- |
| 第 4 层（顶） | `12` |
| 第 3 层 | `4`, `6` |
| 第 2 层 | `2`, `3` |
| 第 1 层（底） | `1` |

连边：`1–2, 1–3, 2–4, 2–6, 3–6, 4–12, 6–12`。（`2 ∥ 3`、`4 ∥ 6` 不可比，同层分开摆。）

**六类元素（`B={2,3,6}`）**

| 概念 | 结果 | 理由 |
| :--- | :--- | :--- |
| `max B` | **6** | `2∣6, 3∣6, 6∣6`，人人 ≤ 它 |
| `min B` | **不存在** | 没有 `b∈B` 能同时整除 2 和 3 |
| 极大元 | **6** | `B` 中无比 6 更大者 |
| 极小元 | **2, 3** | 二者互不可比，都无比自己更小者 |
| 上界 | **6, 12** | `A` 中同时被 2、3 整除者 |
| 下界 | **1** | `A` 中同时整除 2、3 者，且 `1∉B` |
| `sup B` | **6** | 上界 `{6,12}` 中最小者 |
| `inf B` | **1** | 下界 `{1}` 中最大者，`1∉B` |

**对比 `B′={2,3}`**：`max B′` 不存在，极大元为 `2,3`（两个），`sup B′ = 6` 仍存在。

> 点评：==极大元可以有两个而最大元根本不存在；`sup`、`inf` 都能落在 `B` 外面==。三句话记牢：最大元必是极大元；`max B` 存在则 `sup B = max B`；不可比的一对不妨碍上位有第三个元素压住全场。

### 例 23　函数计数（★★★★核心）

`|A|=4`，`|B|=3`。求从 `A` 到 `B` 的函数总数、单射数、满射数、双射数。

双射数   = 0        （|A| ≠ |B|）

### 例 24　复合与反函数（★★★）

`f: R→R`，`f(x)=2x+1`；`g: R→R`，`g(x)=x²`。求 `g∘f`、`f∘g`；再判断 `f` 是否可逆并求 `f⁻¹`。

**解**：

```
(g∘f)(x) = g(f(x)) = (2x+1)² = 4x²+4x+1
(f∘g)(x) = f(g(x)) = 2x²+1
```

两者不等 ⟹ ==复合不满足交换律==。

`f(x)=2x+1`：单射（`2x₁+1=2x₂+1 ⟹ x₁=x₂`）；满射（任取 `y`，`x=(y−1)/2∈R`）⟹ 双射，可逆。

由 `y=2x+1` 解出 `x=(y−1)/2`，故

```
f⁻¹: R→R,  f⁻¹(y) = (y−1)/2
```

验证：`f⁻¹(f(x)) = ((2x+1)−1)/2 = x = I_R(x)` ✓

> 点评：==求反函数的标准动作："解出 x（用 y 表示）+ 换字母 + 回代验证"==。写 `f⁻¹` 前必须先验双射，否则答案应是"逆关系不是函数"。

### 例 25　复合推演与恒等式化简（★★★★进阶）

(1) 设 `f: A→B`、`g: B→C`。若 `g∘f` 是单射，能推出什么？举反例说明不能推出什么。
(2) 设 `f: A→B` 为双射，化简 `g⁻¹∘(g∘f)∘f⁻¹`。

**解**：

**(1)** `g∘f` 单射 ⟹ ==`f` 单射==（不能推出 `g` 单射）。

证明：设 `f(x₁)=f(x₂)`，两边作用 `g` 得 `g(f(x₁))=g(f(x₂))`，由 `g∘f` 单射得 `x₁=x₂`。

反例（`g` 非单射）：`A={1}`，`B={1,2}`，`C={a}`；`f(1)=1`，`g(1)=g(2)=a`。`g∘f` 是单射（定义域单元素自动单射），但 `g(1)=g(2)`，`g` 不单。

**(2)**

```
g⁻¹∘(g∘f)∘f⁻¹ = (g⁻¹∘g)∘(f∘f⁻¹) = I_B∘I_B = I_B
```

> 点评：==口诀"单射向内找 f，满射向外找 g"==。化简题看到 `f⁻¹∘f`、`f∘f⁻¹`、`I∘f` 就直接划掉，这是恒等式题的全部技巧。

            ⟺ x∈A ∧ x∉B ∧ x∉C
