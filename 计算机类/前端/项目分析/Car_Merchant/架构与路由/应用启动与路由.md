# 应用启动与路由

> [!abstract] 一句话
> 应用从 `src/main.ts` 起步：==`createApp(App)` 造出实例 → `app.use(router)` 装上路由 → `app.mount('#app')` 挂到页面==。`App.vue` 作为根组件常驻导航栏并留出 `<router-view />`，路由表则在 `router/index.ts` 里把 `/` 和 `/rent_page` 映射到两个页面。

---

## 一、应用启动过程

应用从 `src/main.ts` 开始执行：

```ts
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'

const app = createApp(App)

app.use(createPinia())
app.use(router)

app.mount('#app')
```

### 1.1 `createApp`

```ts
const app = createApp(App)
```

`createApp(App)` 会创建一个 Vue 应用实例，`App.vue` 是这个应用的根组件。

可以把它理解成：

```text
浏览器页面
  └─ Vue 应用
      └─ App.vue
          ├─ Nav_header.vue
          └─ router-view 当前页面
```

### 1.2 `app.use(router)`

```ts
app.use(router)
```

这一步将 Vue Router 安装到当前 Vue 应用中。安装后，组件中才能使用：

```ts
import { useRouter, useRoute } from 'vue-router'
```

以及模板中的：

```vue
<router-view />
```

### 1.3 `app.use(createPinia())`

项目注册了 Pinia：

```ts
app.use(createPinia())
```

Pinia 是 Vue 官方推荐的状态管理工具。不过当前项目的车辆状态仍然保存在 `Rent_page.vue` 中，没有通过 Pinia store 共享。

> [!note] 这不是错误
> 只说明目前项目规模还可以由页面组件自己管理状态。如果以后需要让订单页、用户页和租车页共享车辆数据，就可以把 `cars` 移动到 Pinia store 中，详见 [[设计原则与改进方向]]。

### 1.4 `app.mount('#app')`

```ts
app.mount('#app')
```

这会把 Vue 应用挂载到 `index.html` 中的元素：

```html
<div id="app"></div>
```

挂载后，Vue 开始接管这个 DOM 节点。

---

## 二、App.vue 的作用

`App.vue` 是根组件：

```vue
<script setup lang="ts">
import Nav_header from './components/Nav_header.vue'
</script>

<template>
  <Nav_header />
  <router-view />
</template>
```

它做了两件事：

1. 无论当前在哪个路由，都显示顶部导航。
2. 使用 `<router-view />` 显示当前路由匹配到的页面组件。

因此导航栏不会随着首页和租车页面切换而消失。

### 2.1 `<router-view />`

`<router-view />` 是 Vue Router 提供的组件占位符。

当当前路径是 `/` 时：

```text
<router-view />
  └─ Home_hero_page.vue
```

当当前路径是 `/rent_page` 时：

```text
<router-view />
  └─ Rent_page.vue
```

页面切换时，通常不会发生传统多页面网站的整页刷新，而是由 Vue Router 替换路由出口中的组件。

## 三、Router 的实现和页面跳转

路由配置位于 `src/router/index.ts`：

```ts
import { createRouter, createWebHistory } from 'vue-router'
import Home_hero_page from '@/components/Home_hero_page.vue'
import Rent_page from '@/components/Rent_page.vue'

const routes = [
  {
    path: '/',
    name: 'Home_page',
    component: Home_hero_page
  },
  {
    path: '/rent_page',
    name: 'Rent_page',
    component: Rent_page
  }
]

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes,
})

export default router
```

### 3.1 路由对象

一个路由对象通常包含三个重要属性：

```ts
{
  path: '/rent_page',
  name: 'Rent_page',
  component: Rent_page
}
```

#### `path`

访问地址：

```text
/rent_page
```

浏览器访问：

```text
http://localhost:5173/rent_page
```

就会匹配到这个路由。

#### `name`

路由名称：

```ts
name: 'Rent_page'
```

使用路由名称跳转比直接写路径更安全：

```ts
router.push({ name: 'Rent_page' })
```

如果以后修改路径为 `/cars`，只要路由名称不变，跳转代码仍然可以正常工作。

#### `component`

指定匹配成功后显示的组件：

```ts
component: Rent_page
```

### 3.2 `createWebHistory`

```ts
history: createWebHistory(import.meta.env.BASE_URL)
```

这里使用 HTML5 History 模式。地址看起来比较自然：

```text
/
/rent_page
```

另一种模式是 `createWebHashHistory`，地址会带 `#`：

```text
/#/rent_page
```

> [!warning] History 模式的部署要求
> History 模式更适合正式网站，但部署到服务器时需要服务器将未知路径回退到 `index.html`，否则直接刷新 `/rent_page` 可能出现 404。

### 3.3 导航栏中的路由跳转

`Nav_header.vue` 中使用：

```ts
import { computed, ref } from 'vue'
import { useRoute, useRouter } from 'vue-router'

const router = useRouter()
const route = useRoute()

const isRentPage = computed(() => route.name === 'Rent_page')
```

#### `useRouter`

`useRouter()` 获取路由操作对象：

```ts
router.push({ name: 'Rent_page' })
```

相当于让程序主动跳转页面。

#### `useRoute`

`useRoute()` 获取当前路由信息：

```ts
route.name
route.path
route.params
route.query
```

本项目用 `route.name` 判断当前是否处于租车页。

### 3.4 根据当前路由切换文字

```ts
const leapText = computed(() =>
  isRentPage.value ? 'Back' : "Let's start"
)
```

如果当前是租车页面，按钮显示 `Back`；否则显示 `Let's start`。

这里使用 `computed`，因为文字依赖于当前路由状态。当路由变化时，`leapText` 会自动重新计算。

### 3.5 导航函数

```ts
function goToRentPage() {
  if (isRentPage.value) {
    router.push({ name: 'Home_page' })
  } else {
    router.push({ name: 'Rent_page' })
  }
}
```

这个函数实现了一个来回切换：

```text
首页       --点击--> 租车页
租车页     --点击--> 首页
```

模板中通过事件绑定调用：

```vue
<div @click="goToRentPage">
```
