
版本控制（Version Control）是一种==**记录文件内容变化**的系统==，让你可以==随时回退==到某个历史版本，看清"谁、在什么时候、改了什么"。

## 为什么需要它

- **可回退**：改坏了能回到之前某个正常状态。
- **可追溯**：每次改动都有记录（作者、时间、原因）。
- **可协作**：多人同时改同一份文件，能合并各自的工作。
- **可分支**：可以并行做不同尝试，互不干扰。

## 两种类型

| 类型 | 说明 | 代表 |
| --- | --- | --- |
| 集中式 | 版本库放在一台中央服务器，所有人连它读写 | SVN |
| 分布式 | 每个人本地都有一份完整版本库，可离线提交 | **Git** |

## 三个关键概念（以 Git 为例）

- **仓库（Repository）**：存放所有版本记录的地方。
- **提交（Commit）**：一次改动的"快照"，是版本控制的基本单位。
- **分支（Branch）**：从某条历史线上分出来独立开发，完成后再合并。

## 一句话理解

> 版本控制 = 给文件装上"时光机 + 多人协作的规则"。
