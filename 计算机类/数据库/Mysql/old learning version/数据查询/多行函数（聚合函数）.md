```sql
AVG(COLUMN)-计算列的平均值-数值类型

SUM(COLUMN)-计算列的总值-数值类型

MIN(COLUMN)-任意类型

MAX(COLUMN)-任意类型

COUNT(COLUMN)-计算某一行或列的记录数
```

聚合函数的运算中，在遇到null值时不做计算

聚合函数不能互相嵌套，如SUM(AVG())

##### COUNT (列名) 完整详解

###### 1. 核心规则

`COUNT(字段名)`：**统计该字段不为 NULL 的记录行数**

只要这一行此字段是 `NULL`，这一行就不计入数量。

###### 2. 三种 COUNT 对比（极易混淆）

假设有表数据：

|id|name|score|
|---|---|---|
|1|小明|90|
|2|小红|NULL|
|3|NULL|85|
|4|小刚|77|

1. **COUNT(score)**
    
    只算 score 不为 null：行 1、3、4 → 结果 = 3
2. **COUNT(name)**
    
    name 不为 null：行 1、2、4 → 结果 = 3
3. **COUNT(*)**
    
    统计整张表所有行数，**无视 NULL**，全部 4 行 → 结果 = 4
4. **COUNT (常量值) 如 COUNT (1)**
    
    等价 COUNT (*)，统计全部行数，性能几乎无差别
