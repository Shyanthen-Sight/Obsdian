# Unit 7 Survey Reports 调查报告 —— 知识点精讲与分析

> 对应书中第 145–170 页。三个部分：Introduction 与 Literature Review、Methodology、Discussion 与 Conclusion。核心训练点：学术报告八段结构、文献综述四原则四组织法、四种定义法、三时态规则、Methodology 三要素、exemplification/quotation/rephrasing 展开。

---

## 一、单元定位

Survey report 是事实+数据支撑的调查结果总结，是全教材学术性最强的文体。它有一套高度结构化的逻辑框架：

**Introduction → Literature Review → Methodology → Findings → Discussion → Conclusion → Recommendation → Bibliography**

学完你应能写出一篇结构完整、可复现、学术规范的调查报告（单元项目要求 ≥3000 词）。

---

## 二、PART 1 Introduction 与 Literature Review（第 146–157 页）

### 1. Introduction 六要素
- Research subject（研究主题）
- Research purpose（研究目的）
- Research scope（研究范围）
- Research criteria（研究标准）
- Research hypotheses（研究假设）
- Research questions（研究问题）

**功能句类型**：交代背景、说明调查必要性、陈述总体目的、提出研究问题/假设、说明范围、概述全文结构。

### 2. Literature Review 六要素
- Defining key concepts（定义关键概念）
- Comparing subjects/methods/findings in previous research（比较前人研究的对象/方法/发现）
- Reviewing main theories（回顾主要理论）
- Identifying main issues or gaps（识别主要问题或研究空白）

### 3. 核心写作技巧
- **Stating the Necessity**：通过指出研究领域的 gap / problem / controversy 交代为什么要做这个研究；
- **Setting a Research Goal**：先写总体目标，再细化成可测量的 objectives / research questions；
- **Writing a Hypothesis**：预测变量间关系，须 accessible（可理解）且 provable（可验证）。

### 4. 文献综述四原则
**Being selective（有选择）/ Being critical（批判性）/ Being relevant（相关）/ Being synthesized（综合）**——不是罗列文献，而是批判性整合。

### 5. 文献综述四种组织法
**Theme-focused（按主题）/ Chronological（按时间）/ Method-focused（按方法）/ Multi-method（多方法）**。

### 6. 四种定义法
- **Elaboration**：用自己的话解释；
- **Quotation**：引用他人原话；
- **Comparison**：比较各家定义；
- **Exemplification**：举例说明。

### 7. 时态规则（Language Focus，重点）
- 研究具普适性且重要 → 一般现在时；
- 仍在进行且直接相关 → 现在完成时；
- 已完成且较次要 → 一般过去时；
- 叙述事件与前人结果用过去时，讨论观点/展示发现用现在时。

引出 gap/不确定性的词：no single study、lack of、much uncertainty、it is not clear、a major problem、fail to、only、little。

### 8. 表达工具
- 文献综述句型：A key issue in … is …；There is an extensive acknowledgement of …, but much uncertainty still exists about …；Although multiple methods for … are widely used …, the majority of the studies to date …；Most of the previous research emphasized …
- 定义句型：Sb. defines it as … / It refers to … / The term means that … / It is defined as … / As defined in / below / herein / by / above …

### 9. 范文解析
贯穿范文为 **Customer satisfaction survey**（用 Fuzzy AHP 模型比较专家与客户对服务满意度因素的观点）；文献综述例句涉及 SERVQUAL（Parasuraman 1988）、service quality 与银行利润。

### 10. 过程写作任务（Project 第一部分）
ABC Company 经理为三个月后的 Corporate Development Strategy Seminar 写 research report，从三个 Key Issues 选一（影响客户满意度的因素 / 创新销售模式 / 出口战略）。先填 Literature Review 笔记（Author 1–3 的 Subject/Questions/Issues/Methods/Findings/Limitations/Bibliography）和 Introduction 笔记（Title/Goal/Research questions）。

## 三、PART 2 Methodology（第 158–165 页）

### 1. 认知
Methodology 是对研究方法的系统描述，必须**清晰可复现、可检验信度（reliability）**。别人读完应能重复你的研究。

### 2. 三要素（重点）
- **Participants（参与者）**：年龄、性别、国籍、教育、地点、职业、样本量；
- **Instruments（工具）**：问卷、访谈、观察、录像等；
- **Procedure（流程）**：按顺序描述做了什么。

### 3. 写作技巧
- 准确清晰描述 participants / instruments / procedures，解释 what / how / why；
- **一律用过去时**描述研究流程；
- **被动语态**是流程描述的标配；
- **Describing a Procedure**：靠 signpost 词（initially / then / later / before / while / at the outset / immediately after / following the pilot study）按顺序展开，给出具体数据、专有名词、时间地点。

### 4. 范文解析
note-taking 调查（102 名大学生、课堂录像+笔记誊抄+15 分钟追踪访谈）；TESCO 女性员工访谈；30 题双语问卷（750 份）；20 份访谈转录。

### 5. 过程写作任务（Project 第二部分）
续写 Methodology。填要点表（Participant information / Instruments used / Procedure to follow），写样本量/年龄/性别/教育、观察/访谈/问卷、时间地点原因；自查 signpost 词、被动语态、动作原因、步骤易跟随。

## 四、PART 3 Discussion 与 Conclusion（第 166–170 页）

### 1. Discussion 功能句类型
- Results of the present study（本研究结果）
- Elaboration of the meanings（意义阐释）
- Rephrasing of the findings（发现重述）
- Comparison with the previous studies（与前人研究比较）
- Possible causes of the result（结果的可能原因）
- Comparison with the hypothesis（与假设对比）

### 2. Elaboration 三种展开法（重点）
对关键概念、发现、结果作进一步解释：
- **Exemplification 举例**：解释概念、澄清事实、论证观点；
- **Quotation 引述**：引用；
- **Rephrasing 改述**：换种说法。

### 3. Comparison 对比
识别差异、发现特点、得出洞见。今昔研究对比句型：the same as / be similar to / differentiate from / rather than / as in / tend to。

### 4. The Conclusion 四要素
- **验证假设**（verify hypotheses）
- **展示启示**（implications）
- **承认局限**（limitations）
- **提出进一步研究建议**（suggest further research）

### 5. 表达工具
展开路标词：for example、for instance、take … for example、an example of this is、such as、e.g.、namely、that is、in other words、in this case。

### 6. 范文解析
education attainment 与 job satisfaction 负相关（Verhostad 1986、Share 2004）；客户满意度与零售银行（Grounded Theory Method）；按 Caruana(2002) 年龄分组的局限。

### 7. 过程写作任务（Project 第三部分）
续写 Findings、Discussion、Conclusion and Recommendation。分析数据（select major data / interpret / compare / present），Discussion 展开结果+分析原因+与前人比较，Conclusion 写发现意义/局限/后续研究建议；各部分齐备，**报告至少 3000 词**，Times New Roman、标题副标题突出。
