## 一、数值类型

### 1. 整数型

| 类型                                            | 字节  | 取值范围                   | 适用场景           |
| --------------------------------------------- | --- | ---------------------- | -------------- |
| TINYINT                                       | 1   | -128~127；无符号 0~255     | 状态、开关、少量分类     |
| SMALLINT                                      | 2   | -32768~32767           | 小数量、年级、次数      |
| MEDIUMINT                                     | 3   | -8388608~8388607       | 人数、浏览量         |
| INT                                           | 4   | -2147483648~2147483647 | 主键 ID、订单号（最常用） |
| BIGINT                                        | 8   | 超大正负整数                 | 雪花 ID、超大流水、时间戳 |
| **修饰：UNSIGNED 无符号，只能存正数；AUTO_INCREMENT 自增主键** |     |                        |                |

### 2. 浮点 & 定点

1. **FLOAT (单精度 4 字节)**：精度低，不适合金额，存温度、百分比粗略小数

2. **DOUBLE (双精度 8 字节)**：精度高于 float，仍有浮点误差

3. **DECIMAL (M,D) 定点数（核心）**
    
    - M：总长度，D：小数位数
    
    - 例：`DECIMAL(10,2)` 最多 8 位整数 + 2 位小数
    
    - **钱、价格、结算金额强制用 Decimal**，无精度丢失
    

## 二、字符串类型

### 1. 定长 / 变长短文本

1. **CHAR(n)**
    
    固定 n 字符长度，不足自动补空格；查询自动去空格；速度快；适合固定长度：手机号、身份证、验证码
    
    例：`CHAR(11)` 存手机号
2. **VARCHAR(n)**
    
    动态长度，占用实际字符大小 + 1~2 字节；节省空间；姓名、地址、标题、备注通用
    
    MySQL 最大 n=65535 字符

### 2. 大文本（长内容）

- TEXT：大段文字、文章、详情描述
- MEDIUMTEXT / LONGTEXT：超长篇文章、富文本

> 注意：大文本不能做主键、索引效率很低，尽量拆分

### 3. 二进制（文件字节流）

BLOB、MEDIUMBLOB、LONGBLOB：存图片、文件、二进制文件；**生产不推荐数据库存文件，存文件路径地址更优**

## 三、日期时间类型

1. **DATE**：3 字节，只存日期 `YYYY-MM-DD`（生日、下单日期）
2. **TIME**：3 字节，时分秒 `HH:mm:ss`
3. **DATETIME**：8 字节，完整日期时间 `YYYY-MM-DD HH:mm:ss`（业务创建、修改时间首选）
4. **TIMESTAMP**：4 字节，时间戳转日期；范围小（1970-2038）；可自动更新 `ON UPDATE CURRENT_TIMESTAMP`
5. **YEAR**：年份

## 四、特殊类型

1. **ENUM 枚举**
    
    限定固定可选值：`ENUM('男','女','未知')`，节省空间，限制非法数据
2. **SET 集合**
    
    可多选标签：`SET('热门','新品','打折')`
3. **JSON**（MySQL5.7+/8.0）
    
    存储数组、对象结构化数据，适合灵活扩展字段，不用频繁改表结构

# 其他数据库差异

## SQL Server

1. 整数：tinyint、smallint、int、bigint
2. 字符串：char、varchar、nchar、nvarchar（n 开头支持 Unicode 中文）
3. 时间：date、time、datetime、datetime2、smalldatetime
4. 金额专用：MONEY

## PostgreSQL

1. 数字：int4、int8、numeric (等价 decimal)
2. 字符串：char、varchar、text
3. 原生强大 JSON/JSONB，数组类型
4. 时间精度更高，支持时区 timestamptz

# 选型关键注意事项

1. **主键优先 BIGINT**，INT 上限约 21 亿，量大容易溢出
2. **金额绝对不用 float/double，只用 DECIMAL**
3. 中文统一 utf8mb4 字符集，varchar 足够，别乱用 text
4. 手机号、身份证固定长度用 CHAR，姓名地址用 VARCHAR
5. 时间字段：常规业务用 DATETIME，需要自动刷新更新时间用 TIMESTAMP
6. 图片、视频、文件存 URL 路径，不要存 BLOB 二进制
7. 固定状态值优先 ENUM，少用 TINYINT 记数字含义（可读性差）
8. 长度不要盲目设很大，varchar (200) 够用就别写 varchar (1000)，影响索引性能
