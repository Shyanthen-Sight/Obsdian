## 零、为什么要有"关系的运算"

4.1 把关系定义成笛卡尔积的子集：`R ⊆ A×B`。既然关系是==集合==，那么**集合能做的运算，关系也能做**：并、交、差、补。

但只做集合运算是**不够**的：

| 只当集合看 | 当关系看（有结构） |
| :--- | :--- |
| `R∪S`、`R∩S`、`R−S` 逐元素拼 | `R∘S`（**接力走两段**） |
| 不知道 `R` 从哪到哪 | `dom R`／`ran R`（**从哪些点出发、到哪些点结束**） |
| 不能反向读 | `R^{-1}`（**箭头全部掉头**） |

> **一句话动机**：==关系不只是"一堆有序对"，它同时是一张有向图。运算要同时照顾"集合身份"和"图的走向"。==

本篇新增的运算，都能在**关系图**和**关系矩阵**里找到直观影子——这也是本篇反复用两个视角对照的原因：

| 运算 | 集合 | 有向图 | 关系矩阵 `M` |
| :--- | :--- | :--- | :--- |
| `R^{-1}` | 有序对互换 | 每条边**反向** | **转置** `M^T` |
| `R∘S` | 中继接力 | 两段路**接起来** | **布尔矩阵乘法** |
| `R^n` | 反复接力 | **走 n 步**可达 | `M` 的 n 次布尔幂 |
| `R↾A` | 掐头 | 只留 A 中出发的边 | 把 A 外的行**清零** |

## 一、关系的基本运算

先约定：本篇默认 `R` 是从 `A` 到 `B` 的二元关系，即 `R ⊆ A×B`。

### 1.1 定义域、值域、域

**定义（定义域）**：

```
dom R = { x | ∃y( <x,y> ∈ R ) }
```

即所有"作为**第一分量**出现过"的元素。通俗说：==有箭头射出去的**出发点**全体==。

**定义（值域）**：

```
ran R = { y | ∃x( <x,y> ∈ R ) }
```

即所有"作为**第二分量**出现过"的元素。通俗说：==有箭头射进来的**终点**全体==。

**定义（域）**：

```
fld R = dom R ∪ ran R
```

> **记忆钩子**：`dom` 是 **d**eparture（出发），`ran` 是 **r**ange（到达），`fld` 是 **f**ield（田地，即"涉及的整片土地"）。==domain 管"前件"，range 管"后件"。==

**关键观察**：

- `dom R ⊆ A`，`ran R ⊆ B`。==一般**不相等**==（`R` 可以"用不满"A 或 B）。只有 `R = A×B` 这类"满关系"才会取等。
- `R = ∅` 时 `dom R = ran R = fld R = ∅`。
- 单个有序对：`dom{<a,b>} = {a}`，`ran{<a,b>} = {b}`。

从**有向图**角度看：

| 量 | 图论含义 |
| :--- | :--- |
| `dom R` | **出度 ≥ 1** 的顶点全体 |
| `ran R` | **入度 ≥ 1** 的顶点全体 |
| `fld R` | 与某条边**有关联**的顶点全体（孤立点被排除） |

### 1.2 逆关系

**定义（逆关系）**：

```
R^{-1} = { <y,x> | <x,y> ∈ R }
```

就是把 `R` 中每个有序对的**两个分量对调**。

**三个视角**：

| 视角 | 逆关系的样子 |
| :--- | :--- |
| 集合 | 每个 `<x,y>` 写成 `<y,x>` |
| 有向图 | 每条边**箭头反向** |
| 关系矩阵 | `M_{R^{-1}} = (M_R)^T`（**转置**） |

**基本性质**（都可以用元素法一行证完）：

| 性质 | 说明 |
| :--- | :--- |
| `(R^{-1})^{-1} = R` | 掉头两次回到原样 |
| `dom(R^{-1}) = ran R` | 逆的出发集 = 原的到达集 |
| `ran(R^{-1}) = dom R` | 逆的到达集 = 原的出发集 |
| `(R∪S)^{-1} = R^{-1}∪S^{-1}` | 逆对并分配 |
| `(R∩S)^{-1} = R^{-1}∩S^{-1}` | 逆对交分配 |

> **⚠️ 易错**：`R^{-1} ≠ R` 是常态。只有**对称关系**才满足 `R^{-1} = R`（这一点 [[4.3 关系的性质]] 会正式给出）。别一看 `^{-1}` 就以为在求"反函数"。

### 1.3 限制与像

**定义（限制）**：

```
R↾A = { <x,y> | <x,y> ∈ R ∧ x ∈ A }
```

读作"`R` 限制在 `A` 上"。==只保留**出发点落在 `A` 里**的有序对==，其它一律扔掉。

**定义（像）**：

```
R[A] = ran(R↾A) = { y | ∃x( x∈A ∧ <x,y> ∈ R ) }
```

读作"`A` 在 `R` 下的像"。==把 `A` 里每个点沿 `R` 走一步，所有落脚点收集起来。==

**两者的关系**：`R[A]` 就是**先把 `R` 缩到 `A`、再取值域**：

```
R[A] = ran( R↾A )
```

> **记忆钩子**：`↾` 是"**掐头**"（限制前件），`[ ]` 是"**问结果**"（像）。==先限制、后取值域，得到像。==

**易混提示**：

| 写法 | 是什么 | 类型 |
| :--- | :--- | :--- |
| `R↾A` | 限制后的**关系** | 有序对集合 |
| `R[A]` | 像 | **元素集合**（一般是 `B` 的子集） |
| `R[∅]` | 空关系的像 | `= ∅` |
| `R[{x}]` | 单点像 | `= { y | <x,y>∈R }`，即 `x` 的直接后继集 |

从矩阵看：`R↾A` 就是把 `M_R` 中**行标不在 `A` 内的那些行整行清零**。

### 1.4 一个完整计算例子

设

```
A = {1, 2, 3},  B = {a, b},  C = {x, y}
R = { <1,a>, <2,a>, <2,b>, <3,b> }      （从 A 到 B）
S = { <a,x>, <b,y> }                    （从 B 到 C）
```

逐个算：

| 运算 | 结果 | 理由 |
| :--- | :--- | :--- |
| `dom R` | `{1, 2, 3}` | 三个起点都出现过 |
| `ran R` | `{a, b}` | 两个终点都出现过 |
| `fld R` | `{1, 2, 3, a, b}` | 取并 |
| `R^{-1}` | `{<a,1>, <a,2>, <b,2>, <b,3>}` | 每个有序对掉头 |
| `R↾{2,3}` | `{<2,a>, <2,b>, <3,b>}` | 扔掉 `1` 出发的边 |
| `R[{2}]` | `{a, b}` | `2` 的直接后继 |
| `R[{1,3}]` | `{a, b}` | `1→a`，`3→b` |
| `R[{1}]` | `{a}` | 只有 `1→a` |

再看 `R^{-1}` 的矩阵（行标 `B={a,b}`，列标 `A={1,2,3}`）：

```
       1  2  3
 a  [  1  1  0 ]
 b  [  0  1  1 ]
```

它正是 `R` 的矩阵（行 `A` 列 `B`）

```
       a  b
 1  [  1  0 ]
 2  [  1  1 ]
 3  [  0  1 ]
```

的**转置**——肉眼可核对。

## 二、关系的复合

### 2.1 定义

**定义（复合关系）**：设 `R` 是从 `A` 到 `B` 的二元关系，`S` 是从 `B` 到 `C` 的二元关系，则==`R` 与 `S` 的复合关系 `R∘S`==是从 `A` 到 `C` 的二元关系，定义为

```
R∘S = { <x,z> | ∃y( <x,y> ∈ R ∧ <y,z> ∈ S ) }
```

**⚠️ 本书（屈婉玲《离散数学》）约定：** ==`R∘S` 表示"先作用 `R`，再作用 `S`"==——中间站 `y` 必须**先被 `R` 用到、后被 `S` 用到**。用走路的说法：

> `x ——R——> y ——S——> z`　　⇒　　`x ——R∘S——> z`

即：==从左往右读，先 `R` 后 `S`；结果 `R∘S` 从 `A` 走到 `C`。==

### 2.2 三条"能不能复合"的判据

`R∘S` 有意义的前提是**接口对得上**：

| 判据   | 内容                                                                      |
| :--- | :---------------------------------------------------------------------- |
| 接口匹配 | `R` 的**到达集** `B` 与 `S` 的**出发集** `B` 是<font color="#c00000">同一个集合</font> |
| 起点   | `R∘S` 从 `R` 的<font color="#c00000">起点 `A` 出发</font>                     |
| 终点   | `R∘S` 到达<font color="#c00000"> `S` 的终点 `C`</font>                       |

> **口诀**：==`A →(R) B →(S) C`，中间那个 `B` 是"中转站"==，<font color="#c00000">必须两边共用</font>。若 `ran R ∩ dom S = ∅`，则 `R∘S = ∅`（接力接不上）。

### 2.3 集合法计算（完整例子）

仍用第一节的 `R`、`S`：

```
R = { <1,a>, <2,a>, <2,b>, <3,b> }      （A→B）
S = { <a,x>, <b,y> }                    （B→C）
```

**逐步接力**：把每个 `<•,y>∈R` 与每个 `<y,•>∈S` 接起来。

| 从 `R` 取 | 检查 `S` | 接力得到 |
| :--- | :--- | :--- |
| `<1,a>` | `<a,x> ∈ S` ✓ | `<1,x>` |
| `<1,a>` | `<a,y> ∈ S` ✗ | — |
| `<2,a>` | `<a,x> ∈ S` ✓ | `<2,x>` |
| `<2,b>` | `<b,x> ∈ S` ✗ | — |
| `<2,b>` | `<b,y> ∈ S` ✓ | `<2,y>` |
| `<3,b>` | `<b,y> ∈ S` ✓ | `<3,y>` |

所以

```
R∘S = { <1,x>, <2,x>, <2,y>, <3,y> }
```

**图视角**：把 `A→B` 的边与 `B→C` 的边在 `B` 的顶点处"焊"起来，去掉中转点，就得到 `A→C` 的复合边。

> **⚠️ 反着算一下**：`S∘R` 在本例中==根本没法算==（`S` 到 `C` 结束，`R` 从 `A` 出发，接口不匹配）。
> 这说明<font color="#c00000">复合天然带方向，`R∘S` 与 `S∘R` 不是一回事</font>。

## 三、复合的性质

先复习符号：下列性质中 `R` 从 `A` 到 `B`，`S`、`T` 从 `B` 到 `C`（涉及逆时按需要调整）。

### 3.1 结合律

```
(R∘S)∘T = R∘(S∘T)
```

**直观**：三段接力 `A →(R) B →(S) C →(T) D`，先焊哪两段都一样，结果都是 `A→D` 的"两站直达"。因此**可以省掉括号**，直接写 `R∘S∘T`。

**证明思路**：任取 `<x,w>`，展开两侧的存在量词，都等价于

```
∃y∃z( <x,y>∈R ∧ <y,z>∈S ∧ <z,w>∈T )
```

（左侧先对 `S,T` 复合，右侧先对 `R,S` 复合，但都归结为同一组"三连"条件，用 ∃ 的换序即可）。

### 3.2 交换律不成立（重点！）

```
R∘S = S∘R      一般情况下 不成立
```

**必须能举反例**。取 `A = {1,2,3}`，`R = {<1,2>}`，`S = {<2,3>}`（都看成 `A` 上的关系）。

| 计算    | 过程                                                               | 结果        |
| :---- | :--------------------------------------------------------------- | :-------- |
| `R∘S` | `<1,2>∈R` 与 `<2,3>∈S` 接上                                         | `{<1,3>}` |
| `S∘R` | 需要 `<x,y>∈S` 与 `<y,z>∈R`：`<2,3>∈S` 要配 `<3,•>∈R`，但 `R` 无 `3` 开头的对 | `∅`       |


于是

```
R∘S = {<1,3>}  ≠  ∅ = S∘R
```

> **⚠️ 结论**：复合==满足结合律，但不满足交换律==

### 3.3 对并的分配律

```
R∘(S∪T) = (R∘S) ∪ (R∘T)          （右分配）
(S∪T)∘R = (S∘R) ∪ (T∘R)          （左分配）
```

**直观**：中间站想走"`S` 或 `T` 的边"，等价于"先分别走 `S`、走 `T`，再把结果并起来"。这里用到 [[3.2 集合的基本运算]] 里的并集分配思想。

> **⚠️ 易错**：对**交**只有单向的 `R∘(S∩T) ⊆ (R∘S)∩(R∘T)`，==一般不取等==（同一个 `<x,z>` 可能一条路走 `S`、另一条路走 `T`）。

### 3.4 逆关系的复合规律（高频证明题）

```
(R∘S)^{-1} = S^{-1} ∘ R^{-1}
```

==注意顺序被**颠倒**了==——这是这条规律的全部精髓（和"脱外套要先解最后穿的那件"一个道理）。

**为什么方向对得上**：`R: A→B`、`S: B→C`，故 `R∘S: A→C`，于是 `(R∘S)^{-1}: C→A`。而 `S^{-1}: C→B`、`R^{-1}: B→A`，`S^{-1}∘R^{-1}: C→A`。==两边都是 `C→A`，先验通过。==

**证明（元素法，要会默写）**：对任意 `<z,x>`：

```
<z,x> ∈ (R∘S)^{-1}
⇔ <x,z> ∈ R∘S                                   （逆的定义）
⇔ ∃y( <x,y> ∈ R ∧ <y,z> ∈ S )                  （复合的定义）
⇔ ∃y( <z,y> ∈ S^{-1} ∧ <y,x> ∈ R^{-1} )        （逆的定义）
⇔ <z,x> ∈ S^{-1} ∘ R^{-1}                       （复合的定义：先 S^{-1} 后 R^{-1}）
```

由 `<z,x>` 任意，得 `(R∘S)^{-1} = S^{-1}∘R^{-1}`。
### 3.5 其他常用规律

| 规律    | 形式                                    | 备注            |
| :---- | :------------------------------------ | :------------ |
| 双重逆   | `(R^{-1})^{-1} = R`                   | 掉头两次复原        |
| 幂与逆   | `(R^n)^{-1} = (R^{-1})^n`             | 掉头与接力可交换      |
| 单调性   | `R₁⊆R₂ ⇒ R₁∘S ⊆ R₂∘S` 且 `S∘R₁ ⊆ S∘R₂` | 越大包含越多        |
| 与恒等关系 | `R∘I_A = I_B∘R = R`                   | `I` 是复合的"单位元" |

其中 `I_A = {<x,x> | x∈A}` 是 `A` 上的**恒等关系**（对角线矩阵），后面 [[4.3 关系的性质]] 会反复用。

## 四、关系的幂 `R^n`

### 4.1 定义

设 `R` 是**集合 `A` 上**的关系（`R ⊆ A×A`，起点终点同一集合——这是幂有定义的前提）。

```
R^0 = I_A                          （恒等关系）
R^{n+1} = R^n ∘ R        (n ≥ 0)   （递推）
```

于是

```
R^1 = R
R^2 = R∘R
R^3 = R^2∘R = R∘R∘R
…
```

> **注意**：`R^0 = I_A` 而**不是** `∅`。这条约定让指数律在 `n=0` 时也成立，务必记牢。

### 4.2 指数律

```
R^{m+n} = R^m ∘ R^n
(R^m)^n = R^{mn}
```

（`m, n` 为非负整数，`R^0 = I_A`。）

> **证明思路**：都归结为"接力 `m` 段再接力 `n` 段 = 接力 `m+n` 段"，结合律保证括号随便打。
> **⚠️ 但 `(R∘S)^n ≠ R^n∘S^n`**（因为复合不交换），这是常见的"想当然陷阱"。

### 4.3 图意义：`R^n` = 走 n 步可达

**核心结论**：`<x,y> ∈ R^n` ⇔ 在关系图上**存在一条从 `x` 到 `y`、恰好 `n` 条边的有向路径**。

| 幂     | 图含义      | 矩阵含义           |
| :---- | :------- | :------------- |
| `R^0` | 不走（就是原地） | 单位矩阵           |
| `R^1` | 走 1 步    | `M_R`          |
| `R^2` | 走 2 步    | `M_R` 的布尔平方    |
| `R^n` | 走 n 步    | `M_R` 的布尔 n 次幂 |

**推论**：关系图上从 `x` 到 `y` 存在一条==长度 ≥ 1== 的路径 ⇔ `<x,y> ∈ R ∪ R^2 ∪ R^3 ∪ …`。这正是 [[4.4 关系的闭包]] 里**传递闭包**的构造公式。

### 4.4 计算例子（循环关系）

设 `A = {1,2,3,4}`，

```
R = { <1,2>, <2,3>, <3,4>, <4,1> }
```

这是一条"环"：`1→2→3→4→1`。逐步算：

```
R^2 = R∘R   = { <1,3>, <2,4>, <3,1>, <4,2> }     （每点向后走两步）
R^3 = R^2∘R = { <1,4>, <2,1>, <3,2>, <4,3> }     （走三步）
R^4 = R^3∘R = { <1,1>, <2,2>, <3,3>, <4,4> } = I_A
```

> **收获**：本例 `R^4 = I_A`（环长 4，走 4 步回到自己），且 `R^5 = R^4∘R = I_A∘R = R`，之后周期为 4 循环：`R^5 = R`、`R^6 = R^2`……
> **⚠️ 常考**：给定 `R` 问 `R^{2024}` 是哪个——先找周期再取余。

## 五、关系矩阵与运算的对应

设 `A = {a₁,…,aₘ}`，`B = {b₁,…,bₙ}`（**行按 `A` 排、列按 `B` 排**），关系 `R ⊆ A×B` 的矩阵 `M_R` 是 `m×n` 的 **0-1 矩阵**：

```
(M_R)_{ij} = 1  当且仅当  <aᵢ, bⱼ> ∈ R
```

> **⚠️ 排布约定**：==行标管第一分量、列标管第二分量==。换一套行/列顺序，矩阵就不同——做题先固定住标号顺序。

### 5.1 逆 = 转置

```
M_{R^{-1}} = (M_R)^{T}
```

即 `(M_{R^{-1}})_{ij} = (M_R)_{ji}`——第 `i` 行第 `j` 列与第 `j` 行第 `i` 列对调。

### 5.2 复合 = 布尔矩阵乘法

设 `R ⊆ A×B`，`S ⊆ B×C`，`R∘S ⊆ A×C`，则

```
(M_{R∘S})_{ij} = ∨ₖ ( (M_R)_{ik} ∧ (M_S)_{kj} )
```

其中 `∨` 是**逻辑或**（0/1 中取大），`∧` 是**逻辑与**（取小）。这正是**布尔（并-交）矩阵乘法**：和普通矩阵乘法一模一样，==只是把"乘"换成 `∧`、把"加"换成 `∨`==。

> **对照**：普通矩阵乘法 `C_{ij} = Σₖ A_{ik}B_{kj}`；布尔乘法把 `Σ → ∨`、`× → ∧`。
> **记忆钩子**：==`∨` 读"至少有一条路"，`∧` 读"这一段必须走得通"，`∨ₖ(…)` 读"存在一个中转站 `k` 把两段接上"。==这恰好就是 `R∘S = {<x,z> | ∃y(…)}` 的矩阵版！

### 5.3 矩阵法算复合（完整例子）

沿用 `R = {<1,a>,<2,a>,<2,b>,<3,b>}`、`S = {<a,x>,<b,y>}`。矩阵（行 `A={1,2,3}`，列 `B={a,b}`；再行 `B`、列 `C={x,y}`）：

```
                a  b                    x  y
        1  [   1  0 ]            a  [   1  0 ]
M_R  =  2  [   1  1 ]    M_S  =  b  [   0  1 ]
        3  [   0  1 ]
```

布尔乘：

| 行 | `∨ₖ` 展开（`k = a, b`） | 结果 `(x, y)` |
| :--- | :--- | :--- |
| 1 | `(1∧1)∨(0∧0)`，`(1∧0)∨(0∧1)` | `(1, 0)` |
| 2 | `(1∧1)∨(1∧0)`，`(1∧0)∨(1∧1)` | `(1, 1)` |
| 3 | `(0∧1)∨(1∧0)`，`(0∧0)∨(1∧1)` | `(0, 1)` |

于是

```
                x  y
        1  [   1  0 ]                              ⇒  R∘S = { <1,x>, <2,x>,
M_{R∘S}=2  [   1  1 ]                                            <2,y>, <3,y> }
        3  [   0  1 ]
```

与第二节集合法的结果==完全一致==，可互为验算。矩阵法的好处：==批量、机械、不易漏==。

## 六、例题

### 例 1（求各种基本量）

设 `A = {1,2,3}`，`B = {a,b,c}`，`R = {<1,b>, <2,a>, <3,c>, <2,b>}`。
求 `dom R`、`ran R`、`R^{-1}`、`R↾{1,2}`、`R[{2}]`。

**解**：整理 `R = {<1,b>, <2,a>, <2,b>, <3,c>}`。

| 量 | 结果 |
| :--- | :--- |
| `dom R` | `{1, 2, 3}` |
| `ran R` | `{a, b, c}` |
| `R^{-1}` | `{<b,1>, <a,2>, <b,2>, <c,3>}` |
| `R↾{1,2}` | `{<1,b>, <2,a>, <2,b>}`（删掉 `3` 出发的边） |
| `R[{2}]` | `{a, b}`（`2` 的直接后继） |

### 例 2（复合）

接例 1，设 `S = {<a,x>, <b,y>, <c,y>} ⊆ B×C`，`C={x,y}`。求 `R∘S`，并验证与矩阵法一致。

**解**：逐个接力

```
<1,b> 与 <b,y>   ⇒ <1,y>
<2,a> 与 <a,x>   ⇒ <2,x>
<2,b> 与 <b,y>   ⇒ <2,y>
<3,c> 与 <c,y>   ⇒ <3,y>
```

所以

```
R∘S = { <1,y>, <2,x>, <2,y>, <3,y> }
```

**矩阵验算**（`M_R` 行 `1,2,3` 列 `a,b,c`；`M_S` 行 `a,b,c` 列 `x,y`）：

```
                 a b c                     x y
       1  [  0 1 0 ]              a  [  1 0 ]
M_R =  2  [  1 1 0 ]      M_S =  b  [  0 1 ]
       3  [  0 0 1 ]              c  [  0 1 ]
```

布尔乘第 1 行 `(1∧0)∨... `：列 `y` = `(0∧0)∨(1∧1)∨(0∧1) = 1`，列 `x` = `0`，得 `(0,1)` 即只到 `y` ✓；第 2 行得 `(1,1)` ✓；第 3 行得 `(0,1)` ✓。与集合法一致。

### 例 3（逆的复合律）

设 `R ⊆ A×B`，`S ⊆ B×C`，证明 `(R∘S)^{-1} = S^{-1}∘R^{-1}`。

**解**：见 [[#3.4 逆关系的复合规律（高频证明题）]] 的元素法证明，此处略（考试要完整写出"逆的定义 ↔ 复合的定义"四步链条）。

### 例 4（幂与周期）

设 `A = {1,2,3}`，`R = {<1,2>, <2,3>, <3,1>}`。求 `R^2`、`R^3`，并求 `R^{2024}`。

**解**：

```
R^2 = R∘R = { <1,3>, <2,1>, <3,2> }
R^3 = R^2∘R = { <1,1>, <2,2>, <3,3> } = I_A
```

所以 `R^3 = I_A`，周期为 3。`2024 = 3×674 + 2`，故

```
R^{2024} = R^{2} = { <1,3>, <2,1>, <3,2> }
```

> **要点**：==先找周期，再对指数取余==；`R^0 = I_A` 是"余 0"的情形。

# 参考答案与详细解析

## 第 1 题

```
dom R = {1, 2, 3}          (每个元素都作第一分量出现过)
ran R = {a, b}             (第二分量只有 a, b)
fld R = {1,2,3,a,b}        (dom ∪ ran)
R^{-1} = { <a,1>, <b,2>, <a,3> }
```

## 第 2 题

限制只保留 `B={1,2}` 中出发的有序对，故删去 `<4,3>`：

```
R↾{1,2} = { <1,1>, <1,2>, <2,3> }
```

像 = 限制后的值域：

| 起点 | 直接后继 |
| :--- | :--- |
| `1` | `1, 2` |
| `2` | `3` |

```
R[{1,2}] = {1, 2, 3}
```

## 第 3 题

接力（先 `R` 后 `S`）：

```
<1,a> 与 <a,y>  ⇒ <1,y>
<2,b> 与 <b,x>  ⇒ <2,x>
<3,c> 与 <c,x>  ⇒ <3,x>
```

```
R∘S = { <1,y>, <2,x>, <3,x> }
```

`S∘R` 不能算：`S` 到 `C` 结束、`R` 从 `A` 出发，==接口不匹配==。

## 第 4 题

```
R^2 = R∘R   = { <1,3>, <2,4>, <3,1>, <4,2> }      (走两步)
R^3 = R^2∘R = { <1,4>, <2,1>, <3,2>, <4,3> }      (走三步)
R^4 = R^3∘R = { <1,1>, <2,2>, <3,3>, <4,4> } = I_A
```

`R^4` 是 `A` 上的**恒等关系 `I_A`**（环长 4，走 4 步回到自身）。由此 `R^5 = R`，周期为 4。

## 第 5 题

矩阵（行 `A={1,2,3}`、列 `B={a,b,c}`；再行 `B`、列 `C={x,y}`）：

```
                 a b c                     x y
       1  [  1 0 0 ]              a  [  0 1 ]
M_R =  2  [  0 1 0 ]      M_S =  b  [  1 0 ]
       3  [  0 0 1 ]              c  [  1 0 ]
```

布尔乘 `(M_{R∘S})_{ij} = ∨ₖ (M_R)_{ik} ∧ (M_S)_{kj}`：

| 行 | 列 `x` | 列 `y` |
| :--- | :--- | :--- |
| 1 | `(1∧0)∨(0∧1)∨(0∧1)=0` | `(1∧1)∨(0∧0)∨(0∧0)=1` |
| 2 | `(0∧0)∨(1∧1)∨(0∧1)=1` | `(0∧1)∨(1∧0)∨(0∧0)=0` |
| 3 | `(0∧0)∨(0∧1)∨(1∧1)=1` | `(0∧1)∨(0∧0)∨(1∧0)=0` |

```
                x y
       1  [  0 1 ]         ⇒  R∘S = { <1,y>, <2,x>, <3,x> }
       2  [  1 0 ]
       3  [  1 0 ]
```

与第 3 题一致 ✓。

## 第 6 题

按本书约定（先 `R` 后 `S`）：

| 复合 | 过程 | 结果 |
| :--- | :--- | :--- |
| `R∘S` | `<1,2>∈R` 配 `<2,3>∈S` | `{<1,3>}` |
| `S∘R` | 需 `<x,y>∈S` 配 `<y,z>∈R`：`<2,3>∈S` 要求 `<3,•>∈R`，而 `R` 无 `3` 开头的对 | `∅` |

```
R∘S = {<1,3>}  ≠  ∅ = S∘R
```

故复合==不满足交换律==。但结合律仍成立。

## 第 7 题

**方向先验证**：`R: A→B`、`S: B→C` ⇒ `R∘S: A→C` ⇒ `(R∘S)^{-1}: C→A`；又 `S^{-1}: C→B`、`R^{-1}: B→A` ⇒ `S^{-1}∘R^{-1}: C→A`。两边同型 ✓。

**元素法**：对任意 `<z,x>`，

```
<z,x> ∈ (R∘S)^{-1}
⇔ <x,z> ∈ R∘S                          (逆定义)
⇔ ∃y( <x,y>∈R ∧ <y,z>∈S )             (复合定义)
⇔ ∃y( <z,y>∈S^{-1} ∧ <y,x>∈R^{-1} )   (逆定义)
⇔ <z,x> ∈ S^{-1}∘R^{-1}                (复合定义)
```

由 `<z,x>` 任意，得 `(R∘S)^{-1} = S^{-1}∘R^{-1}`。∎

**为什么不能写 `R^{-1}∘S^{-1}`**：`R^{-1}: B→A`、`S^{-1}: C→B`，要复合 `R^{-1}∘S^{-1}` 需"`R^{-1}` 的终点 = `S^{-1}` 的起点"，即 `A = C`，==一般情况下接口根本接不上==；即便 `A=C` 使式子有意义，结果也通常不等于 `(R∘S)^{-1}`。==逆的复合必须把顺序倒过来。==

## 第 8 题

对任意 `<x,z> ∈ A×C`：

```
<x,z> ∈ R∘(S∪T)
⇔ ∃y( <x,y>∈R ∧ <y,z>∈ S∪T )                  (复合定义)
⇔ ∃y( <x,y>∈R ∧ ( <y,z>∈S ∨ <y,z>∈T ) )       (并集定义)
⇔ ∃y( (<x,y>∈R ∧ <y,z>∈S) ∨ (<x,y>∈R ∧ <y,z>∈T) )   (∧ 对 ∨ 分配)
⇔ ∃y( <x,y>∈R ∧ <y,z>∈S ) ∨ ∃y( <x,y>∈R ∧ <y,z>∈T )  (∃ 对 ∨ 分配)
⇔ <x,z> ∈ R∘S ∨ <x,z> ∈ R∘T                    (复合定义 ×2)
⇔ <x,z> ∈ (R∘S) ∪ (R∘T)                        (并集定义)
```

由 `<x,z>` 任意，得 `R∘(S∪T) = (R∘S)∪(R∘T)`。∎

> **提醒**：若把 `∪` 换成 `∩`，第 3 步的"存在一个 `y` 同时满足两种走法"==不能拆成"两种走法各自存在一个 `y`"==，所以对交只有单向包含 `⊆`。

## 附一：关系运算速查

**六个基本量**

| 记号 | 名称 | 定义 | 矩阵/图 |
| :--- | :--- | :--- | :--- |
| `dom R` | 定义域 | `{x | ∃y <x,y>∈R}` | 出度 ≥ 1 的点 |
| `ran R` | 值域 | `{y | ∃x <x,y>∈R}` | 入度 ≥ 1 的点 |
| `fld R` | 域 | `dom R ∪ ran R` | 有关联的点 |
| `R^{-1}` | 逆 | `{<y,x> | <x,y>∈R}` | 转置 `M^T` |
| `R↾A` | 限制 | `{<x,y> | <x,y>∈R ∧ x∈A}` | `A` 外的行清零 |
| `R[A]` | 像 | `ran(R↾A) = {y | ∃x∈A, <x,y>∈R}` | `A` 的落点集 |

**复合 `R∘S`（`A→B`，`B→C`）**

- 定义：`R∘S = { <x,z> | ∃y( <x,y>∈R ∧ <y,z>∈S ) }`
- ==本书约定：先 `R` 后 `S`==；结果 `A→C`
- 矩阵：`(M_{R∘S})_{ij} = ∨ₖ (M_R)_{ik} ∧ (M_S)_{kj}`（布尔积）
- ⚠️ 别的教材可能顺序相反，做题以本校教材为准

**五条性质**

| 性质 | 式子 |
| :--- | :--- |
| 结合律 | `(R∘S)∘T = R∘(S∘T)` |
| 交换律 | ==不成立==（`R∘S ≠ S∘R`） |
| 对并分配 | `R∘(S∪T) = (R∘S)∪(R∘T)`，`(S∪T)∘R = (S∘R)∪(T∘R)` |
| 逆的复合 | `(R∘S)^{-1} = S^{-1}∘R^{-1}`（**顺序倒置**） |
| 调头复原 | `(R^{-1})^{-1} = R` |

**幂 `R^n`（`A` 上的关系）**

- `R^0 = I_A`，`R^{n+1} = R^n∘R`
- `R^{m+n} = R^m∘R^n`，`(R^m)^n = R^{mn}`，`(R^n)^{-1} = (R^{-1})^n`
- `<x,y>∈R^n` ⇔ 图上**走 n 步**从 `x` 到 `y`
- ⚠️ `(R∘S)^n ≠ R^n∘S^n`

**三条铁律**（默写级）

1. ==`R∘S` 先 `R` 后 `S`；顺序一错，满盘皆错。==
2. ==`(R∘S)^{-1} = S^{-1}∘R^{-1}`，脱衣服反着脱。==
3. ==`R^0 = I_A`，不是 `∅`。==
