
> **适用对象**：已学过 4.6 函数的定义与性质，熟悉 `f: A → B`、`dom f = A`、`ran f ⊆ B`、满射 / 单射 / 双射判定的同学；本篇承接 4.2 关系的复合与逆，把"关系代数"收缩到"函数"这一特殊关系上。
> **核心内容**：复合函数 `g∘f` 的定义 `(g∘f)(x) = g(f(x))`、复合的先决条件 `ran f ⊆ dom g`、复合的结合律与传递性质（满/单/双射的正向与反向推演）；反函数 `f^{-1}` 的存在条件与性质；核心恒等式 `f^{-1}∘f = I_A`、`f∘f^{-1} = I_B`、`I_B∘f = f`、`(f^{-1})^{-1} = f`；复合与逆的交换律 `(g∘f)^{-1} = f^{-1}∘g^{-1}`；可逆当且仅当双射。
> **使用建议**：定义要能"默写 `(g∘f)(x) = g(f(x))` 并说清先后顺序"，性质要能"对着推演表分清哪些能反推、哪些不能"，恒等式要能"上手就用 `I_A` 化简"。重点背：复合定义、满/单/双射推演表、反函数四条恒等式。易错点：复合顺序（先 `f` 后 `g`）、`(g∘f)^{-1}` 的顺序反转、非双射集合的"逆关系不是函数"。

## 零、动机：函数的"组合"与"逆转"

上一节我们认识了函数：一个把定义域中每个元素"搬运"到值域中某个元素的规则。函数本身是**静态对象**，但我们自然会追问两个动态问题：

1. **能不能把两个函数接起来用？** 先用 `f` 把 `A` 送到 `B`，再用 `g` 把 `B` 送到 `C`，一次走完 `A → C`。这就是**复合**。
2. **能不能把搬运倒过来？** 已知结果 `y`，反过来问"是哪个 `x` 送过来的"？这就是**反函数**。

这两个问题并不新鲜。在 [[4.2 关系的运算]] 里，我们已经学过关系的**复合** `R∘S` 与关系的**逆** `R^{-1}`。==函数是一种特殊的关系，所以"函数的复合 / 逆"理应就是"关系的复合 / 逆"在函数这一特殊情形下的落点==——本篇要做的，只是检查：关系的那一套搬到函数身上，哪些性质保留、哪些需要额外条件。

> **记忆钩子**：函数复合 = 关系的"接力"，函数取逆 = 关系的"翻面"。凡是在 4.2 学过的复合 / 逆的运算规律（结合律、`(R∘S)^{-1} = S^{-1}∘R^{-1}`），搬到函数上都成立；区别只在于"逆关系未必还是函数"这一个新问题。

因此本篇的主线是：==先复合（一定能复合吗？），再反函数（一定能取逆吗？），最后用恒等映射把"可逆"这件事说清楚==。

## 一、复合函数

### 1.1 直观：两个"搬运工"接力

想象 `f` 是"先加工"，`g` 是"再加工"。原料 `x ∈ A` 先被 `f` 加工成 `f(x) ∈ B`，再被 `g` 加工成 `g(f(x)) ∈ C`。把这一整套连续动作打包成一个新函数，就是复合函数 `g∘f`。

所以复合的本质是**装配流水线**：`f` 在前，`g` 在后，产品从 `A` 一路走到 `C`。

### 1.2 严格定义

**定义（复合函数）**：设 `f: A → B`，`g: B → C`，令

```
g∘f = { <x, z> | x ∈ A, z ∈ C, 且 ∃ y ∈ B 使 y = f(x) 且 z = g(y) }
```

则 `g∘f` 是 `A` 到 `C` 的函数，称为 `f` 与 `g` 的**复合函数**，记作 `g∘f: A → C`，且

```
(g∘f)(x) = g(f(x))
```

==`g∘f` 表示"先做 `f`，后做 `g`"==；`∘` 读作"复合"。因为函数作为关系是单值的，这里的 `y` 由 `x` 唯一决定，`z` 又由 `y` 唯一决定，所以 `g∘f` 确实是函数（每个 `x` 恰对应一个 `z`）。

> **⚠️ 顺序提醒（高频失分点）**：写 `g∘f` 时，==靠右的 `f` 先作用，靠左的 `g` 后作用==。符号的书写顺序与执行顺序**相反**，就像一个函数的"洋葱皮"——念作 "`g` 复合 `f`"，实际先剥 `f` 这一层。
>
> **⚠️ 教材差异提醒**：==有些教材（尤其英文教材）把 `f` 与 `g` 的复合写成 `f∘g` 并定义 `(f∘g)(x) = g(f(x))`，符号顺序正好相反==。本校本课程以屈婉玲 / 耿素云教材为准：**一律采用 `(g∘f)(x) = g(f(x))`**，即符号顺序与关系的复合约定（`R∘S` 表示先 `S` 后 `R`）保持一致。做题时先确认题面用的是哪套约定。

### 1.3 与关系复合的对照

| 名称 | 关系的复合（4.2） | 函数的复合（本节） |
| --- | --- | --- |
| 记号 | `R∘S`（先 `S` 后 `R`） | `g∘f`（先 `f` 后 `g`） |
| 定义 | `R∘S = {<x,z> \| ∃y(<x,y>∈S ∧ <y,z>∈R)}` | `(g∘f)(x) = g(f(x))` |
| 结合律 | `(R∘S)∘T = R∘(S∘T)` | `(h∘g)∘f = h∘(g∘f)` |
| 逆的复合 | `(R∘S)^{-1} = S^{-1}∘R^{-1}` | `(g∘f)^{-1} = f^{-1}∘g^{-1}` |
| 结果类型 | 一般仍是关系 | ==仍是函数==（单值性被保留） |

两者的差别只有一处：关系的复合总成立，而函数的复合需要"中间集合对得上"——这就是下一小节。

### 1.4 复合的先决条件 `ran f ⊆ dom g`

上面定义里我特意写了 `f: A → B`、`g: B → C`——两个函数共用同一个中间集合 `B`。这样每个 `f(x) ∈ B = dom g` 都能被 `g` 接住，`g∘f` 才处处有定义。

更一般地，只要 `f: A → B`、`g: B' → C`，则

```
g∘f 有意义  ⟺  ran f ⊆ dom g = B'
```

若某个 `f(x) ∉ dom g`，那么 `(g∘f)(x)` 就无定义，`g∘f` 不能算作 `A` 到 `C` 的函数（定义域会缩小，不再是全体 `A`）。

> **⚠️ 易错警告**：==复合的"能不能复合"取决于值域是否落在对方的定义域里，而不是集合名字是否相同==。当题目给的两个函数定义域 / 值域不整齐时，务必先检查 `ran f ⊆ dom g`。

**例（先决条件的重要性）**：`f: R → R`，`f(x) = x + 1`；`g: [0, +∞) → R`，`g(x) = √x`。这里 `ran f = R ⊄ [0, +∞) = dom g`，所以严格说 `g∘f` 不能作为 `R → R` 的函数。逐点看：`(g∘f)(x) = g(x+1) = √(x+1)`，只在 `x ≥ −1` 时有定义，故 `dom(g∘f) = [−1, +∞) ⊊ R`。这说明复合时"定义域会自动收缩"，而收缩后的结果一般不再是原来意义上的函数。

### 1.5 例子：用集合法与映射图法算复合

**例 1（集合法）**：设

```
A = {1, 2, 3}，  B = {a, b, c}，  C = {1, 2, 3}
f: A → B,  f(1) = a,  f(2) = a,  f(3) = b
g: B → C,  g(a) = 2,  g(b) = 3,  g(c) = 1
```

求 `g∘f` 与 `f∘g`。

解：`g∘f: A → C`（先 `f` 后 `g`），逐个算：

```
(g∘f)(1) = g(f(1)) = g(a) = 2
(g∘f)(2) = g(f(2)) = g(a) = 2
(g∘f)(3) = g(f(3)) = g(b) = 3
```

所以 `g∘f = {<1,2>, <2,2>, <3,3>}`。

`f∘g: B → B`（先 `g` 后 `f`），逐个算：

```
(f∘g)(a) = f(g(a)) = f(2) = a
(f∘g)(b) = f(g(b)) = f(3) = b
(f∘g)(c) = f(g(c)) = f(1) = a
```

所以 `f∘g = {<a,a>, <b,b>, <c,a>}`。

==注意 `g∘f` 与 `f∘g` 是两个完全不同的函数，定义域都不同，不能混淆==。

**例 2（映射图法）**：把函数画成"左中右三列、箭头连线"，复合就是"顺着箭头从最左走到最右"。下面把上式并排画出：

```
      f                g
 A          B                C
 1 ───────► a ───────► 2
 2 ───────► a ───────► 2      （1、2 都走到 2）
 3 ───────► b ───────► 3
```

看最左列到最右列，箭头 `1 → 2`、`2 → 2`、`3 → 3`，正是 `g∘f`。==映射图法的诀窍：把中间列"擦掉"，剩下的首尾连线就是复合函数==。反过来 `f∘g` 则要从 `B` 走 `g` 再走 `f`，得到 `{<a,a>,<b,b>,<c,a>}`。

> **记忆钩子（映射图）**：复合 `g∘f` = 顺着箭头"左 → 中 → 右"走到底，中间站点 `B` 只是中转站。两段箭头首尾相接，就能一次性读出新函数。

## 二、复合的性质

本节讨论 `g∘f` 与 `f`、`g` 性质之间的关系。分三组：运算律（结合律、交换律）、正向传递（由 `f`、`g` 推 `g∘f`）、反向反推（由 `g∘f` 推 `f`、`g`）。

### 2.1 结合律：`(h∘g)∘f = h∘(g∘f)`

**定理**：设 `f: A → B`，`g: B → C`，`h: C → D`，则

```
(h∘g)∘f = h∘(g∘f)
```

**证明思路（元素法）**：对任意 `x ∈ A`，

```
((h∘g)∘f)(x) = (h∘g)(f(x)) = h(g(f(x)))
(h∘(g∘f))(x) = h((g∘f)(x)) = h(g(f(x)))
```

两边相等，由 `x` 任意得证。∎

==结合律告诉我们：三个及以上的函数复合可以省略括号==，一律写作 `h∘g∘f`，执行顺序是从右往左：先 `f`，再 `g`，最后 `h`。

> **⚠️ 易错警告**：结合律允许"省略括号"，但==绝不允许"交换位置"==。`h∘g∘f` 与 `f∘g∘h` 一般不同。

### 2.2 不满足交换律

复合**一般不可交换**，即 `g∘f ≠ f∘g`。注意这里还有一层"能否比较"的问题：`g∘f` 与 `f∘g` 的定义域通常是不同的集合（例 1 中前者从 `A` 出发，后者从 `B` 出发），本身就无法相等。

**反例（同定义域同到达域，仍不交换）**：取 `f: Z → Z`，`f(n) = n + 1`；`g: Z → Z`，`g(n) = 2n`。则

```
(g∘f)(n) = g(n+1) = 2(n+1) = 2n + 2
(f∘g)(n) = f(2n) = 2n + 1
```

两者对每个 `n` 都不相等（差 1），故 `g∘f ≠ f∘g`。

再看一个"非线性"的例子：`f(x) = x²`，`g(x) = x + 1`（都在 `R` 上）：

```
(g∘f)(x) = f(x) + 1 = x² + 1
(f∘g)(x) = (g(x))² = (x+1)²
```

`x = 0` 时，`(g∘f)(0) = 1` 而 `(f∘g)(0) = 1`，恰好相等；`x = 1` 时，`(g∘f)(1) = 2` 而 `(f∘g)(1) = 4`，不等。所以整体不交换。

> **记忆钩子**：复合像"穿衣服"——先穿袜子再穿鞋 ≠ 先穿鞋再穿袜子。==只有极特殊情形（如其中一个为恒等映射，或二者互为反函数）才可能交换==。

### 2.3 正向传递：`f`、`g` 的性质传给 `g∘f`

**定理（保单射）**：若 `f` 与 `g` 都是单射，则 `g∘f` 是单射。

**证明**：设 `(g∘f)(x₁) = (g∘f)(x₂)`，即 `g(f(x₁)) = g(f(x₂))`。由 `g` 单射得 `f(x₁) = f(x₂)`；再由 `f` 单射得 `x₁ = x₂`。故 `g∘f` 单射。∎

**定理（保满射）**：若 `f` 与 `g` 都是满射，则 `g∘f` 是满射。

**证明**：任取 `z ∈ C`。因 `g` 满射，存在 `y ∈ B` 使 `g(y) = z`；因 `f` 满射，存在 `x ∈ A` 使 `f(x) = y`。于是 `(g∘f)(x) = g(f(x)) = g(y) = z`，说明 `z ∈ ran(g∘f)`。由 `z` 任意，`g∘f` 满射。∎

**推论**：`f` 与 `g` 都是双射 ⇒ `g∘f` 是双射。

> **记忆钩子**：=="单射的接力还是单射，满射的接力还是满射"==。证明顺序很关键：保单射是"从外往里剥"（先 `g` 后 `f`），保满射是"从里往外造"（先 `g` 提供 `y`，再 `f` 提供 `x`）。

### 2.4 反向反推：由 `g∘f` 反推 `f`、`g`

当只知道 `g∘f` 是单射 / 满射时，能反推多少？答案是==只能反推一半==。

**定理（满射反推 `g`）**：若 `g∘f` 是满射，则 `g` 是满射（但 `f` 未必满）。

**证明**：任取 `z ∈ C`。因 `g∘f` 满射，存在 `x ∈ A` 使 `g(f(x)) = z`。取 `y = f(x) ∈ B`，则 `g(y) = z`，故 `z ∈ ran g`。由 `z` 任意，`g` 满射。∎

`f` 未必满的例子：`A = {1}`，`B = {a, b}`，`C = {x}`；`f(1) = a`，`g(a) = g(b) = x`。则 `g∘f: A → C` 是满射（像集 `{x} = C`），但 `ran f = {a} ≠ B`，`f` 不是满射。

**定理（单射反推 `f`）**：若 `g∘f` 是单射，则 `f` 是单射（但 `g` 未必单）。

**证明**：设 `f(x₁) = f(x₂)`，则 `g(f(x₁)) = g(f(x₂))`，即 `(g∘f)(x₁) = (g∘f)(x₂)`。由 `g∘f` 单射得 `x₁ = x₂`。故 `f` 单射。∎

`g` 未必单的例子：`A = {1}`，`B = {1, 2}`，`C = {a}`；`f(1) = 1`，`g(1) = g(2) = a`。则 `g∘f: A → C` 是单射（定义域只有一个元素，自动单射），但 `g(1) = g(2)`，`g` 不是单射。

### 2.5 推演总表："能推出什么、推不出什么"

| 已知条件 | `g∘f` 的结论 | 反推能推出 | 反推**推不出** |
| --- | --- | --- | --- |
| `f`、`g` 都单射 | `g∘f` 单射 | — | — |
| `f`、`g` 都满射 | `g∘f` 满射 | — | — |
| `f`、`g` 都双射 | `g∘f` 双射 | — | — |
| `g∘f` 单射 | — | `f` 单射 | `g` 单射（举反例） |
| `g∘f` 满射 | — | `g` 满射 | `f` 满射（举反例） |
| `g∘f` 双射 | — | `f` 单射 且 `g` 满射 | `f` 满射、`g` 单射（都推不出） |

> **⚠️ 易错警告**：反推方向**只对"外层 / 内层"中的一侧成立**：单射性只能从 `g∘f` 反推到**内层 `f`**，满射性只能反推到**外层 `g`**。==记法是"向内找单，向外找满"==。千万不能写成"`g∘f` 单射 ⇒ `g` 单射"，那是错的。

## 三、反函数 `f^{-1}`

### 3.1 从"关系取逆"说起

函数 `f: A → B` 作为关系，其**逆关系**是

```
f^{-1} = { <y, x> | <x, y> ∈ f } = { <f(x), x> | x ∈ A }
```

问题来了：==逆关系 `f^{-1}` 不一定还是函数==！因为函数要求"每个自变量恰有一个像"，而 `f^{-1}` 作为从 `B` 到 `A` 的关系，可能（i）有元素没有像（不是处处有定义），或（ii）有元素对应到多个像（不是单值）。只有排除这两种情况，逆关系才升级为**反函数**。

### 3.2 存在条件与定义

**定义（反函数）**：设 `f: A → B` 是**双射**，则逆关系 `f^{-1}` 是一个从 `B` 到 `A` 的函数，称为 `f` 的**反函数**：

```
f^{-1}: B → A，  且  f^{-1}(y) = x  ⟺  f(x) = y
```

即 ==`f^{-1}` 恰好把 `f` 的每个箭头反向==。

**为什么双射才够？** 两条件正好各补一种缺陷：

- `f` **满射** ⇒ 每个 `y ∈ B` 都是某个 `x` 的像 ⇒ `f^{-1}` 处处有定义（`dom f^{-1} = B`）；
- `f` **单射** ⇒ 每个 `y` 至多来自一个 `x` ⇒ `f^{-1}` 单值（无一对多）。

两者合起来正是"`f^{-1}` 是 `B → A` 的函数"。

### 3.3 `f^{-1}` 也是双射

**定理**：若 `f: A → B` 是双射，则 `f^{-1}: B → A` 也是双射。

**证明思路**：把 `f` 的箭头全部反向，单射与满射的角色互换——`f` 的单射性保证 `f^{-1}` 满射（每个 `x ∈ A` 都是 `f^{-1}` 的像，因为 `f^{-1}(f(x)) = x`）；`f` 的满射性保证 `f^{-1}` 单射（不同 `y` 的 `f^{-1}` 值不同，否则 `f` 会把两个元素映到同一处，违反单射）。∎

逐条对照更直观：

| `f` 的性质 | 在 `f^{-1}` 上变成 | 原因 |
| --- | --- | --- |
| 单射 | `f^{-1}` 满射 | `f` 一对一 ⇒ 每个 `x` 都被唯一 `y` 反向打中 |
| 满射 | `f^{-1}` 单射 | `f` 覆盖整个 `B` ⇒ `f^{-1}` 无重复像 |
| 双射 | `f^{-1}` 双射 | 两者俱全 |

### 3.4 非双射时，逆关系**不是**函数（两类反例）

**反例 A（单射但非满射 ⇒ 逆关系缺定义）**：`A = {1, 2}`，`B = {a, b, c}`，`f(1) = a`，`f(2) = b`。`f` 单射但非满射。逆关系为 `f^{-1} = {<a,1>, <b,2>}`，此时 `c ∈ B` 但 `c` 没有像，`dom f^{-1} = {a,b} ≠ B`，故 `f^{-1}` 不是 `B → A` 的函数。

**反例 B（满射但非单射 ⇒ 逆关系一对多）**：`A = {1, 2, 3}`，`B = {a, b}`，`f(1) = a`，`f(2) = a`，`f(3) = b`。`f` 满射但非单射。逆关系为 `f^{-1} = {<a,1>, <a,2>, <b,3>}`，此时 `a` 对应 `1` 与 `2` 两个值，违反单值性，故 `f^{-1}` 不是函数。

> **⚠️ 易错警告**：=="逆关系"与"反函数"是两回事==。任何函数都有逆关系，但只有**双射**才有反函数。做题遇到"求 `f^{-1}`"先判定 `f` 是否为双射，否则答案应该是"逆关系不是函数"并给出反例。

## 四、核心恒等式

设 `f: A → B` 为双射，`I_A` 表示 `A` 上的**恒等映射**（`I_A(x) = x`，对每个 `x ∈ A`）。

### 4.1 四条基本恒等式

| 恒等式 | 含义 |
| --- | --- |
| `f^{-1}∘f = I_A` | 先 `f` 再倒回来，等于"什么也没做"（作用在 `A` 上） |
| `f∘f^{-1} = I_B` | 先倒回再 `f`，等于"什么也没做"（作用在 `B` 上） |
| `I_B∘f = f` | 恒等映射是复合的单位元 |
| `f∘I_A = f` | 恒等映射是复合的单位元 |

**验证 `f^{-1}∘f = I_A`（元素法）**：对任意 `x ∈ A`，设 `f(x) = y`，则 `f^{-1}(y) = x`。于是

```
(f^{-1}∘f)(x) = f^{-1}(f(x)) = f^{-1}(y) = x = I_A(x)
```

由 `x` 任意，`f^{-1}∘f = I_A`。∎ 同理 `f∘f^{-1} = I_B`。

**验证 `I_B∘f = f`**：对任意 `x ∈ A`，`(I_B∘f)(x) = I_B(f(x)) = f(x)`，故相等。∎

> **记忆钩子**：==`f^{-1}` 与 `f` "贴合"后原地消除==，`I_A` 就是复合运算的"零作用元"（单位元）。看到 `f^{-1}∘f` 或 `f∘f^{-1}` 出现，直接划掉，等于 `I`；看到 `I∘f` 或 `f∘I`，也直接划掉，等于 `f`。

### 4.2 逆的逆

**定理**：`(f^{-1})^{-1} = f`。

**证明思路**：`f^{-1}: B → A` 本身也是双射，故它也有反函数。对任意 `y ∈ B`，`(f^{-1})^{-1}(y) = x ⟺ f^{-1}(x) = y ⟺ f(y) = x`。比较即得 `(f^{-1})^{-1} = f`。∎

直观上，"把箭头反向后再反向一次"就回到原样，==取逆是"对合"运算（两次回到自身）==。

### 4.3 恒等映射的可逆性（了解）

`I_A^{-1} = I_A`（恒等映射的反函数是它自己），且对任何 `f: A → B`，`I_B∘f = f∘I_A = f`。这两点是"恒等映射充当复合单位元"的直接体现，与代数系统中"单位元"的角色一致。

## 五、复合与反函数的关系：`(g∘f)^{-1} = f^{-1}∘g^{-1}`

**定理（复合之逆）**：设 `f: A → B`、`g: B → C` 都是双射，则 `g∘f: A → C` 也是双射，且

```
(g∘f)^{-1} = f^{-1}∘g^{-1}
```

==注意右端的**顺序反转**：`g∘f` 取逆，先逆的是最后作用的 `g`，然后才逆 `f`==。

**证明思路（元素法 / 两边作用法）**：只需验证 `(f^{-1}∘g^{-1})` 确实是 `g∘f` 的反函数，即验证它与 `g∘f` 复合得恒等映射。计算

```
(f^{-1}∘g^{-1})∘(g∘f)
= f^{-1}∘(g^{-1}∘g)∘f        （结合律）
= f^{-1}∘I_B∘f               （g^{-1}∘g = I_B）
= f^{-1}∘f                    （I_B∘f = f）
= I_A                         （f^{-1}∘f = I_A）
```

同法可算 `(g∘f)∘(f^{-1}∘g^{-1}) = I_C`。由可逆函数的唯一性（见第六节），得 `(g∘f)^{-1} = f^{-1}∘g^{-1}`。∎

**另一个视角（逐元素）**：对任意 `z ∈ C`，设 `(g∘f)^{-1}(z) = x`，即 `g(f(x)) = z`。等价地 `f(x) = g^{-1}(z)`，即 `x = f^{-1}(g^{-1}(z))`。故 `(g∘f)^{-1}(z) = f^{-1}(g^{-1}(z)) = (f^{-1}∘g^{-1})(z)`。∎

> **记忆钩子（"穿脱袜鞋"）**：==穿鞋袜的逆 = 先脱鞋、后脱袜==。`g∘f` 是先 `f`（袜）后 `g`（鞋），其逆就要先逆 `g`（脱鞋）再逆 `f`（脱袜），故是 `f^{-1}∘g^{-1}`。这与关系的 `(R∘S)^{-1} = S^{-1}∘R^{-1}` 完全同形。

## 六、可逆的等价刻画

**定理（可逆 ⟺ 双射）**：函数 `f: A → B` 存在反函数当且仅当 `f` 是双射。

**证明**：

（⇒）若 `f` 有反函数 `f^{-1}: B → A`，则 `f^{-1}` 是函数意味着：每个 `y ∈ B` 都有像（即 `f` 满射），且像唯一（即 `f` 单射）。故 `f` 是双射。

（⇐）若 `f` 是双射，由第三节的构造，逆关系 `f^{-1}` 满足"处处有定义 + 单值"，故是 `B → A` 的函数，即 `f` 的反函数存在。∎

**推论（唯一性）**：若 `f` 可逆，则其反函数唯一。

**证明思路**：设 `g`、`g'` 都是 `f` 的反函数，则 `g = g∘I_B = g∘(f∘g') = (g∘f)∘g' = I_A∘g' = g'`。∎

> **记忆钩子**：=="可逆"与"双射"是同义词==。判断反函数是否存在的标准动作：检查 `f` 是否既单又满。若题面问"`f` 可逆吗"，答案就是"看是否双射"。

**可逆性的两条判据（考试常用）**：

| 判据 | 表述 | 适用场合 |
| --- | --- | --- |
| 定义判据 | `f` 既单射又满射 | 一切情形，最稳 |
| 构造判据 | 能写出满足 `f^{-1}(f(x)) = x` 且 `f(f^{-1}(y)) = y` 的 `g` | 已猜出反函数形式，验证即可 |

## 七、例题

**例 1（求复合函数及其定义域）**：设 `f: R → R`，`f(x) = 2x + 1`；`g: R → R`，`g(x) = x²`。求 `g∘f`、`f∘g`，并写出定义域。

解：

```
(g∘f)(x) = g(f(x)) = g(2x+1) = (2x+1)² = 4x² + 4x + 1
(f∘g)(x) = f(g(x)) = f(x²) = 2x² + 1
```

定义域均为 `R`（因为 `f`、`g` 都在 `R` 上定义且取值仍在 `R`）。==`g∘f ≠ f∘g`，可见复合不交换==。

**例 2（判定复合的满 / 单 / 双射）**：设 `A = {1, 2, 3}`，`B = {a, b}`，`C = {α, β}`。`f: A → B`，`f(1)=a, f(2)=a, f(3)=b`；`g: B → C`，`g(a)=α, g(b)=β`。判断 `f`、`g`、`g∘f` 的单射性与满射性。

解：

- `f`：`f(1) = f(2)`，不单射；`ran f = {a,b} = B`，满射。故 `f` 满射非单射。
- `g`：`g(a) ≠ g(b)`，单射；`ran g = {α,β} = C`，满射。故 `g` 是双射。
- `g∘f`：`(g∘f)(1) = g(a) = α`，`(g∘f)(2) = α`，`(g∘f)(3) = g(b) = β`。`1`、`2` 同像，不单射；`ran(g∘f) = {α,β} = C`，满射。故 `g∘f` 满射非单射。

对照 2.5 的表：这里 `g` 满射、`f` 满射，故 `g∘f` 满射（符合）；`f` 非单射，故 `g∘f` 非单射（符合）。

**例 3（求反函数）**：判断 `f: R → R`，`f(x) = 3x − 2` 是否可逆；若可逆，求 `f^{-1}`。

解：`f` 是严格单调的一次函数。单射：若 `3x₁ − 2 = 3x₂ − 2`，则 `x₁ = x₂`。满射：对任意 `y ∈ R`，取 `x = (y+2)/3 ∈ R`，有 `f(x) = y`。故 `f` 是双射，可逆。由 `y = 3x − 2` 解出 `x = (y+2)/3`，故

```
f^{-1}: R → R,  f^{-1}(y) = (y + 2)/3
```

验证：`f^{-1}(f(x)) = (3x − 2 + 2)/3 = x = I_R(x)`；`f(f^{-1}(y)) = 3·(y+2)/3 − 2 = y = I_R(y)`。✓

**例 4（利用恒等式化简）**：设 `f: A → B` 为双射，化简 `f∘f^{-1}∘f` 与 `(f^{-1}∘f)^{-1}`。

解：

```
f∘f^{-1}∘f = (f∘f^{-1})∘f = I_B∘f = f
```

（用 `f∘f^{-1} = I_B` 与 `I_B∘f = f`。）

```
(f^{-1}∘f)^{-1} = I_A^{-1} = I_A
```

（先算括号内 `f^{-1}∘f = I_A`，再用 `I_A^{-1} = I_A`。）

**例 5（证明）**：设 `f: A → B`、`g: B → C` 都是双射，证明 `(g∘f)^{-1} = f^{-1}∘g^{-1}`。

证明：由 `f`、`g` 双射，`g∘f` 也是双射（2.3 推论），故 `(g∘f)^{-1}` 存在。只需验证 `f^{-1}∘g^{-1}` 是 `g∘f` 的反函数。用结合律与核心恒等式：

```
(f^{-1}∘g^{-1})∘(g∘f) = f^{-1}∘(g^{-1}∘g)∘f = f^{-1}∘I_B∘f = f^{-1}∘f = I_A
(g∘f)∘(f^{-1}∘g^{-1}) = g∘(f∘f^{-1})∘g^{-1} = g∘I_B∘g^{-1} = g∘g^{-1} = I_C
```

两式成立，说明 `f^{-1}∘g^{-1}` 与 `g∘f` 互为反函数，由反函数唯一性得 `(g∘f)^{-1} = f^{-1}∘g^{-1}`。∎

**例 6（可逆性的等价刻画）**：设 `f: A → B` 且 `f` 有左逆、右逆：即存在 `g: B → A` 使 `g∘f = I_A`，存在 `h: B → A` 使 `f∘h = I_B`。证明 `f` 是双射且 `g = h = f^{-1}`。

证明：由 `g∘f = I_A`，`I_A` 是双射（进而是单射），由 2.4 反推得 `f` 单射。由 `f∘h = I_B`，`I_B` 是双射（进而是满射），反推得 `f` 满射。故 `f` 双射，可逆。再由

```
g = g∘I_B = g∘(f∘h) = (g∘f)∘h = I_A∘h = h
```

得 `g = h`，且它就是 `f` 的反函数。∎

2. 设 `A = {1, 2, 3}`，`B = {a, b}`，`C = {x, y}`，`f(1)=a, f(2)=b, f(3)=a`；`g(a)=x, g(b)=y`。写出 `g∘f` 作为有序对的集合，并判断 `g∘f` 是否单射。

4. 判断正误：(a) 任何函数都有反函数；(b) 若 `f` 是双射，则 `f^{-1}` 也是双射；(c) `g∘f = f∘g` 恒成立。

**🟡 进阶题**

5. 设 `f: A → B`、`g: B → C`。举例说明：`g∘f` 是单射时，`g` 未必是单射；`g∘f` 是满射时，`f` 未必是满射（分别给出具体的集合与函数）。

7. 设 `f: A → B`、`g: B → C` 都是双射，化简 `g^{-1}∘(g∘f)∘f^{-1}`。

**🔴 挑战题**

8. 设 `f: A → B`、`g: B → C`，证明 `g∘f` 是双射的**充要条件**是：`f` 是单射、`g` 是满射，且 `ran f = g^{-1}(C)`（提示：先证必要性，注意 `f` 的满射性一般推不出）。

9. 设 `f: A → A` 且 `f∘f = f`（这样的 `f` 称为**幂等**）。证明：`f` 可逆当且仅当 `f = I_A`；并举例说明存在不可逆的幂等函数。

# 参考答案与详细解析

**1.** `(g∘f)(x) = g(f(x)) = g(x+3) = 2(x+3) = 2x + 6`；`(f∘g)(x) = f(g(x)) = f(2x) = 2x + 3`。二者对任意 `x` 都不相等（如 `x=0` 时分别为 `6` 与 `3`），故 `g∘f ≠ f∘g`。

**2.** `g∘f: A → C`：`(g∘f)(1) = g(a) = x`，`(g∘f)(2) = g(b) = y`，`(g∘f)(3) = g(a) = x`。故 `g∘f = {<1,x>, <2,y>, <3,x>}`。因 `(g∘f)(1) = (g∘f)(3) = x` 而 `1 ≠ 3`，故 `g∘f` **不是**单射。

**3.** `f^{-1}∘f = I_A`；`f∘f^{-1} = I_B`；`I_B∘f = f`；`(f^{-1})^{-1} = f`。

**4.** (a) 错。只有双射才有反函数；非双射的逆关系不是函数（见 3.4 两类反例）。(b) 对。双射的逆是双射（3.3）。(c) 错。复合一般不交换（2.2 反例 `f(x)=x+1`、`g(x)=2x`）。

**5.** 取 `A = {1}`，`B = {1, 2}`，`C = {a}`，`f(1) = 1`，`g(1) = g(2) = a`。

- `g∘f: A → C` 是单射（定义域单元素，自动单射），但 `g(1) = g(2)`，`g` 不是单射 —— 说明 `g∘f` 单射不能推出 `g` 单射。

取 `A = {1}`，`B = {a, b}`，`C = {x}`，`f(1) = a`，`g(a) = g(b) = x`。

- `g∘f: A → C` 是满射（`ran(g∘f) = {x} = C`），但 `ran f = {a} ≠ B`，`f` 不是满射 —— 说明 `g∘f` 满射不能推出 `f` 满射。

**6.** `f(x) = x²` 在 `R` 上不可逆：它不是单射（`f(1) = f(−1) = 1`），虽满射性也不成立（负数的原像不存在）。若限制为 `f: [0, +∞) → [0, +∞)`，则 `f` 是严格单调的，单射；且对任意 `y ≥ 0` 有 `x = √y` 使 `f(x) = y`，满射。故此时 `f` 是双射，可逆，且 `f^{-1}(y) = √y`。==这说明可逆性依赖定义域 / 到达域的选取，改写定义域能"救活"可逆性==。

**7.**
```
g^{-1}∘(g∘f)∘f^{-1} = (g^{-1}∘g)∘f∘f^{-1} = I_B∘f∘f^{-1} = f∘f^{-1} = I_B
```
（用结合律、`g^{-1}∘g = I_B`、`I_B∘f = f`、`f∘f^{-1} = I_B`。注意中间 `f∘f^{-1}` 未出现括号时按结合律可自由结合。）答：结果为 `I_B`。

**8.** **必要性**：设 `g∘f` 双射，则它单射、满射。由 2.4 得 `f` 单射、`g` 满射。又 `g∘f` 满射 ⇒ `ran(g∘f) = C`，而 `ran(g∘f) = g(ran f)`，故 `g(ran f) = C`；由 `g` 满射且可逆（对 `C` 上元素），两边取 `g^{-1}` 得 `ran f = g^{-1}(C)`。**充分性**：设 `f` 单射、`g` 满射且 `ran f = g^{-1}(C)`。

- `g∘f` 单射：设 `g(f(x₁)) = g(f(x₂))`，两边作用……由于 `g` 未必单射，改用 `ran f = g^{-1}(C)`：由 `g∘f` 在 `C` 上取值，对任意 `x₁, x₂`，`g(f(x₁)) = g(f(x₂))` 且 `f(x₁), f(x₂) ∈ ran f`，又 `g` 在 `ran f` 上单射（因为 `ran f = g^{-1}(C)` 使 `g|_{ran f}` 是 `ran f → C` 的双射），故 `f(x₁) = f(x₂)`，再由 `f` 单射得 `x₁ = x₂`。
- `g∘f` 满射：任取 `z ∈ C`，由 `g` 满射有 `y ∈ B` 使 `g(y) = z`；由 `ran f = g^{-1}(C)` 知对 `z ∈ C` 存在 `x ∈ A` 使 `f(x) ∈ g^{-1}(z)`，即 `g(f(x)) = z`。故 `g∘f` 满射。

两者兼备，`g∘f` 双射。∎（本题为综合命题，重点在于识别"单射性由 `f` 负责、满射性由 `g` 负责、中间要对准"。）

**9.** 若 `f = I_A`，显然可逆（`f^{-1} = I_A`）。反之设 `f` 幂等且可逆。由 `f∘f = f = f∘I_A`，两边左乘 `f^{-1}` 得 `f^{-1}∘(f∘f) = f^{-1}∘(f∘I_A)`，即 `(f^{-1}∘f)∘f = (f^{-1}∘f)∘I_A`，故 `I_A∘f = I_A∘I_A`，即 `f = I_A`。∎

不可逆的幂等例子：`f: R → R`，`f(x) = 0`（常值零函数）。`f∘f(x) = f(0) = 0 = f(x)`，幂等；但 `f` 显然不是单射（所有点映到 0），故不可逆。又如 `A = {1, 2}`，`f(1) = 1`，`f(2) = 1`，幂等但不可逆。

## 附一：函数复合与反函数速查

### 1. 复合定义与前提

| 项目 | 内容 |
| --- | --- |
| 记号 | `g∘f`（读作 "`g` 复合 `f`"） |
| 计算 | `(g∘f)(x) = g(f(x))`，==先 `f` 后 `g`== |
| 前提 | `ran f ⊆ dom g`（中间集合要对上） |
| 类型 | `f: A → B`，`g: B → C` ⇒ `g∘f: A → C` |

### 2. 复合性质推演表

| 已知 | 结论 | 能否反推 |
| --- | --- | --- |
| `f`、`g` 单射 | `g∘f` 单射 | `g∘f` 单射 ⇒ `f` 单射（`g` 未必） |
| `f`、`g` 满射 | `g∘f` 满射 | `g∘f` 满射 ⇒ `g` 满射（`f` 未必） |
| `f`、`g` 双射 | `g∘f` 双射 | 反推 `f` 单、`g` 满（不能全推） |
| 结合律 | `(h∘g)∘f = h∘(g∘f)` | 可省括号，不可换序 |
| 交换律 | ==不成立==（举反例） | — |

### 3. 反函数条件与恒等式

| 项目 | 内容 |
| --- | --- |
| 存在条件 | `f: A → B` 是==双射== |
| 定义 | `f^{-1}(y) = x ⟺ f(x) = y` |
| 性质 | `f` 双射 ⇒ `f^{-1}` 也是双射 |
| 恒等式 | `f^{-1}∘f = I_A`，`f∘f^{-1} = I_B` |
| 单位元 | `I_B∘f = f`，`f∘I_A = f` |
| 对合 | `(f^{-1})^{-1} = f` |
| 复合之逆 | `(g∘f)^{-1} = f^{-1}∘g^{-1}`（==顺序反转==） |
| 可逆刻画 | `f` 可逆 ⟺ `f` 双射；可逆时反函数唯一 |

### 4. 解题三步法

1. **算复合**：先看 `ran f ⊆ dom g`，再逐点代 `(g∘f)(x) = g(f(x))`，并写出定义域；
2. **判性质**：单射用"设 `g(f(x₁)) = g(f(x₂))` 往下剥"，满射用"任取 `z` 往回造 `x`"；
3. **求反函数**：先验证 `f` 是否为双射（否则逆关系不是函数），再从 `y = f(x)` 解出 `x`，并回代验证 `f^{-1}∘f = I_A`。

> **核心口诀**：==复合先右后左，取逆顺序反转，`I` 到手就划掉，可逆当且仅当双射。==
