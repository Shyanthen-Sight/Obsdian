# Docker 命令行

Docker CLI 看着命令多，其实只有一套对象模型：`docker <对象> <动作>`。把对象分清楚，剩下的就是查帮助和记常用参数。

- [[01-镜像|镜像]]：拉取、打标签、推送、查看层、清理
- [[02-容器|容器]]：运行、查看日志、进入、拷贝文件、停止和删除
- [[03-卷|卷]]：创建、检查、备份恢复、清理
- [[04-网络|网络]]：创建、连接、排查 DNS 和端口

几个跨对象的命令更常用：

```bash
docker ps --format 'table {{.Names}}\t{{.Status}}\t{{.Ports}}'
docker inspect -f '{{.State.Status}} {{.State.ExitCode}}' web
docker system df -v
```

`--format` 支持 Go template，排障时能直接把需要的字段打出来，比 `inspect` 一大段 JSON 好读。`docker system df` 看镜像、容器、卷、构建缓存各占多少、哪些可回收，磁盘告警先跑它。这两个命令一个管输出、一个管空间，日常出场率最高。

查参数用 `docker <对象> --help`，比背下来可靠。遇到“命令明明执行了但结果不对”，优先 `docker inspect` 看实际配置，别相信记忆里的启动参数。

学完这一阶段，应该能独立完成：把镜像从构建机搬到内网服务器、定位一个起不来的容器、找出是谁占满了磁盘、判断两个容器为什么互相解析不到。
