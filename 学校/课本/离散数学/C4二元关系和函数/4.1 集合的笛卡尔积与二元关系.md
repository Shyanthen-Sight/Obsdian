## 零、为什么需要"关系"

**关系无处不在**。翻开任何一本数学书，满眼都是关系：

| 关系 | 记法 | 两个对象之间 |
| :--- | :--- | :--- |
| 等于 | `x = y` | 数 ↔ 数 |
| 小于 | `x < y` | 数 ↔ 数 |
| 整除 | `x | y` | 整数 ↔ 整数 |
| 同余 | `x ≡ y (mod 3)` | 整数 ↔ 整数 |
| 父子 | 甲 是 乙 的父亲 | 人 ↔ 人 |
| 包含 | `A ⊆ B` | 集合 ↔ 集合 |
| 有向连边 | 城市 A 到城市 B 有航班 | 城市 ↔ 城市 |

这些例子的**共同结构**是：都不是在说"某个对象怎么样"，而是在说"**两个对象凑成一对，它们之间有某种联系**"。

**问题来了**：前几章我们学会了用集合描述"对象"（个体、集合），但集合只管**收纳**，不管**配对**。`{1, 2, 3}` 里 1 和 2 谁先谁后、谁和谁有关系，集合统统不表态。

> **一句话动机**：==要谈"关系"，先得能把两个对象"绑成一对"并且区分先后——这就是"有序对"。有序对装进集合就是"笛卡尔积"；笛卡尔积的子集，就是"关系"。==

所以本节的三步走，环环相扣：

```
有序对 <x, y>  →  笛卡尔积 A × B（所有有序对的大全）  →  关系 R ⊆ A × B（挑出一部分有序对）
```

> **⚠️ 心法**：后面所有"关系"的题目，本质都是在**对"有序对的集合"做文章**。忘记这层，性质、闭包、等价类都会变成背公式；记住这层，它们都是**画图／打点**。

## 一、有序对与 n 元有序组

### 1.1 两个对象"配对"为什么不够

先看**无序对**（就是前几章学的二元集）：

- `{x, y} = {y, x}`　（集合**不认顺序**）
- `{x, x} = {x}`　     （集合**自动去重**）

这两条性质决定了无序对**没法表达**"x 在 y 前"这种事：

| 想表达 | 用无序对行不行 |
| :--- | :--- |
| `1 < 2` 与 `2 < 1` 是**不同**的 | ❌ `{1, 2}` 两次写出同一个集合 |
| 坐标 `(1, 1)` 与 `(1)` 是**不同**的 | ❌ `{1, 1}` 退化成 `{1}` |

> **结论**：==集合的两个"毛病"（不认顺序、自动去重）正是"有序对"必须解决的问题。==有序对必须**认顺序**、**允许两个分量相同**。

### 1.2 有序对的记号

**有序对**（序偶）记作

`<x, y>`

其中 `x` 是**第一元素**（前件），`y` 是**第二元素**（后件）。核心特征是：

> ==有序对相等的充要条件是"对应位置都相等"。==

即对任意 `x, y, u, v`：

`<x, y> = <u, v>`　**⟺**　`x = u 且 y = v`

**用例子体会"认顺序、许重复"**：

| 有序对 | 是否相等 | 理由 |
| :--- | :--- | :--- |
| `<1, 2>` 与 `<2, 1>` | ❌ 不等 | 第一元素 1 ≠ 2 |
| `<1, 1>` 合法吗 | ✅ 合法 | 允许 `x = y`，它就是 `<1, 1>` |
| `<1, 1>` 与 `<1>` | ❌ 后者根本不是有序对 | |
| `<a, a>` 与 `<a, a>` | ✅ 相等 | |

### 1.3 库拉托夫斯基定义：把有序对翻译成集合

**矛盾**：题目里直接写 `<x, y>` 很方便，可前面说"集合不认顺序"——那 `<x, y>` 到底是不是集合？如果是，该用哪个集合表示它？

**库拉托夫斯基（Kuratowski）的答案**（1921 年）——用**两层集合**把顺序"编码"进去：

> ==`<x, y> = {{x}, {x, y}}`==

**为什么偏偏是这一堆大括号？** 拆开看它的"机关"：

| 分量情况 | `{{x}, {x, y}}` 长什么样 | 能否反推出 x、y |
| :--- | :--- | :--- |
| `x ≠ y` | 两个不同的集合：`{x}` 与 `{x, y}` | ✅ 单元素集给 x，另一个给 y |
| `x = y` | `{{x}, {x}} = {{x}}` | ✅ 退化成只有 `{x}`，也知道两个分量都是 x |

**提取规则**（记忆钩子）：==**单元素的那个集合，元素就是第一元素 `x`**；另一集合去掉 x，剩下的就是 `y`。==

- `{{1}, {1, 2}}`：单元素集 `{1}` ⇒ `x = 1`；另一集合 `{1, 2}` 去掉 1 ⇒ `y = 2`。即 `<1, 2>`。
- `{{1}}`：只有一个单元素集 ⇒ `x = y = 1`。即 `<1, 1>`。

> **⚠️ 易错警告**：`<x, y>` 与 `{x, y}` 是**两回事**：前者有序、可取相同分量；后者无序、自动去重。考试里若把 `<x, y>` 写成 `{x, y}`，性质立刻全错。

### 1.4 定理：有序对相等的充要条件

**定理**：对任意 `x, y, u, v`，

`<x, y> = <u, v>`　**⟺**　`x = u 且 y = v`

**（⇒）方向的证明思路**（这是本节唯一值得推一遍的地方，考过）：

设 `<x, y> = {{x}, {x, y}}`，`<u, v> = {{u}, {u, v}}`，两者相等。用**分情况**讨论（关键在 `x = y` 与否）：

- **情况 1：`x = y`**。则 `<x, y> = {{x}}`。等式成立要求右边也只有一个元素，故 `{{u}, {u, v}}` 必须退化为单元素集，只能 `u = v`，且此时 `{u} = {x}`，得 `x = u`，从而 `y = x = u = v`。✅
- **情况 2：`x ≠ y`**。此时 `{x} ≠ {x, y}`，是两个不同的集合。相等的两个集合必须"逐元素相等"，故 `{x}` 只能对上 `{u}`（单元素对单元素），得 `x = u`；剩下的 `{x, y}` 对上 `{u, v}`，得 `{x, y} = {u, v}`，配合 `x = u` 推出 `y = v`。✅

**（⇐）方向**：若 `x = u` 且 `y = v`，直接代入即得两边同为 `{{x}, {x, y}}`。✅

> **记忆钩子**：==证（⇒）就一句话——"先看集合个数：单元素 vs 双元素，逼出 x = y 还是 x ≠ y"。== 这是典型的**从结构反推分量**，与后面用矩阵、关系图反推关系是同一思路。

### 1.5 n 元有序组

把两个对象扩展成 n 个：

**n 元有序组** 记作 `<x₁, x₂, …, xₙ>`，相等的充要条件是**逐个位置相等**：

`<x₁, …, xₙ> = <y₁, …, yₙ>`　**⟺**　`x₁ = y₁ ∧ x₂ = y₂ ∧ … ∧ xₙ = yₙ`

例如三元有序组 `<1, 2, 3>` 与 `<2, 1, 3>` 不相等（第二位置就不同）。n 元有序组可以用有序对**递归定义**：`<x₁, …, xₙ> = <<x₁, …, xₙ₋₁>, xₙ>`，这样就又回到库拉托夫斯基的两层结构。

> **约定**：本课程主要用**二元**关系，n 元关系只在推广中一带而过；但 n 元有序组的概念在**关系数据库**（一张表就是一个 n 元关系的集合）里处处出现。

## 二、笛卡尔积（直积）

### 2.1 定义

**定义**：设 `A`、`B` 为两个集合，称

`A × B = { <x, y> | x ∈ A ∧ y ∈ B }`

为 `A` 与 `B` 的**笛卡尔积**（也译作**直积**），仍是一个**集合**。

**读法要点**：把 `A × B` 理解为"**从 A 里取一个、从 B 里取一个，把所取结果按 A 前 B 后配成有序对，把所有可能的有序对收集起来**"。

> ==**元素形式是"有序对"，不是"元素本身"。**== `1 ∈ A`、`a ∈ B` 时，`1` 和 `a` 都**不是** `A × B` 的元素；`<1, a>` 才是。

### 2.2 小例子（先动手，再谈性质）

**例 1**：`A = {0, 1}`，`B = {a, b}`。

```
A × B = { <0, a>, <0, b>, <1, a>, <1, b> }
```

可以列成一张"打点表"（行是 A 的元素，列是 B 的元素，每个格子是一个有序对）：

| `A × B` | `a` | `b` |
| :--- | :--- | :--- |
| **0** | `<0, a>` | `<0, b>` |
| **1** | `<1, a>` | `<1, b>` |

再看另一个方向：

```
B × A = { <a, 0>, <a, 1>, <b, 0>, <b, 1> }
```

`A × B` 与 `B × A` 都是**四个元素**，但元素**对不上**：`<0, a> ≠ <a, 0>`。这就是"交换律不成立"的具体长相。

**例 2**（含重复分量与空集）：

- `{1, 2} × {2} = { <1, 2>, <2, 2> }` —— 两分量可以相等，故 `<2, 2>` 合法。
- `A × ∅ = ∅`，`∅ × B = ∅` —— 没有"配对的另一半"，凑不出任何有序对。

### 2.3 基数：|A × B| = |A| · |B|

**定理**：若 `A`、`B` 是**有限集**，则

`|A × B| = |A| · |B|`

**理由**（"乘法原理"的直接体现）：配一个有序对要**分两步**——

1. 第一步选第一元素，有 `|A|` 种选法；
2. 第二步选第二元素，有 `|B|` 种选法（**与第一步的选择无关**，因为允许重复分量）。

两步的选择**独立**，用乘法原理乘起来，共 `|A| · |B|` 个有序对。用 2.2 的打点表看更直观：==表有 `|A|` 行、`|B|` 列，格子数就是 `|A| · |B|`。==

**推广**：`|A₁ × A₂ × … × Aₙ| = |A₁| · |A₂| · … · |Aₙ|`；特别地 `|A²| = |A|²`（`A²` 是 `A × A` 的简写）。

**例**：`|{0, 1}| = 2`，`|{a, b}| = 2` ⇒ `|A × B| = 4`；`|A| = 3`，`|A × A| = |A²| = 9`。

### 2.4 笛卡尔积的运算性质（🎯 必背）

设 `A`、`B`、`C` 为任意集合。

**（1）不满足交换律**：`A × B ≠ B × A`（除非 `A = B` 或其中之一为 `∅`）。

> 反例已在 2.2：`{0, 1} × {a, b} ≠ {a, b} × {0, 1}`。

**（2）不满足结合律**：`(A × B) × C ≠ A × (B × C)`。

> 原因：左边的元素形如 `<<x, y>, z>`（第一分量本身是个有序对），右边是 `<x, <y, z>>`。**嵌套结构不同**，一般不相等。==注意别和"n 元有序组的递归定义"混——那里我们**规定**这种嵌套来表示 n 元组，是人为约定，不是运算律。==

**（3）对并、交满足分配律**：

| 分配律 | 形式 |
| :--- | :--- |
| 对并 | `A × (B ∪ C) = (A × B) ∪ (A × C)` |
| 对并（右） | `(B ∪ C) × A = (B × A) ∪ (C × A)` |
| 对交 | `A × (B ∩ C) = (A × B) ∩ (A × C)` |
| 对交（右） | `(B ∩ C) × A = (B × A) ∩ (C × A)` |

**证 `A × (B ∪ C) = (A × B) ∪ (A × C)`**（集合相等，两边互含）：

```
<x, y> ∈ A × (B ∪ C)
⟺ x ∈ A ∧ y ∈ (B ∪ C)
⟺ x ∈ A ∧ (y ∈ B ∨ y ∈ C)         （并的定义）
⟺ (x ∈ A ∧ y ∈ B) ∨ (x ∈ A ∧ y ∈ C)   （∧ 对 ∨ 分配）
⟺ <x, y> ∈ (A × B) ∨ <x, y> ∈ (A × C)
⟺ <x, y> ∈ (A × B) ∪ (A × C)
```

> **看穿本质**：==笛卡尔积的运算律，就是"∈"定义的逻辑变形——分配律其实是 `∧` 对 `∨`／`∧` 的分配律搬到有序对身上。==沿这条线一路等价，"⟺"从头串到尾，集合相等自然成立。（这条思路在 C1 [[等值演算公式]] 里已练熟。）

**（4）对差集的分配律**：`A × (B − C) = (A × B) − (A × C)`。

**⚠️ 反方向不成立**：`(A − B) × C ≠ (A × C) − (B × C)`（**左边一般不是右边**）。辨析见练习题。

**（5）与 ∅ 的积**：`A × ∅ = ∅ × B = ∅`。（`∅` 里没有元素可供配对。）

**（6）子集的正向保序**：若 `C ⊆ A`，则 `C × B ⊆ A × B`。（`C` 变小，积跟着变小，是单调的。）

### 2.5 一张速记表

| 性质 | 是否成立 | 一句话理由 |
| :--- | :---: | :--- |
| 交换律 `A × B = B × A` | ❌ | 有序对认顺序，`<x, y> ≠ <y, x>` |
| 结合律 `(A × B) × C = A × (B × C)` | ❌ | 嵌套层级/位置不同 |
| 对 ∪ 分配 | ✅ | `∈` 展开后是 `∧` 对 `∨` 分配 |
| 对 ∩ 分配 | ✅ | `∈` 展开后是 `∧` 对 `∧` 结合 |
| 对 − 分配（左） | ✅ | 见 2.4(4) |
| 单调 `C ⊆ A ⇒ C × B ⊆ A × B` | ✅ | 子集变小，积跟着变小 |
| `A × ∅ = ∅` | ✅ | 无处配对 |

## 三、二元关系

### 3.1 从"关系"到"有序对的集合"

回到 0 节的动机：关系刻画的是"**两个对象凑成一对**"。任何一对有关系的对象，都能写成一个有序对；把所有这样的有序对攒起来，就是一个集合。

> ==**关系 = 有序对的集合 = 笛卡尔积的子集。**== 这句话要死死记住。

**定义（从 A 到 B 的二元关系）**：设 `A`、`B` 为集合，`R ⊆ A × B` 称为**从 A 到 B 的一个二元关系**。若 `<x, y> ∈ R`，记为

`x R y`

读作"x 与 y 具有关系 R"；若 `<x, y> ∉ R`，记 `x ⊀ y`（或写 `¬(x R y)`）。

**定义（A 上的二元关系）**：当 `A = B` 时，`R ⊆ A × A` 称为 **A 上的二元关系**。这是我们**最常用**的情形。

**⚠️ 关键认知**：

- **关系是一个集合**，它的元素是**有序对**。
- ==`R ⊆ A × B` 与 `R ∈ P(A × B)` 是**同一件事**==（子集 ⟺ 幂集的元素）。
- 关系 `R` 和它的符号 `R` 别混：`x R y` 是"写成中缀"的便捷写法，本质是 `<x, y> ∈ R`。

### 3.2 例：几种常见关系写成集合

**例 1（整除关系）**：`A = {1, 2, 3, 6}`，关系 `R` 表示"x 整除 y"。因为 `R ⊆ A × A`，先把 `A × A`（共 16 个有序对）全列出来，再挑出满足"整除"的：

```
R = { <1,1>, <1,2>, <1,3>, <1,6>,
      <2,2>, <2,6>,
      <3,3>, <3,6>,
      <6,6> }
```

（1 整除一切，故第一行四个全收；2 整除 2、6；3 整除 3、6；6 只整除自己。）

**例 2（小于关系）**：`A = {1, 2, 3}`，"x < y"：

```
R = { <1,2>, <1,3>, <2,3> }
```

注意 `<1, 1>` **不在**里面（1 不小于 1）——这体现了关系对有序对的筛选作用。

**例 3（同余关系）**：`A = {0, 1, 2, …, 5}`，"x ≡ y (mod 3)"：

```
R = { <0,0>, <0,3>, <3,0>, <3,3>,
      <1,1>, <1,4>, <4,1>, <4,4>,
      <2,2>, <2,5>, <5,2>, <5,5> }
```

（余数相同的数配成对，共 3 个"类"，每类 2 个数 → 每类 `2 × 2 = 4` 对，共 12 对。）

**例 4（包含关系）**：`A = {∅, {a}}`（A 的元素本身是集合），"x ⊆ y"：

A 的两个元素是 `∅` 与 `{a}`。因为 `∅ ⊆ ∅`、`∅ ⊆ {a}`、`{a} ⊆ {a}`，而 `{a} ⊄ ∅`：

```
R = { <∅, ∅>, <∅, {a}>, <{a}, {a}> }
```

> **⚠️ 易错警告**：关系里的元素是**有序对**，有序对的**分量本身可以是集合**（例 4 就是）。别看到 `∅` 当分量就慌——`<∅, ∅>` 完全合法。

### 3.3 关系有多少个？（🎯 高频考点）

**问题**：给定 `A`、`B`，从 `A` 到 `B` 一共有多少个不同的二元关系？

**推导三步**：

1. 关系必须先是 `A × B` 的**子集**；
2. `A × B` 有 `|A| · |B|` 个元素；
3. 一个含 `m` 个元素的集合，它的**子集共有** `2^m` 个（幂集的基数，见 [[3.1 集合的基本概率]]）。

把 `m = |A| · |B|` 代进去：

> ==**从 A 到 B 的二元关系共有 `2^(|A|·|B|)` 个。**==

特别地，`A` 上的关系共有 `2^(|A|²)` 个。

**例（考题原型）**：`|A| = 3`，`|B| = 2`。

- `|A × B| = 3 × 2 = 6`；
- 关系个数 `= 2^6 = 64`。

**为什么"每个子集都是一个关系"？** 因为"挑出哪些有序对成立"这件事，**完全等价于**"从 `A × B` 里选一个子集"。选法有 `2^6` 种，关系就有 64 个。

| `|A|` | `|B|` | `|A × B|` | 关系个数 `2^(|A||B|)` |
| :---: | :---: | :---: | :---: |
| 1 | 1 | 1 | 2 |
| 2 | 2 | 4 | 16 |
| 3 | 2 | 6 | 64 |
| 3 | 3 | 9 | 512 |

> **钩子**：==子集计数是"`2` 的（元素个数）次方"。== 只要数清 `A × B` 有几个有序对，答案就出来了。反之，**"共有 512 个关系" ⇒ `|A| = 3`、`A` 上的关系**，因为 `2^9 = 512`。

## 四、关系的三种表示

同一个关系有三种"写法"，考试里要能**互相翻译**。设 `A = {a₁, a₂, …, aₘ}`，`B = {b₁, b₂, …, bₙ}`，`R ⊆ A × B`。

### 4.1 集合表示（罗列法／描述法）

最原始，就是 3.2 那样把有序对列出来或用 `{ <x, y> | … }` 描述。**优点**：无歧义。**缺点**：元素多时冗长。

### 4.2 关系矩阵 M_R

**定义**：`R` 的**关系矩阵** `M_R = (r_{ij})_{m × n}` 是 `m` 行 `n` 列的 **0-1（布尔）矩阵**，其中

`r_{ij} = 1` 当且仅当 `<aᵢ, bⱼ> ∈ R`，否则为 `0`

**约定（务必记牢）**：

- **行对应 A 的元素**（`a₁, a₂, …, aₘ` 从上到下）；
- **列对应 B 的元素**（`b₁, b₂, …, bₙ` 从左到右）；
- 行、列的顺序**由我们事先约定并固定**（通常按集合默认顺序），换顺序矩阵就换样子，但关系本身不变。

**例**：`A = {1, 2, 3}`，`B = {a, b}`，`R = { <1, a>, <2, b>, <3, a> }`。

以行为 `1, 2, 3`、列为 `a, b`：

```
        a   b
   1 ┌ 1   0 ┐
   2 │ 0   1 │
   3 └ 1   0 ┘
```

即

`M_R = [ [1, 0], [0, 1], [1, 0] ]`

**读法**：第 `i` 行第 `j` 列是 `1` ⇒ `<aᵢ, bⱼ> ∈ R`。例如第 3 行第 1 列是 1 ⇒ `<3, a> ∈ R`。✅

> **⚠️ 易错警告**：==先写死"谁做行、谁做列"，再填 0/1==。题型里最常犯的错就是把行列约定写反、或把 `A`、`B` 的顺序颠倒。若 `A = B`（A 上的关系），行列表头相同，此时 `M_R` 是**方阵**，对角线上的 1 表示"自反的点"。

### 4.3 关系图（有向图）

当 `A` 与 `B` 是**有限集**时，可以画一张**有向图**：

- **顶点**：`A` 和 `B` 中的每个元素画成一个点（若 `A = B`，`aᵢ` 与 `bᵢ` 是同一个点，不重复画）；
- **有向边**：对每个 `<x, y> ∈ R`，从 `x` 画一条**带箭头的边**指向 `y`；
- **自环**：若 `x R x`（即 `<x, x> ∈ R`），从 `x` 出发指回 `x` 的边，画成一个**自环**。

> ==**一句话记忆**：关系图 = 把每个有序对 `<x, y>` 画成"x 指向 y 的箭头"。==

**例（4.2 的 `R` 转关系图，文字描述）**：

```
点：1, 2, 3, a, b
有向边：  1 → a
         2 → b
         3 → a
```

**例（A 上的关系，含自环）**：`A = {1, 2, 3}`，`R = { <1,1>, <1,3>, <2,1> }`。

```
点：1, 2, 3
自环：1 → 1        （因为 <1,1> ∈ R）
有向边：1 → 3
       2 → 1
```

**三种表示对照表**：

| 表示法 | 形态 | 最适合 | 语言/工具类比 |
| :--- | :--- | :--- | :--- |
| **集合** | 有序对的集合 | 精确定义、证明 | 数学本体 |
| **矩阵** `M_R` | 0-1 布尔矩阵 | 计数、复合运算、编程 | 邻接矩阵 |
| **关系图** | 点＋有向边 | 看性质（自反／对称／传递） | 社交网络图 |

> **看性质的诀窍（预告 [[4.3 关系的性质]]）**：==自反 ⇔ 每个点都有自环（或 `M_R` 主对角线全 1）；对称 ⇔ 每条边都有反向边（或 `M_R` 对称）；传递 ⇔ 顺着边走两步必能一步走到。== 现在先记住"有这三种表示"，下一节就靠它们做判据。

## 五、定义域、值域与域

关系既然是"有序对的集合"，就能像函数一样问：**它管到哪些前件？能落到哪些后件？**

**定义**：设 `R ⊆ A × B`。

| 名称 | 记号 | 定义 | 中文读法 |
| :--- | :--- | :--- | :--- |
| **定义域** | `dom R` | `{ x | ∃y ( x R y ) }` | R 中所有有序对的**第一元素**的集合 |
| **值域** | `ran R` | `{ y | ∃x ( x R y ) }` | R 中所有有序对的**第二元素**的集合 |
| **域** | `fld R` | `dom R ∪ ran R` | 定义域与值域的并 |

> ==**记忆钩子**：`dom`＝"出场的 x"，`ran`＝"出场的 y"，`fld`＝"两边加起来"。== 注意 `ran R` 的字母顺序是 r-a-n（range 缩写），别写成 `rn`。

**关键提醒**：

- `dom R ⊆ A`，`ran R ⊆ B`，但**通常不等于 A、B**（有些元素没参与任何有序对）。
- `dom R`、`ran R` 都**只含实际出现的元素**，不是把 `A`、`B` 整个搬过来。

**例 1**：`R = { <1, a>, <2, b>, <3, a> }`（4.2 的那个）。

- 第一元素有 `1, 2, 3` ⇒ `dom R = {1, 2, 3}`；
- 第二元素有 `a, b` ⇒ `ran R = {a, b}`；
- `fld R = {1, 2, 3} ∪ {a, b} = {1, 2, 3, a, b}`。

**例 2**：`A = {1, 2, 3, 6}`，整除关系 `R`（3.2 例 1）。

- `dom R = {1, 2, 3, 6}`（每个数都整除自己）；
- `ran R = {1, 2, 3, 6}`；
- 此时 `dom R = ran R = A`，`fld R = A`。

**例 3**（`dom` 与 `ran` 不相等）：`A = {1, 2, 3}`，"x < y" 关系 `R = {<1,2>, <1,3>, <2,3>}`。

- `dom R = {1, 2}`（3 没做过第一元素）；
- `ran R = {2, 3}`（1 没做过第二元素）；
- `fld R = {1, 2, 3}`。

> **⚠️ 易错警告**：`dom R ≠ A` 很正常，别自作主张补全。=="谁当过第一元素谁才进 `dom R`"==——3.2 例 2 里 3 从没当过前件，所以不在 `dom R` 中。

**与函数的呼应**：后面 [[4.6 函数的定义与性质]] 里，函数 `f: A → B` 是**要求 `dom f = A`** 的特殊关系——每个 `x ∈ A` 都恰好配一个 `y`。可见"定义域"这层概念，正是"关系能否升级为函数"的门槛。

## 六、几种特殊关系

### 6.1 三类最基本的特殊关系

设 `A` 为非空集合（`A ≠ ∅`）。

| 名称 | 记号 | 定义 | 直观 |
| :--- | :--- | :--- | :--- |
| **空关系** | `∅` | `∅ ⊆ A × A` | 谁和谁都"没关系" |
| **全域关系** | `E_A` | `E_A = A × A` | 谁和谁都"有关系" |
| **恒等关系** | `I_A` | `I_A = { <x, x> | x ∈ A }` | 每个人都只"等于自己" |

**逐个体会**（取 `A = {1, 2, 3}`）：

| 关系 | 集合形式 | 关系矩阵 `M_R`（3×3） | 关系图 |
| :--- | :--- | :--- | :--- |
| `∅` | `∅` | 全 0 矩阵 | 三个孤立点，无边 |
| `E_A` | 全部 9 个有序对 | 全 1 矩阵 | 每两点间双向边＋每个点自环 |
| `I_A` | `{<1,1>, <2,2>, <3,3>}` | 主对角线为 1、其余为 0 | 每个点一个自环，无其他边 |

**`E_A` 的基数**：`|E_A| = |A|² = |A × A|`；**`I_A` 的基数**：`|I_A| = |A|`（每个元素配一个自己）。

> **钩子**：==`∅` 是"最小"关系（一个对都没有），`E_A` 是"最大"关系（所有对都有），`I_A` 是"最挑"关系（只认同自己）。==三者夹在 `2^(|A|²)` 个关系的两端与中间。

### 6.2 常见的具体关系举例

| 关系 | 所在集合 | 形式 | 是否含 `<x, x>` |
| :--- | :--- | :--- | :--- |
| **整除** `D_A` | `A ⊆ 正整数` | `{ <x, y> | x 整除 y }` | ✅（每个数整除自己） |
| **模 n 同余** | 整数集 | `{ <x, y> | x ≡ y (mod n) }` | ✅ |
| **小于** `<` | 实数集 | `{ <x, y> | x < y }` | ❌（x 不小于自己） |
| **小于等于** `≤` | 实数集 | `{ <x, y> | x ≤ y }` | ✅ |
| **包含** `⊆` | 幂集 `P(S)` | `{ <X, Y> | X ⊆ Y }` | ✅（每个集合包含自己） |
| **真包含** `⊂` | 幂集 `P(S)` | `{ <X, Y> | X ⊂ Y }` | ❌ |

> **预告**：=="含不含自环"就是下节 [[4.3 关系的性质]] 里"**自反／反自反**"的分水岭；而"每条边有没有反向边"决定对称性；"两步能不能并成一步"决定传递性。== 现在只需建立"关系可以用具体含义来命名"的意识。

### 6.3 易混概念对照

| 容易混的一对 | 区别 |
| :--- | :--- |
| **`<x, y>` vs `{x, y}`** | 前者有序、许重复；后者无序、去重 |
| **`A × B` vs `B × A`** | 有序对前后分量互换，一般不相等 |
| **`R ⊆ A × B` vs `R > A × B`** | 关系必须是子集，`R` 的元素只能是 `A × B` 的元素 |
| **`∅`（空关系）vs `∅`（空集）** | 空关系就是空集本身，但要看它在"哪个 `A × A` 的语境下" |
| **`E_A` vs `A × A`** | `E_A` 就是 `A × A`，两种叫法 |
| **`I_A` vs `E_A`** | `I_A` 只保留对角线，`E_A` 全都要 |
| **`dom R` vs `A`** | `dom R` 是**实际出现**的前件，可能真包含于 `A` |

## 七、例题

### 例 1 🟢 求笛卡尔积

设 `A = {a, b}`，`B = {1, 2, 3}`。求 `A × B`、`B × A`，并说明二者是否相等。

**解**：

```
A × B = { <a,1>, <a,2>, <a,3>, <b,1>, <b,2>, <b,3> }
B × A = { <1,a>, <1,b>, <2,a>, <2,b>, <3,a>, <3,b> }
```

`|A × B| = 2 × 3 = 6 = |B × A|`，但元素 `⟨a,1⟩` 与 `⟨1,a⟩` 不同 ⇒ `A × B ≠ B × A`（**交换律不成立**）。

### 例 2 🟡 关系计数

设 `|A| = 4`，`|B| = 3`。从 `A` 到 `B` 共有多少个二元关系？`A` 上的二元关系共有多少个？

**解**：`|A × B| = 4 × 3 = 12` ⇒ 从 `A` 到 `B` 的关系有 `2¹² = 4096` 个。
`|A × A| = 4 × 4 = 16` ⇒ `A` 上的关系有 `2¹⁶ = 65536` 个。

### 例 3 🟡 三种表示互转

`A = {1, 2, 3}`，`A` 上的关系 `R` 由图描述：`1 → 1`、`1 → 2`、`2 → 3`、`3 → 1`。写出 `R` 的集合表示、关系矩阵、`dom R`、`ran R`。

**解**：

```
R = { <1,1>, <1,2>, <2,3>, <3,1> }
```

以行、列均为 `1, 2, 3`：

```
       1  2  3
   1 ┌ 1  1  0 ┐
   2 │ 0  0  1 │
   3 └ 1  0  0 ┘
```

`dom R = {1, 2, 3}`，`ran R = {1, 2, 3}`，`fld R = {1, 2, 3}`。

> 注意：`dom R`、`ran R` 都等于 `A`，但这**不代表** `R = E_A`（`R` 只有 4 个有序对，`E_A` 有 9 个）。

### 例 4 🔴 证明分配律的一个变形

设 `A`、`B`、`C` 是集合。证明 `(A ∩ B) × C = (A × C) ∩ (B × C)`。

**证**（元素法，两边互含）：

```
<x, y> ∈ (A ∩ B) × C
⟺ x ∈ (A ∩ B) ∧ y ∈ C
⟺ (x ∈ A ∧ x ∈ B) ∧ y ∈ C          （交的定义）
⟺ (x ∈ A ∧ y ∈ C) ∧ (x ∈ B ∧ y ∈ C)   （∧ 结合、交换，复制 y ∈ C）
⟺ <x, y> ∈ (A × C) ∧ <x, y> ∈ (B × C)
⟺ <x, y> ∈ (A × C) ∩ (B × C)
```

故两集合相等。∎

> **方法总结**：==证笛卡尔积等式，就做一件事——把 `<x, y> ∈ 左边` 一路等价变形到 `<x, y> ∈ 右边`，靠的全是 `∈` 的定义与逻辑联结词的运算律。== 这条套路与 C1 [[等值演算公式]] 里证集合等值式完全一致。

### 例 5 🔴（选做）有序对相等

判断：若 `<x, y> = <u, v>`，能否推出 `x = u` 且 `y = v`？若已知 `x = u`，能否推出 `y = v`？

**解**：第一问由 1.4 定理回答"**能**"（充要条件）。
第二问：`<x, y> = <u, v>` 且 `x = u` ⇒ 由充要条件仍得 `y = v`（**能**）。但要注意，若**只知** `{x, y} = {u, v}`（无序对相等），则**不能**推出 `x = u ∧ y = v`——可能 `x = v ∧ y = u`。==这正是"有序对 vs 无序对"的分水岭。==

# 参考答案与详细解析

## 第 1 题

```
A × B = { <0,x>, <0,y>, <1,x>, <1,y> }        （4 个）
B × A = { <x,0>, <x,1>, <y,0>, <y,1> }        （4 个）
A × A = { <0,0>, <0,1>, <1,0>, <1,1> }        （4 个）
```

**解析**：`|A| = |B| = 2`，故三者基数都等于 `2 × 2 = 4`。但 `A × B ≠ B × A`（分量顺序不同）；`A × A` 里出现 `<0,0>`、`<1,1>` 这类"分量相同"的有序对，说明有序对**允许重复分量**。

## 第 2 题

**(1) ❌**。反例：`A = {0, 1}`，`B = {x, y}` ⇒ `A × B ≠ B × A`（例 1）。
**(2) ✅**。`∅` 里无元素可作第二分量，凑不出任何有序对。（前提：这里 `A × ∅` 中 `∅` 作为右集合。）
**(3) ❌**。`(A × B) × C` 的元素形如 `<<x, y>, z>`；`A × (B × C)` 的元素形如 `<x, <y, z>>`。嵌套结构不同，一般不相等。
**(4) ❌**。应为 `|A × B| = 2 × 5 = 10`，不是相加。==基数相乘，不是相加——这是最常见的手滑。==

## 第 3 题

`x + y = 4` 且 `x, y ∈ {1, 2, 3, 4}`：满足的有序对为 `(1,3)`、`(2,2)`、`(3,1)`，（`(4,0)` 中 0 不在 A，(0,4) 同理）。

```
R = { <1,3>, <2,2>, <3,1> }
dom R = {1, 2, 3}
ran R = {1, 2, 3}
fld R = {1, 2, 3}
```

**解析**：4 没当过前件也没当过后件，故不在 `dom R`、`ran R` 中，`fld R` 也不含 4。

## 第 4 题

**(1)** 行列均按 `1, 2, 3` 顺序：

```
       1  2  3
   1 ┌ 1  1  0 ┐
   2 │ 0  0  1 │
   3 └ 1  0  1 ┘
```

**(2)** 关系图：

```
点：1, 2, 3
自环：1 → 1，3 → 3           （因 <1,1>, <3,3> ∈ R）
有向边：1 → 2，2 → 3，3 → 1
```

**解析（易错点）**：矩阵第 3 行第 3 列是 1（`<3,3> ∈ R`），故**不能**漏掉 3 的自环；而第 2 行第 2 列为 0，2 没有自环。

## 第 5 题

**(1)** `|A × B| = nm` ⇒ 关系个数 `2^(nm)`。
**(2)** `A` 上关系 `⊆ A × A`，`|A × A| = n²` ⇒ 关系个数 `2^(n²)`。
**(3)** `2^(nm) = 8 = 2³` ⇒ `nm = 3`。

**解析**：第 (3) 问反用公式。==看到"2 的幂"，先化成 `2^(某数)`，那个"某数"就是 `A × B` 的元素个数。==

## 第 6 题

`A = {1, 2, 3}`：

```
空关系  = ∅                                    （0 个元素）
E_A    = A × A = { <1,1>,<1,2>,<1,3>,
                   <2,1>,<2,2>,<2,3>,
                   <3,1>,<3,2>,<3,3> }         （9 个元素）
I_A    = { <1,1>, <2,2>, <3,3> }               （3 个元素）
```

**解析**：`|∅| = 0`，`|E_A| = |A|² = 9`，`|I_A| = |A| = 3`。三者分别是"最小""最大""只认同自己"的关系。

## 第 7 题

`A = P({a}) = {∅, {a}}`，元素是 `∅` 与 `{a}`（把它们当作两个"点"）。包含关系成立的有 `∅ ⊆ ∅`、`∅ ⊆ {a}`、`{a} ⊆ {a}`，而 `{a} ⊄ ∅`。

```
R = { <∅, ∅>, <∅, {a}>, <{a}, {a}> }
```

行列均按 `∅, {a}` 顺序：

```
        ∅   {a}
   ∅  ┌ 1    1  ┐
 {a}  └ 0    1  ┘
```

**解析**：==关系里的有序对，其分量本身就是集合，照样按"分量是谁、是否成对"填矩阵==。矩阵下三角（`{a}` 行 `∅` 列）为 0，正是因为真包含不成立。

## 第 8 题

```
<x, y> ∈ A × (B ∪ C)
⟺ x ∈ A ∧ y ∈ (B ∪ C)
⟺ x ∈ A ∧ (y ∈ B ∨ y ∈ C)                    （并的定义）
⟺ (x ∈ A ∧ y ∈ B) ∨ (x ∈ A ∧ y ∈ C)          （∧ 对 ∨ 分配律）
⟺ <x, y> ∈ (A × B) ∨ <x, y> ∈ (A × C)         （笛卡尔积定义）
⟺ <x, y> ∈ (A × B) ∪ (A × C)                  （并的定义）
```

故 `A × (B ∪ C) = (A × B) ∪ (A × C)`。∎

**关键一步**：第 3 行 → 第 4 行用到 `x ∈ A` 重复出现可"复制"：`x ∈ A` 在两项里都成立，正是 `∧` 对 `∨` 的分配（见 C1 [[等值演算公式]]）。

## 第 9 题

`x ≡ y (mod 3)`，即 `x`、`y` 除以 3 余数相同。`A = {1, 2, 3, 4, 5, 6}` 按余数分成三组：

- 余 1：`{1, 4}`
- 余 2：`{2, 5}`
- 余 0：`{3, 6}`

组内任意两数（含自身）都同余：

```
R = { <1,1>,<1,4>,<4,1>,<4,4>,
      <2,2>,<2,5>,<5,2>,<5,5>,
      <3,3>,<3,6>,<6,3>,<6,6> }
```

`|R| = 3 组 × 4 = 12`（每组 2 个数，`2 × 2 = 4` 对）。

**矩阵规律**：把行列按 `1, 4 | 2, 5 | 3, 6` 的**分组顺序**排列，`M_R` 呈**分块对角**形状——对角线上是 3 个 `2 × 2` 的全 1 小块，其余全 0：

```
       1 4 | 2 5 | 3 6
   1 ┌ 1 1 | 0 0 | 0 0 ┐
   4 │ 1 1 | 0 0 | 0 0 │
   2 │ 0 0 | 1 1 | 0 0 │
   5 │ 0 0 | 1 1 | 0 0 │
   3 │ 0 0 | 0 0 | 1 1 │
   6 └ 0 0 | 0 0 | 1 1 ┘
```

> **预告**：这种"同一块内全 1、块间全 0"的结构，正是 [[4.5 等价关系和偏序关系]] 里**等价关系**的招牌——同余关系把集合**分成若干互不相交的类**，每一类内部元素两两有关系。

## 附一：速查表

**有序对**

- 记号：`<x, y>`，第一元素 `x`、第二元素 `y`
- 相等：`<x, y> = <u, v> ⟺ x = u ∧ y = v`（**认顺序、许重复**）
- 库拉托夫斯基定义：==`<x, y> = {{x}, {x, y}}`==
- 提取法：单元素集元素＝`x`；另一集合去掉 `x` 剩下＝`y`；只有 `{{x}}` 时 `x = y`
- n 元有序组：`<x₁,…,xₙ>` 逐位相等才相等

**笛卡尔积**

- 定义：`A × B = { <x, y> | x ∈ A ∧ y ∈ B }`，元素是**有序对**
- 基数：`|A × B| = |A| · |B|`（推广 `|A₁ × … × Aₙ| = |A₁|···|Aₙ|`）
- `A × A = A²`
- ❌ 交换律、❌ 结合律
- ✅ `A × (B ∪ C) = (A × B) ∪ (A × C)`
- ✅ `A × (B ∩ C) = (A × B) ∩ (A × C)`
- ✅ `A × (B − C) = (A × B) − (A × C)`
- ✅ `A × ∅ = ∅ × B = ∅`
- ✅ `C ⊆ A ⇒ C × B ⊆ A × B`

**二元关系**

- 定义：`R ⊆ A × B`（从 A 到 B）；`A = B` 时称 **A 上的关系**
- `x R y ⟺ <x, y> ∈ R`
- 关系个数：==从 A 到 B 有 `2^(|A|·|B|)` 个；A 上有 `2^(|A|²)` 个==
- 三种表示：**集合**（罗列有序对）｜**矩阵** `M_R`（行 A、列 B，0/1）｜**关系图**（点＋有向边＋自环）

**定义域、值域、域**

- `dom R = { x | ∃y (x R y) }`（出场的 x）
- `ran R = { y | ∃x (x R y) }`（出场的 y）
- `fld R = dom R ∪ ran R`

**三类特殊关系**（`A ≠ ∅`）

| 关系 | 记号 | 定义 | 基数 |
| :--- | :--- | :--- | :--- |
| 空关系 | `∅` | 空集 | `0` |
| 全域关系 | `E_A` | `A × A` | `|A|²` |
| 恒等关系 | `I_A` | `{ <x, x> | x ∈ A }` | `|A|` |

**常见具体关系**：整除 `D_A`、模 n 同余、小于 `<`、小于等于 `≤`、包含 `⊆`、真包含 `⊂`。

## 附二：易错提醒汇总

| ⚠️ 易错点 | 正确认识 |
| :--- | :--- |
| 把 `<x, y>` 写成 `{x, y}` | 有序对认顺序、许重复；无序对相反 |
| 以为 `A × B = B × A` | 一般不相等，看分量是否为有序对 |
| 以为 `|A × B| = |A| + |B|` | 是**相乘** `|A| · |B|` |
| 以为 `(A × B) × C = A × (B × C)` | 嵌套结构不同，不成立 |
| 关系矩阵行列约定写反 | **行对应 A、列对应 B**，顺序要事先固定 |
| `dom R` 直接写成 `A` | `dom R` 只含**实际出现**的前件，可能真包含于 `A` |
| `ran R` 记成 `Rn R` | 缩写是 r-a-n（range） |
| 漏掉关系图里的自环 | `x R x` 要画自环；矩阵对角线要填 |
| 把 `2^(|A||B|)` 算成 `2^(|A|+|B|)` | 指数是**乘积** `|A| · |B|` |
