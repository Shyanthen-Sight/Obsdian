# 学生信息统计案例：补一个 xAxis 修好柱形图

> [!info] 原题
> 蓝桥云课 · 学生信息统计（题目 1843）
> [题目链接](https://www.lanqiao.cn/problems/1843/learning/?page=1&first_category_id=2&tags=HTML5&tag_relation=union)

> [!summary] 速记版
> ```js
> xAxis: {
> 
>   data: ['张三', '李四', '王五', '贺八', '杨七', '陈九']
> },
> yAxis: {
>   type: 'value'
> },
> series: [{ name: '成绩', type: 'bar', data: [55, 90, 65, 70, 80, 63] }]
> ```
> - 报错原因：ECharts 要求 **x 轴、y 轴即使没有数据也必须定义**，题目把 `xAxis` 整个删掉了，所以 `setOption` 时找不到 x 轴。
> - 修复：补一个 `xAxis` 对象，把学生姓名放进 `xAxis.data`（类目轴）。
> - `yAxis.type: 'value'` 是数值轴，成绩作为柱子高度。
> - 方向不能反：姓名在 x 轴、数值在 y 轴才是题目要求的竖向柱形图。
> - 考试只允许改 `index.html` 的 JS 部分，文件结构（`echarts.js` + `index.html`）不能动。

## 考察内容

- **ECharts 直角坐标系结构**：`xAxis` 与 `yAxis` 必须成对声明，缺一个 `setOption` 就会报错。
- **类目轴与数值轴**：`xAxis.data` 放姓名（自动成为 `category`），`yAxis.type: 'value'` 承载数值。
- **柱形图配置**：`series.type: 'bar'`，`series.data` 的长度要与类目轴对齐。
- **`setOption` 配置项**：`title`、`tooltip`、`legend`、`xAxis`、`yAxis`、`series` 各自的职责。
- **图表方向判断**：姓名在 x 轴、数值在 y 轴才是竖向柱形图，写反会变成横向条形图。
- **考试约束**：只改 `index.html` 中的 JS，不能动文件结构和已有资源。

## 一、题目要求

> 用 ECharts 开发一个学生成绩统计的柱形图。
>
> 1. 按注释提示修复项目报错；
> 2. 让统计图表按照正确的方向显示（提示：x 轴的写法请参照 y 轴）；
> 3. 只修改 `index.html` 中的 JS 部分。

项目初始结构：

```text
├── echarts.js
└── index.html
```

题目给的 `option` 里已经有 `title`、`tooltip`、`legend`、`yAxis`、`series`，**唯独缺了 x 轴**，控制台因此报错。

## 二、错误原因

==ECharts 的直角坐标系由 x 轴和 y 轴共同构成==。`series` 里每个数据点都要同时映射到两条轴上，所以：

- 没有 `xAxis` → `setOption` 直接抛错，整个图表渲染失败；
- ==即使 x 轴没有数据，也必须先声明 `xAxis: {}`，否则同样报错==。

题目把学生姓名和成绩分别给了两处：`legend.data` 里是系列名「成绩」，`series.data` 里是成绩数值，但**姓名数组没有地方放**。姓名就应该放在 `xAxis.data` 里。

## 三、完整代码

补完后的 `index.html`：

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta http-equiv="X-UA-Compatible" content="IE=edge" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>echarts 柱形图</title>
    <script src="./echarts.js"></script>
  </head>

  <body>
    <div id="main" style="width: 600px; height: 400px;"></div>

    <script type="text/javascript">
      // 基于准备好的 dom，初始化 echarts 实例
      var myChart = echarts.init(document.getElementById("main"));

      // 指定图表的配置项和数据
      var option = {
        title: {
          text: "学生成绩统计",
        },
        tooltip: {},
        legend: {
          data: ["成绩"],
        },
        // x 轴：类目轴，放学生姓名
        xAxis: {
          data: ["张三", "李四", "王五", "贺八", "杨七", "陈九"],
        },
        // y 轴：数值轴，放成绩
        yAxis: {
          type: "value",
        },
        series: [
          {
            name: "成绩",
            type: "bar",
            data: [55, 90, 65, 70, 80, 63],
          },
        ],
      };

      // 使用刚指定的配置项和数据显示图表
      myChart.setOption(option);
    </script>
  </body>
</html>
```

## 四、关键点

### 1. 只要写 `data`，x 轴自动成为类目轴

```js
xAxis: {
  data: ["张三", "李四", "王五", "贺八", "杨七", "陈九"],
}
```

ECharts 检测到 `xAxis.data` 后会自动把类型当作 `category`（类目轴），所以不用再写 `type: 'category'`。写成下面这样也等价：

```js
xAxis: {
  type: "category",
  data: ["张三", "李四", "王五", "贺八", "杨七", "陈九"],
}
```

> [!warning] 最常见的报错：`type` 拼错
> ECharts 的轴类型只认固定几个值：`category` / `value` / `time` / `log`。
> 写成 `type: 'categtory'`（多一个 `t`）时，代码本身没有语法错误，但 `setOption` 会直接抛错、图表白屏（控制台类似 `Unsupported axis type`）。
> 所以更稳的写法是**干脆不写 `type`，只给 `data`**，让 ECharts 自己判断为类目轴，少一个拼错的机会。

### 2. 两条轴的分工

| 轴 | 类型 | 放的 data | 作用 |
| --- | --- | --- | --- |
| `xAxis` | 类目轴（`category`） | 学生姓名 | 决定柱子沿横向排列的位置 |
| `yAxis` | 数值轴（`value`） | 不写 data | 按 `series.data` 的数值自动算刻度 |

`yAxis` 不需要 `data`，数值来自 `series`；`xAxis` 的 `data` 只提供类目名，长度要和 `series.data` 对齐（这里都是 6 个）。

### 3. 方向反了会怎样

如果写成：

```js
xAxis: { type: "value" },
yAxis: { data: ["张三", "李四", "王五", "贺八", "杨七", "陈九"] }
```

图不会报错，但会变成**横向条形图**——姓名在纵轴、柱子从左往右长。题目截图要求姓名在横轴、柱子从下往上长，所以必须按「姓名 → x 轴，数值 → y 轴」来写。
