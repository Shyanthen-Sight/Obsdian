# Java 创建对象

> 关联笔记：[[类的声明]]、[[构造方法]]、[[使用对象]]、[[对象的引用和实体]]

## 一句话解释

==**创建对象就是用 `new` 运算符，配合构造方法，在堆内存中开辟出一块该类的实体，并把它的地址交给一个引用变量。**==

类只是画好的图纸（模板），`new` 出来的对象才是能真正干活的实例。前面 [[类的声明]] 只是把模板画出来，这里才让模板变成了实物。

---

## 一、最完整的语法结构

```java
类名 引用变量名 = new 构造方法(参数列表);
```

```java
Dog dog = new Dog("旺财");
//  ↑(1)      ↑(2)        ↑(3)
```

这一行其实压缩了两件事，拆开写就是：

```java
Dog dog;               // ① 声明一个 Dog 类型的引用变量
dog = new Dog("旺财");  // ② 创建对象，并让引用指向它
```

两步能合并，也能分开写。很多初学者以为 `Dog dog = new Dog();` 是「一个动作」，其实它是「声明 + 创建 + 赋值」三件事。

> [!note] 两个名字
> `new Dog("旺财")` 得到的是==对象实体==，`dog` 是==对象的引用==。这两者的关系单独记在 [[对象的引用和实体]] 里。

---

## 二、`new` 到底做了什么

执行 `new Dog("旺财")` 时，JVM 按下面的顺序干活：

1. **分配内存**：在**堆**中划出一块空间，大小由类的成员变量决定。
2. **默认初始化**：给所有实例变量赋默认值——`0`、`0.0`、`false`、`null`。
3. **显式初始化**：执行成员变量定义处写的初值、以及构造代码块。
4. **调用构造方法**：执行构造方法体里的代码（这一步才用到你传进去的参数）。
5. **返回地址**：把这块实体的内存地址返回，交给左边的引用变量。

所以构造方法体内看到的字段，==已经是默认值 + 显式初值都赋过之后的状态==，这和 [[构造方法]] 第八节的初始化顺序是同一件事。

```java
public class Dog {
    private String name = "无名氏";   // ③ 显式初始化先执行
    private int age;                  // ② 默认值 0

    public Dog(String name) {         // ④ 构造方法最后执行
        this.name = name;
    }
}
```

## 三、几种创建方式对照

| 写法                                     | 含义                              | 使用场景            |
| -------------------------------------- | ------------------------------- | --------------- |
| `Dog d = new Dog();`                   | 无参构造，最基本的写法                     | 最常见             |
| `Dog d = new Dog("旺财");`               | 带参构造，创建时顺便初始化                   | 字段需要初始值         |
| `new Dog().bark();`                    | ==匿名对象==，用一次就丢                  | 只调用一次方法，不需要再引用它 |
| `Dog[] ds = new Dog[3];`               | 对象数组，==只创建了数组本身，三个格子都是 `null`== | 批量存放同类对象        |
| `Dog[] ds = { new Dog(), new Dog() };` | 数组字面量，元素是真的对象                   | 已知要放几个          |

```java
// 匿名对象：创建后马上调用方法，之后再也找不到这个实体
new Dog("旺财").bark();
```

> [!warning] 对象数组的坑
> `new Dog[3]` 只创建了「三个能装 Dog 的格子」，==并没有创建任何 Dog 对象==。要在使用前逐个 `new`：
> ```java
> Dog[] ds = new Dog[3];
> for (int i = 0; i < ds.length; i++) {
>     ds[i] = new Dog();      // 每个格子都要单独 new
> }
> ```
> 少了这一步，`ds[0].bark()` 会抛出 `NullPointerException`。

## 四、同一个类可以创建任意多个对象

每 `new` 一次，就多一个独立的实体，它们的**实例变量各自一份、互不干扰**；而 `static` 修饰的静态变量是整类共享的。

```java
public class Dog {
    private String name;
    private static int count = 0;      // 静态变量：所有对象共享

    public Dog(String name) {
        this.name = name;
        count++;                        // 每创建一个对象就加一
    }
}
```

```java
Dog a = new Dog("旺财");
Dog b = new Dog("大黄");
// a.name 是"旺财"，b.name 是"大黄"，互不影响
// 而 Dog.count 是 2
```

静态变量与实例变量的区别详见 [[成员变量]]。

## 五、创建对象时的常见错误

| 错误写法 | 结果 | 原因 |
| --- | --- | --- |
| `Dog d;` 之后就 `d.bark()` | 编译错误 | 引用变量还没指向任何对象，==未初始化不能使用== |
| `Dog d = Dog();` | 编译错误 | 漏了 `new`，Java 里创建对象必须写 `new` |
| `new Dog("旺财", 3)` 但只有单参构造 | 编译错误 | 参数列表与所有构造方法都对不上 |
| `Dog d = null; d.bark();` | 运行期 `NullPointerException` | 引用不指向任何实体，却去调用它的成员 |
| `Dog[] ds = new Dog[3]; ds[0].bark();` | 运行期 `NullPointerException` | 数组格子还是 `null`，没 `new` 过 |

- **编译错误**发生在你写错语法或参数时，IDE 会直接标红；
- **`NullPointerException`（NPE）**是运行期才爆的，说明手里的引用没有指向真正的实体，排查方法见 [[对象的引用和实体]]。

## 六、注意事项

1. **创建对象必须用 `new`**，Java 里没有「直接在栈上构造对象」的写法（这点与 C++ 不同）。
2. **`new` 后面跟的一定是构造方法**，参数列表要和某个构造方法对得上（可以是编译器默认生成的无参那个，见 [[构造方法]]）。
3. **数组创建 ≠ 对象创建**，`new Dog[3]` 里的元素默认是 `null`。
4. **创建对象会在堆里占内存**，创建前先想清楚生命周期，避免无意义地反复 `new`。
5. **`new` 出来的对象一定带着默认值**，不会像局部变量那样「未初始化」。
6. **每次 `new` 都是一个新实体**，即使参数完全一样，也是两个不同的对象（`==` 比较为 `false`）。

---

## 七、一句话总结

> ==**`类名 变量 = new 构造方法(参数);` —— `new` 负责在堆里造实体，构造方法负责初始化，`=` 把实体的地址交给引用变量。**==
