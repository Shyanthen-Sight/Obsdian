# 和手机相处的时光：把 x/y 轴类型换回来

> [!info] 原题
> 蓝桥云课 · 和手机相处的时光（题目 2450）
> [题目链接](https://www.lanqiao.cn/problems/2450/learning/?page=1&first_category_id=2&tags=%E5%BC%82%E6%AD%A5,ECharts&tag_relation=union)

> [!summary] 速记版
> ```js
> xAxis: {
>   type: 'category',
>   data: ['周一', '周二', '周三', '周四', '周五', '周六', '周日']
> },
> yAxis: {
>   type: 'value'
> },
> series: [{ data: [2.5, 2, 2.6, 3.2, 4, 6, 5], type: 'line' }]
> ```
> - 原代码把两条轴的 `type` 写反了：`xAxis.type` 是 `'value'`，`yAxis.type` 是 `'category'`。
> - 星期是**类别**，只能放在 `category` 轴；时长是**数值**，必须放在 `value` 轴。
> - `value` 轴不认 `data`，所以周一～周日会整组失效，坐标轴显示错乱。
> - 只改 `option`，`js/echarts.js`、文件结构和配置项以外的代码都不能动。

## 考察内容

- **坐标轴类型**：`category`（类目轴）与 `value`（数值轴）的适用场景。
- **类目轴的 `data`**：`xAxis.data` 只对 `category` 轴生效，类型写错时这组标签会被忽略。
- **数值轴刻度**：`value` 轴不需要 `data`，会根据 `series.data` 自动计算范围与刻度。
- **折线图配置**：`series.type: 'line'`，`series.data` 与类目轴一一对应。
- **`option` 结构**：`title`、`xAxis`、`yAxis`、`series` 各自的职责。
- **考试约束**：只能改 ECharts 配置项，不能动 `js/echarts.js` 和项目结构。
- **关于标签里的「异步」**：题目所在学习路径带「异步 / ECharts」标签，但这道题的代码没有异步请求，本质仍是坐标轴类型修复。

## 二、错误原因

原代码把两条轴的类型写反了：

```js
/* 原代码（错误） */
xAxis: {
  type: "value",                                    // ❌ 星期是类别，却用了数值轴
  data: ["周一", "周二", "周三", "周四", "周五", "周六", "周日"],
},
yAxis: {
  type: "category",                                 // ❌ 时长是数值，却用了类目轴
},
series: [
  {
    data: [2.5, 2, 2.6, 3.2, 4, 6, 5],
    type: "line",
  },
],
```

- ==`xAxis.type: 'value'` 是数值轴，不会把 `data` 当成类目标签==，所以「周一～周日」这组数据等于白写；
- `yAxis.type: 'category'` 是类目轴，却拿去承载 2.5、2、2.6 这些连续数值，刻度无法按数值大小排布；
- 两条轴的分工一错，折线的横纵坐标就整体错位，页面显示的坐标轴自然不正确。

修复只需要互换两处 `type`：

```js
xAxis: { type: "category", data: [/* 周一～周日 */] },
yAxis: { type: "value" },
```

## 四、关键点

### 1. 两种轴的分工

| 轴类型 | 用途 | 需要 `data` 吗 | 典型数据 |
| --- | --- | --- | --- |
| `category`（类目轴） | 离散的类别，如星期、姓名、城市 | 需要，标签写在 `axis.data` | `["周一", "周二", …]` |
| `value`（数值轴） | 连续数值，自动算刻度 | 不需要，数值来自 `series.data` | `[2.5, 2, 2.6, …]` |

判断口诀：**谁是「名字」谁上 `category`，谁是「数字」谁上 `value`**。本题里星期是名字、时长是数字，所以 x 轴 `category`、y 轴 `value`。

### 2. 为什么 `value` 轴上的 `data` 不生效

`axis.data` 是**类目轴专属**的配置。把 `data` 写在 `type: 'value'` 的轴上时，ECharts 会忽略它，按数值范围自己生成刻度。所以原代码看起来「数据都写了」，实际星期标签一个都没显示出来。

### 3. 折线图只需要 `type: 'line'`

```js
series: [{ data: [2.5, 2, 2.6, 3.2, 4, 6, 5], type: "line" }]
```

`type: 'line'` 把数据点按 x 轴顺序连成折线。`series.data` 的长度要和 `xAxis.data` 对齐（这里都是 7 个），否则多出的点没有类目可对应。

### 4. 修改范围

- 只能改 `var option = {}` 里的内容；
- `echarts.init`、`setOption`、`<script>` 引入、`#main` 容器都不能动；
- 不要改文件名、目录层级，否则判题脚本找不到文件直接 0 分。
