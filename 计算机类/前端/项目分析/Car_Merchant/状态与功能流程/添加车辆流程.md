# 添加车辆流程

> [!abstract] 一句话
> 添加车辆是一条标准的 ==props 下、emit 上== 链路：父组件把 `isAddModalOpen` 传给弹窗控制显隐，弹窗用 `v-model` 收集表单并在校验后 `emit('submit', 数据)`，父组件生成 `id`、`cars.push` 并弹出成功提示。

---

## 一、添加车辆的完整通信流程

### 1.1 父组件打开弹窗

左侧添加按钮：

```vue
<button
  type="button"
  title="Add a car"
  @click="addCar"
>
```

执行：

```ts
const addCar = () => {
  isAddModalOpen.value = true;
};
```

然后父组件把状态传给弹窗：

```vue
<AddVehicleModal
  :visible="isAddModalOpen"
  @close="closeAddModal"
  @submit="submitNewCar"
/>
```

### 1.2 弹窗接收 `visible`

```ts
defineProps<{
  visible: boolean;
}>();
```

模板中：

```vue
<div v-if="visible" class="modal_backdrop">
```

当 `visible` 为 `true`，弹窗显示；为 `false`，弹窗不渲染。

### 1.3 表单使用 `v-model`

```vue
<input v-model="name" type="text" />
```

`v-model` 负责：

1. 把 `name` 显示到输入框。
2. 用户输入时自动更新 `name`。

数字输入使用：

```vue
<input v-model.number="dailyPrice" type="number" />
```

`.number` 会尝试将输入值转换为数字。

### 1.4 子组件提交表单

```ts
const submit = () => {
  const trimmedName = name.value.trim();

  if (
    !trimmedName ||
    dailyPrice.value < 0 ||
    mileage.value < 0 ||
    stock.value < 0
  ) {
    return;
  }

  emit('submit', {
    name: trimmedName,
    type: type.value,
    dailyPrice: dailyPrice.value,
    mileage: mileage.value,
    stock: stock.value,
    image: image.value,
  });

  close();
};
```

模板中：

```vue
<form @submit.prevent="submit">
```

`.prevent` 会阻止浏览器默认提交行为，防止页面刷新。

### 1.5 父组件创建新车辆

父组件监听：

```vue
@submit="submitNewCar"
```

执行：

```ts
const submitNewCar = (input: NewCarInput) => {
  const nextNumber =
    Math.max(
      0,
      ...cars.value.map(
        (car) => Number.parseInt(car.id.replace('CAR-', ''), 10) || 0,
      ),
    ) + 1;

  const newCar: Car = {
    id: `CAR-${String(nextNumber).padStart(3, '0')}`,
    fileName: 'new-car.png',
    ...input,
  };

  cars.value.push(newCar);
  selectedCarId.value = newCar.id;
  closeAddModal();
  showSuccessMessage(`Vehicle added successfully: ${newCar.name}`);
};
```

完整流程：

```text
点击添加
  ↓
Rent_page: isAddModalOpen = true
  ↓
AddVehicleModal 显示
  ↓
用户填写表单
  ↓
子组件 emit('submit', 表单数据)
  ↓
Rent_page 接收 NewCarInput
  ↓
父组件生成 id
  ↓
cars.push(newCar)
  ↓
VehicleGrid 自动显示新车辆
```
