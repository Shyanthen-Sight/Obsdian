# 第1章 判断题（共22题，满分100）

> 来源：学习通作业《第1章判断题》。题干为原文抄录；页面本身不含答案，解析按《数据库系统概论》（王珊、萨师煊）第1章绪论知识点给出。
> **错题**（3 题）：第 13、19、22 题 —— 标有 ❌。

---

## 1. 《数据库系统概论》课程中提到的数据库系统的结构分为单用户结构、主从式结构、分布式结构、客户-服务器结构以及浏览器-应用服务器/数据库服务器多层结构等，这表明数据库系统具有很高的灵活性和可扩展性。( )

**答案：对**

**解析：** 数据库系统的体系结构确实依次演进为单用户结构、主从式结构、分布式结构、客户-服务器结构以及浏览器-应用服务器/数据库服务器多层结构，结构多样、可按需选择，说明其灵活性高、可扩展性强。

---

## 2. 根据《数据库系统概论》课程内容，数据库管理员(DBA)的职责不包括设计和编写应用系统的程序模块。( )

**答案：对**

**解析：** DBA 的主要职责包括：决定数据库中的信息内容和结构、决定数据库的存储结构和存取策略、定义数据的安全性和完整性约束、监控数据库的使用和运行、数据库的改进与重组重构。**"设计和编写应用系统的程序模块"属于系统分析员和应用程序员的职责**，故"不包括"表述正确。

---

## 3. 在《数据库系统概论》课程中，数据库系统的结构分为单用户结构、主从式结构、分布式结构、客户-服务器结构以及浏览器-应用服务器/数据库服务器多层结构等。( )

**答案：对**

**解析：** 同第 1 题，为数据库系统体系结构的标准表述。

---

## 4. 《数据库系统概论》课程中提到的数据库管理系统的主要功能不包括数据定义功能。( )

**答案：错**

**解析：** DBMS 的主要功能是：**数据定义、数据组织/存储和管理、数据操纵、数据库的事务管理和运行管理、数据库的建立和维护**。**数据定义（DDL）正是其核心功能之一**，故"不包括"错误。

> ⚠ **易错点：** 与第 9 题对照记忆 —— DBMS 的功能里**有**数据定义，**没有**硬件维护。

---

## 5. 在《数据库系统概论》课程中，数据库的二级映像功能包括外模式/模式映像和模式/内模式映像，它们保证了数据的逻辑独立性和物理独立性。( )

**答案：对**

**解析：** **外模式/模式映像**保证数据的**逻辑独立性**；**模式/内模式映像**保证数据的**物理独立性**。

---

## 6. 数据库系统的数据操纵语言(DML)允许执行的操作包括查询、插入、删除和修改。( )

**答案：对**

**解析：** DML 用于对**数据本身**的操纵，包括**查询、插入、删除、修改**；"数据定义"属于 DDL。

---

## 7. 在《数据库系统概论》课程中，数据库系统的组成包括数据库、数据库管理系统、应用程序和数据库管理员。( )

**答案：对**

**解析：** 数据库系统由**数据库、数据库管理系统（及其开发工具）、应用程序、数据库管理员**构成，运行于相应的硬件平台之上、由软件系统支撑。

---

## 8. 根据《数据库系统概论》课程内容，数据库技术是信息系统的核心和基础，它的出现极大地促进了计算机应用向各行各业的渗透。( )

**答案：对**

**解析：** 数据库技术是计算机科学技术中发展最快、应用最广的领域之一，已成为信息系统的核心技术和重要基础。

---

## 9. 《数据库系统概论》课程中提到的数据库管理系统的主要功能不包括硬件维护功能。( )

**答案：对**

**解析：** 硬件维护属于**操作系统/硬件平台**层面的工作，**不属于 DBMS 的功能**，故"不包括"表述正确。

---

## 10. 在《数据库系统概论》课程中，数据库系统阶段的背景包括大规模数据管理、大容量磁盘、磁盘阵列和数据库管理系统。( )

**答案：对**

**解析：** 数据库系统阶段产生的背景是**大规模数据管理的需要**；硬件上出现了**大容量磁盘、磁盘阵列**，软件上出现了**数据库管理系统**。

---

## 11. 在《数据库系统概论》课程中，数据模型的组成要素包括数据结构、数据操作和数据的完整性约束条件。( )

**答案：对**

**解析：** 数据模型三要素 = **数据结构 + 数据操作 + 数据的完整性约束条件**。（应用层次上分为概念模型、逻辑模型、物理模型。）

---

## 12. 在《数据库系统概论》课程中，数据库管理员的职责包括决定数据库中的信息内容和结构、监控数据库的使用和运行以及数据库的改进和重组。( )

**答案：对**

**解析：** 均为 DBA 的主要职责（另含存储结构与存取策略、安全性与完整性约束的定义）。

---

## ❌ 13. 根据《数据库系统概论》课程内容，数据库系统的特点之一是数据由操作系统统一管理和控制。( ) #错题

**答案：错**

**解析：** 数据库系统阶段的特点是数据由**数据库管理系统（DBMS）**统一管理和控制，而不是由操作系统。操作系统只管文件级存取，不管数据的整体结构、共享与完整性。

> 🔁 **易错点：** 记住主语是 **DBMS**。"操作系统级管理"是**文件系统阶段**的做法；考试就爱在主语上做文章。

## 14. 数据库系统阶段的特点是数据由数据库管理系统统一管理和控制，数据结构化，数据的共享性高、冗余度低且易扩充，以及数据独立性高。( )

**答案：对**

**解析：** 与教材对数据库系统阶段特点的表述一致。

---

## 15. 在《数据库系统概论》课程中，数据模型仅包括概念模型，不包括逻辑模型和物理模型。( )

**答案：错**

**解析：** 数据模型按应用层次分为**概念模型、逻辑模型和物理模型**三类（如 E-R 模型属概念模型，关系模型属逻辑模型），并非只有概念模型。

> ⚠ **易错点：** "仅包括……不包括……"式的绝对化表述，多数为**错**。概念模型（信息模型）只是三层之一。

## ❌ 19. 在《数据库系统概论》课程中，数据库系统的特点之一是数据由用户统一管理和控制。( ) #错题

**答案：错**

**解析：** 正确表述是数据由**数据库管理系统（DBMS）**统一管理和控制，而不是"由用户"。**由用户各自管理恰恰是文件系统阶段的特征**。

> 🔁 **易错点：** 与第 13 题是姊妹题，只换了主语（操作系统 / 用户）。**唯有 DBMS 才是正确主语**，遇到"操作系统/用户"直接判错。

## 20. 在《数据库系统概论》课程中，数据库系统的三级模式结构包括概念模式、外模式和内模式。( )

**答案：对**

**解析：** 三级模式为**模式（概念模式/逻辑模式）、外模式（子模式/用户模式）、内模式（存储模式）**。

## ❌ 22. 根据《数据库系统概论》课程内容，数据库系统的三级模式结构包括概念模式、外模式和内模式，其中概念模式是数据库用户的数据视图。( ) #错题

**答案：错**

**解析：** 三级模式的**组成部分**没错，错在后半句。**概念模式（模式）是数据库中全体数据的逻辑结构描述，是所有用户的公共数据视图**；**外模式才是数据库用户（局部）的数据视图**。故整句为**错**。

> 🔁 **易错点：** 一半对、一半错 → 整句判**错**。**公共视图 = 模式；用户视图 = 外模式**，别记反。
