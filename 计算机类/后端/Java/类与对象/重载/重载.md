# 重载（Overloading）

## 一句话解释

==**同一个类里，方法名相同，但参数列表不同。**==

编译器根据调用时传入的参数，自动判断该调用哪个方法。

---

## 三个条件

1. **方法名必须相同**
2. **参数列表不同**（个数、类型、顺序至少有一个不同）
3. **返回类型不能作为区分依据**

---

## 示例

```java
class Calculator {
    // 两个 int
    int add(int a, int b) {
        return a + b;
    }

    // 三个 int —— 参数个数不同
    int add(int a, int b, int c) {
        return a + b + c;
    }

    // 两个 double —— 参数类型不同
    double add(double a, double b) {
        return a + b;
    }
}
```

调用：

```java
new Calculator().add(1, 2);        // 走第一个
new Calculator().add(1, 2, 3);     // 走第二个
new Calculator().add(1.0, 2.0);    // 走第三个
```

---

## 实际意义

- 不用给功能相近的方法起不同名字。
- 让 API 更直观，例如 `System.out.println()` 可以打印字符串、整数、对象等，本质就是重载。

---

## 注意

只有返回类型不同，不算重载，编译会报错：

```java
int foo(int a) { return a; }
double foo(int a) { return a; }  // 错误！参数列表相同
```
