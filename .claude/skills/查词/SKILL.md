# 查词技能

## 目标笔记
- 查词结果统一写入 `英语/翻译功能.md` 的「📖 词条库」区域，**按编号顺序追加**，不覆盖已有内容。
- 待查词来源（按优先级）：
  1. `/查词` 命令后直接跟随的词（如 `/查词 serendipity`）
  2. 笔记「🔍 查词输入区」中用户写入的词（每行一个或多个）
  3. 对话中用户提及的词

## 执行流程
1. 读取 `英语/翻译功能.md`，获取待查词列表和现有词条编号
2. 逐个查词：优先用我的知识；遇到生僻词、多义词拿不准或需要核实发音时，用 WebSearch/WebFetch 查权威词典（剑桥、有道、Merriam-Webster）
3. 每个词生成一个词条，追加到词条库，编号接续现有最大编号
4. 查过的词在输入区原词旁标记 ✅（保留原词，方便用户核对遗漏）
5. 完成后用一句话总结（如"共查了 3 个词，见词条 #4–#6"）

## 词条格式

```markdown
### 4. serendipity n.
- **音标**：/ˌserənˈdɪpəti/
- **词性**：n. 名词
- **释义**：意外发现珍宝的运气；机缘巧合（常用义在前，多义词全部列出，按常用度排序）
- **词族**：serendipitous adj. 偶然发现的 / serendipitously adv.
- **搭配**：by serendipity 机缘巧合；a stroke of serendipity 一个意外的发现
- **例句**：They met by pure serendipity. 他们纯属机缘巧合才相遇。
- **易混/注意**：近义词 luck/chance；注意与 coincidence（巧合，中性）区分
```

各字段规则：
- **音标**：英式音标（/.../ 格式），拿不准就查证
- **释义**：中文为主；必要时补充简明英英释义
- **词族**：词形变化、派生词（n./v./adj./adv. 变换）
- **搭配**：常用搭配 + 固定短语，各配一个中文
- **例句**：1–2 个精选例句，附中文翻译；优先选能体现常见用法的
- **易混/注意**：仅在有价值时写（近义词辨析、多义词陷阱、拼写易混），没必要的词条可省略此字段

## 风格要求
- 对齐用户已有笔记的写法（参考 `英语/WORD.md`：同义分组、中文释义、易混辨析），帮用户形成连贯的词汇库
- 词条之间用空行分隔；批量查词保持编号连续
- 不修改用户已有的词条和输入内容，只追加和打 ✅
