## 考察内容

- **双 Y 轴**：`yAxis` 配成数组，两个 `series` 用 `yAxisIndex` 各用一根轴。
- **轴名与位置**：`yAxis[i].name` 显示轴名称，`position: 'left' / 'right'` 决定轴在图表哪一侧。
- **类目轴**：`xAxis.data` 放时间字符串，ECharts 自动按类目轴处理。
- **异步编程**：`Promise`、`async / await`、`setTimeout` 模拟 1 秒延迟的接口。
- **对象 ↔ 数组**：`Object.keys()` 取键、`Object.values()` 取值、`Object.entries()` 取键值对。
- **数据类型**：`toFixed()` 返回字符串，图表数值建议 `Number()` 显式转换。
- **动态更新**：`setOption(option, true)` + `setInterval` / `clearInterval` 实现实时看板。
- **考试约束**：只允许改 `js/index.js`，文件结构、id、class 都不能动。

## 三、解题思路

### 1. 为什么需要双 Y 轴

模拟接口生成的数据量级差得很远：

| 数据 | 生成公式 | 大致范围 |
| --- | --- | --- |
| 销售额 | `randomNum * 500 + 900` | 900 ~ 1400 |
| 销量 | `randomNum * 50 + 80` | 80 ~ 130 |

如果共用一根 Y 轴，销量柱子只有销售额的十分之一高，几乎贴在地板上看不见。所以分两根轴各自定刻度：

```js
yAxis: [
    { type: 'value', name: '销售额', position: 'left' },
    { type: 'value', name: '销量', position: 'right' }
],
```

| `series` | `type` | `yAxisIndex` | 使用哪根轴 | 轴位置 |
| --- | --- | --- | --- | --- |
| 销售额 | `line`（折线） | `0` | `yAxis[0]` | 左 |
| 销量 | `bar`（柱形） | `1` | `yAxis[1]` | 右 |

- ==`yAxis` 是数组时，`yAxisIndex` 就是 series 选择轴的索引==；
- 若把 `yAxis` 写成单个对象，`series[1].yAxisIndex: 1` 会指向不存在的轴，图表渲染异常；
- 两根轴都默认在左侧，不写 `position` 会重叠在一起，所以必须一左一右。

### 2. 异步数据的结构

`Ajax()` 返回的 `respondBody` 长这样：

```js
{
  code: 200,
  msg: "success",
  data: {
    saleObj: { "10:00": "1234.56", "10:10": "1100.00", ... },
    countObj: { "10:00": "112.34", "10:10": "98.20", ... }
  }
}
```

几个关键点：

1. ==`saleObj` 是对象不是数组==：键是时间，值是金额；
2. 值是 `sale.toFixed(2)` 的结果，**类型是字符串**；
3. 每次 `Ajax()` 往同一个对象里 `Object.assign` 一个新时间点，键的顺序就是插入顺序（`"10:00"`、`"10:10"`…），所以 `Object.keys()` 天然按时间先后排列；
4. `setTimeout(..., 1000)` 说明这是**异步**接口，必须 `await` 拿到 `result` 再赋值。

### 3. 三行赋值的对应关系

```js
const { saleObj, countObj } = result.data;

charData.xAxis.data = Object.keys(saleObj);                     // 时间 → X 轴
charData.series[0].data = Object.values(saleObj).map(Number);   // 销售额 → 左 Y 轴
charData.series[1].data = Object.values(countObj).map(Number);  // 销量 → 右 Y 轴
```

- `Object.keys(saleObj)` 得到 `["10:00", "10:10", ...]`，给类目轴当标签；
- `Object.values(saleObj)` 得到 `["1234.56", ...]`，`map(Number)` 转成 `[1234.56, ...]`；
- 两条 series 的数据长度必须和 `xAxis.data` 一致，这里因为 `saleObj`、`countObj` 同步插入，长度天然相等；
- 用 `countObj` 的键当 X 轴也等价，但保持「时间来自同一个对象」更直观。

> [!tip] 不写 `map(Number)` 行不行？
> ECharts 通常能把数字字符串画出来，但工具提示、坐标轴刻度、`dataZoom` 等场景对字符串处理不一致。显式 `Number()` 成本极低，建议养成习惯。

### 4. `setOption` 的第二个参数

```js
myChart.setOption(charData, true);
```

`true`（`notMerge`）表示**不与旧配置合并，直接整体替换**。因为 `charData` 每次都是完整配置，且数据数组每次重写，用 `true` 可以避免旧数据残留。若不传，ECharts 会做合并，对于长度变化的数组可能出现残留点。

### 5. 实时刷新流程

```js
renderChart();                      // 首次：立刻拉一次数据
let times = 0;
let timer = setInterval(() => {     // 之后每 2 秒拉一次
    renderChart();
    ++times == 6 && clearInterval(timer);  // 第 6 次后停止
}, 2000);
```

时序大致是：

| 时刻 | 调用 | `index` | 新增键 |
| --- | --- | --- | --- |
| 0s | 首次 `renderChart()` | 0 → 1 | `10:00` |
| 2s | 定时器第 1 次 | 1 → 2 | `10:10` |
| 4s | 定时器第 2 次 | 2 → 3 | `10:20` |
| … | … | … | … |
| 12s | 定时器第 6 次 | 6 → 7 | 不新增（`index < 7` 不成立） |

所以最终图上有 6 个时间点（`10:00` ~ `10:50`），折线是销售额、柱子是销量，左右两根轴各自缩放。

## 四、完整代码

`js/index.js` 修复后（其余文件不动）：

```js
// 指定图表的配置项和数据
const charData = {
    title: {
        text: '云课课程销量和销售额看板',
        width: 100,
        height: 50,
        textStyle: {
            lineHeight: 50,
        },
        left: 'center',
    },
    grid: {
        top: 80,
    },
    tooltip: {
        show: true,
    },
    xAxis: {
        data: [],
    },
    // 双 Y 轴：销售额在左，销量在右
    yAxis: [
        {
            type: 'value',
            name: '销售额',
            position: 'left',
        },
        {
            type: 'value',
            name: '销量',
            position: 'right',
        }
    ],
    series: [
        {
            name: '销售额',
            type: 'line',
            data: [],
            yAxisIndex: 0,
            smooth: true
        },
        {
            name: '销量',
            type: 'bar',
            data: [],
            yAxisIndex: 1,
            smooth: true
        }
    ]
};

// 以下代码为模拟后端服务器返回数据
let sale = 0;
let count = 0;
// 销售额
const saleObj = {};
// 销量
const countObj = {};
let index = 0;
function Ajax() {
    return new Promise((resolve, reject) => {
        let randomNum = Math.random();
        const randomSum = () => (randomNum * 500 + 900);
        const randomCount = () => (randomNum * 50 + 80);
        let i = index++ * 10
        let key = `10:${i == 0 ? "00" : i}`;
        if (index < 7) {
            sale = randomSum();
            Object.assign(saleObj, { [key]: sale.toFixed(2) })
            count = randomCount();
            Object.assign(countObj, { [key]: count.toFixed(2) })
        }

        const respondBody = {
            "code": 200,
            "msg": "success",
            "data": {
                saleObj,
                countObj
            }
        };
        setTimeout(() => {
            resolve(respondBody);
        }, 1000)
    })
}

async function renderChart() {
    const result = await Ajax();
    document.querySelector("#result").innerText = JSON.stringify(result);
    const myChart = echarts.init(document.getElementById('main'));

    // 从响应对象中取出两个数据对象
    const { saleObj, countObj } = result.data;
    // X 轴：时间（对象的键）
    charData.xAxis.data = Object.keys(saleObj);
    // 左 Y 轴：销售额（对象的值，字符串转数字）
    charData.series[0].data = Object.values(saleObj).map(Number);
    // 右 Y 轴：销量
    charData.series[1].data = Object.values(countObj).map(Number);

    myChart.setOption(charData, true);
    document.querySelector("#data").innerText = JSON.stringify(charData);
}
renderChart();
let times = 0;
let timer = setInterval(() => {
    renderChart();
    ++times == 6 && clearInterval(timer);
}, 2000)
```

## 五、关键点与易错点

### 1. 双轴的三个要素

```js
yAxis: [轴0, 轴1]          // 必须是数组
series: [
  { ..., yAxisIndex: 0 },  // 系列用哪根轴
  { ..., yAxisIndex: 1 }
]
```

三者缺一不可：`yAxis` 写数组、两个 `name` 区分含义、`position` 一左一右。只写 `name` 不写 `position`，两根轴会叠在同一侧。

### 2. 别把「键」和「值」弄反

| 位置 | 取什么 | 方法 |
| --- | --- | --- |
| `xAxis.data` | 时间（对象的**键**） | `Object.keys(saleObj)` |
| `series[0].data` | 销售额（对象的**值**） | `Object.values(saleObj)` |
| `series[1].data` | 销量（对象的**值**） | `Object.values(countObj)` |

写成 `Object.values` 给 X 轴，横轴就变成一串金额；写成 `Object.keys` 给 series，柱子高度会变成 `NaN`。

### 3. `toFixed(2)` 返回的是字符串

```js
sale.toFixed(2)          // "1234.56" —— 字符串
Number("1234.56")        // 1234.56  —— 数字
```

`Object.values(saleObj)` 拿到的是字符串数组；`map(Number)` 是最省事的转换方式。

### 4. `echarts.init` 会被重复调用

题目给的 `renderChart` 每次都 `echarts.init(document.getElementById('main'))`，第二次起控制台会出现：

```text
There is a chart instance already initialized on the dom.
```

这不是错误：ECharts 发现容器已有实例时会直接返回旧实例，后面的 `setOption` 仍然生效，图表能正常刷新。这是题目原有代码，**不要改**，忽略警告即可。

### 5. `await` 之前不要碰数据

```js
const result = await Ajax();   // 必须先等
const { saleObj } = result.data; // 再取值
```

`Ajax()` 内部 `setTimeout` 1 秒后才 `resolve`，不 `await` 拿到的就是 `Promise`，`result.data` 是 `undefined`。
