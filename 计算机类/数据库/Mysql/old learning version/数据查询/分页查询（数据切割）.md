概念:
数据太多，展示不完，将其分割成一小段来显示
![[Pasted image 20260611233739.png]]

语法如下：
```sql
select 列，列，函数
from 表
[where condition]
[limit [位置偏移量]，行数]
```

位置偏移量：不写默认为0，说明**不偏移**
行数：返回记录行数

limit必须**放在语句最后**

![[Pasted image 20260611234118.png|367]]



截取工资最高的一个
```sql
SELECT * FROM employee ORDER BY salary DESC limit 1;
```
![[Pasted image 20260611234345.png]]

截取工资第二高的
```sql
SELECT * FROM employee ORDER BY salary DESC limit 1,1;
```

截取工资倒数第二高
```sql
SELECT * FROM employee ORDER BY salary ASC limit 1,1;
```
![[Pasted image 20260611234640.png|586]]

查工资最高的女性员工信息
```sql
SELECT * FROM employee WHERE gender='女' ORDER BY salary DESC LIMIT 1;
```

公式：
```sql
limit（page-1）*page,size
```

page是页数，size是每一页要显示的数据条数
