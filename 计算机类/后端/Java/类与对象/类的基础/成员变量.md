# Java 成员变量

> 关联笔记：[[继承]]、[[父类的构造方法与子类的关系]]

## 1. 什么是成员变量

**成员变量（Field / 字段）声明在类体中、方法之外，====用来描述对象或类自身的数据====。按是否被 `static` 修饰，分为两类：

| 类型            | 修饰符        | 归属       | 生命周期                   |
| ------------- | ---------- | -------- | ---------------------- |
| ==实例变量==      | 无 `static` | 每个对象各有一份 | ==随对象创建而创建，随对象被回收而消失== |
| ==静态变量（类变量）== | `static`   | 整个类共有一份  | ==类加载而存在，程序结束才释放==     |
>[!tip]
>注意成员变量分为实例变量和静态变量两类

```java
public class Employee {
    private static int count = 0;   // 静态变量：所有员工共享
    protected String name;          // 实例变量：每个对象独立
    protected double baseSalary;
}
```

## 2. 成员变量 vs 局部变量

| 维度   | 成员变量                                                 | 局部变量          |
| ---- | ---------------------------------------------------- | ------------- |
| 声明位置 | 类体中，方法外                                              | 方法内、形参、代码块内   |
| 存储位置 | 堆（实例变量）/ 方法区（静态变量）                                   | 栈             |
| 默认值  | 有默认值（0 / 0.0 / false / null）                         | 无默认值，必须先赋值再使用 |
| 修饰符  | 可用 `public`、`protected`、`private`、`static`、`final` 等 | 只能使用 `final`  |
| 作用范围 | 整个类                                                  | 从声明处到所在代码块结束  |

```java
public void test() {
    int x;              // 局部变量
    System.out.println(x); // 编译错误：可能尚未初始化
}
```

## 3. 继承中成员变量的访问规则

子类可以访问父类中非 `private` 的成员变量，访问时遵循**就近原则**：

1. 先在**子类**中查找该变量；
2. 找不到再到**父类**中查找；
3. 都没有则编译报错。

```java
class Parent {
    String name = "父类";
}

class Child extends Parent {
    String name = "子类";   // 与父类同名

    void print() {
        System.out.println(name);        // 子类
        System.out.println(this.name);   // 子类
        System.out.println(super.name);  // 父类
    }
}
```

## 4. 成员变量的隐藏（Variable Hiding）

当子类声明了与父类同名的成员变量时，父类的变量并没有被覆盖，而是被"隐藏"了。两个变量在内存中**同时存在**，只是通过子类对象直接访问时看到的是子类那一份。

```java
public class Demo {
    public static void main(String[] args) {
        Child c = new Child();
        System.out.println(c.name);              // 子类
        System.out.println(((Parent) c).name);   // 父类 —— 强转后访问到父类变量
    }
}
```

> 注意：这里的"隐藏"只发生在变量上，与[[继承]]中的**方法重写**是两回事。

## 5. 用 super 访问被隐藏的父类变量

`super.变量名` 可以显式指定访问父类的成员变量，常用于子类初始化时保留父类语义：

```java
class Employee {
    protected String name;

    public Employee(String name) {
        this.name = name;
    }
}

class Manager extends Employee {
    private String department;

    public Manager(String name, String department) {
        super(name);              // 交给父类初始化 name
        this.department = department;
    }

    public String getFullInfo() {
        return super.name + " - " + this.department;
    }
}
```

## 6. 关键区别：变量隐藏 vs 方法重写

这是继承部分最容易混淆的一点。核心结论是：

- 成员变量的访问在**编译期**决定，看的是**引用变量的声明类型**（静态绑定）；
- 方法的调用在**运行期**决定，看的是**对象的实际类型**（动态绑定 / 多态）。

```java
class Parent {
    String name = "Parent";
    String getName() { return "Parent"; }
}

class Child extends Parent {
    String name = "Child";
    @Override
    String getName() { return "Child"; }
}

public class Demo {
    public static void main(String[] args) {
        Parent p = new Child();       // 上转型对象
        System.out.println(p.name);    // Parent —— 看引用类型
        System.out.println(p.getName()); // Child —— 看对象实际类型
    }
}
```

| 维度 | 变量隐藏 | 方法重写 |
| --- | --- | --- |
| 绑定时机 | 编译期（静态绑定） | 运行期（动态绑定） |
| 决定因素 | 引用变量的声明类型 | 对象的实际类型 |
| 父子变量是否共存 | 共存，父类那份被隐藏 | 只有一份，运行时选择 |
| 是否有多态效果 | 无 | 有 |

> 结论：不要把多态的期望强加到成员变量上。想获得多态效果，应当通过方法（尤其是 `getter`）暴露字段，而不是直接访问字段。

## 7. 上转型对象访问变量的陷阱

```java
Employee e = new Manager("张三", "M001", 8000, 2000);
System.out.println(e.baseSalary);  // 访问的是 Employee 中声明的 baseSalary
// e.bonus;  // 编译错误：Employee 类型中没有 bonus
```

上转型对象的**成员变量**由声明类型决定，而**成员方法**才走子类重写后的实现。这也是面向抽象编程偏爱方法、回避直接暴露字段的原因之一（参见 [[面向抽象编程]]）。

## 8. private 成员变量能否被继承

- `private` 成员变量对子类不可见，子类无法直接访问；
- 但对象内存中**依然包含**父类那部分 `private` 字段，它仍然会被父类构造方法初始化；
- 子类想读写它，只能通过父类提供的 `getter / setter` 或 `protected` 方法。

```java
class Parent {
    private int age = 18;

    public int getAge() { return age; }
}

class Child extends Parent {
    void print() {
        // System.out.println(age);  // 编译错误
        System.out.println(getAge()); // 通过父类方法间接访问
    }
}
```

## 9. 静态成员变量与继承

`static` 成员变量属于类，子类可以通过继承直接访问，但它始终只有一份，存储在父类所属的类变量中：

```java
class Counter {
    static int count = 0;
}

class SubCounter extends Counter {
    void inc() { count++; }   // 修改的仍是 Counter.count
}
```

若子类**又声明了一个同名静态变量**，同样构成隐藏，且通过类名访问更清晰、不易出错：`SubCounter.count` 与 `Counter.count` 是两个不同的变量。

## 10. 最佳实践

- 字段一律 `private`，对外通过方法暴露：既能被继承体系安全使用，又能避免被外部随意修改。
- 子类不要随意声明与父类同名的字段：一旦同名就会隐藏父类字段，极易引发数据不一致的 Bug。
- 需要多态就用方法，不要指望字段：字段是静态绑定，不具备多态能力。
- 常量用 `static final`：命名约定为全大写加下划线，如 `MAX_SIZE`。
- 避免子类字段与父类字段语义重复：若确实需要扩展，考虑把公共部分上提到父类。

## 11. 常见面试题

| 问题 | 答案 |
| --- | --- |
| 子类可以定义与父类同名的成员变量吗？ | 可以，但父类变量被隐藏，两份变量同时存在于对象中 |
| 上转型对象访问成员变量看谁？ | 看引用变量的声明类型（编译期绑定） |
| 上转型对象调用成员方法看谁？ | 看对象的实际类型（运行期动态绑定） |
| `private` 成员变量会被子类继承吗？ | 不能直接访问，但对象中仍存在并由父类构造方法初始化 |
| 成员变量有默认值吗？ | 有，引用类型为 `null`，数值为 0，布尔为 `false` |

## 12. 总结

成员变量是描述对象状态的数据单元，实例变量每个对象一份，静态变量全类共享。在继承体系中，子类可访问父类非 `private` 的成员变量，遵循就近原则；同名变量会隐藏而非覆盖，两份同时存在，可用 `super.变量名` 访问父类版本。最关键的一点是：成员变量是编译期静态绑定，由引用类型决定；成员方法是运行期动态绑定，由对象实际类型决定。因此追求多态时应面向方法编程，而不是直接访问字段。
