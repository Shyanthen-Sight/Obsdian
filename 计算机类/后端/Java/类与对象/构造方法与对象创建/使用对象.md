# Java 使用对象

> 关联笔记：[[创建对象]]、[[java中的权限修饰符]]、[[成员变量]]、[[方法]]、[[对象的引用和实体]]

## 一句话解释

==**对象创建出来之后，用「引用变量 . 成员」的方式访问它的字段、调用它的方法。**==

引用变量就像遥控器，对象实体就像电视机——你按遥控器（`对象.方法()`），实际发生变化的却是电视机（堆里的对象）。

---

## 一、基本语法

```java
引用变量.成员变量          // 访问（读 / 写）字段
引用变量.方法名(参数列表)   // 调用方法
```

```java
Dog d = new Dog("旺财");    // 先创建对象
d.name = "大黄";            // 访问字段并赋值
d.bark();                   // 调用方法
int a = d.getAge();         // 调用有返回值的方法
```

那个点 `.` 叫**成员访问运算符**，意思是「去这个对象里找某个成员」。

---

## 二、访问成员变量

```java
public class Dog {
    public String name;      // public 才能被外部直接访问
    private int age;         // private 只能在类内部访问
}

Dog d = new Dog();
d.name = "旺财";             // 合法，name 是 public
// d.age = 3;                // 编译错误，age 是 private
```

==字段能不能被 `对象.字段` 直接访问，取决于它的权限修饰符==：

| 修饰符 | 外部能否 `d.字段` 访问 |
| --- | --- |
| `public` | 能，任何地方 |
| `protected` | 同包内 / 子类能 |
| 默认（不写） | 同包内能 |
| `private` | ==不能==，只能通过类内部提供的方法间接访问 |

这也是为什么实际开发中字段几乎都写成 `private`，再配上 `getter / setter` 方法对外暴露：

```java
public class Dog {
    private String name;

    public String getName() { return name; }      // 读
    public void setName(String name) { this.name = name; }  // 写
}

Dog d = new Dog();
d.setName("旺财");            // 通过方法访问私有字段
System.out.println(d.getName());
```

权限规则详见 [[java中的权限修饰符]]。

## 三、调用方法

调用时按参数列表去挑方法，挑中的那个才执行：

```java
public class Calculator {
    public int add(int a, int b) { return a + b; }
    public double add(double a, double b) { return a + b; }
}

Calculator c = new Calculator();
int x = c.add(1, 2);         // 走 int 版本，返回 3
double y = c.add(1.0, 2.0);  // 走 double 版本，返回 3.0
```

同名方法靠参数列表区分，这就是 [[重载]]。

- **有返回值的方法**：结果可以赋给变量、当参数继续传，也可以忽略不用。
- **返回 `void` 的方法**：只能单独作为一条语句调用。

```java
c.add(1, 2);            // 合法，但返回值被丢弃
// int z = c.bark();    // 若 bark() 返回 void，编译错误
```

## 四、静态成员用类名访问

被 `static` 修饰的成员属于**整个类**，不属于某个对象。规范写法是**用类名访问**：

```java
public class Dog {
    public static int count = 0;          // 静态变量
    public static void info() { }         // 静态方法
}

Dog.count = 10;          // 推荐：用类名访问
Dog.info();              // 推荐

Dog d = new Dog();
d.count = 10;            // 能编译，但不推荐
d.info();                // 能编译，但不推荐
```

> [!tip] 为什么不该用对象调静态成员
> 静态成员跟具体对象无关，用 `d.count` 会让人误以为它是这个对象独有的数据。IDE 也会给出警告。区分详见 [[static关键字]] 与 [[成员变量]]。

## 五、对象作为方法参数

对象可以当参数传进别的方法，方法里就能操作这个对象：

```java
public class Main {
    static void rename(Dog d, String newName) {
        d.setName(newName);          // 改的是传进来的那个对象
    }

    public static void main(String[] args) {
        Dog dog = new Dog();
        dog.setName("旺财");
        rename(dog, "大黄");
        System.out.println(dog.getName());   // 大黄
    }
}
```

> [!warning] 这里藏着一个大坑
> 方法里改字段能影响外部，但==让形参重新 `new` 一个对象就不会影响外部==。原因和「引用传递」有关，详见 [[对象的引用和实体]]。

## 六、对象数组的使用

数组里的元素是对象引用，访问时先取元素、再取成员：

```java
Dog[] dogs = new Dog[2];
dogs[0] = new Dog("旺财");
dogs[1] = new Dog("大黄");

dogs[0].bark();                       // 取元素 → 调用方法
System.out.println(dogs[1].getName());

for (Dog d : dogs) {                  // 增强 for 遍历
    d.bark();
}
```

创建对象数组时元素默认是 `null`，忘了逐个 `new` 就会 NPE，详见 [[创建对象]]。

## 七、常见错误

| 错误 | 结果 | 原因 |
| --- | --- | --- |
| 用 `private` 字段做 `d.age` | 编译错误 | 权限不够，应通过 getter / setter |
| 引用还没 `new` 就 `d.bark()` | 运行时 `NullPointerException` | 引用不指向任何实体 |
| `d.name == other.name` 判断内容是否相同 | 结果常常不符预期 | `==` 比的是地址不是内容，见 [[对象的引用和实体]] |
| 调方法时参数类型不匹配 | 编译错误 | 找不到能匹配的方法 |

---

## 八、注意事项

1. **访问成员统一用「`.`」**，`d.name`、`d.bark()`，不存在别的写法。
2. **能访问到什么，由权限修饰符决定**，不是由「有没有这个成员」决定。
3. **静态成员用类名访问**，别用对象名，可读性更好。
4. **每次调用方法，`this` 都指向当前这个对象**，方法里改的字段属于调用它的那个对象。
5. **对象的值比较用 `equals` 而不是 `==`**，除非你确认要比的是「是不是同一个对象」。
6. **对 `null` 引用做任何成员访问都会 NPE**，用之前先确认它已被 `new` 过。

---

## 九、一句话总结

> ==**`对象.成员` —— 字段用 `.` 读写、方法用 `.` 调用，能碰到什么由权限修饰符说了算；静态成员则改用「类名.成员」。**==
