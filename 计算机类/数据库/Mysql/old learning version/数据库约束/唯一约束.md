**在创建表的时添加唯一约束**
```sql
create table 表名(
字段名 数据类型 unique,
字段名 数据类型 unique key    #两者完全等价
);

create table 表名(
字段名 数据类型,
[constraint 约束名] unique key(字段名) 
);
```

**建表后修改**
```sql
alter table 表名 add constraint 约束名 unique(列名,列名...);
```

**删除**
```sql
#查看约束
select * from infomation_schema.table_constraints
where table_schema='库名'
and table_name='表名';

#删除约束
alter 表名 drop constraint 约束名;
```
