
基本语法：

```sql
select 分组列1，分组列2，聚合函数 from table 
[where condition]
[group by 分组列1 having 分组条件]
```

having是分组后的条件再次筛选，where是分组前；

having只能在group by后面出现，where随时可以出现；

having后面几乎全是聚合函数

举例：

```sql
SELECT gender,COUNT(*),AVG(salary)FROM employee GROUP BY gender 
HAVING AVG(salary>7000);
```

### WITH ROLLUP语法

```sql
SELECT 分组字段, 聚合函数(列)
FROM 表名
GROUP BY 分组字段 WITH ROLLUP;
```
`WITH ROLLUP` 属于 **GROUP BY 分组统计的扩展修饰符**，是 MySQL 分组聚合里的汇总工具。

作用：在分组结果末尾自动生成**小计、合计行**。

举例：

```sql
SELECT IFNULL(note,'总数量'),SUM(num) FROM book GROUP BY note WITH ROLLUP; 
```
