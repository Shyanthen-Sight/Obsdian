# 设计原则与改进方向

> [!abstract] 一句话
> 这个项目体现了四条常见的 Vue 设计原则：==状态放在真正拥有它的组件里、子组件不越权处理父级业务、UI 状态与业务数据分开、派生数据用 `computed`==；在此之上，还有几条把 demo 推向生产的方向（拆数据文件、上 Pinia、路由懒加载、资源 URL 生命周期、后端持久化）。

---

## 一、项目中几个重要的 Vue 设计原则

### 1.1 状态应该放在真正拥有它的组件中

车辆列表被多个子组件使用：

- `VehicleGrid` 需要读取
- `VehicleToolbar` 需要影响筛选
- `DeleteVehicleModal` 需要读取选中的车辆
- `AddVehicleModal` 需要提交新车辆

因此车辆状态放在共同父组件 `Rent_page.vue` 中最合适。参见 [[组件关系与父子通信]]。

### 1.2 子组件尽量不要直接处理父级业务

`VehicleGrid` 不负责真正删除车辆，它只发出选择事件。

`DeleteVehicleModal` 不负责修改车辆数组，它只负责验证并发出确认事件。

这样每个组件的职责更加清晰。

### 1.3 UI 状态和业务数据分开

例如：

```ts
const cars = ref<Car[]>(initialCars);
const isAddModalOpen = ref(false);
```

`cars` 是业务数据，`isAddModalOpen` 是界面状态。分开管理便于理解和维护。

### 1.4 派生数据使用 computed

不要手动在多个地方同步筛选结果：

```ts
const filteredCars = computed(() => ...)
```

只要源数据变化，计算属性会自动更新。

## 二、后续可以如何改进

### 2.1 将车辆初始数据单独拆出

目前车辆数据直接写在 `Rent_page.vue` 中：

```ts
const carData = [...]
```

可以新建：

```text
src/components/car/carData.ts
```

然后：

```ts
import { carData } from './car/carData';
```

这样页面组件只负责逻辑，车辆数据单独维护。

### 2.2 将车辆状态移动到 Pinia

如果多个页面都需要访问车辆列表，可以创建：

```text
src/stores/car.ts
```

示意：

```ts
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';

export const useCarStore = defineStore('car', () => {
  const cars = ref<Car[]>([]);

  const addCar = (car: Car) => {
    cars.value.push(car);
  };

  const removeCar = (id: string) => {
    cars.value = cars.value.filter((car) => car.id !== id);
  };

  return {
    cars,
    addCar,
    removeCar,
  };
});
```

页面中使用：

```ts
const carStore = useCarStore();
carStore.addCar(newCar);
```

### 2.3 添加路由懒加载

目前路由直接导入页面：

```ts
import Rent_page from '@/components/Rent_page.vue'
```

页面较多时，可以使用懒加载：

```ts
const Rent_page = () =>
  import('@/components/Rent_page.vue');
```

这样租车页面只会在真正访问时加载。

### 2.4 改善资源 URL 生命周期

添加车辆图片时使用：

```ts
URL.createObjectURL(file)
```

实际项目中删除图片或关闭页面时，可以调用：

```ts
URL.revokeObjectURL(imageUrl)
```

释放浏览器创建的临时 URL，避免长期运行时产生资源占用。

### 2.5 增加后端持久化

目前车辆数据保存在前端内存中：

```text
刷新页面后，新增车辆和删除操作会丢失
```

如果要做成真正的租车系统，需要连接后端 API 或数据库，例如：

```text
GET    /api/cars
POST   /api/cars
DELETE /api/cars/:id
```
