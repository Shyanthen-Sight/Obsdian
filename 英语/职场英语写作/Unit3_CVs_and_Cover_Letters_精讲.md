# Unit 3 CVs and Cover Letters 简历与求职信 —— 知识点精讲与分析

> 对应书中第 53–74 页。两个部分：个人简历 CV、求职信 Cover Letter。核心训练点：CV 五种写作原则、两种工作经历写法（job-based / skill-based）、profile 写作、断句修改、topic sentence 与 qualifiers。

---

## 一、单元定位

简历和求职信是"求职两件套"：CV 是客观的资质清单，求职信是说服性的自荐信。本单元教你用**事实和结构**说服招聘方，而不是空喊口号。

学完你应能：
- 为有经验者和应届生各写一份结构合理的 CV；
- 写好一段突出亮点的 Profile；
- 避免碎句（choppy sentences）；
- 写有 topic sentence、有支撑细节、用词准确的求职信。

---

## 二、PART 1 Curriculum Vitaes (CVs)（第 54–67 页）

### 1. CV 的标准结构
一份英文 CV 通常按以下顺序组织：

```
姓名 + 联系方式
→ Profile / Summary（个人概述）
→ Objective（求职目标）
→ Education Background（教育背景）
→ Work Experience（工作经历）
→ Relevant Skills（相关技能）
→ Awards & Achievements（奖项成绩）
→ References（证明人）
```

### 2. 五条写作原则
**Relevant（相关）/ Credible（可信）/ Positive（正面）/ Clear（清晰）/ Concise（简洁）**，且**控制在一页纸**。

### 3. 文化差异（重要）
- **英文 CV**：通常**不写**出生日期、国籍、性别、婚姻状况；
- **中文 CV**：通常需要这些信息。
写英文简历时不要把中式简历的习惯照搬过去。

### 4. 工作经历两种写法
这是本部分的核心决策点：

| 写法 | 组织方式 | 适合人群 |
|------|----------|----------|
| **Job-based pattern** | 时间倒序列岗位 | 有连续、相关工作经验的人 |
| **Skill-based pattern** | 按技能/活动归类（如销售/调研/翻译/组织） | 应届生或经验零碎者 |

教材范文：
- **Lee Geoff**（有经验者，job-based）应聘 senior sales manager；
- **Java Hying**（应届生，skill-based），Work Experience 分成 Promoting sales / Doing surveys / Translating & Interpreting / Organizing activities 四类。

### 5. Profile / Summary 怎么写
- 概括四个维度：**Personality（性格）/ Skill（技能）/ Experience（经历）/ Ability（能力）**；
- 只选雇主需要的亮点，不要面面俱到；
- 用**第三人称**叙述（第一人称像自夸）；
- 用"形容词 + 副词 + 具体信息"塑造形象。

### 6. 工作经历四模式
展开每段经历时，写清四类信息：
- **展开所获能力**：…which provided me with…
- **展开职责**：including… / responsible for…
- **展开目的**：to increase… / aiming to…
- **展开成效**：which expanded / enhanced…

即每条经历要写：main duties、results、skills gained、做事原因。

### 7. 语言点：Choppy sentences 碎句
CV 常用短语而非完整句，但要避免一堆碎句堆在一起。修改方法：
- 删除重叠信息和功能词；
- 用 **A. 介词 / B. 连词 / C. 形容词短语** 合并重组。

### 8. 表达工具
- **性格形容词**：energetic, dynamic, sociable, confident, optimistic, resilient, punctual, conscientious, determined…
- **能力表达**：with skills in managing customers / able to negotiate price / with cross-cultural sensitivity / with problem-solving ability / with teamwork spirit / with creativity and initiative。
- **教育背景**：GPA、IELTS、CET-4/6、National Computer Certificate；奖项 First Prize Scholarship、Top Graduate、Excellent Dissertation。
- **技能三结构**：
  - 形容词开头：Proficient in / Competent in / Fluent in / Skilled in
  - 介词开头：With sound knowledge of / With six-year hands-on experience
  - 名词开头：Experience in / Ability to / Accomplishment in / Skill in

### 9. 过程写作任务（Project）
以应届生身份写目标岗位的工作经历。Step 1 调查岗位 main duties 与 requirements；Step 2 用短语起草（Activities / Main duties / When / Where / Why / Result / Skills gained）；Step 3 用具体信息增强说服力；Step 4 按时间顺序、粗体、一页内、左对齐。

## 三、PART 2 Cover Letters 求职信（第 68–74 页）

### 1. 认知
求职信随 CV 附送，是对 CV 的**补充和说服**，简洁，通常不超过一页。

### 2. 四段式结构
1. **Introduction**：申请什么岗位、从哪看到的、自我介绍；
2. **Persuasive body paragraph 1**：正面特质 + 相关经历，带 topic sentence + supportive facts；
3. **Persuasive body paragraph 2**：另一组卖点，同样 topic sentence + supportive facts；
4. **Conclusion**：表达面试意愿、可面试时间、联系方式。

### 3. 核心技巧
- **Body paragraph = topic sentence + supportive facts**：每段先用一句主题句亮明观点，再用具体事实支撑。这和中文作文的"总分"逻辑一致，但英文求职信要求更严格。
- **Qualifiers（限定词）**：在名词前加程度词让表达准确、不夸张。要会区分程度：somewhat / very / definitely true 的差别。

### 4. Nouns × Qualifiers 对照（重点记忆）
| 名词 | 常用限定词 |
|------|-----------|
| company | pioneer / dynamic / leading |
| skill | strong / proven / outstanding |
| knowledge | solid / sound / in-depth |
| experience | hands-on / extensive / broad |
| role | challenging / rewarding |
| technology | leading / latest |
| background | diverse / academic |
| understanding | acute / strategic |
| computer | familiar / proficient |
| language | fluent / conversational / mastered |

### 5. 范文解析
Samuel Kramer（应届生）致 Wynun Marketing Group 人力资源总监 Mr Matthew Boudon 的求职信，应聘 export merchandiser。

### 6. 常见错误避坑
- ❌ 求职信重复 CV 全部内容（它是"说服"不是"复述"）；
- ❌ body paragraph 没有主题句，直接堆事实；
- ❌ 形容词不加限定词，通篇 "very good / very strong"；
- ❌ 用第一人称堆简历（Profile 用第三人称）。

### 7. 过程写作任务（Project）
应聘 ABC Company 的 executive secretary，写至少 150 词申请信。对照招聘广告：文件翻译、排版归档、会议差旅安排、客户电话；要求商科本科；具备行政写作/汇报演示/IT/电话沟通技能。按四段结构，用 topic sentence + supportive facts，用 qualifiers，不超过一页。

## 四、单元速记卡

| 要点 | 关键内容 |
|------|----------|
| CV 五原则 | Relevant / Credible / Positive / Clear / Concise，一页 |
| 文化差异 | 英文 CV 不写年龄/国籍/性别/婚姻 |
| 两种经历写法 | job-based（有经验者）vs skill-based（应届生） |
| Profile 四要素 | Personality / Skill / Experience / Ability，第三人称 |
| 工作经历四展开 | 能力 / 职责 / 目的 / 成效 |
| 碎句修改 | 删冗余，用介词/连词/形容词短语合并 |
| 求职信结构 | 引言 + 两段说服 + 结尾，四段 |
| 段落公式 | topic sentence + supportive facts |
| 限定词 | 在名词前表程度，让表达准确不夸张 |
