## 回顾：

| 术语            | 含义                                  | 例（公式 ∀x(P(x) → ∃yQ(x, y))）                   |
| :------------ | :---------------------------------- | :------------------------------------------- |
| **个体域 D**（论域） | 个体变元的==取值范围==                       | 如 D = 整数集                                    |
| **个体词**       | ==个体常元 a, b, c== ｜ ==个体变元 x, y, z== | x, y                                         |
| **谓词**        | 刻画个体性质或个体间关系的词，==P(x)、Q(x, y)==     | P, Q                                         |
| **量词**        | ∀（全称，"对所有"）｜ ∃（存在，"存在"）             | ∀x、∃y                                        |
| **指导变元**      | 紧跟在量词后的那个变元                         | ∀ 后是 **x**，∃ 后是 **y**                        |
| **辖域**（作用域）   | ==量词后面紧邻的**那个公式**==                 | ==∀x 的辖域是 P(x) → ∃yQ(x, y)；∃y 的辖域是 Q(x, y)== |
| **约束出现**      | 变元出现在**相应量词的辖域内**且与**指导变元同名**       | 后一个 x（在 ∃yQ(x,y) 中）                          |
| **自由出现**      | 不是约束出现的出现                           | 前一个 x（在 P(x) 中）                              |
| **闭式**        | ==不含自由出现的公式==。闭式在给定解释下**有确定的真值**    | ∀x∃yQ(x, y)                                  |

> **关键认知**：`∀x(P(x) → ∃yQ(x, y))` 里同一个 x 有两种身份——==P(x) 里的 x 是**自由出现**==，==Q(x, y) 里的 x 是**约束出现**==。这种"同名不同命"正是第五节换名规则要解决的对象。

**约定**：本页用 `A(x)` 表示**含变元 x** 的公式，用 `B` 表示**不含变元 x** 的公式（即 x 在 B 中无自由出现）。这是第三组等值式的前提条件，务必留意。

## 一、什么是一阶逻辑等值式

**定义**：设 A、B 为一阶逻辑公式，==若 A ↔ B 是<mark style="background: #FFB8EBA6;">永真式</mark>（逻辑有效式），则称 A 与 B 是<mark style="background: #FFB8EBA6;">等值</mark>**的，记作 A ⇔ B==，==称 A ⇔ B 为**等值式**==。

**与命题逻辑等值的两点区别**：

|          | 命题逻辑         | 一阶逻辑                          |
| :------- | :----------- | :---------------------------- |
| 判定标准     | A ↔ B 是**重言式** | A ↔ B 是**永真式**                   |
| "永真"的含义  | 所有赋值下为真      | ==**任意个体域、任意解释**下都为真==         |
| 判定的难度    | 真值表可机械判定     | 无一般机械方法（半可判定），靠等值演算             |
>[!warning]
>  一阶逻辑的"永真"要求**更强**：换个体域、换谓词的具体含义都必须成立。
> 所以判断一个等值式能否成立时，**必须先确认 B 中不含被移出的变元**——这是最常见的破功点。

**等值式的两类来源**：

1. **命题逻辑等值式的代换实例**——把 C1 的 16 组等值式中的命题变元换成一阶逻辑公式。
2. **量词特有等值式**——涉及 ∀、∃ 自身性质的等值式，命题逻辑里没有对应物。**这是本节的重点。**

**判定两式等值的三条路**：==等值演算法｜构造解释法｜证明法==

## 二、第一类：命题逻辑等值式的代换实例

**规则**：若 A ⇔ B 是命题逻辑中的等值式（C1 的 16 组 + 导出公式），把其中所有命题变元 p, q, r 一律用**一阶逻辑公式**替换，所得等值式仍然成立。

| 命题逻辑等值式                     | 一阶逻辑代换实例                                       |
| :-------------------------- | :--------------------------------------------- |
| ¬¬p ⇔ p                     | ¬¬P(x) ⇔ P(x)                                  |
| p → q ⇔ ¬p ∨ q              | ∀xP(x) → ∃yQ(y) ⇔ ¬∀xP(x) ∨ ∃yQ(y)             |
| ¬(p ∧ q) ⇔ ¬p ∨ ¬q          | ¬(∃xP(x) ∧ Q(y)) ⇔ ¬∃xP(x) ∨ ¬Q(y)             |
| p ∧ (q ∨ r) ⇔ (p∧q) ∨ (p∧r) | ∀xP(x) ∧ (Q ∧ R) ⇔ (∀xP(x) ∧ Q) ∨ (∀xP(x) ∧ R) |

**使用要点**：

- 代换时**整个量词公式被当作一个不可分割的"原子"**处理。即 `∀xP(x)` 的角色等同于一个命题变元 `p`。
- 因此这一条**不会**帮你把量词搬来搬去——量词内部的化简要靠第三、四节。

>[!tip]
> ⚠️ 反过来的坑：德摩根律对 `¬(A ∧ B)` 成立，但**不能**据此把 `¬∀x(P(x) ∧ Q(x))` 写成 `¬∀xP(x) ∧ ¬∀xQ(x)` 再"穿"进去。正确的是 `∃x¬(P(x) ∧ Q(x)) ⇔ ∃x(¬P(x) ∨ ¬Q(x))`——依 3.1 + 3.3。

## 三、第二类：量词等值式（四组，共 16 条）

这四组是本节全部运算能力的来源。**建议按序号背，考试时脑子里过一遍"否定／辖域／分配／顺序"四个抽屉。**

### 3.1 量词否定等值式（2 条）

==¬∀xA(x) ⇔ ∃x¬A(x)==
==¬∃xA(x) ⇔ ∀x¬A(x)==

**推广到多个量词**：否定从外往里穿透时，**每个量词都要翻转**，即

![[Pasted image 20260924115529.png]]

==其中 Q̄ᵢ 是与 Qᵢ **对偶**的量==

例：`¬∀x∃yP(x, y) ⇔ ∃x∀y¬P(x, y)`　**必须全部翻转
### 3.2 量词辖域收缩与扩张等值式（8 条）

**前提条件（全组统一）**：==B 中不含变元 x==（即 x 在 B 中无自由出现）。

| 类型  | 等值式                           | 量词搬运方向       |
| :-- | :---------------------------- | :----------- |
| ∨ 型 | ∀x(A(x) ∨ B) ⇔ ∀xA(x) ∨ B     | ∀ 原样移出       |
| ∨ 型 | ∃x(A(x) ∨ B) ⇔ ∃xA(x) ∨ B     | ∃ 原样移出       |
| ∧ 型 | ∀x(A(x) ∧ B) ⇔ ∀xA(x) ∧ B     | ∀ 原样移出       |
| ∧ 型 | ∃x(A(x) ∧ B) ⇔ ∃xA(x) ∧ B     | ∃ 原样移出       |
| → 型 | ∀x(A(x) → B) ⇔ ==∃x==A(x) → B | 前件：∀ → ∃（翻转） |
| → 型 | ∃x(A(x) → B) ⇔ ==∀x==A(x) → B | 前件：∃ → ∀（翻转） |
| → 型 | ∀x(B → A(x)) ⇔ B → ∀xA(x)     | 后件：∀ 原样      |
| → 型 | ∃x(B → A(x)) ⇔ B → ∃xA(x)     | 后件：∃ 原样      |

**记忆钩子**：

> **∨、∧ 型原样搬；→ 型"前件翻转、后件原样"。**

**验算（为什么前件要翻转）**：以 `∀x(A(x) → B) ⇔ ∃xA(x) → B` 为例

```
∀x(¬A(x) ∨ B)
⇔ ∀x¬A(x) ∨ B        （∨ 型辖域扩张，B 不含 x）
⇔ ¬∃xA(x) ∨ B        （量词否定等值式）
⇔ ∃xA(x) → B          （蕴含等值式）
```

**这八条的实际用途**：把量词"吸进来"或"推出去"，为的是让每个量词的辖域**互不重叠**，从而能合并到公式最前面——这正是第六节求前束范式的第 4 步。

### 3.3 量词分配等值式（成立 2 条，不成立 2 条）

**✅ 成立的（只有这两条！）**：

==∀x(A(x) ∧ B(x)) ⇔ ∀xA(x) ∧ ∀xB(x)==　　（**∀ 对 ∧ 分配**）
==∃x(A(x) ∨ B(x)) ⇔ ∃xA(x) ∨ ∃xB(x)==　　（**∃ 对 ∨ 分配**）

**❌ 不成立的（⚠️ 本节最大的陷阱）**：

| 错误写法 | 实际成立的只是单向蕴含 |
| :--- | :--- |
| ∀x(A(x) ∨ B(x)) ⇔ ∀xA(x) ∨ ∀xB(x)　**✘** | ∀xA(x) ∨ ∀xB(x) ⇒ ∀x(A(x) ∨ B(x)) |
| ∃x(A(x) ∧ B(x)) ⇔ ∃xA(x) ∧ ∃xB(x)　**✘** | ∃x(A(x) ∧ B(x)) ⇒ ∃xA(x) ∧ ∃xB(x) |

**反例（务必自己会举）**：取 D = {1, 2}，令 A(1)=1, A(2)=0, B(1)=0, B(2)=1。

- ∀x(A(x) ∨ B(x))：x=1 时 1∨0=1，x=2 时 0∨1=1 → **真**
- ∀xA(x) ∨ ∀xB(x)：∀xA(x)=0，∀xB(x)=0 → **假**
  ⇒ 说明 `∀x(A∨B) ⇐ ∀xA ∨ ∀xB` 的反向不成立 ✔
- ∃xA(x) ∧ ∃xB(x)：∃xA(x)=1，∃xB(x)=1 → **真**
- ∃x(A(x) ∧ B(x))：x=1 得 1∧0=0，x=2 得 0∧1=0 → **假**
  ⇒ 说明 `∃x(A∧B) ⇒ ∃xA ∧ ∃xB` 的反向不成立 ✔

**直观理解**：`∀x(A ∨ B)` 只要求"每个个体至少满足 A、B 之一"，允许"有的个体靠 A、有的靠 B"，因此**比 `∀xA ∨ ∀xB` 弱**；`∃x(A ∧ B)` 要求"有一个个体同时满足 A 和 B"，因此**比 `∃xA ∧ ∃xB` 强**。

### 3.4 量词顺序等值式

**可交换（同名量词）**：

- ==∀x∀yA(x, y) ⇔ ∀y∀xA(x, y)==
- ==∃x∃yA(x, y) ⇔ ∃y∃xA(x, y)==

**不可交换（异名量词）**——只能单向：

- ==∃y∀xA(x, y) ⇒ ∀x∃yA(x, y)==（反向**不成立**）

**反例**：D = 整数集，A(x, y) 表示 "x + y = 0"。

- ∀x∃yA(x, y)：对每个整数 x，取 y = −x 即可 → **真**
- ∃y∀xA(x, y)：不存在一个整数 y 使所有 x 都满足 x + y = 0 → **假**

**直观记忆**："**∀∃ 弱，∃∀ 强**"（∃∀ 蕴含 ∀∃，反之不成立）。口语化："存在一个人被所有人喜欢" ⇒ "每个人都有喜欢的人"，但反过来不对。

### 3.5 四组总表（速背版）

| 组别 | 条数 | 内容 | 口诀 |
| :--- | :-: | :--- | :--- |
| **3.1 量词否定** | 2 | ¬∀x ⇔ ∃x¬，¬∃x ⇔ ∀x¬ | 否定跨量词，∀∃ 互换 |
| **3.2 辖域收缩扩张** | 8 | ∨/∧ 型 4 条、→ 型 4 条 | ∨∧ 原样搬；→ 前件翻转、后件原样 |

## 四、⚠️ 只单向成立的重言蕴含式

这些式子是"看着像等值式、实际只单方向"的重灾区。**考试里写成 ⇔ 直接扣分。**

| 重言蕴含式 | 反例（D = {1, 2}，A(1)=1,A(2)=0, B(1)=0,B(2)=1） |
| :--- | :--- |
| ∀xA(x) ∨ ∀xB(x) ⇒ ∀x(A(x) ∨ B(x)) | 右边真、左边假，反向不成立 |
| ∃x(A(x) ∧ B(x)) ⇒ ∃xA(x) ∧ ∃xB(x) | 左边假、右边真，反向不成立 |
| ∃y∀xA(x, y) ⇒ ∀x∃yA(x, y) | 见 3.4 的 x + y = 0 例，反向不成立 |
| ∀x(A(x) → B(x)) ⇒ ∀xA(x) → ∀xB(x) | 反向：取 B 恒假、A 一半真，可破 |
| ∀x(A(x) → B(x)) ⇒ ∃xA(x) → ∃xB(x) | 同上，反向不成立 |

**还有一个"意外成立"的漂亮式子**（可当结论用）：

==∃x(A(x) → B(x)) ⇔ ∀xA(x) → ∃xB(x)==

推导：`∃x(¬A(x) ∨ B(x)) ⇔ ∃x¬A(x) ∨ ∃xB(x) ⇔ ¬∀xA(x) ∨ ∃xB(x) ⇔ ∀xA(x) → ∃xB(x)`。

> **总原则**：`∀` 往外"散"时会**变弱**（∀A ∨ ∀B ⇒ ∀(A∨B)），`∃` 往里"收"时会**变强**（∃(A∧B) ⇒ ∃A ∧ ∃B）。凡是"把两个量词拆开"的操作，先怀疑它是不是只单向。

## 五、三条规则：置换、换名、代替

这三条是等值演算的"合法性依据"，做前束范式时第 3 步全靠换名规则撑腰。

### 5.1 置换规则

**内容**：设 Φ(A) 是含公式 A 的公式，Φ(B) 是用 B 替换 Φ 中 **A 的所有出现**后所得的公式。==若 A ⇔ B，则 Φ(A) ⇔ Φ(B)==。

要点：与命题逻辑的"替换规则"同源——可以只替换**部分**出现，但被替换的那部分必须**整体**换成 B。

### 5.2 换名规则（约束变元改名）

**内容**：将公式中某量词辖域内的一个**约束出现**的个体变元，连同相应的**指导变元**，一起换成该辖域内**未曾出现过**的个体变元符号，其余部分不变，所得公式与原公式**等值**。

**三条操作要点**：

1. **指导变元和辖域内的同名约束出现必须同时改**——只改一处就不是换名了。
2. **新名不能在该量词辖域内出现过**（否则会造成"变元捕获"）。
3. 自由变元**不动**。

**例**：`∀x(P(x) ∧ ∃xQ(x))` → 把内层 ∃x 改名 → `∀x(P(x) ∧ ∃yQ(x, y))` ❌ 错，Q 只含一个变元，应写成 `∀x(P(x) ∧ ∃yQ(y))` ✔

### 5.3 代替规则（自由变元替代）

**内容**：将公式中某个**自由出现**的个体变元，用公式中**未曾出现过**的个体变元符号**处处**代替，所得公式与原公式**等值**。

**例**：`P(x) → ∀xQ(x)` 中，第一个 x 自由、第二个 x 约束。用 z 代替自由出现的 x → `P(z) → ∀xQ(x)` ✔（仍等值）

### 5.4 三者对比

| 规则 | 动谁 | 是否处处替换 | 新名的要求 |
| :--- | :--- | :--- | :--- |
| **置换规则** | 子公式 A | 可只替换部分出现 | 无（换成等值的 B） |
| **换名规则** | **约束**变元（指导变元 + 辖域内同名约束出现） | 该辖域内**全部**同名约束出现 | 辖域内**未出现过** |
| **代替规则** | **自由**变元 | 必须**处处**替换 | 公式中**未出现过** |

**一句话记**：==**换名动约束，代替动自由；两者的新名字都必须是"没见过的"。**==

**⚠️ 不改名会出错的经典反例**：`∀xF(x, y) ∨ ∃yG(x, y)`

这里有**自由 y** 和**约束 y** 同名。如果直接做辖域扩张，会得到 `∀x(F(x, y) ∨ ∃yG(x, y))` 甚至 `∀x∃y(F(x, y) ∨ G(x, y))`——后者**把 F 里的自由 y 也一并捕获了**，公式含义已经改变，是错的。

正确做法：先把 `∃yG(x, y)` 换名为 `∃zG(x, z)`，再扩张：

```
∀xF(x, y) ∨ ∃zG(x, z)
⇔ ∀x(F(x, y) ∨ ∃zG(x, z))
⇔ ∀x∃z(F(x, y) ∨ G(x, z))
```

> **这就是"求前束范式必须先换名"的根本原因**，也是本页最容易失分的一步。

## 六、前束范式

### 6.1 定义

**前束范式**：一个公式，如果它的**所有量词都出现在公式的最前面**，并且每个量词的**辖域都延伸到公式的末端**，则称之为前束范式。

标准形式：

==Q₁x₁ Q₂x₂ … Qₙxₙ M(x₁, x₂, …, xₙ)==

其中：

- Q₁x₁Q₂x₂…Qₙxₙ 称为**前束词**（量词前缀），其中 Qᵢ ∈ {∀, ∃}；
- M 称为**母式**（matrix），==母式中**不含量词**==，且一般要求只含 ¬、∧、∨（已消去 → 和 ↔）。

**判据（自检两问）**：① 量词是不是**全部**在最前面？② 每个量词的辖域是不是都**延伸到公式末端**？

### 6.2 存在性定理与"三不"性质

**定理**：==任何一阶逻辑公式都存在与它等值的前束范式。==

**但要注意"三不"**：

1. **不唯一**。例如 `∀xF(x) ∨ ∀yG(y) ⇔ ∀x(F(x) ∨ G(y)) ⇔ ∀x∀y(F(x) ∨ G(y))`，写法可以不同。
2. **不改变可满足性／永真性**（因为等值演算保持真值）。
3. **不是"主范式"那种唯一标准形**。所以考试里答案形式多样，只要**等值**且**符合前束结构**即可。

### 6.3 求前束范式的四步流程

| 步骤 | 做什么 | 用什么公式 |
| :-: | :--- | :--- |
| **第 1 步** | **消去 → 和 ↔** | A → B ⇔ ¬A ∨ B；A ↔ B ⇔ (A∧B) ∨ (¬A∧¬B) |
| **第 2 步** | **否定词内移**，把 ¬ 推到原子公式前 | 德摩根律 + **3.1 量词否定** + ¬¬A ⇔ A |
| **第 3 步** | **换名**，消除变元冲突 | **换名规则**（5.2） |
| **第 4 步** | **量词左移**，全部提到最前面 | **3.2 辖域收缩与扩张**（∨∧ 型 + → 型） |

**每一步的要点提示**：

- **第 1 步**：消 ↔ 时推荐用 `A ↔ B ⇔ (A∧B) ∨ (¬A∧¬B)`——它把 ¬ 直接"送到"A、B 门口，比用 `(A→B)∧(B→A)` 少一轮化简。若已在第 2 步处理的范围内，也可用 `¬(A↔B) ⇔ A ↔ ¬B` 把外面的 ¬ 消费掉。
- **第 2 步**：顺序是**先德摩根、再量词否定**，且要一直推到"¬ 只作用于原子公式（谓词符号）"为止。
- **第 3 步**：==**只要同一个变元被两个量词约束，或既被约束又自由出现，就必须改名。**== 判定方法：把公式里所有量词列出来，指导变元有重复的一律换。
- **第 4 步**：把量词从内往外逐层"提"，**每次提出前确认被越过的部分不含该变元**。若不含 → 可以越过；若含 → 说明第 3 步没做干净，回去改名。

### 6.4 例题

#### 例 1 🟢　求 ∀xF(x) → ∃xG(x) 的前束范式

**第 1 步**（消去 →）：

```
∀xF(x) → ∃xG(x) ⇔ ¬∀xF(x) ∨ ∃xG(x)
```

**第 2 步**（否定内移）：

```
¬∀xF(x) ⇔ ∃x¬F(x)
⇔ ∃x¬F(x) ∨ ∃xG(x)
```

**第 3 步**（换名）：两个 ∃ 都用 x，虽各自辖域独立无实质冲突，但为清晰统一改名：

```
⇔ ∃x¬F(x) ∨ ∃yG(y)
```

**第 4 步**（量词左移）：先提 ∃y，再提 ∃x

```
⇔ ∃x(¬F(x) ∨ ∃yG(y))      （¬F(x) 不含 y ✔）
⇔ ∃x∃y(¬F(x) ∨ G(y))
```

**结果**：==**∃x∃y(¬F(x) ∨ G(y))**==　（等价地可写成 ∃x∃y(F(x) → G(y))）

---

#### 例 2 🟢　求 ∃x(F(x) ∧ ∀yG(x, y)) 的前束范式

**第 1、2 步**：已只含 ¬、∧、∨（无 →、↔），且 ¬ 不出现，跳过。

**第 3 步**：指导变元是 x 和 y，无重名，且 x、y 无自由出现 → 无需换名。

**第 4 步**：量词不在最前——∀y 嵌在 ∃x 的辖域内部，需把 ∀y 提到 ∃x 之后。

越过 F(x)：F(x) **含 x**，但被提出的是 ∀y，只需确认 F(x) **不含 y** ✔

```
∃x(F(x) ∧ ∀yG(x, y))
⇔ ∃x∀y(F(x) ∧ G(x, y))       （∧ 型辖域扩张，F(x) 不含 y ✔）
```

**结果**：==**∃x∀y(F(x) ∧ G(x, y))**==

---

#### 例 3 🟡　求 ∀x(F(x) → G(x)) → ∃xH(x) 的前束范式

**第 1 步**（消去外层的 →，再消内层）：

```
¬∀x(F(x) → G(x)) ∨ ∃xH(x)
```

**第 2 步**（否定内移，两层）：

```
⇔ ∃x¬(F(x) → G(x)) ∨ ∃xH(x)
⇔ ∃x¬(¬F(x) ∨ G(x)) ∨ ∃xH(x)         （内层 → 先化掉）
⇔ ∃x(F(x) ∧ ¬G(x)) ∨ ∃xH(x)           （德摩根 + 双重否定）
```

**第 4 步**（换名 + 量词左移）：两个 ∃ 重名 x，先换名，再逐个提出：

```
⇔ ∃x(F(x) ∧ ¬G(x)) ∨ ∃yH(y)
⇔ ∃x[(F(x) ∧ ¬G(x)) ∨ ∃yH(y)]         （¬G(x) 等不含 y ✔）
⇔ ∃x∃y[(F(x) ∧ ¬G(x)) ∨ H(y)]
```

**结果**：==**∃x∃y((F(x) ∧ ¬G(x)) ∨ H(y))**==

---

#### 例 4 🟡（必考换名）　求 ∀xF(x, y) ∨ ∃yG(x, y) 的前束范式

**⚠️ 先检查变元冲突**：这里 **y 既是 ∀x 辖域外 F(x, y) 中的自由变元，又是 ∃y 的指导变元**。直接扩张会把自由 y 捕获 → **必须先换名**。

**第 3 步**（换名）：把 `∃yG(x, y)` 中的 y 换成未出现过的 z：

```
∀xF(x, y) ∨ ∃zG(x, z)
```

**第 4 步**（量词左移）：

```
⇔ ∀x(F(x, y) ∨ ∃zG(x, z))     （∀x 的辖域只延伸到 F(x, y)，越过时 F(x,y) 含 x 故留在 ∀x 辖域内；右半不含 x ✔）
⇔ ∀x∃z(F(x, y) ∨ G(x, z))     （F(x, y) 不含 z ✔）
```

**结果**：==**∀x∃z(F(x, y) ∨ G(x, z))**==，其中 **y 仍为自由变元**（它不属于任何量词的辖域）。

> **本题是"忘记换名"的典型考点**。若不做第 3 步而直接写成 `∀x∃y(F(x, y) ∨ G(x, y))`，含义已变，判错。

---

#### 例 5 🔴（含 ↔ 与外层 ¬）　求 ¬(∀xF(x) ↔ ∃xG(x)) 的前束范式

**第 1 步**（消去 ↔）：这里用 `¬(A ↔ B) ⇔ A ↔ ¬B` 先把最外层的 ¬ 消费掉最省事：

```
¬(∀xF(x) ↔ ∃xG(x)) ⇔ ∀xF(x) ↔ ¬∃xG(x)
```

**第 2 步**（否定内移 + 消 ↔）：

```
⇔ ∀xF(x) ↔ ∀x¬G(x)                     （¬∃xG(x) ⇔ ∀x¬G(x)）
⇔ (∀xF(x) → ∀x¬G(x)) ∧ (∀x¬G(x) → ∀xF(x))   （↔ 等值式）
⇔ (¬∀xF(x) ∨ ∀x¬G(x)) ∧ (¬∀x¬G(x) ∨ ∀xF(x))
⇔ (∃x¬F(x) ∨ ∀x¬G(x)) ∧ (∃xG(x) ∨ ∀xF(x))
```

**第 3 步**（换名）：四个量词指导变元**全是 x**，全部改成互不相同的字母（y, z 只用于约束，注意别与自由变元撞名）：

```
⇔ (∃a¬F(a) ∨ ∀b¬G(b)) ∧ (∃cG(c) ∨ ∀dF(d))
```

**第 4 步**（量词左移，两个合取支分别处理）：

左支：

```
∃a¬F(a) ∨ ∀b¬G(b)
⇔ ∀b(∃a¬F(a) ∨ ¬G(b))        （∃a¬F(a) 不含 b ✔）
⇔ ∀b∃a(¬F(a) ∨ ¬G(b))        （¬G(b) 不含 a ✔）
```

右支：

```
∃cG(c) ∨ ∀dF(d)
⇔ ∀d(∃cG(c) ∨ F(d))          （∃cG(c) 不含 d ✔）
⇔ ∀d∃c(G(c) ∨ F(d))          （F(d) 不含 c ✔）
```

合并后再把右支的量词统一提到最前：

```
∀b∃a(¬F(a) ∨ ¬G(b)) ∧ ∀d∃c(G(c) ∨ F(d))
⇔ ∀d∃c[ ∀b∃a(¬F(a) ∨ ¬G(b)) ∧ (G(c) ∨ F(d)) ]   （右支量词可越过左支：左支不含 c、d ✔）
⇔ ∀d∃c∀b∃a[ (¬F(a) ∨ ¬G(b)) ∧ (G(c) ∨ F(d)) ]   （(G(c)∨F(d)) 不含 a、b ✔）
```

**结果**：==**∀d∃c∀b∃a((¬F(a) ∨ ¬G(b)) ∧ (G(c) ∨ F(d)))**==

> **要点**：本题的答案**不唯一**（量词块的排列顺序可以不同），只要母式与整体等值、且所有量词都在最前即可。

---

#### 例 6 🔴（外层 ¬ 直接作用）　求 ¬(∀xF(x) → ∃yG(y)) 的前束范式

**第 1 步**（先别急着消 →，让 ¬ 先"进去"更简单）：

```
¬(∀xF(x) → ∃yG(y))
```

**第 2 步**：把 `∀xF(x) → ∃yG(y)` 看成一个整体，用 `¬(A → B) ⇔ A ∧ ¬B`：

```
⇔ ∀xF(x) ∧ ¬∃yG(y)
⇔ ∀xF(x) ∧ ∀y¬G(y)          （量词否定）
```

**第 3 步**：指导变元 x、y 无冲突 → 无需换名。

**第 4 步**：两个量词都已在最前，母式 `F(x) ∧ ¬G(y)` 不含量词 → **已经是前束范式**。

**结果**：==**∀x∀y(F(x) ∧ ¬G(y))**==

> **要点**：`¬(A → B) ⇔ A ∧ ¬B` 是比"先消蕴含再德摩根"更快的一条捷径——外层否定作用在一个蕴含式上时优先使用。

### 6.5 前束析取范式与前束合取范式

若在前束范式的**母式**上再要求"是标准范式"，得到两种加强形式：

| 名称 | 结构要求 | 说明 |
| :--- | :--- | :--- |
| **前束析取范式** | 前束词 + **析取范式**的母式 | 母式形如"简单合取式的析取" |
| **前束合取范式** | 前束词 + **合取范式**的母式 | 母式形如"简单析取式的合取" |

**求法**：先求出前束范式，再用 C1 的**分配律**把母式整理成析取范式／合取范式。注意：整理母式时**不再有量词**，所以这一步就是纯粹命题逻辑的主范式技术。

**用途**：前束范式是**归结原理**（自动定理证明）与 **Skolem 标准形**的出发点——把量词集中到最前面之后，才能对母式做统一的机械化处理。这也是 2.3 节在整个数理逻辑课程中的位置。

## 七、常见易错点速查表

| 易错点 | 正解 |
| :--- | :--- |
| 否定穿透多个量词时只翻最外层 | ==**每个量词都要翻转**==：¬∀x∃yP ⇔ ∃x∀y¬P |
| 把 ∨、∧ 型辖域扩张当成无条件成立 | 前提是 ==**B 中不含被移出的变元 x**==，含则不能移 |
| → 型辖域扩张忘记"前件翻转" | ∀x(A(x)→B) ⇔ **∃x**A(x)→B；∃x(A(x)→B) ⇔ **∀x**A(x)→B |
| ∀ 对 ∨ 分配、∃ 对 ∧ 分配 | **不成立**！只单向：∀xA ∨ ∀xB ⇒ ∀x(A∨B)；∃x(A∧B) ⇒ ∃xA ∧ ∃xB |
| 记成"∀ 配 ∨、∃ 配 ∧" | 恰好记反了。正确是 ==**∀ 配 ∧、∃ 配 ∨**== |
| 做前束范式不换名 | 同名变元必须先换名（用换名规则），否则**变元被捕获**，答案等值性被破坏 |
| 换名只改指导变元 | 指导变元 **和** 辖域内所有同名约束出现要**同时改** |
| 用自由变元名做换名的新名 | 新名必须在该辖域内**未出现过**，否则同样发生捕获 |
| ∃y∀x ⇔ ∀x∃y | 不成立！只有 ∃y∀x ⇒ ∀x∃y 单向 |
| 前束范式中母式仍含量词 | 母式必须**不含量词**；且应已消去 →、↔ |
| 认为前束范式唯一 | **不唯一**，是"存在且等值"，不是"唯一确定" |
| 前束范式里自由变元被"消掉" | 自由变元不属于任何量词，必须原样保留（例 4 的 y） |

# 参考答案与详细解析

## 第 1 题

**(1)** 逐层剥：

```
¬∃x(P(x) ∧ ¬Q(x))
⇔ ∀x¬(P(x) ∧ ¬Q(x))         （量词否定）
⇔ ∀x(¬P(x) ∨ ¬¬Q(x))         （德摩根）
⇔ ∀x(¬P(x) ∨ Q(x))           （双重否定）
⇔ ∀x(P(x) → Q(x))            （蕴含等值式）
```

**答案**：`∀x(¬P(x) ∨ Q(x))`，即 `∀x(P(x) → Q(x))`。

**解析**：这里顺带得到一个常用结论——`¬∃x(P(x) ∧ ¬Q(x)) ⇔ ∀x(P(x) → Q(x))`，正是"**没有人 P 且非 Q**"="**所有 P 都是 Q**"。这是自然语言翻译成量词公式时最常用的一条。

**(2)**

```
¬∀x(P(x) → Q(x))
⇔ ∃x¬(P(x) → Q(x))           （量词否定）
⇔ ∃x¬(¬P(x) ∨ Q(x))          （消蕴含）
⇔ ∃x(P(x) ∧ ¬Q(x))           （德摩根 + 双重否定）
```

**答案**：`∃x(P(x) ∧ ¬Q(x))`。

**解析**："并非所有 P 都 Q" = "**有 P 不是 Q**"。注意排除区：**不是** `∃x(P(x) ∧ Q(x))`，也不是 `∀x(P(x) ∧ ¬Q(x))`。

---

## 第 2 题

**(1) 不成立。** `∃x(P ∧ Q) ⇒ ∃xP ∧ ∃xQ` 只单向。

反例：D = {1, 2}，P(1)=1, P(2)=0, Q(1)=0, Q(2)=1。
- `∃xP(x)` = 1，`∃xQ(x)` = 1 → 右边 = **1（真）**
- `P(1)∧Q(1)` = 1∧0 = 0，`P(2)∧Q(2)` = 0∧1 = 0 → 左边 = **0（假）**

⇒ 右边真而左边假，"⇐"方向不成立。

**(2) 成立。** 这是 3.3 的"∀ 对 ∧ 分配"。证明思路：`∀x(P∧Q)` 表示"每个个体既满足 P 又满足 Q"；`∀xP ∧ ∀xQ` 表示"每个个体满足 P，且每个个体满足 Q"。两者是同一件事，双向成立。

**(3) 不成立。** 只有 `∃x∀yA(x, y) ⇒ ∀y∃xA(x, y)` 单向。

反例：D = 整数集，A(x, y) 表示 "x + y = 0"。
- `∃x∀yA(x, y)`：需要存在一个整数 x 与**所有**整数 y 之和为 0 → **假**
- `∀y∃xA(x, y)`：对每个 y，取 x = −y 即可 → **真**

⇒ 左边假、右边真，"⇐"方向不成立。

**解析**：本题把三个"只单向"的典型集中在一起。记忆主线——==**∀ 拆开变弱，∃ 拆开变弱；异名量词 ∀∃ 弱、∃∀ 强**==。

---

## 第 3 题

**(1)**

```
¬∃x(F(x) ∧ ∀yG(x, y))
⇔ ∀x¬(F(x) ∧ ∀yG(x, y))            （量词否定）
⇔ ∀x(¬F(x) ∨ ¬∀yG(x, y))            （德摩根）
⇔ ∀x(¬F(x) ∨ ∃y¬G(x, y))            （量词否定）
⇔ ∀x∃y(¬F(x) ∨ ¬G(x, y))            （∃y 辖域扩张，¬F(x) 不含 y ✔）
```

**答案**：`∀x∃y(¬F(x) ∨ ¬G(x, y))`

**解析**：顺序是"先量词否定 → 再德摩根 → 再量词否定 → 最后辖域扩张"。注意 ¬F(x) 中含 x，但被提出的量词是 ∃y，只需 ¬F(x) 不含 y ✔，所以可以越过。指导变元 x、y 无重名，无需换名。

**(2)**

```
∀xP(x) ∨ ∃xQ(x)
```

⚠️ 两个量词指导变元**都是 x**，且**并非同一辖域**，直接提会出错 → **先换名**：

```
⇔ ∀xP(x) ∨ ∃zQ(z)                   （换名规则：∃xQ(x) → ∃zQ(z)）
⇔ ∀x(P(x) ∨ ∃zQ(z))                 （∀x 辖域扩张，右半不含 x ✔）
⇔ ∀x∃z(P(x) ∨ Q(z))                 （P(x) 不含 z ✔）
```

**答案**：`∀x∃z(P(x) ∨ Q(z))`

**解析**：若偷懒不换名写成 `∀x(P(x) ∨ ∃xQ(x))`，表面上"也是前束范式"，但内层 ∃x 与外层 ∀x 同名却不同辖域，**含义不清**，判错。

**(3)**

```
∃xP(x) → ∀yQ(y)
⇔ ¬∃xP(x) ∨ ∀yQ(y)                  （消蕴含）
⇔ ∀x¬P(x) ∨ ∀yQ(y)                  （量词否定）
```

⚠️ 两个量词都是 ∀（同名量词可交换），但指导变元重名 x…这里一个是 x、一个是 y，不重名 ✔。继续提出：

```
⇔ ∀x(¬P(x) ∨ ∀yQ(y))                （∃… 已变 ∀x；¬P(x) 不含 y ✔）
⇔ ∀x∀y(¬P(x) ∨ Q(y))                （¬P(x) 不含 y ✔）
```

**答案**：`∀x∀y(¬P(x) ∨ Q(y))`

**解析**：也可用 → 型辖域扩张一步到位：`∃xP(x) → ∀yQ(y) ⇔ ∀x(P(x) → ∀yQ(y)) ⇔ ∀x∀y(P(x) → Q(y))`（**前件翻转**：∃ 变 ∀），结果一致 ✔

---

## 第 4 题

```
∀x(P(x) → Q(x)) ∧ ∃yR(y)
```

**第 1 步**（消去 →）：

```
⇔ ∀x(¬P(x) ∨ Q(x)) ∧ ∃yR(y)
```

**第 3 步**：指导变元 x、y 无重名 → 无需换名。

**第 4 步**（量词左移）：先把 ∃y 提出（在 ∧ 左支中，左支不含 y ✔），再把 ∀x 提出（右支 R(y) 不含 x ✔）：

```
⇔ ∃y[ ∀x(¬P(x) ∨ Q(x)) ∧ R(y) ]
⇔ ∃y∀x[ (¬P(x) ∨ Q(x)) ∧ R(y) ]
```

**答案**：`∃y∀x((¬P(x) ∨ Q(x)) ∧ R(y))`

**解析**：提出顺序**不影响结果**（这里先提 ∃y 再提 ∀x，也可先提 ∀x 得 `∀x∃y(...)`，两种都等值合法）。检查母式：只含 ¬、∧、∨，不含量词 ✔

## 第 5 题

**错误在第 4 行**：把 `∃x¬P(x, y) ∨ ∃yQ(x, y)` 直接合并成 `∃x∃y(¬P(x, y) ∨ Q(x, y))`。

**错因**：原式中 **x 在 `Q(x, y)` 中是自由出现**（`∃x` 的辖域只有 `P(x, y)`）。第一个 ∃x 的作用范围**不覆盖** `Q(x, y)`；但写出来的 `∃x∃y(...)` 中，母式里的 x **被 ∃x 约束了**——发生了==**变元捕获**==，等值性被破坏。

**正确解法**：

```
∀xP(x, y) → ∃yQ(x, y)
⇔ ¬∀xP(x, y) ∨ ∃yQ(x, y)
⇔ ∃x¬P(x, y) ∨ ∃yQ(x, y)
```

**先换名**（把内层 ∃y 的 y 换成未出现的 z，避免与自由变元 y 及 `Q(x, y)` 中的 y 混淆）：

```
⇔ ∃x¬P(x, y) ∨ ∃zQ(x, z)
```

**再左移**：

```
⇔ ∃x(¬P(x, y) ∨ ∃zQ(x, z))         （¬P(x, y) 不 z ✔）
⇔ ∃x∃z(¬P(x, y) ∨ Q(x, z))         （¬P(x, y) 不含 z ✔）
```

**答案**：`∃x∃z(¬P(x, y) ∨ Q(x, z))`，其中 **x 与 y 均为自由变元**。

**解析**：本题是例 4 的翻版，考点完全一致——==**自由变元与约束变元同名时，必须先换名再扩张**==。判断方法：逐行检查"母式里出现的每个变元，是被新引入的量词约束了，还是保持自由"。

## 第 6 题

```
¬(∃xP(x) → ∀y(Q(y) ∨ R(x, y)))
```

**第 2 步**（用 `¬(A → B) ⇔ A ∧ ¬B`）：

```
⇔ ∃xP(x) ∧ ¬∀y(Q(y) ∨ R(x, y))
```

**第 2 步续**（量词否定 + 德摩根）：

```
⇔ ∃xP(x) ∧ ∃y¬(Q(y) ∨ R(x, y))
⇔ ∃xP(x) ∧ ∃y(¬Q(y) ∧ ¬R(x, y))
```

**第 3 步**（换名）：两个量词是 ∃x 与 ∃y，指导变元不同名；x 在 `¬R(x, y)` 中出现但受 ∃x 约束（**注意**：原公式中 `R(x, y)` 的 x 是自由的，但此时 x 已被 ∃x 约束，y 已被 ∃y 约束，各自都在自己辖域内）→ 无需换名。

**第 4 步**（量词左移）：

```
⇔ ∃x(P(x) ∧ ∃y(¬Q(y) ∧ ¬R(x, y)))   （P(x) 不含 y ✔）
⇔ ∃x∃y(P(x) ∧ ¬Q(y) ∧ ¬R(x, y))     （P(x) 不含 y ✔）
```

**答案**：`∃x∃y(P(x) ∧ ¬Q(y) ∧ ¬R(x, y))`

**解析**：本题的关键是第 2 步**不要**先消蕴含再德摩根（那样要绕好几圈），直接用 `¬(A → B) ⇔ A ∧ ¬B`。另外要注意：原式中 `R(x, y)` 里的 x 虽然是自由的，但因为 `∃xP(x)` 已经在最前面，把它提为 `∃x` 之后 x 变成约束变元，**这是合法的**——因为它本来就在"整体 ∃x 的扩张结果"里，不涉及捕获。为严谨可在第 3 步把 `∃xP(x)` 的 x 换成 u 再提出，结果等值。

## 第 7 题

```
∀x(F(x) → ∃yG(y)) → ∃zH(z)
```

**第 1 步**（消去外层 →）：

```
⇔ ¬∀x(F(x) → ∃yG(y)) ∨ ∃zH(z)
```

**第 2 步**（否定内移）：

```
⇔ ∃x¬(F(x) → ∃yG(y)) ∨ ∃zH(z)          （量词否定）
⇔ ∃x(F(x) ∧ ¬∃yG(y)) ∨ ∃zH(z)          （¬(A→B) ⇔ A ∧ ¬B）
⇔ ∃x(F(x) ∧ ∀y¬G(y)) ∨ ∃zH(z)          （量词否定）
```

**第 3 步**（换名）：指导变元为 x、y、z，互不相同，且无自由变元 → 无需换名。

**第 4 步**（量词左移）：

先整理左支：

```
∃x(F(x) ∧ ∀y¬G(y))
⇔ ∃x∀y(F(x) ∧ ¬G(y))                   （F(x) 不含 y ✔）
```

再合并左右支：

```
∃x∀y(F(x) ∧ ¬G(y)) ∨ ∃zH(z)
⇔ ∃z[ ∃x∀y(F(x) ∧ ¬G(y)) ∨ H(z) ]      （左支不含 z ✔）
⇔ ∃z∃x[ ∀y(F(x) ∧ ¬G(y)) ∨ H(z) ]      （H(z) 不含 x ✔）
⇔ ∃z∃x∀y[ (F(x) ∧ ¬G(y)) ∨ H(z) ]      （H(z) 不含 y ✔）
```

**答案**：`∃z∃x∀y((F(x) ∧ ¬G(y)) ∨ H(z))`

**解析**：第 4 步一共做了 **4 次辖域扩张**，每次都要确认"被越过的式子不含该量词的指导变元"。为了省力，可以先把两个合取/析取支的量词**各自提到各自的最前**，再统一合并。注意 `∃z` 顺序可以往后调整（如写成 `∃x∃z∀y(...)` 也等值），前束范式不唯一。

## 第 8 题

```
∀x(F(x) ↔ G(x)) ∨ ∃yH(y)
```

**第 1 步**（先把 ∃y 提出，因为 ∃y 与 ∀x 的辖域不重叠，先提出可简化后续）：

```
⇔ ∃y[ ∀x(F(x) ↔ G(x)) ∨ H(y) ]        （∀x(...) 不含 y ✔）
⇔ ∃y∀x[ (F(x) ↔ G(x)) ∨ H(y) ]         （H(y) 不含 x ✔）
```

**第 1 步续**（现在只需处理母式里的 ↔，用 `A ↔ B ⇔ (A∧B) ∨ (¬A∧¬B)`）：

```
⇔ ∃y∀x[ ((F(x) ∧ G(x)) ∨ (¬F(x) ∧ ¬G(x))) ∨ H(y) ]
```

**第 2 步**：母式中 ¬ 只作用于原子公式 F(x)、G(x) → 已到位。

**第 3、4 步**：量词已全在最前，母式不含量词 → **已完成**。

**答案**：`∃y∀x((F(x) ∧ G(x)) ∨ (¬F(x) ∧ ¬G(x)) ∨ H(y))`

**解析**：本题关键在于**先处理 ∨（把外层量词逐层提出），最后再消母式里的 ↔**——顺序反了会多出好几步。也可用 `A ↔ B ⇔ (¬A ∨ B) ∧ (A ∨ ¬B)`，得到等值的另一种前束范式 `∃y∀x((¬F(x) ∨ G(x)) ∧ (F(x) ∨ ¬G(x)) ∨ H(y))`，两者都对（**前束范式不唯一**）。

## 附一：核心公式一览

**量词否定（3.1）**

- ¬∀xA(x) ⇔ ∃x¬A(x)
- ¬∃xA(x) ⇔ ∀x¬A(x)
- ¬Q₁x₁…QₙxₙA ⇔ Q̄₁x₁…Q̄ₙxₙ¬A　（每个量词都翻转）

**辖域收缩与扩张（3.2，条件：B 不含 x）**

- ∀x(A(x) ∨ B) ⇔ ∀xA(x) ∨ B　｜　∃x(A(x) ∨ B) ⇔ ∃xA(x) ∨ B
- ∀x(A(x) ∧ B) ⇔ ∀xA(x) ∧ B　｜　∃x(A(x) ∧ B) ⇔ ∃xA(x) ∧ B
- ∀x(A(x) → B) ⇔ ∃xA(x) → B　　← 前件翻转
- ∃x(A(x) → B) ⇔ ∀xA(x) → B　　← 前件翻转
- ∀x(B → A(x)) ⇔ B → ∀xA(x)　　← 后件原样
- ∃x(B → A(x)) ⇔ B → ∃xA(x)　　← 后件原样

**量词分配（3.3）**

- ✅ ∀x(A(x) ∧ B(x)) ⇔ ∀xA(x) ∧ ∀xB(x)
- ✅ ∃x(A(x) ∨ B(x)) ⇔ ∃xA(x) ∨ ∃xB(x)
- ❌ ∀x(A(x) ∨ B(x)) ⇔ ∀xA(x) ∨ ∀xB(x)　（只 ⇒）
- ❌ ∃x(A(x) ∧ B(x)) ⇔ ∃xA(x) ∧ ∃xB(x)　（只 ⇒）

**量词顺序（3.4）**

- ∀x∀yA ⇔ ∀y∀xA　｜　∃x∃yA ⇔ ∃y∃xA
- ∃y∀xA(x,y) ⇒ ∀x∃yA(x,y)　（反向不成立）

**常用导出式**

- ∃x(A(x) → B(x)) ⇔ ∀xA(x) → ∃xB(x)
- ¬∃x(P(x) ∧ ¬Q(x)) ⇔ ∀x(P(x) → Q(x))
- ¬∀x(P(x) → Q(x)) ⇔ ∃x(P(x) ∧ ¬Q(x))
- ¬(A → B) ⇔ A ∧ ¬B　（外层 ¬ 作用在蕴含上时的捷径）

**三条规则（第五节）**

- 置换规则：A ⇔ B ⇒ Φ(A) ⇔ Φ(B)
- 换名规则：约束变元（指导变元 + 辖域内同名出现）统一改名，新名辖域内未出现
- 代替规则：自由变元处处替换为新名，新名公式中未出现

**前束范式（第六节）**

- 形式：Q₁x₁…Qₙxₙ M，M 不含量词、只含 ¬ ∧ ∨
- 四步：① 消 →／↔　② 否定内移　③ 换名　④ 量词左移

## 附二：易混概念对照

| 容易混的一对 | 区别 |
| :--- | :--- |
| `⇔`（等值，元语言） vs `↔`（等价联结词，对象语言） | `↔` 是公式内部的运算；`⇔` 是两公式间的"永真等价"关系 |
| 换名规则 vs 代替规则 | 换名动**约束**变元；代替动**自由**变元。共同点：新名必须"没出现过" |
| 辖域扩张的 ∨∧ 型 vs → 型 | ∨∧ 型量词**原样**搬；→ 型**前件翻转**（∀↔∃）、后件原样 |
| ∀ 对 ∧ 分配 vs ∀ 对 ∨ 分配 | 前者是**等值式**✅；后者只是**蕴含式**❌ |
| `∀x∃y` vs `∃y∀x` | 前者弱、后者强；`∃y∀x ⇒ ∀x∃y`，反之不成立 |
| 前束范式 vs 主析取／合取范式 | 前者管**量词**的位置；后者管**命题联结词**的结构。二者可叠加（前束析取／合取范式） |
| 前束范式的"唯一性" | **不唯一**！只有"存在且等值"，没有唯一标准形 |
| 闭式 vs 含自由变元的公式 | 闭式有确定真值；含自由变元的公式要**先加量词**（全称闭包／存在闭包）才能谈真值 |
