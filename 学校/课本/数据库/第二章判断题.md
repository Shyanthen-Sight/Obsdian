# 第2章 判断题（共20题，满分100）

> 来源：学习通作业《第2章判断题》，作答时间 09-29 16:00 至 12-31 16:00。题干为原文抄录；页面本身不显示标准答案，以下答案为按《数据库系统概论》（王珊、萨师煊）第2章关系数据库知识点给出，供核对。

---

## 1. 关系数据库中的主码是用来唯一标识关系中每个元组的属性或属性组。( )

**答案：对**

**解析：** 候选码能唯一标识一个元组，从候选码中选定一个作为**主码**（主键），其取值唯一且非空。

---

## 2. 非规范化关系是指关系中的分量可以是不可分的数据项。( )

**答案：错**

**解析：** 说反了。**规范化关系**才要求每个分量必须是**不可分的数据项**（原子值）；**非规范化关系**允许分量再分（表中有表），不满足第一范式。

---

## 3. 元组(tuple)是笛卡儿积中的每一个元素(d1，d2，…，dn)的简称。( )

**答案：对**

**解析：** 笛卡儿积 D₁×D₂×…×Dₙ 中的每一个元素 (d₁, d₂, …, dₙ) 称为一个 **n 元组**，简称元组。

---

## 4. 实体完整性规则要求关系中的每一列都不能取空值。( )

**答案：错**

**解析：** 实体完整性只要求**主属性**（主码中的各属性）不能取空值，**非主属性可以取空值**，并非"每一列"。

---

## 5. 参照完整性约束要求关系中的外码必须与被参照关系的主码相对应。( )

**答案：对**

**解析：** 外码的取值只能是：**空值**，或等于被参照关系中某个元组的**主码值**，以此保证引用关系的有效性。

---

## 6. 在关系数据库中，一个关系中的任意两个元组的码可以相同。( )

**答案：错**

**解析：** 码的职责就是**唯一标识**元组，不同元组的候选码（主码）不能相同。关系是元组的集合，也**不允许出现完全相同的元组**。

---

## 7. Oracle公司是在1978年发布了Oracle1.0数据库系统。( )

**答案：错**

**解析：** Oracle V1 于 1978 年开发完成，但**从未正式商业发布**；1979 年推出的 **Oracle V2.0** 才是世界上第一个商品化的关系数据库管理系统（因市场策略跳过了"第 1 版"）。

> 若课程 PPT 按"1978 年 Oracle 1.0"表述，则以课程口径为准。

---

## 8. 笛卡儿积的基数是所有参与计算的域的基数的乘积。( )

**答案：对**

**解析：** 若各域基数分别为 m₁, m₂, …, mₙ，则笛卡儿积的基数为 m₁×m₂×…×mₙ，即元组的总个数。

---

## 9. 在关系数据库中，一个元组可以包含重复的分量。( )

**答案：对**

**解析：** 元组的各分量分别取自各自的域，**不同属性取到相同数值是允许的**；被禁止的是关系中出现**完全相同的元组**，以及属性列重复。

---

## 10. E.F. Codd是在1970年提出了关系数据模型。( )

**答案：对**

**解析：** 1970 年 E.F. Codd 发表《A Relational Model of Data for Large Shared Data Banks》，奠定关系数据模型基础。

---

## 11. 域是一组具有不同数据类型的值的集合。( )

**答案：错**

**解析：** 域是一组具有**相同数据类型**的值的集合（如"性别"域 = {男, 女}）。

---

## 12. IBM公司的System R是在20世纪70年代末研制成功的。( )

**答案：对**

**解析：** IBM 圣何塞实验室的 System R 于 20 世纪 70 年代末研制成功，是首个实现 SQL 的关系数据库原型系统，验证了关系模型的实用性。

---

## 13. 用户定义的完整性是关系模型必须满足的完整性约束条件。( )

**答案：错**

**解析：** 关系模型**必须满足**的是**实体完整性**和**参照完整性**；**用户定义完整性**是针对某一具体应用由用户自行定义的约束（如年龄取值范围），不是模型层面的强制条件。

---

## 14. 笛卡儿积是给定一组域D1，D2，…，Dn的所有取值的一个组合，且可以重复。( )

**答案：错**

**解析：** 笛卡儿积是**所有可能组合构成的集合**，每个组合只出现一次，**不可重复**；其子集——关系，同样不允许重复元组。

---

## 15. 在关系数据库中，基本关系是实际存在的表，而视图表不存储实际数据。( )

**答案：对**

**解析：** 基本表（基本关系）实际存储数据；视图是由基本表导出的**虚表**，只存定义、不存数据。

---

## 16. 关系代数是一种过程性查询语言，它用对关系的运算来表达查询。( )

**答案：对**

**解析：** 关系代数通过选择、投影、连接、除等**运算**逐步得到结果，属于**过程性**语言；关系演算（元组演算、域演算）则是非过程性语言。

---

## 17. 在关系模型中，一个关系只能包含一个域。( )

**答案：错**

**解析：** n 目关系包含 **n 个属性**，各属性可取自不同域（也可出自同一域）；一个关系不可能只含一个域。

---

## 18. 关系模型是由美国IBM公司的E.F.Codd在1960年提出的。( )

**答案：错**

**解析：** 提出者是 E.F. Codd 无误，但时间是 **1970 年**，不是 1960 年。

---

## 19. 在关系数据库中，外码用于建立关系之间的引用关系。( )

**答案：对**

**解析：** 外码在本关系中取值，指向另一关系的主码，从而实现**关系之间的联系**（参照完整性）。

---

## 20. 关系模型中的数据结构只能是二维表。( )

**答案：对**

**解析：** 关系模型的数据结构**单一**，实体和实体间的联系都用**关系（二维表）**表示，这是它区别于层次、网状模型的重要特征。
