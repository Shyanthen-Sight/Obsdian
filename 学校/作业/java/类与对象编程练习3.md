## 题目一：跨包引用与类间关系

### 1.1 原题

> 有类图如下所示：
>
> ![[类与对象编程练习3-题1-类图.png|428]]
>
> 编写程序代码，以 **PkgTest** 为主类，在 main 方法中输出 **User** 类成员 name 的值。
> （提示：代码要能够体现类间的关系）

### 1.2 类图解读

类图是「三层嵌套」的包结构：

```
yznu
├── cs
│   └── pkgone
│       └── User          // 成员：name : String
└── dm
    └── pkgtwo
        └── PkgTest       // 主类，main 方法在这里
```

- **User 的完整类名**：`yznu.cs.pkgone.User`
- **PkgTest 的完整类名**：`yznu.dm.pkgtwo.PkgTest`
- 图中从 PkgTest 指向 User 的**虚线箭头**表示「依赖」，在 Java 里对应的就是 **`import yznu.cs.pkgone.User;`**——这就是题目说的「体现类间的关系」：主类不在 User 所在的包里，必须通过 import 才能使用 User。

> **关于 name 的可见性**：类图只写了 `name: String`，**没有** `+` / `-` / `#` / `~` 符号。按 UML 约定，不写可见性符号即为**默认（包）权限**（对应 Java 的 default）。第二题类图明确标了 `+name`、`~teacher`、`-score`，说明作者会用这些符号，所以第一题应当按默认权限来读。
> 但 PkgTest 位于**另一个包**，默认权限的字段它访问不到，因此 User 还必须提供一个 `public` 的访问方法——这本身也是「类间关系」的一部分。

### 1.3 考点

| 考点 | 说明 |
| :--- | :--- |
| `package` 声明 | 包名必须与源码目录结构一一对应 |
| 跨包使用类 | 先 `import 包名.类名;`，再直接写类名 |
| 访问权限 | `name` 未标符号 → 默认（包）权限；跨包读取需另提供 `public` 方法 |
| 主类 | 含 `public static void main(String[] args)` 的类才能用 `java` 运行 |

### 1.4 参考代码

**目录结构（务必保持一致）：**

```
src
├── yznu
│   ├── cs
│   │   └── pkgone
│   │       └── User.java
│   └── dm
│       └── pkgtwo
│           └── PkgTest.java
```

**User.java**

```java
package yznu.cs.pkgone;

public class User {
    String name;                         // 默认（包）权限，与类图一致

    public User(String name) {           // 构造方法，用于给 name 赋值
        this.name = name;
    }

    public String getName() {            // public 方法：跨包只能通过它读取 name
        return name;
    }
}
```

**PkgTest.java**

```java
package yznu.dm.pkgtwo;

import yznu.cs.pkgone.User;              // 体现类间关系：跨包导入

public class PkgTest {
    public static void main(String[] args) {
        User user = new User("张三");      // 创建 User 对象
        System.out.println("User 的 name = " + user.getName());
    }
}
```

**编译与运行：**

```bash
javac -encoding UTF-8 -d out src/yznu/cs/pkgone/User.java src/yznu/dm/pkgtwo/PkgTest.java
java -cp out yznu.dm.pkgtwo.PkgTest
```

**运行结果：**

```
User 的 name = 张三
```

### 1.5 补充说明：name 到底该用什么权限？

类图没标可见性符号，严格说题目是**欠定义**的，三种写法都能自圆其说，但访问路径不同：

| 写法 | 字段声明 | PkgTest（异包）能否直接写 `user.name` | 说明 |
| :--- | :--- | :---: | :--- |
| **默认权限（最贴合类图）** | `String name;` | ❌ | 必须再加 `public getName()` 才能读到 |
| `private` | `private String name;` | ❌ | 封装最严，同样必须加 getter |
| `public` | `public String name;` | ✅ | 可直接访问，但破坏了封装 |

**本题推荐第一种**：字段按图写成默认权限，再补一个 `public` 的 `getName()`。这样既忠于类图，又能让异包的 PkgTest 拿到值，还顺带体现了「默认权限跨包不可见」这一考点。

如果你写成 `private + getter`，程序同样能运行、输出一致，只是字段声明与类图不符；如果老师示例用的是 `public` 字段，那把 getter 去掉、直接写 `user.name` 即可。**三种写法都能输出 name，区别只在访问路径。**
- `import` 只对**编译**有意义，不会把类「复制」过来；运行时 JVM 依据 `-cp`（classpath）去找 `yznu/cs/pkgone/User.class`。
- 常见错误：① 包名和目录不一致（如文件放在 `src/yznu/cs/pkgone/` 却写 `package pkgone;`）；② 只写 `import pkgone.User;` 而漏掉外层包；③ `User` 类写成 `public` 但文件名不是 `User.java`。

## 题目二：包与三种访问权限

### 2.1 原题

> 有类图定义如下：
>
> ![[类与对象编程练习3-题2-类图.png|529]]
>
> 请编写代码，完成下列要求：
> [1] 在 Lesson 中添加访问私有变量的方法；
> [2] 在主类 SamePkg 的 main 方法中，输出 Lesson 实例变量的值；
> [3] 在主类 DiffPkg 的 main 方法中，输出 Lesson 实例变量的值。
>
> 注：原题第 [1][2] 条把类名写成 `Lession`，类图中为 `Lesson`，以下统一按类图的 `Lesson` 处理。

### 2.2 类图解读

```
yznu
└── cs
    ├── Lesson        // +name : String   （public）
    │                 // ~teacher : String（包访问权限，默认）
    │                 // -score : double   （private）
    └── SamePkg       // 与 Lesson 同包

cqu
└── cs
    └── DiffPkg       // 与 Lesson 不同包
```

三个成员刻意用了三种不同的访问修饰符，题目本质是考察**访问权限的作用范围**：

| 成员 | 修饰符 | 符号 | 本类内部 | 同包（yznu.cs） | 不同包（cqu.cs） |
| :--- | :--- | :---: | :---: | :---: | :---: |
| `name` | `public` | `+` | ✅ | ✅ | ✅ |
| `teacher` | 默认（包私有） | `~` | ✅ | ✅ | ❌ 编译错误 |
| `score` | `private` | `-` | ✅ | ❌（同包也不行） | ❌ |

> **关键点**：`private` 的可见范围是「**本类**」，不是「本包」。所以即使在同一个包 `yznu.cs` 里的 `SamePkg`，也不能写 `lesson.score`，必须通过 Lesson 提供的公共方法访问。

### 2.3 参考代码

**目录结构：**

```
src
├── yznu
│   └── cs
│       ├── Lesson.java
│       └── SamePkg.java
└── cqu
    └── cs
        └── DiffPkg.java
```

**Lesson.java（要求 [1]：添加访问私有变量的方法）**

```java
package yznu.cs;

public class Lesson {
    public String name = "Java 程序设计";   // public：任何地方都能访问
    String teacher = "王老师";              // 默认权限：仅同包可访问
    private double score = 95.5;           // private：仅本类可访问

    // [1] 访问私有变量 score 的方法（getter / setter）
    public double getScore() {
        return score;
    }

    public void setScore(double score) {
        this.score = score;
    }
}
```

**SamePkg.java（要求 [2]：同包访问）**

```java
package yznu.cs;

public class SamePkg {
    public static void main(String[] args) {
        Lesson lesson = new Lesson();

        System.out.println("name = " + lesson.name);       // public，可以
        System.out.println("teacher = " + lesson.teacher); // 同包，可以
        System.out.println("score = " + lesson.getScore());// private，只能走 getter
    }
}
```

**DiffPkg.java（要求 [3]：跨包访问）**

```java
package cqu.cs;

import yznu.cs.Lesson;                     // 不同包，必须先导入

public class DiffPkg {
    public static void main(String[] args) {
        Lesson lesson = new Lesson();

        System.out.println("name = " + lesson.name);       // public，可以
        System.out.println("score = " + lesson.getScore());// 通过公共方法访问
        // System.out.println("teacher = " + lesson.teacher); // ❌ 编译错误
    }
}
```

**编译与运行：**

```bash
javac -encoding UTF-8 -d out src/yznu/cs/Lesson.java src/yznu/cs/SamePkg.java src/cqu/cs/DiffPkg.java
java -cp out yznu.cs.SamePkg
java -cp out cqu.cs.DiffPkg
```

**运行结果（SamePkg）：**

```
name = Java 程序设计
teacher = 王老师
score = 95.5
```

**运行结果（DiffPkg）：**

```
name = Java 程序设计
score = 95.5
```

### 2.4 为什么 DiffPkg 不能输出 teacher？

把注释掉的那行取消注释，`javac` 会直接报错：

```
DiffPkg.java:9: 错误: teacher 在 Lesson 中不是公共的;
无法从外部程序包中对其进行访问
```

这正是 `~`（默认/包访问权限）的意义：**只有同一个包里的类才能访问**。`teacher` 想跨包使用，要么改成 `public`，要么在 Lesson 里再加一个 `getTeacher()` 方法。

### 2.5 三种权限一句话记忆

- `public`：谁都能用；
- 默认（不写修饰符）：**同包**才能用；
- `private`：**本类**才能用；
- （补充）`protected`：同包 + 不同包的**子类**能用。

## 题目三：静态导入、java.time 与时间戳

### 3.1 原题

> 编写代码，完成下列要求内容：
> [1] 静态导入 `java.lang.Math` 类
> [2] 使用包 `java.time` 获取当前日期（`LocalDate`）、时间（`LocalTime`）、日期时间（`LocalDateTime`）
> [3] 使用 `java.lang.System.currentTimeMillis()` 获取时间戳
> [4] 输出下列文本：
>
> ```
> 绝对值 abs(-9.8) = 9.8
> 随机数 random() [0,1) = 0.4257192
> 四舍五入 round(2.68) = 3
> 最大值 max(10,20) = 20
> 2的3次幂 pow(2,3) = 8.0
> 当前日期：2026-10-17
> 当前时间：15:30:22.134
> 当前日期+时间：2026-10-17T15:30:22.134
> 年份：2026
> 月份：10
> 日期：17
> 执行一百万次累加的耗时（毫秒）是：2
> ```

### 3.2 知识点拆解

| 要求 | 关键语法 | 说明 |
| :--- | :--- | :--- |
| [1] 静态导入 Math | `import static java.lang.Math.*;` | 导入的是**静态成员**（方法/常量），调用时省略 `Math.`。Java 5 起支持 |
| [2] 日期时间 | `LocalDate.now()`、`LocalTime.now()`、`LocalDateTime.now()` | Java 8 新增 `java.time`，对象**不可变**、线程安全 |
| [3] 时间戳 | `System.currentTimeMillis()` | 返回从 1970-01-01 00:00:00 UTC 到现在的**毫秒数**（`long`） |
| [4] 精确到毫秒 | `DateTimeFormatter.ofPattern("HH:mm:ss.SSS")` | `LocalTime.toString()` 会输出 9 位纳秒（如 `15:30:22.134562300`），**必须格式化**才能得到 3 位毫秒 |

几个容易踩的细节：

- `abs(-9.8)` 输出 `9.8`；`pow(2,3)` 返回 `double`，所以是 `8.0` 而不是 `8`。
- `round(2.68)` 返回 `long`，输出 `3`（没有小数点）。
- `max(10,20)` 用的是 `int` 重载，输出 `20`。
- `random()` 返回 `[0,1)` 的 `double`，直接打印会有十几位小数；题目示例是 7 位小数，用 `String.format("%.7f", random())` 对齐格式。
- 日期时间用同一个瞬间取，避免「日期」和「时间」跨秒不一致（更严谨的写法是由一个 `LocalDateTime` 拆出 `toLocalDate()` / `toLocalTime()`）。

### 3.3 完整代码

```java
import static java.lang.Math.*;          // [1] 静态导入 Math

import java.time.LocalDate;              // [2] 日期
import java.time.LocalDateTime;          // [2] 日期时间
import java.time.LocalTime;              // [2] 时间
import java.time.format.DateTimeFormatter;

public class MathDemo {
    public static void main(String[] args) {
        // ---------- [4] 数学方法（因静态导入，无需写 Math.）----------
        System.out.println("绝对值 abs(-9.8) = " + abs(-9.8));
        System.out.println("随机数 random() [0,1) = " + String.format("%.7f", random()));
        System.out.println("四舍五入 round(2.68) = " + round(2.68));
        System.out.println("最大值 max(10,20) = " + max(10, 20));
        System.out.println("2的3次幂 pow(2,3) = " + pow(2, 3));

        // ---------- [2] java.time 获取当前日期 / 时间 / 日期时间 ----------
        LocalDate date = LocalDate.now();
        LocalTime time = LocalTime.now();
        LocalDateTime dateTime = LocalDateTime.now();

        DateTimeFormatter timeFmt = DateTimeFormatter.ofPattern("HH:mm:ss.SSS");
        DateTimeFormatter dateTimeFmt = DateTimeFormatter.ofPattern("yyyy-MM-dd'T'HH:mm:ss.SSS");

        System.out.println("当前日期：" + date);                            // 默认格式 yyyy-MM-dd
        System.out.println("当前时间：" + time.format(timeFmt));           // 固定 3 位毫秒
        System.out.println("当前日期+时间：" + dateTime.format(dateTimeFmt));
        System.out.println("年份：" + date.getYear());
        System.out.println("月份：" + date.getMonthValue());               // 1~12
        System.out.println("日期：" + date.getDayOfMonth());

        // ---------- [3] 时间戳 + 一百万次累加计时 ----------
        long start = System.currentTimeMillis();
        long sum = 0;
        for (int i = 0; i < 1_000_000; i++) {
            sum += i;
        }
        long end = System.currentTimeMillis();
        System.out.println("执行一百万次累加的耗时（毫秒）是：" + (end - start));

        // 让 sum 参与判断，防止 JIT 把整个循环当作无用代码优化掉
        if (sum < 0) {
            System.out.println(sum);
        }
    }
}
```

**编译与运行：**

```bash
javac -encoding UTF-8 MathDemo.java
java MathDemo
```

**运行结果（本机实测，随机数与耗时每次不同）：**

```
绝对值 abs(-9.8) = 9.8
随机数 random() [0,1) = 0.0280737
四舍五入 round(2.68) = 3
最大值 max(10,20) = 20
2的3次幂 pow(2,3) = 8.0
当前日期：2026-10-28
当前时间：19:27:33.622
当前日期+时间：2026-10-28T19:27:33.622
年份：2026
月份：10
日期：28
执行一百万次累加的耗时（毫秒）是：6
```

### 3.4 变体与追问

- **静态导入的等价写法**：不写 `import static`，改为 `Math.abs(...)`、`Math.random()` 等，效果一样。静态导入只是省掉类名，**不推荐导入 `*` 之外的歧义场景**（若两个类有同名静态方法会编译报错）。
- **时间格式化**：`DateTimeFormatter` 是线程安全的；而老的 `SimpleDateFormat` 不是。`HH` 是 24 小时制，`hh` 是 12 小时制。
- **时间戳用途**：`System.currentTimeMillis()` 适合做毫秒级计时；要更高精度可用 `System.nanoTime()`（它只适合算差值，不代表真实时间）。
- **耗时可能为 0**：现代 JVM 对 100 万次简单累加只需几毫秒，甚至可能显示 0，属正常现象，不是代码错误。

## 小结：三道题的共同主线

1. **包（package）决定物理目录**，`import` 解决「跨包用类」——题目一、二的核心；
2. **访问修饰符决定可见范围**，`public` / 默认 / `private` 的边界要能背下来——题目二的核心；
3. **`import static` + `java.time` + `System.currentTimeMillis()`** 是常用 API 的组合使用——题目三的核心。

三份代码都可以直接复制到 IDE 中运行；提交作业前记得把**包名、目录结构、文件名**三者核对一致。
