# 访问修饰符有哪些

> **一句话**：Java 的修饰符分两拨 —— ==管"能不能访问"的**访问修饰符**只有 4 种==（`private`、默认、`protected`、`public`），==其余全是**非访问修饰符**==（`static`、`final`、`abstract` 等），它们管的是"性质"而不是"权限"。

## 一、先分清两类修饰符

很多人把 `static`、`final` 也叫成"访问修饰符"，其实不是。以 `public static void main` 为例：

```java
public static void main(String[] args) { }
//  ↑         ↑
// 访问修饰符  非访问修饰符
```

| 大类                              | 作用                | 有哪些                                                                          |
| ------------------------------- | ----------------- | ---------------------------------------------------------------------------- |
| **访问修饰符**（Access Modifier）      | 控制==可见范围/访问权限==   | `private`、默认、`protected`、`public`（共 **4** 种）                                 |
| **非访问修饰符**（Non-Access Modifier） | 控制==性质/行为==，与权限无关 | `static`、`final`、`abstract`、`synchronized`、`volatile`、`transient`、`native` 等 |

> 所以问"访问修饰符有哪些"，答案就是那 **4 种**。本笔记只讲这 4 种。

## 二、四种访问修饰符一览

| 修饰符 | 同类 | 同包 | 子类（跨包） | 任意类 |
| --- | --- | --- | --- | --- |
| `private` | ✅ | ❌ | ❌ | ❌ |
| 默认（不写，也叫包权限） | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

可见范围从小到大：

```
private  <  默认（包）  <  protected  <  public
```

> **记忆口诀**：==`private` 藏自己，默认藏外包，`protected` 给继承，`public` 全开放。==

## 三、四种各自能修饰什么

| 修饰符 | 可以修饰 | 说明 |
| --- | --- | --- |
| `private` | 类成员（字段、方法、构造器）、内部类 | ==不能修饰外部类== |
| 默认 | 类、成员 | 写外部类时只能用 `public` 或默认 |
| `protected` | 类成员、内部类 | ==不能修饰外部类== |
| `public` | 类、成员 | 一个 `.java` 文件里最多一个 `public` 类 |

要点：
- **顶层类**只有 `public` 和"默认"两种选择，详见 [[class跟public class.md]]。
- `protected` 的细节（跨包子类的规则）见 [[protected关键字.md]]。

## 四、一句话回答

> ==Java 的访问修饰符一共 **4 种**：`private`、默认（包权限）、`protected`、`public`。==
