# 基础

这阶段不背命令，而是把“拉镜像、起容器、看日志、进容器、清理”跑顺，知道每步动了什么。

```bash
docker pull nginx
docker run -d --name web -p 8080:80 nginx
docker ps
docker logs -f web
docker exec -it web sh
docker stop web && docker rm web
```

`-d` 后台运行；`-p 8080:80` 把宿主机 8080 转到容器 80；`--name` 给容器命名。`logs -f` 跟 stdout/stderr，`exec -it` 在已有容器的命名空间里再开一个进程，不是登录虚拟机。`stop` 先 SIGTERM，10 秒后 SIGKILL；`rm` 连可写层一起删。

构建一个最小镜像，看清镜像和容器的分界：

```dockerfile
FROM nginx:alpine
COPY index.html /usr/share/nginx/html/index.html
```

```bash
docker build -t my-web .
docker run -d -p 8080:80 my-web
```

`FROM` 指定基础层，`COPY` 新增一层，`-t` 给镜像起名字。

需要记住的对象只有四个：

| 对象 | 一句话 | 常用命令 |
| --- | --- | --- |
| 镜像 | 只读模板，由层叠加 | `pull` `build` `images` `rmi` |
| 容器 | 镜像加可写层和隔离 | `run` `ps` `logs` `exec` `rm` |
| 卷 | 生命周期独立的存储 | `volume create` `volume ls` |
| 网络 | 容器之间的虚拟网络 | `network create` `network inspect` |

后面 [[00-Docker 命令行|Docker 命令行]] 按这四类展开，[[00-运行容器|运行容器]] 讲 run 和 compose 怎么选，[[00-数据持久化|数据持久化]] 讲卷和绑定挂载。遇到 `port is already allocated`，多半是宿主机端口被占，用 `docker ps` 和 `ss -lntp` 一起看。
