
> **适用对象**：已学过 3.1 集合的概念、子集与相等，知道"集合由元素确定"、`A = B ⟺ A ⊆ B 且 B ⊆ A` 的同学；本篇为课堂笔记主体，面向期末复习与习题逐个击破。

## 零、动机：从"单个集合"到"集合间的运算"

3.1 我们认识了集合这个"容器"：它有元素、有大小关系（`⊆`）、有相等关系（`=`）。但到目前为止，我们只是在**描述**集合，还没有**制造**集合。

本节要回答的问题是：

> 给定若干已知集合，能不能按照一套确定的规则，**造出新的集合**？这些新集合与原来的集合有什么关系？

这个"规则"就是**运算**。日常算术里 `+` 是两个数造出第三个数；集合运算则是"两个（或一个）集合造出第三个集合"。==关键在于：集合运算的结果必须由原集合的元素情况完全决定，规则要能写成"对任意元素 x 的判断条件"。==

因此，本节所有定义都会长成一个模板：

```
A 与 B 做某种运算 = { x | P(x) }     其中 P(x) 是一个用 ∈ 和逻辑联结词写的判断条件
```

而这里的逻辑联结词，正是 C1 命题逻辑里的 `∨`、`∧`、`¬`、`⊕`（以及 C2 的 `∀`）。==集合运算律与命题逻辑等值式几乎是同一张表的两副面孔==，这个"对偶"是本节最省力的记忆线索。

> **记忆钩子**：集合运算 = "把逻辑联结词翻译成集合"，`∪` 对应 `∨`、`∩` 对应 `∧`、`~` 对应 `¬`、`⊕` 对应"异或"。看到集合运算律记不住，就去 C1 找对应的等值式。

## 一、并集 `A ∪ B` 与交集 `A ∩ B`

### 1.1 为什么会先有这两个

并和交是"最自然"的两个运算，因为我们判断一个元素属不属于结果，只需要问两个"是/否"问题，再用"或者"、"并且"把它们连起来。这就是命题逻辑里最简单的两个联结词，也是所有复合判断的起点。

- "至少属于其中一个" → 或者 → 析取 → 并集
- "同时属于两个" → 并且 → 合取 → 交集

### 1.2 严格定义

**定义（并集）**：设 `A`、`B` 是任意两个集合，称

```
A ∪ B = { x | x ∈ A ∨ x ∈ B }
```

为 `A` 与 `B` 的**并集**。即：==`x ∈ A ∪ B` 当且仅当 `x ∈ A` 或 `x ∈ B`==（这里的"或"是**可兼或**，两者都成立也算）。

**定义（交集）**：设 `A`、`B` 是任意两个集合，称

```
A ∩ B = { x | x ∈ A ∧ x ∈ B }
```

为 `A` 与 `B` 的**交集**。即：==`x ∈ A ∩ B` 当且仅当 `x ∈ A` 且 `x ∈ B`==。

两者都是"外向"定义，不依赖任何具体元素是什么，所以对任何集合都成立。

### 1.3 由定义直接得到的性质

| 编号 | 性质 | 直觉解释 |
| --- | --- | --- |
| 幂等律 | `A ∪ A = A`，`A ∩ A = A` | 自己和自己运算没有新信息 |
| 交换律 | `A ∪ B = B ∪ A`，`A ∩ B = B ∩ A` | 题目顺序无关，`∨`/`∧` 可交换 |
| 结合律 | `(A ∪ B) ∪ C = A ∪ (B ∪ C)` | 三个以上并/交可以省括号 |
| 分配律 | `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` | 交对并可分配 |
| 分配律（对偶） | `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)` | 并对交也可分配（算术里没有！） |
| 吸收律 | `A ∪ (A ∩ B) = A`，`A ∩ (A ∪ B) = A` | "大吃了小的" |
| 同一律 | `A ∪ ∅ = A`，`A ∩ E = A` | ∅ 是并的单位元，E 是交的单位元 |
| 零元律 | `A ∪ E = E`，`A ∩ ∅ = ∅` | E 是并的零元，∅ 是交的零元 |
| 包含关系 | `A ∩ B ⊆ A ⊆ A ∪ B` | 交最小、并最大 |

> **⚠️ 易错警告**：算术里的分配律只有 `×` 对 `+` 成立，而集合里 ==并、交**互相**都可分配==。这是集合运算与算术最大的不同，也常常是化简题的关键一步。

### 1.4 两个"从属"概念（只作了解）

- **不相交（互斥）**：若 `A ∩ B = ∅`，称 `A` 与 `B` 不相交。
- **一般化**：`n` 个集合的并 `A₁ ∪ A₂ ∪ … ∪ Aₙ` 表示"至少属于其中一个"，交表示"全部都属于"；这两个记号在 3.3 容斥原理里会大量使用。

> **口诀**：并集是"沾边就算"，交集是"都有才算"。

## 二、相对补（差集）`A − B` 与绝对补 `~A`

### 2.1 动机

判断"属于 A"我们已经会用 `∨`、`∧` 组合了。剩下的两种基本判断是：
- "属于 A 但**不**属于 B" —— 这是**否定**加上"并且"；
- "**不**属于 A" —— 这是纯粹的否定。

前者就是差集，后者就是补集。==补运算的本质是"取反"，它必须有一个参照系，这个参照系就是全集 `E`。==

### 2.2 严格定义

**定义（相对补 / 差集）**：设 `A`、`B` 是集合，称

```
A − B = { x | x ∈ A ∧ x ∉ B }
```

为 `A` 与 `B` 的**差集**（也称 `B` 对 `A` 的相对补）。

**定义（绝对补）**：设 `E` 是全集，`A ⊆ E`，称

```
~A = E − A = { x | x ∈ E ∧ x ∉ A }
```

为 `A` 的**绝对补**（也记作 `Aᶜ`、`Ā`）。由于 `x ∈ E` 恒真，通常简写成

```
~A = { x | x ∉ A }
```

> **⚠️ 易错警告**：`A − B` 与 `B − A` ==一般不等==（差运算不满足交换律）。例如 `A = {1, 2}`、`B = {2, 3}`，则 `A − B = {1}` 而 `B − A = {3}`。
>
> **⚠️ 易错警告**：`~A` 必须**先有全集 E**才有意义。同一个集合 `A`，在 `E = {1,2,3}` 下与在 `E = {1,2,3,4}` 下补集不同。做题时若题目给了全集，补运算一律按给定全集算。

### 2.3 差集与补集的关系

差集可以完全用交和补表示，这一步把"三种运算"压缩成"两种运算"，是化简的核心工具：

==`A − B = A ∩ ~B`==

（证明：`x ∈ A − B ⟺ x ∈ A ∧ x ∉ B ⟺ x ∈ A ∧ x ∈ ~B ⟺ x ∈ A ∩ ~B`。这就是元素法的最小范例。）

于是本节所有的运算，最终都可以只保留 `∪`、`∩`、`~` 三种（`⊕` 也能由这三种表示，见下节）。

### 2.4 补集与差集的性质

| 编号 | 性质 | 备注 |
| --- | --- | --- |
| 双重否定 | `~~A = A` | 补两次回到原样 |
| 补的边界 | `~∅ = E`，`~E = ∅` | 空集与全集互为补 |
| 排中律 | `A ∪ ~A = E` | 任何元素要么在 A 要么不在 |
| 矛盾律 | `A ∩ ~A = ∅` | 不可能既在又不在 |
| 德摩根律 | `~(A ∪ B) = ~A ∩ ~B` | 补进括号，并变交 |
| 德摩根律（对偶） | `~(A ∩ B) = ~A ∪ ~B` | 补进括号，交变并 |
| 差集展开 | `A − B = A ∩ ~B` | 最常用的化归 |
| 差集与包含 | `A − B = ∅ ⟺ A ⊆ B` | 判断包含关系的好工具 |
| 对合差 | `A − (A − B) = A ∩ B` | 见练习题 |
| 分配型 | `(A − B) ∩ C = (A ∩ C) − (B ∩ C)` | 差对交可分配 |

> **记忆钩子（德摩根）**："去括号，变符号"——看到 `~` 从左往右跨过 `∪`/`∩` 时，==`~` 分发给每个集合，`∪` 与 `∩` 互换==。这与 C1 里 `¬(p ∨ q) ⇔ ¬p ∧ ¬q` 完全同形。

## 三、对称差 `A ⊕ B`

### 3.1 动机

并集有个"缺点"：`A ∪ B` 里，同时属于两边的元素被"合并"了，你无法从结果反推它在哪边。如果我们想要一个"只保留单边贡献、抵消公共部分"的运算，就需要**对称差**。

直观上：==对称差 = 并集挖掉交集 = "至多属于两者之一"==。它正是逻辑里的**异或**（`p ⊕ q`）。

### 3.2 严格定义

**定义（对称差）**：设 `A`、`B` 是集合，称

```
A ⊕ B = (A − B) ∪ (B − A)
```

为 `A` 与 `B` 的**对称差**。等价形式有：

```
A ⊕ B = (A ∪ B) − (A ∩ B)
A ⊕ B = (A ∩ ~B) ∪ (~A ∩ B)
```

用元素判断写出来是：

```
x ∈ A ⊕ B ⟺ (x ∈ A 而 x ∉ B) 或 (x ∉ A 而 x ∈ B)
```

即 ==`x ∈ A ⊕ B` 当且仅当 "x ∈ A" 与 "x ∈ B" 恰好一个成立==。

### 3.3 性质

| 编号 | 性质 | 备注 |
| --- | --- | --- |
| 交换律 | `A ⊕ B = B ⊕ A` | 由定义中两边对称可见 |
| 结合律 | `(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)` | 可以省括号，是"异或"的奇偶性 |
| 自反（消去） | `A ⊕ A = ∅` | 自己和自己抵消 |
| 单位元 | `A ⊕ ∅ = A` | ∅ 是零对称差单位元 |
| 与全集 | `A ⊕ E = ~A` | 与全集对称差等于取补 |
| 与补 | `A ⊕ ~A = E` | 注意区别于 `A ⊕ A = ∅` |
| 交对对称差分配 | `A ∩ (B ⊕ C) = (A ∩ B) ⊕ (A ∩ C)` | 对称差唯一的分配律 |
| 与并的关系 | `A ∪ B = (A ⊕ B) ∪ (A ∩ B)` | 并 = 对称差 ∪ 交 |
| 与差的关系 | `A ⊕ B = (A − B) ⊕ (B − A)` | 两半不相交 |

> **⚠️ 易错警告**：`A ⊕ B` 与 `A ∪ B` 只在 `A ∩ B = ∅` 时相等。若题目没说两集合不相交，==千万不要把 `⊕` 随手写成 `∪`==。
>
> **记忆钩子**：对称差是"奇数次出现的元素留下"——`A ⊕ B ⊕ C` 恰好保留在 A、B、C 中出现次数为奇数的元素。用"奇偶性"想，结合律、`A ⊕ A = ∅` 都变得理所当然。

## 四、集合运算律总表

下表把并、交、补、对称差的运算律集中罗列，==左右两列互为对偶==（把 `∪` 与 `∩` 互换、`E` 与 `∅` 互换，等式仍成立）。背诵时只背一列，另一列对偶写出来即可。

| 名称 | 并 / 交形式（左） | 对偶形式（右） |
| --- | --- | --- |
| 幂等律 | `A ∪ A = A` | `A ∩ A = A` |
| 交换律 | `A ∪ B = B ∪ A` | `A ∩ B = B ∩ A` |
| 结合律 | `(A ∪ B) ∪ C = A ∪ (B ∪ C)` | `(A ∩ B) ∩ C = A ∩ (B ∩ C)` |
| 分配律 | `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)` | `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)` |
| 德摩根律 | `~(A ∪ B) = ~A ∩ ~B` | `~(A ∩ B) = ~A ∪ ~B` |
| 吸收律 | `A ∪ (A ∩ B) = A` | `A ∩ (A ∪ B) = A` |
| 同一律 | `A ∪ ∅ = A` | `A ∩ E = A` |
| 零元律 | `A ∪ E = E` | `A ∩ ∅ = ∅` |
| 排中律 | `A ∪ ~A = E` | — |
| 矛盾律 | — | `A ∩ ~A = ∅` |
| 双重否定 | `~~A = A` | （补运算自身） |
| 补的边值 | `~∅ = E` | `~E = ∅` |

对称差补充表（不参与并/交对偶）：

| 名称 | 等式 |
| --- | --- |
| 交换律 | `A ⊕ B = B ⊕ A` |
| 结合律 | `(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)` |
| 幂等抵消 | `A ⊕ A = ∅` |
| 单位元 | `A ⊕ ∅ = A` |
| 与全集 | `A ⊕ E = ~A` |
| 分配律 | `A ∩ (B ⊕ C) = (A ∩ B) ⊕ (A ∩ C)` |

> **核心口诀**：==并、交、补构成一个"分配格"，运算律与命题逻辑等值式一一对应==。补运算的作用是把并变交、把 E 变 ∅，这就是对偶的对偶。

### 常用恒等式速记（化简必备）

```
A − B = A ∩ ~B
A − B = A − (A ∩ B)
A − (B ∪ C) = (A − B) ∩ (A − C)
A − (B ∩ C) = (A − B) ∪ (A − C)
(A ∪ B) − C = (A − C) ∪ (B − C)
(A ∩ B) − C = (A − C) ∩ (B − C)
~A − ~B = B − A
A ⊕ B = (A ∪ B) ∩ ~(A ∩ B)
```

> **⚠️ 易错警告**：`A − (B ∪ C) = (A − B) ∩ (A − C)` 里，==减号"分配"进去时并要变交、交要变并==，和德摩根律同一个道理（因为 `A − X = A ∩ ~X`，再套德摩根）。写错方向是本章最高频的失分点。

## 五、集合恒等式的证明方法

### 5.1 三种方法定位

| 方法 | 严格性 | 适用场景 | 缺点 |
| --- | --- | --- | --- |
| 元素法 | 严格 | 一切恒等式，尤其是含差、补的 | 步骤长，容易漏方向 |
| 恒等变形法 | 严格 | 表达式化简、式子规整的恒等式 | 需要熟记运算律 |
| 文氏图法 | 仅辅助 | 快速验证猜想、找反例 | 不能作为证明（图上分区域有限） |

### 5.2 方法一：元素法（万能药）

**要证 `A = B`，等价于证两个包含关系**（或直接证双向隶属）：

```
∀x,  x ∈ A ⟺ x ∈ B
```

**标准套路**：

1. 任取（设）`x` 为论域中任意元素，"不妨设 `x ∈ 左端`"；
2. 用定义把 `∈ 左端` 逐层翻译成关于 `x ∈ A`、`x ∈ B`、… 的逻辑表达式；
3. 用命题逻辑等值演算（分配、德摩根、吸收等）把它化成 `∈ 右端` 的逻辑表达式；
4. 由于 `x` 任意，得证。

**范例 1**：证明 `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`。

```
对任意 x：
  x ∈ A ∩ (B ∪ C)
⟺ x ∈ A ∧ (x ∈ B ∨ x ∈ C)          （交集、并集定义）
⟺ (x ∈ A ∧ x ∈ B) ∨ (x ∈ A ∧ x ∈ C)  （∧ 对 ∨ 的分配律，C1 等值式）
⟺ x ∈ A ∩ B ∨ x ∈ A ∩ C              （交集定义）
⟺ x ∈ (A ∩ B) ∪ (A ∩ C)             （并集定义）
故 A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)。 ∎
```

注意第 3 步用的是**命题逻辑**的分配律，不是集合的——这正是"集合运算 = 逻辑运算"的体现。

**范例 2**：证明 `A − (B ∪ C) = (A − B) ∩ (A − C)`。

```
对任意 x：
  x ∈ A − (B ∪ C)
⟺ x ∈ A ∧ x ∉ B ∪ C
⟺ x ∈ A ∧ ¬(x ∈ B ∨ x ∈ C)
⟺ x ∈ A ∧ (x ∉ B ∧ x ∉ C)            （德摩根）
⟺ (x ∈ A ∧ x ∉ B) ∧ (x ∈ A ∧ x ∉ C)  （同一律/幂等）
⟺ x ∈ (A − B) ∧ x ∈ (A − C)
⟺ x ∈ (A − B) ∩ (A − C)              （交集定义）
∎
```

### 5.3 方法二：恒等变形法

从左端出发，逐步用运算律替换子表达式，直到等于右端。关键技巧：

1. **消灭差与对称差**：先把所有 `−`、`⊕` 用 `A − B = A ∩ ~B`、`A ⊕ B = (A ∪ B) ∩ ~(A ∩ B)` 换成 `∪ / ∩ / ~`。
2. **消灭补运算**：用德摩根把 `~` 尽量推到单个字母上（"补进到位"）。
3. **展开再合并**：用分配律展开，用吸收律、幂等律、排中/矛盾律合并同类项。
4. **观察目标形态**，决定是"外向内展开"还是"内向外提取"。

**范例 3**：化简 `(A ∪ B) ∩ (A ∪ ~B)`。

```
(A ∪ B) ∩ (A ∪ ~B)
= A ∪ (B ∩ ~B)        （并对交的分配律）
= A ∪ ∅               （矛盾律）
= A                   （同一律）
```

三步到位，比元素法短得多。

**范例 4**：化简 `A ∩ ~(B ∪ ~C) ∩ (B ∩ C)`。

```
~(B ∪ ~C) = ~B ∩ ~~C = ~B ∩ C         （德摩根 + 双重否定）
原式 = A ∩ (~B ∩ C) ∩ (B ∩ C)
     = A ∩ C ∩ (~B ∩ B)               （交换、结合）
     = A ∩ C ∩ ∅                       （矛盾律）
     = ∅                               （零元律）
```

### 5.4 方法三：文氏图法（只能辅助）

画两个（或三个）相交的圆，把全集分成若干互不重叠的区域，逐个区域检查算式的"覆盖情况"是否相同。

- **优点**：一眼看出恒等式真假，快速给出化简方向。
- **缺点**：==图中区域划分有限，无法覆盖一般情形，因此不是严格证明==；只能用于验证或找反例。
- **常见用法**：判断 `A − B`、`A ⊕ B` 等表达式对应哪些区域；给选择题"秒杀"。

> **做题建议**：考试中"证明题"一律用元素法或恒等变形法；文氏图只用来打草稿、找思路。

## 六、运算优先级与括号约定

当表达式里几种运算混在一起时，约定如下（与命题逻辑一致）：

1. **补运算 `~` 优先级最高**，紧贴它右侧的集合先补；
2. 其次 `∩`（交）；
3. 再次 `∪`（并）、`−`（差）、`⊕`（对称差），同级**从左到右**。

因此：

```
~A ∩ B         表示 (~A) ∩ B
A ∪ B ∩ C      表示 A ∪ (B ∩ C)
A − B ∪ C      表示 (A − B) ∪ C
```

> **建议**：==考试中不要依赖优先级，凡有多种解读可能的一律加括号==。尤其 `A ∪ B − C` 一定要写成 `(A ∪ B) − C` 或 `A ∪ (B − C)` 说明清楚。

**点到为止（了解）**：`(P(E), ∪, ∩)` 满足结合律、交换律、幂等律、分配律、吸收律，构成一个**分配格**；若把 `⊕` 作为运算，`(P(E), ⊕)` 构成一个**群**（单位元 `∅`，每个元素自逆）。这些代数结构属于后续代数系统章节的内容，此处只需知道"集合运算律漂亮是因为背后有结构"，不必展开。

## 七、例题

**例 1（化简）**：化简 `((A ∪ B) − B) ∪ (A ∩ B)`。

解：

```
(A ∪ B) − B = (A ∪ B) ∩ ~B = (A ∩ ~B) ∪ (B ∩ ~B) = (A ∩ ~B) ∪ ∅ = A ∩ ~B
原式 = (A ∩ ~B) ∪ (A ∩ B) = A ∩ (~B ∪ B) = A ∩ E = A
```

答：原式 `= A`。

**例 2（判断包含）**：判断 `(A − B) − C ⊆ A − (B − C)` 是否恒成立。

解：元素法。

```
x ∈ (A − B) − C ⟺ x ∈ A ∧ x ∉ B ∧ x ∉ C          … (1)
x ∈ A − (B − C) ⟺ x ∈ A ∧ ¬(x ∈ B ∧ x ∉ C)
                 ⟺ x ∈ A ∧ (x ∉ B ∨ x ∈ C)        … (2)
```

(1) 蕴含 (2)：若 `x ∈ A ∧ x ∉ B ∧ x ∉ C`，则取 (2) 中析取式的前支 `x ∉ B` 成立，故 (2) 成立。所以包含关系恒成立。反之不成立（取 `A = {1,2}`，`B = ∅`，`C = {2}`，则 `(A−B)−C = {1}`，`A−(B−C) = {1,2}`），故一般不等。

**例 3（证明恒等式）**：证明 `A ⊕ B = (A ∪ B) ∩ ~(A ∩ B)`。

解（恒等变形）：

```
(A ∪ B) ∩ ~(A ∩ B)
= (A ∪ B) ∩ (~A ∪ ~B)         （德摩根）
= [(A ∪ B) ∩ ~A] ∪ [(A ∪ B) ∩ ~B]   （分配律）
= (B ∩ ~A) ∪ (A ∩ ~B)         （吸收 + 矛盾律）
= (B − A) ∪ (A − B)           （差集定义）
= A ⊕ B                        （对称差定义） ∎
```

**例 4（文氏图辅助）**：用文氏图说明 `A − (B − C) ⊇ (A − B) ∪ (A ∩ C)`。把三圆划分的 8 个区域逐一核对即可发现等式两边覆盖的区域一致（实际上面这个包含其实是等式）。此处画图核对略，留作练习。

## 练习题

**🟢 基础题**

1. 设 `A = {1, 2, 3}`，`B = {2, 3, 4}`，`E = {1, 2, 3, 4, 5}`。求 `A ∪ B`、`A ∩ B`、`A − B`、`B − A`、`~A`、`A ⊕ B`。

2. 写出下列各式的含义并化简：`A ∩ ~A`；`A ∪ ~A`；`~∅`；`~~A`。

3. 判断正误并说明理由：(a) `A − B = B − A`；(b) `A ∩ B ⊆ A`；(c) 若 `A ∩ B = ∅`，则 `A ⊕ B = A ∪ B`。

**🟡 进阶题**

4. 用元素法证明 `A − (B ∪ C) = (A − B) ∩ (A − C)`。

5. 化简 `(A ∪ B) ∩ (A ∪ ~B) ∩ (~A ∪ B)`。

6. 证明 `(A − B) − C = A − (B ∪ C)`。

7. 设 `A ∩ B = ∅`，证明 `A ⊕ (B ∪ C) = (A ⊕ B) ⊕ (A ⊕ C)` 的反例与成立条件（提示：先展开 `A ⊕ X`）。

**🔴 挑战题**

8. 证明对称差的结合律：`(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)`。（提示：用 `A ⊕ B = (A ∪ B) ∩ ~(A ∩ B)` 化为 `∪ / ∩ / ~` 后整理，或说明"奇数隶属"这一特征。）

9. 证明 `A ⊕ E = ~A`，并由此求 `A ⊕ B ⊕ A` 的化简结果。

---

# 参考答案与详细解析

**1.** `A ∪ B = {1,2,3,4}`；`A ∩ B = {2,3}`；`A − B = {1}`；`B − A = {4}`；`~A = {4,5}`；`A ⊕ B = {1,4}`。

**2.** `A ∩ ~A = ∅`（矛盾律）；`A ∪ ~A = E`（排中律）；`~∅ = E`；`~~A = A`（双重否定）。

**3.** (a) 错。差集不满足交换律，`A − B` 与 `B − A` 一般不同，取 `A = {1}`、`B = {2}` 即可验证 `A − B = {1}`、`B − A = {2}`。(b) 对。`x ∈ A ∩ B ⟹ x ∈ A`，由子集定义即得。(c) 对。`A ⊕ B = (A ∪ B) − (A ∩ B) = (A ∪ B) − ∅ = A ∪ B`。

**4.** 对任意 `x`：

```
x ∈ A − (B ∪ C) ⟺ x ∈ A ∧ x ∉ B ∪ C
              ⟺ x ∈ A ∧ ¬(x ∈ B ∨ x ∈ C)
              ⟺ x ∈ A ∧ (x ∉ B ∧ x ∉ C)      （德摩根）
              ⟺ (x ∈ A ∧ x ∉ B) ∧ (x ∈ A ∧ x ∉ C)
              ⟺ x ∈ (A − B) ∧ x ∈ (A − C)
              ⟺ x ∈ (A − B) ∩ (A − C)
```

由 `x` 任意，两边相等。∎

**5.** 令 `X = (A ∪ B) ∩ (A ∪ ~B) = A ∪ (B ∩ ~B) = A`。于是

```
X ∩ (~A ∪ B) = A ∩ (~A ∪ B) = (A ∩ ~A) ∪ (A ∩ B) = ∅ ∪ (A ∩ B) = A ∩ B
```

答：`A ∩ B`。

**6.** 恒等变形：

```
(A − B) − C = (A ∩ ~B) ∩ ~C = A ∩ (~B ∩ ~C) = A ∩ ~(B ∪ C) = A − (B ∪ C)
```

其中第三步用了德摩根律 `~(B ∪ C) = ~B ∩ ~C`（反用）。∎

**7.** 先记 `A ⊕ X = (A ∪ X) ∩ ~(A ∩ X)`，且当 `A ∩ B = ∅` 时 `A ⊕ B = A ∪ B`。
取反例：`A = {1}`，`B = {2}`，`C = {3}`。左式 `A ⊕ (B ∪ C) = {1} ⊕ {2,3} = {1,2,3}`；右式 `(A ⊕ B) ⊕ (A ⊕ C) = {1,2} ⊕ {1,3} = {2,3}`（因为 `{1,2} ∩ {1,3} = {1}` 被对称差消去）。两者不等，故一般不成立。
注意到 `A` 在右式中出现两次会互相抵消，只有当 `A = ∅` 时右式才退化为 `B ⊕ C`，而左式为 `B ∪ C`，仍需 `B ∩ C = ∅`。故原式一般**不成立**，只能作为反例辨识题。

**8.** 记 `A ⊕ B = (A ∩ ~B) ∪ (~A ∩ B)`。关键观察：`x ∈ A ⊕ B ⊕ C` 当且仅当 `x` 在 `A、B、C` 中**恰好奇数次**隶属（1 次或 3 次）。

- `(A ⊕ B) ⊕ C`：`x` 先看它在 `A ⊕ B` 中的隶属奇偶，再与 `C` 异或，最终仍为"在 A、B、C 中总出现次数为奇数"。
- `A ⊕ (B ⊕ C)`：同理得到同一判据。

由于二者对每个 `x` 的判据完全相同，故相等。∎
（也可用 `A ⊕ B = (A ∪ B) ∩ ~(A ∩ B)` 展开，用分配律与德摩根把两边都化成不交并，工作量较大，此略。）

**9.** `A ⊕ E = (A ∪ E) ∩ ~(A ∩ E) = E ∩ ~A = ~A`。于是

```
A ⊕ B ⊕ A = (A ⊕ A) ⊕ B = ∅ ⊕ B = B
```

（用到交换律、结合律、`A ⊕ A = ∅`、`∅ ⊕ B = B`。）

## 附一：集合运算速查

### 1. 五种运算定义

| 运算 | 记号 | 定义式 | 一句话 |
| --- | --- | --- | --- |
| 并集 | `A ∪ B` | `{x \| x ∈ A ∨ x ∈ B}` | 至少属于一个 |
| 交集 | `A ∩ B` | `{x \| x ∈ A ∧ x ∈ B}` | 两个都属于 |
| 差集 | `A − B` | `{x \| x ∈ A ∧ x ∉ B}` | 属于 A 不属于 B |
| 补集 | `~A` | `E − A = {x \| x ∉ A}` | 全集里不属于 A |
| 对称差 | `A ⊕ B` | `(A − B) ∪ (B − A)` | 恰属于其中一个 |

### 2. 运算律总表（对偶记忆）

| 律 | 并/交 | 补 / 对称差 |
| --- | --- | --- |
| 幂等 | `A ∪ A = A`，`A ∩ A = A` | `A ⊕ A = ∅` |
| 交换 | `A ∪ B = B ∪ A` | `A ⊕ B = B ⊕ A` |
| 结合 | `(A ∪ B) ∪ C = A ∪ (B ∪ C)` | `(A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)` |
| 分配 | `A ∩ (B ∪ C) = (A∩B) ∪ (A∩C)` | `A ∩ (B ⊕ C) = (A∩B) ⊕ (A∩C)` |
| 德摩根 | `~(A ∪ B) = ~A ∩ ~B` | `~(A ∩ B) = ~A ∪ ~B` |
| 吸收 | `A ∪ (A ∩ B) = A` | `A ∩ (A ∪ B) = A` |
| 同一 | `A ∪ ∅ = A`，`A ∩ E = A` | `A ⊕ ∅ = A` |
| 零元 | `A ∪ E = E`，`A ∩ ∅ = ∅` | `A ⊕ E = ~A` |
| 排中/矛盾 | `A ∪ ~A = E`，`A ∩ ~A = ∅` | `A ⊕ ~A = E` |
| 双重否定 | `~~A = A` | `~∅ = E`，`~E = ∅` |

### 3. 高频恒等式

```
A − B = A ∩ ~B
A − B = A − (A ∩ B)
A − (B ∪ C) = (A − B) ∩ (A − C)
A − (B ∩ C) = (A − B) ∪ (A − C)
~(A ∪ B) = ~A ∩ ~B
~(A ∩ B) = ~A ∪ ~B
A ⊕ B = (A ∪ B) − (A ∩ B)
A ⊕ B = (A ∪ B) ∩ ~(A ∩ B)
A ∪ B = (A ⊕ B) ∪ (A ∩ B)
A ⊆ B ⟺ A − B = ∅ ⟺ A ∪ B = B ⟺ A ∩ B = A
```

### 4. 化简四步法

1. 用 `A − B = A ∩ ~B` 消灭差、用展开式消灭对称差；
2. 用德摩根把 `~` 推到单个字母；
3. 用分配律展开、吸收律合并；
4. 用排中/矛盾律、同一/零元律清尾。
