# 翻译技能

## 目标笔记
- 翻译结果写入 `英语/翻译功能.md` 的「✍️ 译文库」区域，**按编号顺序追加**，不覆盖已有内容。
- 待翻译文本来源（按优先级）：
  1. `/翻译` 命令后直接跟随的文本（如 `/翻译 Today I learned...`）
  2. 笔记「🌐 翻译输入区」中用户写入的文本
  3. 对话中用户提及的文本

## 执行流程
1. 读取 `英语/翻译功能.md`，获取待翻译文本和现有译文编号
2. 判断翻译方向：
   - 英文 → 中文（默认）
   - 中文 → 英文（用户明确要求时）
3. 翻译并追加到译文库，编号接续现有最大编号
4. 翻译过的文本在输入区原文旁标记 ✅
5. 完成后用一句话总结（如"译文 #2 已生成"）

## 译文格式

```markdown
### 翻译 2
**原文**：The early bird catches the worm.
**译文**：早起的鸟儿有虫吃。
**关键表达**：
- the early bird → 早起者；早到的人
- catch the worm → （比喻）抢占先机
```

各字段规则：
- **原文**：保留原文（较长时保持原文完整）
- **译文**：通顺地道的译文，不逐字硬译；专业术语、人名地名用常见译法
- **关键表达**：2–5 条真正值得记的词组、句型、生词 → 释义；没有明显表达时可省略此字段

## 风格要求
- 长文本（整段/多段）：先给全文译文，再附简要的逐段对照（每段 1–2 句概括，不重复全译）
- 生词不必在译文库里展开词条——若用户想细查，引导其用 /查词
- 不修改用户已有的译文和输入内容，只追加和打 ✅
