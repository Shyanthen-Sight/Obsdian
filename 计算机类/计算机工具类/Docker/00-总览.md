## 先跑通一个最小闭环

概念看累了就动手，下面四条命令覆盖了拉镜像、端口映射、看日志、清理：

```bash
docker run -d --name web -p 8080:80 nginx:1.27
curl -I http://localhost:8080
docker logs --tail 20 web
docker rm -f web
```

镜像名后面的 `1.27` 是 tag，`-p 8080:80` 把宿主机端口转到容器端口。跑通之后，再回头理解 `docker run` 背后创建了哪些命名空间，比空看概念有效。
