# Navicat 使用笔记

## 是什么

- Navicat 是**数据库图形化管理工具**（GUI 客户端），**不是数据库本身**
- 由香港公司 PremiumSoft 开发，支持 MySQL、MariaDB、PostgreSQL、SQL Server、Oracle、SQLite 等
- 作用：用鼠标点选就能完成建库、建表、查数据、备份等操作，不用记命令行

## 和 MySQL 的关系：客户端 - 服务器

MySQL 和 Navicat 是 **C/S（客户端/服务器）架构**的两端，互相配合，谁也不能替代谁：

| | MySQL（服务器） | Navicat（客户端） |
| --- | --- | --- |
| 角色 | 真正干活的数据库引擎 | 图形化操作界面 |
| 数据 | 真实存储在磁盘上 | 不存任何数据 |
| 做的事 | 执行 SQL、管理数据 | 把鼠标操作翻译成 SQL，展示结果 |
| 运行方式 | 后台服务，监听 3306 端口 | 需要时打开，随时可关 |

- 连接流程：Navicat 通过网络协议连接 `localhost:3306`，把 SQL 发给 MySQL 执行，再把结果画成表格给你看
- 类比：MySQL 是**发动机/仓库**，Navicat 是**仪表盘/前台**；命令行 `mysql -u root -p` 则是"手摇启动"——同一台发动机，换不同的操作方式而已
- 一个 MySQL 可以同时被多个客户端连接（Navicat、命令行、你的代码程序都行）
- 佐证：同一套 Navicat 还能连 PostgreSQL、SQL Server 等——它是"通用遥控器"，MySQL 才是"电视机"本身

## 常见版本

| 版本 | 说明 |
| --- | --- |
| Navicat Premium | 支持所有数据库，最常用 |
| Navicat for MySQL | 只支持 MySQL，更便宜 |

- 收费软件，试用期约 14 天
- 免费替代品：**MySQL Workbench**（官方免费）、**DBeaver**（开源免费）

## 连接 MySQL

1. 官网 navicat.com 下载安装（Windows 选 Windows x64 版本）
2. 打开后点左上角 **连接 → MySQL**
3. 填写连接信息：
   - 连接名：随便起，如"本地MySQL"
   - 主机：`localhost`（或 `127.0.0.1`）
   - 端口：`3306`（MySQL 默认端口）
   - 用户名：`root`
   - 密码：安装 MySQL 时设置的密码
4. 点 **测试连接**，提示成功后再点确定

## 常用操作

| 想做什么 | 怎么做 |
| --- | --- |
| 新建数据库 | 右键连接 → 新建数据库 → 填名字，字符集选 `utf8mb4` |
| 新建表 | 右键数据库 → 新建表 → 添加字段 |
| 查看 / 编辑数据 | 双击表名，直接点单元格修改 |
| 写 SQL | 点 **查询 → 新建查询**，输入 SQL 后点"运行" |
| 导入数据 | 右键表 → 导入向导（支持 CSV / Excel 等） |
| 导出数据 | 右键表 → 导出向导 |
| 备份数据库 | 右键数据库 → 备份 → 新建备份 |

## 字段类型速查

- `INT`：整数
- `VARCHAR(n)`：可变长度字符串（n 是最大字符数）
- `TEXT`：长文本
- `DATETIME`：日期时间
- `DECIMAL(p,s)`：小数（金额用这个，别用 FLOAT，避免精度问题）
- 每个表至少一个**主键**，通常用自增的 `id`

## 常见问题

- 连不上：先确认 MySQL 服务已启动（任务管理器 → 服务里找 MySQL，或 `net start mysql`）
- 报错 2003：一般是 MySQL 没启动或端口被改
- 忘记 root 密码：以管理员权限用 `mysqld --skip-grant-tables` 重置
