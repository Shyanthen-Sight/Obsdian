# Car Merchant 项目完整详解

> [!abstract] 一句话
> Car Merchant 是一个用 ==Vue 3 + TypeScript + Vite + Vue Router== 写的汽车租赁展示项目，只有**首页**和**租车页**两个页面，却把 Composition API、父子通信、`v-model`、路由、`ref` / `computed` / `watch` 这些核心知识点串了一遍。本笔记按「架构 → 组件通信 → 状态与流程 → 语法样式」拆成若干子笔记。

---

## 一、项目概况

Car Merchant 是一个基于 Vue 3、TypeScript、Vite 和 Vue Router 实现的汽车租赁展示项目。

项目目前包含两个主要页面：

- **首页**：展示视频背景、项目标题和进入租车页面的入口。
- **租车页面**：展示车辆列表，支持按价格区间和车辆类型筛选，并支持添加、选择和删除车辆。

> [!info] 适合学习哪些 Vue 知识
> - Vue 3 Composition API
> - `<script setup>` 语法
> - `ref`、`computed`、`watch`
> - 父子组件通信
> - `props` 和 `emit`
> - `v-model` 双向绑定
> - `v-if`、`v-for`、`v-bind`、`v-on`
> - Vue Router 路由跳转
> - TypeScript 接口和联合类型
> - 组件化开发
> - CSS 作用域和 CSS 自定义变量
