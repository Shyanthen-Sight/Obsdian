# Java 类的声明

## 一句话解释

==**类的声明就是告诉编译器：我要造一个新的数据类型，它叫什么名字、从谁那里继承、肚子里面装哪些成员。**==

类是一个模板，声明只是把模板画出来；==真正跑起来的是用 `new` 造出来的对象（实例）==。

---

## 一、最完整的语法结构

```java
[修饰符] class 类名 [extends 父类] [implements 接口1, 接口2] {
    // 类体：成员变量 + 方法 + 构造方法 + 初始化块 + 嵌套类
}
```

用方括号括起来的部分都是==可选的==，只有 `class 类名 { }` 是必须的。所以最短的类声明是：

```java
class A { }        // 合法，只是什么都没装
```

---

## 二、逐段拆解

### 1. 修饰符

写在 `class` 关键字之前，可以有多个，顺序一般不影响编译。

| 修饰符        | 作用                  | 能否与 `public` 同用 |
| ---------- | ------------------- | --------------- |
| `public`   | ==任何包都能访问这个类==      | ——              |
| 默认（不写）     | 只有同一个包内能访问          | ——              |
| `abstract` | 抽象类，不能 `new`，用来被继承  | ✅               |
| `final`    | ==最终类，不能被继承==       | ✅               |
| `strictfp` | 浮点运算严格按 IEEE 754 执行 | ✅               |

```java
public abstract class Animal { }      // 对外公开的抽象类
final class Tool { }                  // 不允许被继承的工具类
```

> [!note] 注意
> 一个 `.java` 文件里==最多只能有一个 `public` 类==，且类名必须和文件名完全一致。没有 `public` 的类可以随便写几个。详细规则见 [[class跟public class]]。

### 2. 类名

- 必须符合标识符规则：<mark style="background: #FFB8EBA6;">字母、数字、`_`、`$` 组成</mark>，==不能以数字开头==，==不能是关键字==。

- 约定：==**大驼峰命名（PascalCase）**==，`StudentScore`、`OrderService`，不用 `student_score`。

- 类名要做到见名知意，最好是名词。

### 3. 继承与实现（可选）

```java
class 子类 extends 父类 implements 接口 {
    ...
}
```

| 关键字 | 数量限制 | 含义 |
| --- | --- | --- |
| `extends` | ==最多一个== | 继承父类，拿到父类非私有的成员 |
| `implements` | ==可以多个== | 承诺实现若干个接口的全部抽象方法 |

Java 是单继承，所以 `extends` 只能写一个；`implements` 后面用逗号分隔就能挂多个接口。

```java
class Dog extends Animal implements Runable, Swimmable { }
```

`extends` 和 `implements` 同时出现时，==`extends` 必须写在前面==，写反了直接编译报错。

### 4. 类体

一对 `{ }` 就是类体，里面可以装五样东西：

| 成员       | 说明                    | 示例                       |
| -------- | --------------------- | ------------------------ |
| 成员变量（字段） | 描述对象的状态               | `private String name;`   |
| 方法       | 描述对象的行为               | `public void eat() { }`  |
| 构造方法     | 创建对象时初始化，名字与类名相同、无返回值 | `Dog(String n) { }`      |
| 初始化块     | 每次创建对象时执行的代码块         | `{ count++; }`           |
| 嵌套类      | 定义在类里面的类              | `static class Order { }` |

一个都写不写也行（空类合法），但通常至少要有字段和构造方法。

## 三、一个完整的例子

```java
package com.example.demo;                 // 包声明（类的声明之外，但写在文件开头）

public class Student extends Person implements Comparable<Student> {

    // 1. 成员变量
    private String name;
    private int score;

    // 2. 构造方法
    public Student(String name, int score) {
        this.name = name;
        this.score = score;
    }

    // 3. 方法
    public void show() {
        System.out.println(name + " : " + score);
    }

    // 4. 重写接口方法
    @Override
    public int compareTo(Student other) {
        return Integer.compare(this.score, other.score);
    }
}
```

逐段对应上面的语法：

- `public` → 修饰符，本类对外公开
- `Student` → 类名，大驼峰
- `extends Person` → 继承一个父类
- `implements Comparable<Student>` → 实现一个接口
- `{ ... }` → 类体，里面装了字段、构造方法、方法

## 四、常见声明形式对照

| 写法                     | 含义                  | 使用场景            |
| ---------------------- | ------------------- | --------------- |
| `class A { }`          | 包权限的普通类             | 只在本包内使用的辅助类     |
| `public class A { }`   | 公开类，文件名必须是 `A.java` | 对外暴露的类          |
| `abstract class A { }` | 抽象类，不能直接 `new`      | 作为父类被继承         |
| `final class A { }`    | 最终类，不能被继承           | 工具类、`String` 这类 |
| `static class A { }`   | ==只用于嵌套类==，不能修饰顶层类  | 定义在别的类内部的静态嵌套类  |
| `interface A { }`      | 接口，不是类              | 定义行为契约          |

> [!warning] 最容易踩的坑
> `static` 只能修饰==嵌套类==。写成 `static class A {}` 放到文件顶层，编译器直接报错。

---

## 五、注意事项

1. **顶层类的修饰符只有 `public` 和默认两种**。`private`、`protected` 只能用在==嵌套类==上，顶层类写了会报错。
2. **类名和文件名**：`public` 类必须同名；`class` 类可以不同名，但编译出来的是 `类名.class`。
3. **一个文件一个 `public` 类**，其余辅助类只能是不带 `public` 的。
4. **`extends` 在前、`implements` 在后**，写反编译不过。
5. **声明 ≠ 实例化**。上面的代码只是声明，`new Student(...)` 才是创建对象。

```java
Student s = new Student("小明", 90);   // 声明 + 实例化
s.show();
```

---

## 六、一句话总结

> ==**`[修饰符] class 类名 [extends 父类] [implements 接口] { 类体 }` —— 修饰符管权限，类名管标识，继承接口管关系，类体管内容。**==
