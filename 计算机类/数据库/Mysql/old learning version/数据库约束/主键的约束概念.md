## 一、建表时添加主键（两种写法）

### 1. 列级模式（单字段主键）

直接在字段后声明，仅支持**单个字段**做主键
```sql
create table 表名称( 
字段名 数据类型 primary key 
);
```
示例：
```sql
create table emp( 
id int primary key, 
name varchar(20) 
);
```
### 2. 表级模式（单主键 / 联合复合主键）

写在所有字段定义下方，支持**多字段联合主键**，可选自定义约束名
```sql
create table 表名称( 
字段名1 数据类型, 
字段名2 数据类型, 
[constraint 约束名] primary key(字段名1[,字段名2...]) 
);
```
示例 1（单字段表级主键）：
```sql
create table emp( 
id int, name varchar(20), 
constraint pk_emp_id primary key(id) 
);
```
示例 2（联合复合主键，仅表级语法可用）：
```sql
create table student_course( 
sid int, cid int, 
primary key(sid,cid) -- 学生id+课程id组合唯一 
);
```
## 二、建表后追加主键

语法
```sql
ALTER TABLE 表名称 ADD PRIMARY KEY(字段列表);
```

示例：前置条件目标字段**无 NULL 数据**，否则添加失败。
```sql
-- 单字段追加主键 
alter table emp add primary key(id); 
-- 复合主键追加 
lter table student_course add primary key(sid,cid);
```
## 三、删除主键约束

语法
```sql
alter table 表名称 drop primary key;
```
## 四、主键核心特性总结

- 唯一性：主键字段值==全局唯一，不可重复==；
- 非空性：主键字段自动附带 `NOT NULL`，==不允许存 NULL==；
- 数量限制：单表仅能定义 1 组主键（可单字段、可多字段联合）；
- 索引底层：主键会自动创建聚簇索引，查询效率更高。
## 五、配套查询（结合你之前的 SQL）

查询某张表的主键约束信息：
```sql
SELECT * FROM INFORMATION_SCHEMA.TABLE_CONSTRAINTS 
WHERE TABLE_SCHEMA = 'test05_constraint' 
AND TABLE_NAME = 'emp3' 
AND CONSTRAINT_TYPE = 'PRIMARY KEY';
```
