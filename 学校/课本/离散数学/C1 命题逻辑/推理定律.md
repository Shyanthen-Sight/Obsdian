
> **适用对象**：学完等值演算、开始做"证明推理有效"题型的人
> **核心内容**：推理的形式结构、四种判定方法、推理规则（P / T / CP / 反证）、9 条推理定律、证明的规范写法与常见题型
> **使用建议**：9 条定律必须背熟（考场没时间现推）；规则里最常用的是 T 规则和 CP 规则，先练熟这两条
> 难度标记：🟢 基础 ｜ 🟡 进阶 ｜ 🔴 挑战

## 一、推理的形式结构

**定义**：设 A₁, A₂, …, Aₙ, B 都是命题公式。若

==(A₁ ∧ A₂ ∧ … ∧ Aₙ) → B==

是**重言式**，则称由前提 A₁, …, Aₙ 推出结论 B 的推理**正确（有效）**，B 是**有效结论**。

记作 ==A₁ ∧ A₂ ∧ … ∧ Aₙ ⇒ B==，简写 (A₁, …, Aₙ) ⇒ B。

**三条关键认知**：

1. 推理只管**形式**，不管内容真假。"前提真则结论必真"是唯一的判断标准。
2. **前提可以全是假的**——只要不出现"真前提推出假结论"，推理就是有效的。==有效 ≠ 结论为真。==
3. 前提集合若是**矛盾式**（永假），则任何结论都有效（前件永假，蕴含式恒真）。

> ⚠️ `⇒` 是**元语言**符号，表示两个公式之间的重言蕴含关系；`→` 是对象语言里的联结词，`A → B` 本身是个公式。二者不可混写。

---

## 二、判定方法

判 A₁ ∧ … ∧ Aₙ ⇒ B 有效，即判 (A₁∧…∧Aₙ) → B 是重言式。四条路：

| 方法 | 做法 | 适用 |
|:---|:---|:---|
| **真值表法** | 找出所有使前提全为真的赋值，检查这些行里 B 是否都为真 | 变元少（n ≤ 3） |
| **主析取范式法** | 求 (A₁∧…∧Aₙ)→B 的主析取范式，含**全部 2ⁿ 个极小项**即有效 | 交作业、要严格 |
| **等值演算法** | 把 (A₁∧…∧Aₙ)→B 逐步化简为 **1** | 式子简单 |
| **构造证明法** | 从前提出发，用推理规则一步步推出结论 | ==做题首选== |

> 真值表法的省力版：不必列全表，**只讨论"前提为真"的赋值**，看结论真不真。

## 三、推理规则

| 规则 | 名称 | 内容 |
|:---|:---|:---|
| **P 规则** | 前提引入 | 证明中随时可以引用题目给的前提 |
| **T 规则** | 结论引入 | 由前面已推出的公式推出新公式；用等值式替换也算 T |
| **CP 规则** | 附加前提 | 要证 A ⇒ (B → C)，可把 **B 当附加前提**先推出 C |
| **反证法** | 归谬 | 要证 A ⇒ B，把 **¬B 当附加前提**，推出矛盾（如 C ∧ ¬C） |

**依据**：

- CP 规则的依据是输出律 / 输入律：`A → (B → C) ⇔ (A ∧ B) → C`
- 反证法的依据是归谬论：`(A → B) ∧ (A → ¬B) ⇔ ¬A`

> 一句话记：**证蕴含用 CP，证不出用反证。** CP 用完记得把结论写成 `B → C` 的形式。
> 「附加前提」的完整套路、三个例子与易错点，见 ==六、题型 2==。

---

## 四、推理定律

九条，全部是**单向**的重言蕴含（只能 `⇒`，不能写 `⇔`）：

| 名称 | 推理定律 |
|:---|:---|
| 附加 | A ⇒ A ∨ B |
| 化简 | A ∧ B ⇒ A |
| 假言推理 | A ∧ (A → B) ⇒ B |
| 拒取式 | ¬B ∧ (A → B) ⇒ ¬A |
| 析取三段论 | ¬A ∧ (A ∨ B) ⇒ B |
| 假言三段论 | (A → B) ∧ (B → C) ⇒ A → C |
| 等价三段论 | (A ↔ B) ∧ (B ↔ C) ⇒ A ↔ C |
| 构造性二难 | (A → B) ∧ (C → D) ∧ (A ∨ C) ⇒ B ∨ D |
| 破坏性二难 | (A → B) ∧ (C → D) ∧ (¬B ∨ ¬D) ⇒ ¬A ∨ ¬C |

**对偶记忆**：构造性二难 ↔ 破坏性二难（`A∨C → B∨D` 换成 `¬B∨¬D → ¬A∨¬C`）。

**口决**：==假言推理"肯定前件"，拒取式"否定后件"。==

## 五、证明的写法

构造证明法统一用三列表格，**每一步都要写依据**（哪几条公式 + 什么定律）：

| 序号 | 公式 | 依据 |
|:---:|:---|:---|
| ① | A → B | P |
| ② | A | P |
| ③ | B | T ① ② 假言推理 |

**书写纪律**：

- 用到 16 组等值式时写"T ① 德摩根律"这种格式。
- 附加前提（CP / 反证）要明确标注"**附加前提**"。
- CP 成功后，最终结论必须**恢复成蕴含式** `B → C`。
- 推出矛盾（C ∧ ¬C 或 0）即刻结束，不必再推。

## 六、常见题型

### 题型 1｜直接证（前提、结论都是简单式）

> **题**：前提 p → q，q → r，p；结论 r。

| 序号 | 公式 | 依据 |
|:---:|:---|:---|
| ① | p → q | P |
| ② | q → r | P |
| ③ | p | P |
| ④ | q | T ① ③ 假言推理 |
| ⑤ | r | T ② ④ 假言推理 |

### 题型 2｜结论是蕴含式 → CP（附加前提）

**识别信号**：结论形如 `B → C`，或题目直接要求"证明 …… → ……"。有时结论表面不是蕴含式，等值改写后才是——如 `¬A ∨ B` ⇔ `A → B`，此时也可用 CP。

**附加前提是什么**：题目没给、自己**临时加进去**的前提，依据是输出律

```
A → (B → C)  ⇔  (A ∧ B) → C
```

即"要证 `B → C`，就把前件 `B` 拿来当已知，改证 `C`"。注意它与九条定律里的==附加律 `A ⇒ A ∨ B` 只是名字像，毫无关系==。

**固定三步**：

1. 把结论的**前件**作为附加前提写在第 ① 行，依据栏写"**附加前提**"（⚠️ 不能写 P）；
2. 用 P / T 规则推出结论的**后件**；
3. 最后一行依据写 **CP**，并把结论**恢复成 `B → C`**——这一步是"还债"，漏掉整题作废。

**例 1**：前提 ¬p ∨ q，¬q ∨ r；结论 p → r。

| 序号 | 公式 | 依据 |
|:---:|:---|:---|
| ① | p | **附加前提** ← 借来的 |
| ② | ¬p ∨ q | P |
| ③ | q | T ① ② 析取三段论 |
| ④ | ¬q ∨ r | P |
| ⑤ | r | T ③ ④ 析取三段论 |
| ⑥ | **p → r** | **CP ①—⑤** ← 还债 |

> **逐行看点**：③ 用 ① 剥掉 `¬p ∨ q` 的"¬p 壳"，⑤ 同理剥掉 `¬q ∨ r`；⑥ 把 ① 收回结论。② ④ 是题目给的前提，与 ① 的先后顺序不影响正确性。

**例 2（前件是合取）**：前提 ¬p ∨ r，¬q ∨ s；结论 (p ∧ q) → (r ∧ s)。

| 序号 | 公式 | 依据 |
|:---:|:---|:---|
| ① | p ∧ q | **附加前提** |
| ② | p | T ① 化简 |
| ③ | q | T ① 化简 |
| ④ | ¬p ∨ r | P |
| ⑤ | r | T ② ④ 析取三段论 |
| ⑥ | ¬q ∨ s | P |
| ⑦ | s | T ③ ⑥ 析取三段论 |
| ⑧ | r ∧ s | T ⑤ ⑦ 合取 |
| ⑨ | **(p ∧ q) → (r ∧ s)** | **CP ①—⑧** |

> 结论前件是合取时，附加进来先用**化简**拆成两个变元分别去用，别整个 `p ∧ q` 硬套。

**例 3（嵌套 CP）**：前提 p → q；结论 (r → p) → (r → q)。

| 序号 | 公式 | 依据 |
|:---:|:---|:---|
| ① | p → q | P |
| ② | r → p | **附加前提**（外层） |
| ③ | r | **附加前提**（内层） |
| ④ | p | T ② ③ 假言推理 |
| ⑤ | q | T ① ④ 假言推理 |
| ⑥ | r → q | **CP ③—⑤**（还内层） |
| ⑦ | **(r → p) → (r → q)** | **CP ②—⑥**（还外层） |

> 两层 CP 的关键是**从里往外逐层还债**：内层结论 `r → q` 先还完，才能对外层收尾。

**变体：结论是等价式 `A ↔ B`**：拆成两个蕴含——先 CP 证 `A → B`，再 CP 证 `B → A`，最后用等价等值式 `(A → B) ∧ (B → A) ⇔ A ↔ B` 合起来。

**本类题易错点**：

- 附加前提的依据栏写成 P（无依据引入前提，扣分）。
- 忘了最后一步 CP，或 CP 后结论没写成 `B → C`。
- 把附加前提当"已证事实"继续推别的结论——**CP 一还完，它就作废**。
- 与附加律 `A ⇒ A ∨ B` 混淆。
- 嵌套 CP 时内层还没还债就对外层收尾，顺序写乱。

### 题型 3｜正着推不动 → 反证

> **题**：前提 (p ∨ q) → r，¬r；结论 ¬p ∧ ¬q。

先取结论的否定 ¬(¬p ∧ ¬q) ⇔ p ∨ q 作附加前提：

| 序号 | 公式 | 依据 |
|:---:|:---|:---|
| ① | (p ∨ q) → r | P |
| ② | ¬r | P |
| ③ | p ∨ q | **附加前提**（反证） |
| ④ | r | T ① ③ 假言推理 |
| ⑤ | ¬r ∧ r（矛盾） | T ② ④ 合取 |

### 题型 4｜结论是析取式

常用**附加**把结论一项"补"出来，或配合**构造性二难**；实在不行套用 CP + 反证。

> 🔴 综合题往往需要"CP + 反证 + 三段论"混用，先定结论形状（合取 / 蕴含 / 析取 / 否定）再选策略。

## 七、易错点

- **有效 ≠ 结论为真**：前提假时推理照样有效，别拿内容对错判断。
- **`⇒` 不能当 `⇔` 用**：9 条定律反向都不成立。
- **T 规则必须写依据**：只写公式不写理由，通常不给分。
- **CP / 反证的附加前提要标注**，且 CP 最后别忘恢复成蕴含式。
- **别混淆两类目标**："证明 B 为真"和"证明 A ⇒ B 有效"是两件事。

---

## 八、一页速记

**推理的定义**：(A₁ ∧ … ∧ Aₙ) → B 是重言式 ⟺ A₁ ∧ … ∧ Aₙ ⇒ B。

**判定四法**：真值表 · 主析取范式 · 等值演算 · 构造证明（首选）。

**四条规则**：P 引入前提 · T 引入结论 · CP 加前提证蕴含 · 反证加否定找矛盾。

**九条定律**：附加 · 化简 · 假言推理 · 拒取式 · 析取三段论 · 假言三段论 · 等价三段论 · 构造性二难 · 破坏性二难。

**证明三招**：结论简单 → 直接推；结论是蕴含 → CP；推不出 → 反证。

---

## 九、出题

**用法**：先独立做，再展开折叠答案对照；每步**必须写出依据**，只写公式不给分。

### A 组 · 判断有效（🟢）

**1.** 前提 `p → q`、`p`；结论 `q`。

> [!example]- 答案
> 有效。假言推理——真值表中 `p → q` 与 `p` 同时为真的行里，`q` 必为真。

**2.** 前提 `p → q`、`q`；结论 `p`。

> [!example]- 答案
> **无效**。取 p 假、q 真，前提全真而结论假。==这是"肯定后件"，是最常见的假推理。==

**3.** 前提 `p ∨ q`、`p → r`、`q → r`；结论 `r`。

> [!example]- 答案
> 有效。用**构造性二难**：`(p → r) ∧ (q → r) ∧ (p ∨ q) ⇒ r ∨ r`，再由幂等律得 `r`。

### B 组 · 构造证明（🟡）

**4.** 前提 `p → q`、`q → r`、`r → s`；结论 `p → s`。

> [!example]- 答案
> 结论是蕴含式，用 CP：附加 `p` → 连续两次假言推理得 `s` → CP 收尾。
> 更省事：直接两次**假言三段论**。

**5.** 前提 `p ∨ q`、`p → r`、`q → s`；结论 `r ∨ s`。

> [!example]- 答案
> 前提正好凑成**构造性二难**的三个条件，一步出结论。

**6.** 前提 `p → (q → r)`、`p`、`¬r`；结论 `¬q`。

> [!example]- 答案
> ① `q → r`（T P 假言推理）；② `¬q`（T ① ¬r **拒取式**）。

**7.** 前提 `¬p ∨ q`、`¬q ∨ r`；结论 `p → r`。

> [!example]- 答案
> CP：附加 `p` → 由 `¬p ∨ q` 析取三段论得 `q` → 由 `¬q ∨ r` 析取三段论得 `r` → CP。

### C 组 · 综合（🔴）

**8.** 证明 `(p → q) ∧ (r → q) ⇒ (p ∨ r) → q`。

> [!example]- 答案
> CP：附加 `p ∨ r`。两个条件用**前件为 ∨**的等值式合成为 `(p ∨ r) → q`，再假言推理得 `q`，最后 CP 收尾。

**9.** 前提 `(p ∨ q) → r`、`¬r`；结论 `¬p ∧ ¬q`。

> [!example]- 答案
> **解法一（反证）**：附加 ¬(¬p ∧ ¬q) ⇔ `p ∨ q`，假言推理得 `r`，与 `¬r` 矛盾。
> **解法二（更省事）**：由 `(p ∨ q) → r` 与 `¬r` 用**拒取式**直接得 `¬(p ∨ q)`，再用**德摩根律**得 `¬p ∧ ¬q`。

**10.** 前提 `p → q`、`q → r`、`¬r ∨ s`、`p`；结论 `s`。

> [!example]- 答案
> ① `q`（假言推理）；② `r`（假言推理）；③ `s`（T ② ¬r ∨ s **析取三段论**）。

**出题套路**：九条定律就是出题模板——**把定律的前提当已知、结论当待证**，再往已知里掺冗余前提、把结论改写成蕴含（逼你用 CP）或用否定形式（逼你用反证），一道题就出来了。
