# SQL 完整学习计划

> [!info] 使用说明
> 这是一份从零到进阶的 SQL 学习路线，共 **4 个阶段**，建议总时长 **6～8 周**（每天 1～1.5 小时）。
> 每个阶段都有「学习目标 → 核心知识点 → 练习任务 → 验收标准」，学完即勾选。

---

## 总览：四阶段路线图

| 阶段 | 主题 | 建议时长 | 里程碑 |
| --- | --- | --- | --- |
| 第一阶段 | 基础查询（SELECT） | 1～2 周 | 能独立写出单表查询 |

## 第一阶段：基础查询（1～2 周）

### 学习目标
读懂一张表，并能从中按条件取出想要的数据。

### 核心知识点
- [ ] 数据库、表、行、列、字段类型等基本概念
- [ ] `SELECT` / `FROM` / `WHERE` 基本结构
- [ ] `WHERE` 条件：`=`, `<>`, `>`, `<`, `BETWEEN`, `IN`, `LIKE`, `IS NULL`
- [ ] `AND` / `OR` / `NOT` 逻辑组合与优先级
- [ ] `ORDER BY` 排序（`ASC` / `DESC`）
- [ ] `LIMIT` / `TOP` 限制返回行数
- [ ] `DISTINCT` 去重
- [ ] 别名 `AS` 的使用

### 练习任务
- [ ] 从 `employees` 表查出工资大于 8000 的员工姓名与工资
- [ ] 查询姓名以 "张" 开头的员工
- [ ] 按部门编号排序并只取前 10 条
- [ ] 完成 SQLZoo 的 SELECT basics / SELECT from world 全部题目

### 验收标准
> 给定一张表和一段中文需求，能独立写出单表 `SELECT` 查询并得到正确结果。

---

## 第二阶段：多表连接与聚合（1～2 周）

### 学习目标
把多张表"拼"起来分析，并做出分组统计。

### 核心知识点
- [ ] 聚合函数：`COUNT` / `SUM` / `AVG` / `MAX` / `MIN`
- [ ] `GROUP BY` 分组统计
- [ ] `HAVING` 对分组结果过滤（与 `WHERE` 的区别）
- [ ] 连接查询
  - `INNER JOIN`（内连接）
  - `LEFT JOIN` / `RIGHT JOIN`（外连接，重点理解空值）
  - 多表连接与连接条件
- [ ] 表的别名与自连接
- [ ] `UNION` / `UNION ALL` 合并结果集
- [ ] 常用函数：`ROUND`, `COALESCE`, 日期函数、字符串函数

### 练习任务
- [ ] 查询每个部门的平均工资，并按平均工资降序
- [ ] 查询每个部门人数超过 5 人的部门编号
- [ ] 用 `LEFT JOIN` 找出「没有任何订单的客户」
- [ ] 统计每个客户的下单总金额
- [ ] 完成 SQLZoo 的 JOIN / SUM and COUNT 章节

### 验收标准
> 能看懂 `WHERE → GROUP BY → HAVING → ORDER BY` 的执行逻辑，独立完成两表及以上的统计查询。

## 第三阶段：进阶特性（2 周）

### 学习目标
掌握子查询、窗口函数、建表修改等生产环境常用能力。

### 核心知识点
- [ ] 子查询
  - 标量子查询
  - `IN` / `EXISTS` 子查询
  - 相关子查询
- [ ] `CASE WHEN` 条件表达式
- [ ] 窗口函数（重点）
  - `ROW_NUMBER()` / `RANK()` / `DENSE_RANK()`
  - `PARTITION BY` 分组排名
  - `LAG` / `LEAD` 前后行
  - 移动平均、累计求和
- [ ] CTE：`WITH` 公共表表达式（可读性神器）
- [ ] 数据定义与修改（DDL / DML）
  - `CREATE TABLE` / `ALTER TABLE` / `DROP TABLE`
  - 主键、外键、索引基础
  - `INSERT` / `UPDATE` / `DELETE`
- [ ] 事务基础：`BEGIN` / `COMMIT` / `ROLLBACK`
- [ ] 查询优化入门：索引为什么快、`EXPLAIN` 初探

### 练习任务
- [ ] 用窗口函数查出每个部门工资最高的员工
- [ ] 用 `CASE WHEN` 把分数转成 "优/良/及格/不及格" 等级
- [ ] 用 CTE 分步骤拆解一个复杂查询
- [ ] 自己设计并建一张表，插入、更新、删除数据
- [ ] 完成 LeetCode 数据库中等难度题 10 道

### 验收标准
> 能用窗口函数和 CTE 解决"分组取 Top N""同比环比"等典型问题；能独立建库建表。

## 第四阶段：实战项目（2 周）

### 学习目标
把零散知识串成一个端到端的小项目，形成作品。

### 项目建议（任选一个）
- [ ] **电商销售分析**：基于订单/商品/用户表，分析销售额趋势、畅销商品、复购率
- [ ] **校园成绩分析**：基于学生/课程/成绩表，分析班级排名、及格率、分数分布
- [ ] **个人记账分析**：自建表记录收支，按月分类统计

### 项目要求
- [ ] 至少 3 张关联表
- [ ] 综合运用：多表连接 + 聚合 + 子查询 + 窗口函数 + CTE
- [ ] 输出 5～10 条有价值的分析结论
- [ ] 把关键 SQL 和结论整理成一篇笔记（可放到本 vault）

### 验收标准
> 能独立回答"这个业务问题该用什么 SQL 解决"，并写出结构清晰、可复用的查询。

## 学习方法建议

1. **动手优先**：看懂 ≠ 会写。每学一个语法点，立刻在数据库里敲一遍。
2. **先想后写**：拿到需求先用中文写出"分几步、每步干嘛"，再翻译成 SQL。
3. **重视执行顺序**：`FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT`，很多 bug 源于此。
4. **每日一题**：LeetCode / SQLZoo 每天 1 道，坚持比突击有效。
5. **记录错题**：把踩过的坑写进笔记，定期回看。
