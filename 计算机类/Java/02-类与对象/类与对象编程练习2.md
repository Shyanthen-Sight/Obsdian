## 第 1 题（填空题）

有主类定义如下：

```java
class TestOne {
    String s;
    int number;

    TestOne(String str, int n) {
        s = str;
        number = n;
    }

    String testFun() {
        String str = "";
        for (int i = 0; i < number; i++)
            str += s;
        return str;
    }

    public static void main(String args[]) {
        System.out.println(______________________);
    }
}
```

如果执行主类的输出文本是 `WooWooWooWooWoo!`，请填写 main 方法中缺失的代码。

> 提示：不要直接填写 `"WooWooWooWooWoo!"`，要求调用 TestOne 对象的实例方法 `testFun` 实现文本输出。

### 答案

```java
new TestOne("Woo", 5).testFun() + "!"
```

### 解析

- 构造方法把 `s` 设为 `"Woo"`、`number` 设为 `5`，`testFun()` 循环拼接 5 次，得到 `WooWooWooWooWoo`。
- 题目要求的输出末尾还有一个感叹号，因此必须再拼接 `"!"`。
- 这里用匿名对象 `new TestOne("Woo", 5)` 直接调用实例方法，不需要先声明变量。

## 第 2 题（简答题）Circle 类

有类图如下（文字描述）：按下列要求编写代码。

1. `Circle()` 方法执行语句 `numberOfObject++;`
2. `Circle(double radius)` 方法把参数变量 `radius` 的值赋给成员变量 `radius`，同时调用 `Circle()` 方法
3. `getRadius()` 方法返回类成员变量 `radius` 的值
4. `setRadius()` 方法执行与 `Circle(double radius)` 相同的操作
5. `getCircumference()` 方法返回半径 `radius` 的圆的周长（`2 × 3.1415 × radius`）
6. `getArea()` 方法返回半径 `radius` 的圆的面积
7. `getNumOfObject()` 方法返回创建的对象的个数（成员变量 `numberOfObject` 的值）
8. 添加 `main` 方法使 `Circle` 成为主类，并在 `main` 方法中创建 4 个 `Circle` 对象（半径分别为 1、2、3、4）
9. 执行主类，调用 4 个对象的对应方法，输出文本如下所示：

```text
创建的对象数量为：4
半径为1的圆周长是6.28，面积是12.57
<参考上一行的文本，下列各行分别是半径为2、3和4的圆周长和面积>
```

### 参考答案

```java
class Circle {
    private double radius;
    private static int numberOfObject = 0;

    public Circle() {
        numberOfObject++;
    }

    public Circle(double radius) {
        this();               // 先调用 Circle()，对象计数 +1
        this.radius = radius;
    }

    public double getRadius() {
        return radius;
    }

    public void setRadius(double radius) {
        this.radius = radius;
    }

    public double getCircumference() {
        return 2 * 3.1415 * radius;
    }

    public double getArea() {
        return 3.1415 * radius * radius;
    }

    public static int getNumOfObject() {
        return numberOfObject;
    }

    public static void main(String[] args) {
        Circle[] circles = {
                new Circle(1),
                new Circle(2),
                new Circle(3),
                new Circle(4)
        };

        System.out.println("创建的对象数量为：" + Circle.getNumOfObject());

        for (Circle c : circles) {
            System.out.printf("半径为%d的圆周长是%.2f，面积是%.2f%n",
                    (int) c.getRadius(),
                    c.getCircumference(),
                    c.getArea());
        }
    }
}
```

运行结果：

```text
创建的对象数量为：4
半径为1的圆周长是6.28，面积是3.14
半径为2的圆周长是12.57，面积是12.57
半径为3的圆周长是18.85，面积是28.27
半径为4的圆周长是25.13，面积是50.26
```

> **注意**：题目示例中“半径为1的圆周长是6.28，面积是12.57”与要求 [5][6] 的公式不一致——按面积公式 `3.1415 × r²`，半径为 1 时面积应为 `3.14`，`12.57` 实际是半径为 2 时的面积。上方代码严格按 [5][6] 的公式实现。若老师要求输出必须与示例完全一致，需要与老师确认这一点。

## 第 3 题（简答题）BankAccount 类

1. 定义一个银行账户（`BankAccount`）类：
   - 构造方法用于创建账户时初始化账号名称和余额
   - `deposit`：存款
   - `withdraw`：取款
   - `queryBalance`：查询余额
   - `showAccount`：显示账号名称
2. 创建一个用于测试的主类 `Test`，运行后创建不少于两个银行账户对象，测试上述方法。

测试结果参考：

```text
账号：202605661234
初始余额：2000.00 元
存款 500.00 元成功，余额：2500.00 元
取款 2000.00 元成功，余额：500.00 元
取款 1000.00 元失败，余额不足
存款 500.00 元成功，余额：1000.00 元
...
账号：202609180930
...
```

### 参考答案

`BankAccount.java`：

```java
class BankAccount {
    private String accountName;
    private double balance;

    public BankAccount(String accountName, double balance) {
        this.accountName = accountName;
        this.balance = balance;
    }

    public void deposit(double amount) {
        balance += amount;
        System.out.printf("存款 %.2f 元成功，余额：%.2f 元%n", amount, balance);
    }

    public boolean withdraw(double amount) {
        if (amount > balance) {
            System.out.printf("取款 %.2f 元失败，余额不足%n", amount);
            return false;
        }
        balance -= amount;
        System.out.printf("取款 %.2f 元成功，余额：%.2f 元%n", amount, balance);
        return true;
    }

    public double queryBalance() {
        return balance;
    }

    public void showAccount() {
        System.out.println("账号：" + accountName);
    }
}
```

`Test.java`：

```java
public class Test {
    public static void main(String[] args) {
        BankAccount a = new BankAccount("202605661234", 2000.00);
        a.showAccount();
        System.out.printf("初始余额：%.2f 元%n", a.queryBalance());
        a.deposit(500.00);
        a.withdraw(2000.00);
        a.withdraw(1000.00);
        a.deposit(500.00);

        System.out.println();

        BankAccount b = new BankAccount("202609180930", 5000.00);
        b.showAccount();
        System.out.printf("初始余额：%.2f 元%n", b.queryBalance());
        b.deposit(1000.00);
        b.withdraw(500.00);
        b.withdraw(9999.00);
    }
}
```

> 账号请换成自己的学号；第二组存款、取款的次数和金额可自行调整，保持合理即可。

## 第 4 题（简答题）Point 与 SimpleVector 类

有 UML 类图如下（文字描述）：按下列要求编写代码。

1. 分别实现 `Point` 类和 `SimpleVector` 类
2. 在主类的 `main()` 方法中实例化 `Point` 类和 `SimpleVector` 类，要求 `Point` 类以**匿名对象**形式实例化
3. 主类输出文本参考下列内容，以矢量（8-0，6-0）为例：

```text
矢量的模长为：10.0
单位矢量的模长为：1.0
单位矢量的起点为：0.0, 0.0
单位矢量的终点为：0.8, 0.6
```

### 参考答案

`Point.java`：

```java
public class Point {
    private double x;
    private double y;

    public Point(double x, double y) {
        this.x = x;
        this.y = y;
    }

    public double getX() {
        return x;
    }

    public double getY() {
        return y;
    }
}
```

`SimpleVector.java`：

```java
public class SimpleVector {
    private Point start;
    private Point end;

    public SimpleVector(Point start, Point end) {
        this.start = start;
        this.end = end;
    }

    public Point getStart() {
        return start;
    }

    public Point getEnd() {
        return end;
    }

    /** 矢量的模长 */
    public double getLength() {
        double dx = end.getX() - start.getX();
        double dy = end.getY() - start.getY();
        return Math.sqrt(dx * dx + dy * dy);
    }

    /** 单位矢量：方向不变、模长为 1，起点平移到原点 */
    public SimpleVector getUnitVector() {
        double len = getLength();
        double ux = (end.getX() - start.getX()) / len;
        double uy = (end.getY() - start.getY()) / len;
        return new SimpleVector(new Point(0, 0), new Point(ux, uy));
    }
}
```

`Main.java`：

```java
public class Main {
    public static void main(String[] args) {
        // Point 以匿名对象的形式传入
        SimpleVector v = new SimpleVector(new Point(0, 0), new Point(8, 6));

        System.out.println("矢量的模长为：" + v.getLength());

        SimpleVector u = v.getUnitVector();
        System.out.println("单位矢量的模长为：" + u.getLength());
        System.out.println("单位矢量的起点为："
                + u.getStart().getX() + ", " + u.getStart().getY());
        System.out.println("单位矢量的终点为："
                + u.getEnd().getX() + ", " + u.getEnd().getY());
    }
}
```

运行结果与题目示例一致：

```text
矢量的模长为：10.0
单位矢量的模长为：1.0
单位矢量的起点为：0.0, 0.0
单位矢量的终点为：0.8, 0.6
```
