# 传送门案例：滚动监听 + 滚动距离定位的"电梯"导航

> [!info] 原题
> 蓝桥云课 · 传送门（题目 2458）
> 第十三届蓝桥杯大赛 Web 应用与开发 · 国赛 · 职业院校组
> [题目链接](https://www.lanqiao.cn/problems/2458/learning/?page=1&first_category_id=2&tags=HTML5&tag_relation=union)

> [!summary] 速记版
> ```js
> $(window).scroll(function () {
>   let top = document.documentElement.scrollTop;
>   let index = 0;
>   if (top >= 0 && top < 960) index = 0;
>   if (top >= 960 && top < 1920) index = 1;
>   if (top >= 1920) index = 2;
>   $(".default-color")
>     .eq(index)
>     .addClass("active-color")
>     .siblings()
>     .removeClass("active-color");
> });
>
> function toFunction(scrollTopVal) {
>   document.documentElement.scrollTop = scrollTopVal;
> }
> ```
> - `document.documentElement.scrollTop`：**既能读、也能写**——读是当前滚动距离，写就是跳转。
> - 三个区间是半开区间：`[0, 960)`、`[960, 1920)`、`[1920, +∞)`，对应 index `0 / 1 / 2`。
> - `let index = 0` 先兜底，再让三条 `if` 各自写完整的半开区间；三个条件互斥且覆盖全部取值，`index` 永远有值。
> - `.eq(index)` 按**0 基下标**取按钮，`.addClass` 激活，`.siblings()` 把其余按钮的高亮清掉。
> - HTML 已经写好 `onclick="toFunction.call(this, 0/960/2000)"`，所以跳转函数只管把参数写进 `scrollTop`。
> - 只要补 `js/index.js`，**HTML、CSS、文件名、class 名、id 名一律不能动**。

## 考察内容

- **滚动事件**：`$(window).scroll(fn)` / `window.addEventListener('scroll', fn)` 的触发时机。
- **滚动距离读写**：`scrollTop` 是滚动容器被卷起的高度，可读可写；写入即滚动。
- **区间判断**：半开区间 `[a, b)` 的写法，以及 `>=` / `<` 的边界归属。
- **jQuery 选择器与遍历**：`$(".default-color").eq(i)`、`.siblings()`。
- **类名切换**：`addClass` / `removeClass` 实现"单选高亮"。
- **链式调用**：jQuery 方法返回 jQuery 对象，可以一路点下去。
- **DOM 约定的遵守**：不改动既有结构、class、id，只补 TODO。
- **判分点拆解**：点击定位 2 分 + 滚动高亮 3 分。

## 二、结论先行

题目要补的就是**读一次滚动距离、判一次区间、切一次类名**，再加**写一次滚动距离**：

```js
// 滚动 → 高亮
let top = document.documentElement.scrollTop;
let index = 0;
if (top >= 0 && top < 960) index = 0;
if (top >= 960 && top < 1920) index = 1;
if (top >= 1920) index = 2;

// 点击 → 跳转
document.documentElement.scrollTop = scrollTopVal;
```

**原理一句话：滚动和跳转其实是同一个属性的两面——`scrollTop` 读出来就是当前位置，写进去就是目标位置。**

```
用户点击「中间」
        │
        ▼
onclick → toFunction.call(this, 960)
        │
        ▼
document.documentElement.scrollTop = 960
        │
        ▼
浏览器滚动到 960px，并触发 scroll 事件
        │
        ▼
$(window).scroll 回调里读到 960
        │
        ▼
960 < 1920 且 960 不 < 960 → index = 1
        │
        ▼
第 1 个按钮加 .active-color，兄弟节点移除 .active-color
        │
        ▼
「中间」变蓝，#2e7eee
```

注意这条闭环：**点击本身不需要手动改颜色**。点击只是改滚动位置，滚动事件会自然把颜色修正过来。少写一段代码，逻辑还更统一。

## 三、解题思路

### 第 1 步：分清两件事

题目其实是两个独立功能，判分也是分开的：

| 功能 | 触发源 | 要做的事 | 分值 |
| --- | --- | --- | --- |
| 点击定位 | `onclick` | 把页面滚到指定位置 | 2 分 |
| 滚动高亮 | `scroll` | 让对应按钮变蓝 | 3 分 |

它们共享同一个数据源：**滚动距离**。所以不要试图在 `onclick` 里手动加类名，那是重复实现。

### 第 2 步：确定"滚动距离"怎么取

页面滚动距离有三个常见来源：

```js
document.documentElement.scrollTop; // <html> 的滚动距离，标准模式首选
document.body.scrollTop;            // <body>，老浏览器 / 怪异模式
window.scrollY;                     // 只读，等价于上面两个的"正确答案"
document.scrollingElement;          // 现代浏览器：自动指向真正在滚的那个
```

本题项目按 `document.documentElement.scrollTop` 写，跟着题目走即可；想稳一点可以加兜底：

```js
let top = document.documentElement.scrollTop || document.body.scrollTop || window.scrollY;
```

### 第 3 步：把题干区间翻译成代码

题干写得很精确，直接照抄成半开区间：

| 区域 | 题干 | 代码条件 | index |
| --- | --- | --- | --- |
| 顶部 | 0 ~ 960px，**不含** 960 | `0 <= top < 960` | 0 |
| 中间 | 960 ~ 1920px，**含** 960，**不含** 1920 | `960 <= top < 1920` | 1 |
| 底部 | **>=** 1920 | `top >= 1920` | 2 |

写法上用**一条默认值 + 三条完整区间判断**，每条 `if` 都把区间两头写全：

```js
let index = 0;
if (top >= 0 && top < 960) index = 0;
if (top >= 960 && top < 1920) index = 1;
if (top >= 1920) index = 2;
```

为什么这样不担心漏值：三个条件首尾相接、互不重叠，并且合起来覆盖 `[0, +∞)`；就算哪天条件写得有缝隙，`let index = 0` 也会兜住，不会变成 `undefined`。三行各自独立，看哪一行就能直接对上题干里的一个区间，比压成一行或 `else if` 链更好检查。

### 第 4 步：按 index 选按钮并切类名

三个 `<a>` 都有 `.default-color`，所以：

```js
$(".default-color").eq(index)        // 第 index 个（0 基）
  .addClass("active-color")          // 自己变蓝
  .siblings()                        // 同一父级下的其它兄弟（包括 .line）
  .removeClass("active-color");      // 把别人的蓝去掉
```

`.eq()` 之后仍然是 jQuery 对象，所以能继续链式调用；`.siblings()` 从**当前元素**出发找兄弟，正好覆盖另外两个 `<a>`。

CSS 里 `.active-color` 写在 `.default-color` 之后，优先级相同、后者覆盖前者，所以元素同时带两个类时显示蓝色，不需要真的删掉 `default-color`。

### 第 5 步：补跳转函数

```js
function toFunction(scrollTopVal) {
  document.documentElement.scrollTop = scrollTopVal;
}
```

`scrollTopVal` 由 HTML 传进来（0 / 960 / 2000），函数体只需一行赋值。写 `window.scrollTo(0, scrollTopVal)` 也能达到同样效果，但项目里统一用 `scrollTop` 赋值更贴近出题意图。

### 第 6 步：自测

```
点「顶部」   → 滚到 0      → 顶部高亮
点「中间」   → 滚到 960    → 中间高亮
点「底部」   → 滚到 2000   → 底部高亮（2000 >= 1920）
手动滚到 959 → 顶部高亮
手动滚到 960 → 中间高亮   ← 边界归中间，别写成 959
手动滚到 1919→ 中间高亮
手动滚到 1920→ 底部高亮   ← 边界归底部，别写成 > 1920
滚回顶端     → 顶部高亮
```

## 四、边界为什么最容易丢分

### 1. 题干是半开区间，不是"大概"

```js
// ✅ 正确：默认 0 + 三条完整半开区间
let index = 0;
if (top >= 0 && top < 960) index = 0;
if (top >= 960 && top < 1920) index = 1;
if (top >= 1920) index = 2;

// ❌ 常见错误一：写成闭区间，960 和 1920 归属模糊
if (top <= 960) index = 0;

// ❌ 常见错误二：手抖写成 959 / 1921
if (top < 959) index = 0;
if (top > 1920) index = 2;
```

网上流传的某版答案就是 `top < 959` + `top > 1920`，在 `959 ≤ top ≤ 960` 和 `top == 1920` 这几段里 `index` 保持 `undefined`，结果**一个按钮都不高亮**。

### 2. `scrollTop` 可能是小数

在 HiDPI 屏幕或缩放比例非 100% 时，`scrollTop` 会返回小数（如 `959.5`、`960.0`、`1919.5`）。所以：

- 用 `< 960` / `< 1920` 判断，任何小数都能落进正确区间；
- 用 `< 959` / `> 1920` 则会在 `959 ~ 960` 这段出现"空档"。

### 3. `index` 必须保证有值

```js
let index;               // ❌ 如果三个 if 都没命中，就是 undefined
$(".default-color").eq(undefined); // 空集合，什么都不发生
```

```js
let index = 0;                                     // ✅ 先给默认值
if (top >= 0 && top < 960) index = 0;
if (top >= 960 && top < 1920) index = 1;
if (top >= 1920) index = 2;
```

默认值负责兜底，三条 `if` 负责精确落档；把 `>=` 和 `<` 一起写上，边界就不会"两边都沾"或"两边都不沾"。

### 4. 页面总高限制了"底部"能否到达

`#foot` 高 1020px，页面总高 2940px，最大可滚动距离是：

```
maxScrollTop = 2940 - window.innerHeight
```

- 视口高 900px → 最大 2040，能滚过 1920 ✅
- 视口高 1080px → 最大 1860，**永远进不了底部区间** ❌

考试环境的分辨率通常没问题；本地用大屏预览时如果"底部"不高亮，先怀疑窗口太高，而不是代码写错。

## 五、jQuery 部分逐行拆

### `$(window).scroll(function () { ... })`

- 监听的是 **window 的滚动**，不是某个 `div`：整页滚动时 `scroll` 事件从 `window`（准确说是 `document`）冒泡上来。
- 回调在**滚动过程中高频触发**（一次拖动可能几十上百次），所以里面只做轻量计算：读一个数、比两次、切几个类。
- 不要在这个回调里写 `alert`、`console.log` 大量输出或重排 DOM，会明显卡顿。

### `document.documentElement.scrollTop`

| 操作 | 结果 |
| --- | --- |
| 读 | 当前 `<html>` 被卷起的高度（px） |
| 写 | 浏览器立即滚动到该位置（超出范围会被**夹到最大值**） |

写 `2000` 时如果最大只能滚到 1860，实际会停在 1860——这就是"夹紧"（clamp）。浏览器不会报错。

### `$(".default-color").eq(index)`

- `$(".default-color")` 取得 3 个 `<a>`，**按文档顺序**。
- `.eq(index)` 按 0 基下标取第 index 个，**返回仍是 jQuery 对象**，可以继续链。
- 也可以用原生等价写法：

```js
document.querySelectorAll(".default-color")[index];
```

但原生返回的是 Element，后面得换 `classList.add` / `classList.remove`，且要自己遍历兄弟节点。

### `.addClass("active-color")` / `.removeClass("active-color")`

- `addClass` 幂等：已经有这个类再加一次也没事。
- `removeClass` 对没有该类的元素也安全，不会报错。
- 不要用 `.css("color", "#2e7eee")` 替代：那是**内联样式**，优先级比类选择器高，后面想靠 CSS 改颜色就改不动了；题目要求的是切 `.active-color` 类。

### `.siblings()`

- 返回当前元素**所有同级兄弟**（不含自己），本题即另外两个 `<a>` 和两个 `.line`。
- `.line` 上没有 `active-color`，`removeClass` 对它无副作用。
- 注意 `.siblings()` 只找**同一父级**，不做深度遍历；如果三个按钮不在同一个父容器里，这个写法就失效了。本题 `#lift` 结构保证了它们互为兄弟。

### 链式调用等价展开

```js
let $btns = $(".default-color");
let $current = $btns.eq(index);
$current.addClass("active-color");
$btns.not($current).removeClass("active-color");   // 等价于 siblings 的效果
```

`siblings()` 与 `not($current)` 在本题结果一致，但语义不同：前者是"兄弟关系"，后者是"集合排除自己"。

## 六、其他实现方案对比

### 方案 A：滚动距离判断（本题标准解）

```js
let top = document.documentElement.scrollTop;
let index = 0;
if (top >= 0 && top < 960) index = 0;
if (top >= 960 && top < 1920) index = 1;
if (top >= 1920) index = 2;
```

- 优点：与题干数值一一对应，最好理解、最好判题。
- 缺点：阈值写死，页面高度一改就要同步改数字。

### 方案 B：用分区元素的 `offsetTop`

```js
let sections = ["#top", "#middle", "#foot"].map(function (s) {
  return document.querySelector(s);
});
let top = document.documentElement.scrollTop;
let index = 0;
sections.forEach(function (el, i) {
  if (top >= el.offsetTop) index = i;
});
```

- 阈值来自真实布局，改高度不用改代码。
- 但 `offsetTop` 是相对**定位祖先**的偏移，遇到 `position: relative` 的祖先要小心。

### 方案 C：`scrollIntoView`

```js
function toFunction(scrollTopVal) {
  let map = { 0: "#top", 960: "#middle" };
  // 底部没有固定对应值，2000 还得手写
}
```

- 能跳，但"底部"参数是 2000 而不是某个元素的偏移，混用两套机制反而更乱；`behavior: "smooth"` 的动画时长不可控，判题截图可能截在动画中途。
- 题目禁止改 HTML，所以也不方便给按钮加 `data-target`。

### 方案 D：`IntersectionObserver`（现代写法）

```js
let btns = document.querySelectorAll(".default-color");
let io = new IntersectionObserver(function (entries) {
  entries.forEach(function (e) {
    if (!e.isIntersecting) return;
    btns.forEach(function (b) { b.classList.remove("active-color"); });
    let i = ["top", "middle", "foot"].indexOf(e.target.id);
    btns[i].classList.add("active-color");
  });
}, { threshold: 0.5 });
["top", "middle", "foot"].forEach(function (id) {
  io.observe(document.getElementById(id));
});
```

- 性能好、不用手写阈值；但 `threshold` 语义是"可见比例"，与"滚动 960px"不完全等价，边界行为和题干可能有出入。
- 考试求稳，还是用方案 A。

### 方案对比

## 七、常见坑

1. **边界写成 `<= 960` / `< 959` / `> 1920`**
   题干是半开区间，960 归中间、1920 归底部。写错就会出现"滚到 1920 时三个按钮都不亮"。

2. **`index` 声明了但可能没赋值**
   `let index;` + 三个互斥 `if`，在空档处是 `undefined`，`.eq(undefined)` 静默失效。写成 `let index = 0;` 给个默认值就不会了。

3. **在 `onclick` 里手动加类名**
   会和 scroll 回调打架，还容易漏掉键盘、滚轮、滚动条拖动等场景。颜色统一交给 scroll 回调。

4. **读 `document.body.scrollTop`**
   HTML5 标准模式下 `body` 不滚动，读出来恒为 0，永远高亮"顶部"。用 `documentElement.scrollTop` 或 `window.scrollY`。

5. **写 `document.body.scrollTop = x` 没反应**
   同一原因：真正在滚的是 `<html>`。要么写 `documentElement.scrollTop`，要么用 `window.scrollTo(0, x)`。

6. **用 `.css("color", ...)` 代替类名切换**
   题目判分看的是 `.active-color` 类是否落在正确的按钮上（以及最终颜色），内联样式既不符合要求，也难撤销。

7. **`.siblings()` 用错层级**
   如果先 `.parent()` 再 `siblings()` 会跑到 `#lift` 的兄弟节点（基本没有）。正确姿势是直接在按钮集合上调 `.siblings()`。

8. **改了 HTML / CSS / 文件名**
   题目明确禁止：文件名、文件夹路径、class 名、id 名、图片名都必须保持原样，判题按原路径校验。**只在 `js/index.js` 里写代码。**

9. **把 `toFunction` 写成 `toFunction = function(){}` 或箭头函数**
   HTML 里是 `onclick="toFunction.call(...)"`，依赖**全局函数声明**。`function toFunction()` 会挂到 `window` 上，改成 `const` / 箭头函数在 `<script>` 作用域里可能找不到。

10. **重复绑定 scroll**
    代码如果被热更新或二次执行，会绑多个回调。考试环境一次性加载问题不大，写的时候注意别在回调里再绑回调。

11. **在 scroll 回调里做重运算**
    比如每次都 `querySelectorAll` 整页元素。本题三个按钮，直接 `$(".default-color")` 足够；真要优化可以缓存选择结果，或用 `requestAnimationFrame` 节流。

12. **以为点击"底部"必须滚到 1920**
    HTML 传的是 **2000**，因为要确保落进 `>= 1920` 区间，并且让用户看到页面真正的底。判分看的是"是否进入底部区间"，不是"是否精确等于 1920"。

## 九、延伸：更工程化的写法

### 1. 平滑滚动

```js
function toFunction(scrollTopVal) {
  window.scrollTo({ top: scrollTopVal, behavior: "smooth" });
}
```

体验更好，但滚动是异步的：判题如果立刻读取位置，可能读到动画中的中间值。**考试别用**。

### 2. 节流

```js
let ticking = false;
$(window).scroll(function () {
  if (ticking) return;
  ticking = true;
  requestAnimationFrame(function () {
    updateActive();
    ticking = false;
  });
});
```

scroll 事件频率可能高于屏幕刷新率，用 rAF 合并到每帧一次。

### 3. 配置化阈值

```js
let OFFSETS = [0, 960, 1920];   // 各区间起点

function getIndex(top) {
  let i = 0;
  for (let k = 0; k < OFFSETS.length; k++) {
    if (top >= OFFSETS[k]) i = k;
  }
  return i;
}
```

页面分区一变，只改 `OFFSETS` 数组，逻辑不用动。这也是方案 B 的思路雏形。

### 4. 原生 JS 等价写法（脱离 jQuery）

```js
let btns = Array.prototype.slice.call(
  document.querySelectorAll(".default-color")
);

function updateActive() {
  let top = document.documentElement.scrollTop;
  let index = 0;
  if (top >= 0 && top < 960) index = 0;
  if (top >= 960 && top < 1920) index = 1;
  if (top >= 1920) index = 2;
  btns.forEach(function (b, i) {
    b.classList.toggle("active-color", i === index);
  });
}

window.addEventListener("scroll", updateActive);

function toFunction(scrollTopVal) {
  document.documentElement.scrollTop = scrollTopVal;
}
```

`classList.toggle(name, force)` 一行完成"命中就加、不命中就去"，比 `addClass` + `siblings` 更直白。

## 十、记忆口诀

> **滚动距离一属性，读是位置写是跳；**
> **半开区间判三档，九六零、一九二零别写飘。**

> **`eq` 选中加蓝类，`siblings` 把旧色消；**
> **点击只改 `scrollTop`，颜色交给滚动报。**

> [!quote] 一句话总结
> **滚动事件负责"感知"，`scrollTop` 赋值负责"指挥"，`.active-color` 负责"显示"。三者各管一件事，不要混着写。**
