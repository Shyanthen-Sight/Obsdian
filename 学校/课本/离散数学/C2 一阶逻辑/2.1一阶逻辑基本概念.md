## 零、为什么命题逻辑不够用

**命题逻辑的三条硬伤**：

1. **命题不可再分**。取 `p`："苏格拉底是人"，`q`："人都是会死的"，`r`："苏格拉底会死"。从 p、q 推不出 r——因为命题逻辑**看不见 p、q 内部**"苏格拉底"与"人"的关系。
2. **无法表达量词**。"所有"、"存在"、"至少有一个"这类限定，命题逻辑里**根本没有对应符号**。
3. **无法刻画关系**。"小明比小红高"和"小红比小明高"在命题逻辑里是两个互不相干的原子命题，看不出它们共用同一个"比…高"的关系。

**一阶逻辑（谓词逻辑）的补救**：

| 命题逻辑只有            | 一阶逻辑新增              |
| :---------------- | :------------------ |
| 命题变元 p, q, r      | **个体词**（对象）、**谓词**（性质／关系） |
| 联结词 ¬ ∧ ∨ → ↔     | 同上（**完全保留，一条不改**）     |
| ——                | **量词** ∀ ∃            |

> **一句话**：==一阶逻辑把命题"劈开"，露出里面的个体与谓词，再加两把量词"钳子"把个体批量约束起来。==

**三段论的"复活"**：苏格拉底三段论在一阶逻辑里可写成

```
∀x(M(x) → D(x))        （所有人都是会死的）
M(s)                   （苏格拉底是人）
────────────────────
∴ D(s)                 （苏格拉底会死）
```

依据是**全称例示**（从 ∀x 得 M(s) → D(s)）＋**假言推理**。命题逻辑做不到，一阶逻辑一步到位。

## 一、个体词

**个体**：可以独立存在的研究对象。可以是具体的人、物，也可以是抽象的数、集合、概念。

**个体词**：表示个体的词，分两类。

| 类别 | 记号习惯 | 含义 | 例 |
| :--- | :--- | :--- | :--- |
| **个体常元**（个体常项） | a, b, c（小写字母前部） | 表示**一个特定的**个体 | a：张三 ｜ b：2 |
| **个体变元**（个体变项） | x, y, z（小写字母后部） | 表示**任意／抽象**的个体 | x：某个数 |

**个体域 D（论域）**：个体变元的**取值范围**。

- 个体域可以有限，也可以无限。D = {1, 2, 3} 或 D = 实数集 R。
- ==**个体域不同，同一个公式的真值可能完全不同**==（详见 [[2.2一阶逻辑合式公式及解释]] 第六节"解释"）。
- 不作特别声明时，考试默认使用**全总个体域**（见第四节）。

> **⚠️ 约定**：个体域**非空**（D ≠ ∅）。这条看似无关紧要，却是 `∀xP(x) ⇒ ∃xP(x)` 成立的全部理由。

---

## 二、谓词

**定义**：谓词是表示个体**性质**或个体之间**关系**的词，常用大写字母 P, Q, R, F, G, H 表示。

**n 元谓词** `P(x₁, x₂, …, xₙ)`：带着 n 个个体词的谓词。

|   元数    | 刻画             | 例                      |
| :-----: | :------------- | :--------------------- |
| **1 元** | 个体的**性质**      | `P(x)`：x 是大学生          |
| **2 元** | 两个个体间的**关系**   | `Q(x, y)`：x < y        |
| **n 元** | n 个个体之间的关系     | `R(x, y, z)`：x + y = z |
| **0 元** | 不含个体词，**就是命题** | `P`：今天下雨               |

**关键区别**：

| 写法 | 名称 | 是否有真值 |
| :--- | :--- | :--- |
| `P(a)`（填个体常元） | **命题** | ✅ 有确定真值 |
| `P(x)`（填个体变元） | **命题函数** | ❌ 无真值，要等 x 被赋值或被量化 |
| `∀xP(x)` | 命题（闭式） | ✅ |
| `P(x) → Q(x)` | 命题函数 | ❌ 含自由 x，不是命题 |

> **理解钩子**：把谓词想成一个"**带槽的函数**"。`P( )` 有一个槽——塞进常元就出真值，塞进变元就还是"待定的函数"。==**量词的作用就是把变元槽"打包"起来，让整句重新变成有真值的命题。**==

**谓词常元／变元**：P 的具体含义由**解释 I** 给定（见 [[2.2一阶逻辑合式公式及解释]] 第六节），这样用的 P 叫谓词常元；若把 P 也当成可变的，叫谓词变元（本课程一般不涉及，了解即可）。

## 三、量词

| 量词 | 符号 | 读作 | 自然语言对应词 |
| :--- | :-: | :--- | :--- |
| **全称量词** | ∀ | "对所有 x" | 所有的、一切的、每一个、凡是、任意 |
| **存在量词** | ∃ | "存在 x" | 存在、有一个、有些、至少有一个、有的 |

**真值条件**（D 为个体域）：

- `∀xP(x)` 为真 ⟺ **D 中每一个**个体 c 都使 `P(c)` 为真。
- `∃xP(x)` 为真 ⟺ **D 中至少有一个**个体 c 使 `P(c)` 为真。

**有限个体域时的等价变形（做题金矿）**：若 D = {a₁, a₂, …, aₙ}，则

```
∀xP(x) ⇔ P(a₁) ∧ P(a₂) ∧ … ∧ P(aₙ)
∃xP(x) ⇔ P(a₁) ∨ P(a₂) ∨ … ∨ P(aₙ)
```

> ==**这是本章最重要的"桥"。**== 它让一阶公式在有限域下**退化为命题公式**——2.2 判断公式真值、2.3 举反例（惯例取 D = {1, 2}）全靠它。看到"有限个体域"四个字，立刻把 ∀ 换成 ∧ 的连乘、∃ 换成 ∨ 的连加。

**个体域非空带来的常用结论**：

- ==∀xP(x) ⇒ ∃xP(x)==　（每个都满足，当然至少有一个满足；前提是 D ≠ ∅）
- 但 **`∀xP(x) → ∃xP(x)` 是永真式，而 `∃xP(x) → ∀xP(x)` 不是**（反例：D = 整数集，P(x)：x > 0）。

## 四、特性谓词与全总个体域（🎯 高频考点）

**问题**：一句话里常常牵涉不同范围的个体。

- "所有**人**都是会死的"——范围是人；
- "所有**实数**都满足 x² ≥ 0"——范围是实数。

若每换一句话就换个体域，公式既不通也不通用。**解决办法：统一使用全总个体域，把"范围"用谓词写进公式内部。**

**全总个体域**：把宇宙间**一切事物**作为个体域（不再缩小范围）。

**特性谓词** `M(x)`：刻画"x 属于我们真正关心的那类对象"的谓词。如 `M(x)`：x 是人。

### 4.1 两条铁律

> ==**∀ 后面加蕴含 →，∃ 后面加合取 ∧。**==

| 命题 | 正确写法 | 错误写法 |
| :--- | :--- | :--- |
| 所有的 M 都是 P | ==∀x(M(x) → P(x))== | ~~∀x(M(x) ∧ P(x))~~ |
| 有的 M 是 P | ==∃x(M(x) ∧ P(x))== | ~~∃x(M(x) → P(x))~~ |

### 4.2 为什么恰好相反（想透了就永远记不反）

- `∀x(M(x) → P(x))`：对全总个体域里**每个东西**，若它是人则会死。对"桌子、星星"这类不是人的东西，前件 M(x) 为假 ⇒ 蕴含式为真，**不影响结论**。✔
- `∀x(M(x) ∧ P(x))`：要求**每一个东西**既是人又会死——连桌子也得是人。**假得离谱**。✘
- `∃x(M(x) ∧ P(x))`：存在一个东西**既是人又会死**。✔
- `∃x(M(x) → P(x))`：随便拿块石头（M 为假）就使蕴含式为真，命题白真。"约束形同虚设"。✘

## 五、六类经典命题的符号化模板（必背表）

设特性谓词 `M(x)`，谓词 `P(x)`。

| # | 自然语言 | 符号化 | 备注 |
| :-: | :--- | :--- | :--- |
| 1 | 所有的 M 都是 P | ∀x(M(x) → P(x)) | **∀ 配 →** |
| 2 | 所有的 M 都不是 P | ∀x(M(x) → ¬P(x)) | 等价于 `¬∃x(M(x) ∧ P(x))` |
| 3 | 有的 M 是 P | ∃x(M(x) ∧ P(x)) | **∃ 配 ∧** |
| 4 | 有的 M 不是 P | ∃x(M(x) ∧ ¬P(x)) | 等价于 `¬∀x(M(x) → P(x))` |
| 5 | 并非所有 M 都是 P | ∃x(M(x) ∧ ¬P(x)) | 就是 4，即 1 的否定 |
| 6 | 没有 M 是 P | ¬∃x(M(x) ∧ P(x)) ⇔ ∀x(M(x) → ¬P(x)) | 2 的两种等价写法 |

**对偶观测（先埋下 2.3 的伏笔）**：

- 1 与 4 互为否定：`¬∀x(M → P) ⇔ ∃x(M ∧ ¬P)`
- 2 与 3 互为否定：`¬∃x(M ∧ P) ⇔ ∀x(M → ¬P)`
- ==**"所有…是" 的否定是 "有的…不是"；"有的…是" 的否定是 "所有…不是"。**==
  这两条就是 [[2.3 一阶逻辑等值式与前束范式]] 3.1 节量词否定等值式的自然语言版本。

**个体域已被限定时可省略 M(x)**：若题干说"个体域为人群"，则 `∀x(P(x) → Q(x))` 即可，不必再写 M。

## 六、多元谓词与量词顺序

### 6.1 一个量词不够用：按"谁先谁后"逐层套

**例 1**：每个人都有母亲。（个体域：人）

```
∀x∃y F(y, x)         F(y, x)：y 是 x 的母亲
```

**例 2**：有的人谁都喜欢。

```
∃y∀x L(y, x)         L(y, x)：y 喜欢 x
```

### 6.2 量词顺序决定含义

| 公式 | 含义 | 强弱 |
| :--- | :--- | :--- |
| `∀x∃y F(x, y)` | 对**每个** x，各自都能找到 y | **弱** |
| `∃y∀x F(x, y)` | **存在一个** y，对**所有** x 都成立 | **强** |

> `∃y∀xF(x, y) ⇒ ∀x∃yF(x, y)`，**反之不成立**（详见 [[2.3 一阶逻辑等值式与前束范式]] 3.4 节）。
> 口诀：==**"同一个 y 通吃所有人" 强于 "一人配一个 y"。**==

### 6.3 多条件叠加：条件全进 ∀ 的 → 前件

**例 3**：任意两个实数之间都有一个实数。

```
∀x∀y( (R(x) ∧ R(y) ∧ x < y) → ∃z(R(z) ∧ x < z ∧ z < y) )
```

- `R(x)`：x 是实数（全总个体域下的特性谓词）；
- 三个条件 `R(x) ∧ R(y) ∧ x < y` 一起放在 → 的**前件**；
- `∃z` 后面仍是 ∧（特性谓词 + 结论条件一起平铺）。

> **套路**：==**∀ 的辖域内，条件用 ∧ 连成前件再 → 结论；∃ 的辖域内，条件与结论一律用 ∧ 平铺。**==

## 七、符号化的常见陷阱

| 陷阱 | 反例／正解 |
| :--- | :--- |
| **∀ 错用 ∧** | ~~∀x(M(x) ∧ P(x))~~ → 应为 `∀x(M(x) → P(x))` |
| **∃ 错用 →** | ~~∃x(M(x) → P(x))~~ → 应为 `∃x(M(x) ∧ P(x))` |
| **忘记特性谓词** | 全总个体域下"所有学生都及格"若写 `∀xP(x)`，就变成"万物都及格" |
| **个体域搞错** | 题干给"人群"却按全总个体域翻，或反之——**先看清个体域再动手** |
| **否定关系写反** | "并非所有 M 是 P" 是 `∃x(M ∧ ¬P)`，**不是** `∀x(M → ¬P)`（那是"所有 M 都不是 P"） |
| **量词顺序随意** | "每个人都有喜欢的人" = `∀x∃yL(x,y)`，**不是** `∃y∀xL(x,y)`（后者是"有个人被所有人喜欢"） |
| **多条件没进前件** | "所有实数 x 都满足 x² ≥ 0" 应写 `∀x(R(x) → x² ≥ 0)`；`∀x(R(x) ∧ x² ≥ 0)` 错 |
| **漏掉量词** | `P(x) → Q(x)` 含自由 x，不是命题；须写 `∀x(P(x) → Q(x))` |
| **特性谓词重复堆砌** | "有的 M 是 P 且是 Q" 应 `∃x(M(x) ∧ P(x) ∧ Q(x))`，特性谓词只写一次 |
| **常元也加量词** | "苏格拉底会死" 直接写 `D(s)`，**不要**写成 `∃xD(x)` |

# 参考答案与详细解析

## 第 1 题

个体域是"全体人类"，范围**已经限定** ⇒ **不需要特性谓词**。

设 `S(x)`：x 是大学生；`a`：张三；`b`：李四。

**(1)** `S(a) ∧ S(b)`

**(2)** `¬S(b)`

**解析**：个体域已限定，直接用谓词填个体词。(1) 的"都"在**两个确定个体**之间用 ∧，不是 →（→ 是给"任意个体"划界用的）。

---

## 第 2 题

特性谓词 `M(x)`，全总个体域。

**(1)** `∀x(M(x) → D(x))`

**(2)** `∃x(M(x) ∧ ¬D(x))`

**(3)** `D(s)`　（**s 是常元，直接填进谓词，不需要量词**）

**(4)** `∃x(M(x) ∧ ¬D(x))`

**解析**：(2) 与 (4) 写法**相同**——"有的人不会死"就是"并非所有人都会死"，这是 ∀/∃ 对偶的第一次亮相。(3) 提醒：==个体常元不需要量化==。

---

## 第 3 题

**(1)** `∀x(F(x) → R(x))`

**(2)** `∃x(F(x) ∧ ¬R(x))`

**关系**：(2) 恰是 (1) 的**否定**，即 `(2) ⇔ ¬(1)`。

**验证**（用 [[2.3 一阶逻辑等值式与前束范式]] 的 3.1 + 3.3）：

```
¬∀x(F(x) → R(x))
⇔ ¬∀x(¬F(x) ∨ R(x))          （蕴含等值式）
⇔ ∃x¬(¬F(x) ∨ R(x))          （量词否定）
⇔ ∃x(F(x) ∧ ¬R(x))           （德摩根 + 双重否定）✔
```

---

## 第 4 题

**(1)** `∃x(N(x) ∧ E(x) ∧ O(x))`

**(2)** `∀x(N(x) → (E(x) ∨ O(x)))`

**解析**：

- (1) 是 ∃ 辖域：特性谓词与两个结论条件**全用 ∧ 平铺**。
- (2) 是 ∀ 辖域："不是…就是…"是**析取**，整个析取放在 → 的**后件**里；**不要**拆成 `∀x(N(x) → E(x)) ∧ ∀x(N(x) → O(x))`（那两句都是假的了）。

---

## 第 5 题

**(1)** `∀x∃yL(x, y)`　（每个人**各自**有喜欢的人）

**(2)** `∃y∀xL(x, y)`　（**有一个人**被所有人喜欢）

**比较**：==**(2) ⇒ (1) 成立，(1) ⇒ (2) 不成立。**==

**解析**：(2) 真 ⇒ 取那个"万人迷"作 y，对每个 x 都有 L(x, y) ⇒ (1) 真。
反过来，(1) 真时各人的心上人**可能各不相同**，未必存在一个共同的 y。

**反例**（D = {1, 2}）：

| L(x, y) | y = 1 | y = 2 |
| :-: | :-: | :-: |
| **x = 1** | 假 | 真 |
| **x = 2** | 真 | 假 |

- `∀x∃yL(x, y)`：x=1 有 y=2 ✔，x=2 有 y=1 ✔ ⇒ **真**
- `∃y∀xL(x, y)`：y=1 时 x=1 不满足；y=2 时 x=2 不满足 ⇒ **假**

⇒ (1) 真而 (2) 假，`(1) ⇒ (2)` 不成立 ✔

---

## 第 6 题

设 `M(x)`：x 是人；`E(x)`：x 犯错误。

- 字面直译："不存在 **一个人 且 不犯错误**" ⇒ `¬∃x(M(x) ∧ ¬E(x))`
- 用否定穿透（[[2.3 一阶逻辑等值式与前束范式]] 3.1）⇒ `∀x(M(x) → E(x))`

**答案**：`¬∃x(M(x) ∧ ¬E(x))`，等值形式 `∀x(M(x) → E(x))`（"所有人都会犯错误"）。

**解析**：本题"否定词 + 存在量词 + 否定谓词"三重否定叠加，最易错写成 `∃x(M(x) ∧ ¬E(x))`（**漏掉最外层 ¬**）。
==**读题先找"没有／并非"这类否定词，再套模板。**==

## 第 7 题

设 `R(x)`：x 是实数。

**(1)** 每个实数都有比它大的实数：`∀x(R(x) → ∃y(R(y) ∧ y > x))`

**(2)** 存在一个实数比所有实数都大：`∃y(R(y) ∧ ∀x(R(x) → y > x))`

**比较**：==**(2) ⇒ (1)**，但 **(1) ⇏ (2)**== —— 与第 5 题同构（∃∀ 强、∀∃ 弱）。

**解析**：在实数集上：

- (1) 为**真**（阿基米德性质：任给 x 都能找到更大的 y）；
- (2) 为**假**（不存在最大的实数）。

这正好构造出"∀∃ 真而 ∃∀ 假"，与 [[2.3 一阶逻辑等值式与前束范式]] 3.4 节 `x + y = 0` 的反例同一思路。

## 附一：符号化速查

**四个基本概念**

- **个体词**：个体常元 a, b, c ｜ 个体变元 x, y, z
- **个体域 D**：变元的取值范围；默认全总个体域，D ≠ ∅
- **谓词**：n 元谓词 P(x₁,…,xₙ)｜0 元谓词 = 命题｜填常元得命题，填变元得命题函数
- **量词**：∀（所有）｜∃（存在）

**两条铁律**

- ∀ 后配 →（划界）：`∀x(M(x) → P(x))`
- ∃ 后配 ∧（抓人）：`∃x(M(x) ∧ P(x))`

**六类模板**：见第五节整表

**有限域桥（本章最重要工具）**

- `∀xP(x) ⇔ P(a₁) ∧ … ∧ P(aₙ)`　｜　`∃xP(x) ⇔ P(a₁) ∨ … ∨ P(aₙ)`

**个体域非空 ⇒ 常用结论**

- `∀xP(x) ⇒ ∃xP(x)`

**两组对偶否定**

- `¬∀x(M → P) ⇔ ∃x(M ∧ ¬P)`
- `¬∃x(M ∧ P) ⇔ ∀x(M → ¬P)`

## 附二：易混概念对照

| 容易混的一对 | 区别 |
| :--- | :--- |
| **个体常元 vs 个体变元** | 常元指"某个确定的个体"（可直接命题化）；变元指"任意个体"（须赋值或量化） |
| **谓词 vs 命题变元** | 谓词**带槽**、可填个体；命题变元无内部结构（只有 0 元谓词才退化为命题） |
| **∀ + → vs ∃ + ∧** | 全称要"划界"用蕴含；存在要"抓人"用合取。==记反就全盘皆错== |
| **量词 vs 特性谓词** | 量词管"批量约束"；特性谓词管"限定范围"。二者配合，不是替代关系 |
| **`∀x∃y` vs `∃y∀x`** | 前者"一人配一个"（弱）；后者"一个通吃"（强）。`∃∀ ⇒ ∀∃`，反之不然 |
| **"都" vs "且"** | 两个**确定**个体之间用 ∧（`S(a) ∧ S(b)`）；**任意**个体用 → 划界 |
