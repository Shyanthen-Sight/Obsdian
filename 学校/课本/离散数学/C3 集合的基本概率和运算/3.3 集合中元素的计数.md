## 零、动机：为什么要"计数"

集合论前半段处理的是**关系**（谁包含谁、谁等于谁），从本节开始处理**数量**（有多少个元素）。这两件事的区别，用一句话概括：

> ==包含关系问"是不是"，计数问"有几个"。==

### 0.1 数数的三类提问

现实与考试中的计数问题，几乎都能归入下面三类。**先把问题翻译成集合语言，是解题的第一动作。**

| 提问方式         | 集合语言                          | 例                      |
| :----------- | :---------------------------- | :--------------------- |
| **至少满足其一**   | 求 `\|A ∪ B ∪ C\|`             | "会英语或日语或法语的有几人"        |
| **恰好满足某几个**  | 求"恰属于 2 个集合"的元素数              | "只会两门语言的有几人"           |
| **都不满足**     | 求 `\|~A ∩ ~B ∩ ~C\|`          | "三门都不会的有几人"            |
| **同时满足全部**   | 求 `\|A ∩ B ∩ C\|`             | "三门都会的有几人"             |

> **易错警告**：题目里"**至少**"和"**恰好**"是两个完全不同的词。
> ==至少 = 并集；恰好 = 必须精确到个数。== 见到"至少一门外语"，你求的是并；见到"**恰好**只会一门外语"，你求的是文氏图里**孤立的三个单块之和**。

### 0.2 文氏图分块直觉

先建立**分块思想**：把全集用若干个集合的边界切成若干块，**每一块内部的元素"身份"完全相同**（属于哪些集合、不属于哪些集合一模一样）。

以两个集合 A、B 为例，全集被切成 **4 块**：

| 分块            | 含义（身份）              | 用交集表示                 |
| :------------ | :------------------ | :-------------------- |
| 第 1 块         | 只在 A 中              | `A ∩ ~B`              |
| 第 2 块         | 同时在 A 与 B 中          | `A ∩ B`               |
| 第 3 块         | 只在 B 中              | `~A ∩ B`              |
| 第 4 块         | 都不在                 | `~A ∩ ~B`             |

以三个集合为例，全集被切成 **8 块**（= 2³，每个集合"在/不在"两种状态）。**这就是三集合文氏图为什么有七块可填**（第 8 块是"都不在"，常常就是全集减掉并集的那部分）。

> **记忆钩子**：==n 个集合把全集切成 2ⁿ 块；"恰好属于 k 个集合"就是把其中"身份为 k"的若干块加起来。==

**为什么不能简单相加？** 因为 `|A| + |B|` 会把 `A ∩ B` 里的元素**数两次**。计数问题的全部难点，就在于"**谁被数重了、谁被数漏了**"。

## 一、基数、有限集与可加性

### 1.1 基数

**定义**：集合 A 中元素的个数称为 A 的**基数**，记作 ==`|A|`==。

- 若 `|A|` 是某个非负整数，称 A 为**有限集**；
- 否则称 A 为**无限集**。

> **约定**：全集记作 `E`，空集 `∅` 满足 `|∅| = 0`。
> ==全集 E 是"计数问题里的参照系"==：只有明确了 E，才能谈"都不在"的那一块有多少。

### 1.2 有限集的基本计数律

设 A、B、C 都是全集 E 的有限子集，以下式子**不需要任何额外条件**即成立：

| 律             | 公式                          | 说明                |
| :------------ | :-------------------------- | :---------------- |
| 空集            | `\|∅\| = 0`                 | 没元素就是 0           |
| 单点集           | `\|{a}\| = 1`               |                   |
| **可加性**（互斥）   | `\|A ∪ B\| = \|A\| + \|B\|`   | ==仅供 A ∩ B = ∅ 时使用== |
| 补集            | `\|~A\| = \|E\| − \|A\|`      | 全集减去自身            |
| 笛卡尔积          | `\|A × B\| = \|A\| · \|B\|`   | 有序对计数（乘法原理）       |
| 幂集            | `\|P(A)\| = 2^{\|A\|}`       | 每个元素"取/不取"两种      |

> **⚠️ 易错警告**：`|A ∪ B| = |A| + |B|` **只在 A 与 B 不相交时成立**。
> ==一旦 A、B 可能有公共元素，直接相加必然"数重"。== 这是容斥原理的出发点——容斥原理就是"可加性"的**一般化修补版**。

**分块视角下的可加性**：由于 2ⁿ 个分块两两不交，可以把全集**按块相加**。例如

`|E| = |A ∩ B| + |A ∩ ~B| + |~A ∩ B| + |~A ∩ ~B|`

这是文氏图做题法的定量基础。

## 二、容斥原理（Inclusion–Exclusion Principle）

### 2.1 两个集合

**定理（两集合容斥）**：设 A、B 为有限集，则

==`|A ∪ B| = |A| + |B| − |A ∩ B|`==

**直观理解**：先把 `|A|` 和 `|B|` 加起来，此时 `A ∩ B` 里的每个元素被**数了两次**，所以要**减去一次** `|A ∩ B|` 把它"多数的"还回去。

**证明（分块计数法）**：把 `A ∪ B` 分成三块讨论。

| 元素身份      | 在 `\|A\| + \|B\|` 中的贡献 | 应计的 1 次 | 是否被多计 |
| :-------- | :-------------------- | :------ | :---- |
| 只在 A（`A∩~B`） | 1                     | 1       | 不多不少  |
| 只在 B（`~A∩B`） | 1                     | 1       | 不多不少  |
| 都在（`A∩B`）  | 2                     | 1       | **多计 1 次** |

在 `A ∩ B` 中的元素被多计 1 次，恰好由 `−|A ∩ B|` 抵消。三块相加右边 = 左边，等式成立。∎

**证明（代数法）**：由 `A ∪ B = A ∪ (B − A)` 且 `A ∩ (B − A) = ∅`，用可加性得 `|A ∪ B| = |A| + |B − A|`；又 `B = (A ∩ B) ∪ (B − A)`（同样不交），故 `|B| = |A ∩ B| + |B − A|`，即 `|B − A| = |B| − |A ∩ B|`。代入即得。∎

### 2.2 三个集合

**定理（三集合容斥）**：设 A、B、C 为有限集，则

==`|A ∪ B ∪ C| = |A| + |B| + |C| − |A ∩ B| − |A ∩ C| − |B ∩ C| + |A ∩ B ∩ C|`==

**逐项解释**：

| 项                       | 符号         | 作用                    |
| :---------------------- | :--------- | :-------------------- |
| 三个单块                    | `+|A|, +|B|, +|C|` | 先把各集合大小加起来            |
| 三个两两交                   | `−|A∩B|` 等 | 把"数两次"的还回去            |
| **中央三交**                | `+|A∩B∩C|` | ==被减了三次，其实应留一次，故要加回==  |

**为什么中央要"加回"？** 见下表（按元素身份逐块核算）。设某元素**恰好属于 k 个集合**，看它在右边被计多少次：

| 元素身份（属于几个集合） | 被"三个单块"计 | 被"三个两两交"计 | 被"中央三交"计 | **总计** |
| :------------ | :------- | :-------- | :------- | :---- |
| k = 1（只在 A）   | 1        | 0         | 0        | **1** ✔ |
| k = 2（如 A∩B）  | 2        | 1         | 0        | **2 − 1 = 1** ✔ |
| k = 3（A∩B∩C）  | 3        | 3         | 1        | **3 − 3 + 1 = 1** ✔ |
| k = 0（都不在）    | 0        | 0         | 0        | **0** ✔ |

> **记忆钩子（本节最重要的一句）**：==**加多了要减、减多了要加**——奇加偶减。==
> 三个集合时符号依次是：**+ + +（三个单）→ − − −（三个两两）→ +（一个三交）**，即"**三加、三减、一加**"。

### 2.3 一般 n 个集合：容斥原理

**定理（容斥原理）**：设 `A₁, A₂, …, Aₙ` 是有限集，记

- 单块和 `S₁ = ∑_{i=1}^{n} |A_i|`
- 两两交和 `S₂ = ∑_{1≤i<j≤n} |A_i ∩ A_j|`
- 三交和 `S₃ = ∑_{1≤i<j<k≤n} |A_i ∩ A_j ∩ A_k|`
- ……
- 全交和 `Sₙ = |A₁ ∩ A₂ ∩ … ∩ Aₙ|`

则

==`|A₁ ∪ A₂ ∪ … ∪ Aₙ| = S₁ − S₂ + S₃ − S₄ + … + (−1)^{n−1} Sₙ`==

展开写全即为：

==`|⋃_{i=1}^{n} A_i| = ∑_{i=1}^{n}|A_i| − ∑_{1≤i<j≤n}|A_i∩A_j| + ∑_{1≤i<j<k≤n}|A_i∩A_j∩A_k| − … + (−1)^{n−1}|A₁∩…∩Aₙ|`==

用集合子集的记号可写得极其紧凑：

==`|⋃_{i=1}^{n} A_i| = ∑_{∅ ≠ S ⊆ {1,2,…,n}} (−1)^{|S| − 1} |⋂_{i∈S} A_i|`==

**口诀**：==**奇加偶减**——交集合个数为奇数的项带正号，个数为偶数的项带负号。==

### 2.4 容斥原理的严格证明（按"出现次数"计数）

这是本节证明的核心思想，**务必理解它，因为"恰好属于 k 个"的公式也靠它**。

**证明**：任取一个元素 `x ∈ ⋃_{i=1}^{n} A_i`，设 `x` **恰好属于其中 k 个集合**（`1 ≤ k ≤ n`）。我们计算 `x` 在等式右端被**计了多少次**。

- `x` 出现在 `S₁` 中的次数：从 k 个含它的集合里选 1 个，即 `C(k, 1)`；
- `x` 出现在 `S₂` 中的次数：选 2 个，即 `C(k, 2)`；
- ……
- `x` 出现在 `Sⱼ` 中的次数：`C(k, j)`（当 `j > k` 时为 0）。

于是 `x` 在右端的总计数为

==`C(k,1) − C(k,2) + C(k,3) − … + (−1)^{k−1} C(k,k)`==

由二项式定理 `(1 − 1)^k = ∑_{j=0}^{k} (−1)^j C(k,j) = 0`，得

`C(k,0) − C(k,1) + C(k,2) − … + (−1)^k C(k,k) = 0`

即 `C(k,1) − C(k,2) + … + (−1)^{k−1} C(k,k) = C(k,0) = 1`。

换成漂亮的等价写法：

==右端对 x 的贡献 = `1 − (1 − 1)^k` 的展开首项 = 1==

（因为 `1 − (1−1)^k`，当 `k ≥ 1` 时为 `1 − 0 = 1`；当 `k = 0` 即 `x` 不在任何 Aᵢ 中时为 `1 − 1 = 0`。）

**结论**：==每个属于并集的元素恰好被计 1 次，不属于并集的元素被计 0 次==，故右端总和恰等于并集的基数。∎

> **核心领悟**：容斥原理不是"凑公式"，而是==**每一项都精确地把"多重计数"掰回"一次计数"**==。所谓"奇加偶减"，本质是二项式恒等式 `∑_{j}(−1)^{j−1}C(k,j) = 1` 的几何化身。

## 三、由容斥导出的常用计数

有了容斥，几乎所有"数数"问题都可以由它推出来。下面五个是必须熟练的"导出公式"。

### 3.1 求交集

由 `|A ∪ B| = |A| + |B| − |A ∩ B|` 反解：

==`|A ∩ B| = |A| + |B| − |A ∪ B|`==

三集合情形（三交）可由 2.2 式反解：

==`|A ∩ B ∩ C| = |A ∪ B ∪ C| − |A| − |B| − |C| + |A ∩ B| + |A ∩ C| + |B ∩ C|`==

### 3.2 求"都不满足"（德摩根 + 补集）

设全集为 E，则

==`|~A₁ ∩ ~A₂ ∩ … ∩ ~Aₙ| = |E| − |A₁ ∪ A₂ ∪ … ∪ Aₙ|`==

这正是 [[3.2 集合的基本运算]] 中德摩根律 `~(A ∪ B) = ~A ∩ ~B` 的定量版本。

> **记忆钩子**：==**"都不是" = 全集 − 并集**。== 凡见"三门都不选的人有多少""都不被整除的数有多少"，第一反应就是它。

### 3.3 "恰好属于某一个"

"恰好属于某一个"指==恰好属于 A、B、C 中**一个且仅一个**==的元素总数。可由文氏图的三个单块直接相加，也可由容斥推出：

三集合情形，记 `N₁` 为恰属于 1 个集合的元素数，则

==`N₁ = |A| + |B| + |C| − 2(|A∩B| + |A∩C| + |B∩C|) + 3|A∩B∩C|`==

**推导思路**：用 2.4 的"计数次数"表反推——我们要让 k=1 的元素计 1 次、k≥2 的元素计 0 次。以 `S₁, S₂, S₃` 线性组合 `a·S₁ + b·S₂ + c·S₃`，令 `k=1: a = 1`，`k=2: 2a + b = 0`，`k=3: 3a + 3b + c = 0`，解得 `a=1, b=−2, c=3`，即上式。

### 3.4 "恰好属于 k 个"的一般公式

设 `Sⱼ = ∑_{|S|=j} |⋂_{i∈S} A_i|`（所有 j 个集合交的基数之和，`S₀ = |E|`）。记恰属于恰好 k 个集合的元素数为 `N_k`，则

==`N_k = ∑_{j=k}^{n} (−1)^{j−k} C(j, k) S_j`==

- `k = 0`（都不属于）：`N₀ = ∑_{j=0}^{n} (−1)^{j} S_j = |E| − S₁ + S₂ − … ± Sₙ`（就是"都不满足"公式）；
- `k = 1`：即 3.3 的一般化 `N₁ = S₁ − 2S₂ + 3S₃ − …`。

> **使用建议**：一般公式不必死背，==记住"它来自逐 k 配平计数次数"的方法，考试能现场推导即可==。真正要背到滚瓜烂熟的是 3.1、3.2 和三集合的 2.2。

### 3.5 对称差的计数

对称差 `A △ B = (A ∪ B) − (A ∩ B)`，由容斥立得：

==`|A △ B| = |A ∪ B| − |A ∩ B| = |A| + |B| − 2|A ∩ B|`==

即"只在一个集合里"的元素数——正好是 k=1 的两集合特例。

## 四、典型模型与套路

### 4.1 三集合文氏图七分块法（万能解）

**核心动作：从"中央三交"开始，由内向外填充。** 顺序如下（`x` 表示待填的数）：

| 步   | 填哪一块        | 用哪个已知量求                            |
| :-- | :---------- | :--------------------------------- |
| ①   | 中央 `A∩B∩C`  | 题干直接给的最内侧数据                        |
| ②   | 两两交的"外圈"三块 | 两两交基数**减去**三交，如 `\|A∩B\|−\|A∩B∩C\|` |
| ③   | 单块三块        | 单集合基数减去与它相关的两个两两交（见下）              |
| ④   | 都不在的一块      | `\|E\| − \|A∪B∪C\|`                |

三块"只有 A"的填法：

- 只有 A：`|A| − |A∩B| − |A∩C| + |A∩B∩C|`
- 只有 B：`|B| − |A∩B| − |B∩C| + |A∩B∩C|`
- 只有 C：`|C| − |A∩C| − |B∩C| + |A∩B∩C|`

> **⚠️ 易错警告**：==步骤③里减完两个两两交后，一定要把中央三交**加回来**==。原因：`|A∩B|` 和 `|A∩C|` 都包含了中央那块，直接相减会把中央那块减掉两次，而它本应完全不属于"只有 A"。

### 4.2 "至少／至多／恰好"的翻译表

| 题型用语          | 翻译为                              |
| :------------ | :------------------------------- |
| 至少一个 / 至少一门   | `\|A∪B∪C\|`                       |
| 至多一个（某个属性）    | = 0 个 + 恰好 1 个 = 都不满足 + `N₁`     |
| 恰好一个          | `N₁`（三个单块之和）                    |
| 恰好两个          | `N₂ = S₂ − 3S₃`（三集合时）            |
| 都不 / 都不是      | `\|E\| − \|A∪B∪C\|`               |
| 至少两个          | 恰好两个 + 恰好三个 = `\|A∪B∪C\| − N₁`  |

> **记忆钩子**：==**并集 − 恰好一个 = 至少两个**；== **全集 − 并集 = 一个都没有**。这两个恒等式能秒杀一大半应用题。

### 4.3 整除计数模型（数论型应用）

求 `1 ~ n` 中**被 a 或 b 或 c 整除**或**与 m 互素**的数个数，是本节的经典模型。设

- `A_d` = {`x ∈ {1,…,n}` : `d | x`}，则 ==`|A_d| = ⌊n / d⌋`（下取整）==。

**（1）被 2 或 3 或 5 整除的个数**：

`|A₂ ∪ A₃ ∪ A₅| = |A₂| + |A₃| + |A₅| − |A₆| − |A₁₀| − |A₁₅| + |A₃₀|`

其中 `A₂ ∩ A₃ = A₆`，`A₂ ∩ A₃ ∩ A₅ = A₃₀`（**被两个数同时整除 ⇔ 被它们的 lcm 整除**）。

**（2）1 ~ n 中与 n 互素的个数（欧拉函数的思想）**：若 `n = p₁^{α₁} … p_r^{α_r}`，则

==与 n 互素的个数 = `n · (1 − 1/p₁)(1 − 1/p₂) … (1 − 1/p_r)`==

其推导正是容斥：先减被每个 `pᵢ` 整除的，再加回被 `pᵢpⱼ` 整除的……

> **⚠️ 易错警告**：==两数"同时整除"要取**最小公倍数**，不是乘积==！例如 4 与 6 同时整除的数，形如 `A_12` 而非 `A_24`。乘积只在两数互素时才等于 lcm。

## 五、例题

### 例 1（两集合·工作分配）

某班 40 人，参加数学建模的有 25 人，参加程序设计的有 18 人，两项都参加的有 10 人。求至少参加一项的人数与两项都不参加的人数。

**解**：令 `|A| = 25, |B| = 18, |A ∩ B| = 10`。由两集合容斥

`|A ∪ B| = 25 + 18 − 10 = 33`

都未参加人数 = `|E| − |A ∪ B| = 40 − 33 = 7`。

**答**：至少参加一项 **33 人**，都不参加 **7 人**。

### 例 2（三集合·课程选修）

某年级 120 人，选修方式为：选 A 的 70 人，选 B 的 55 人，选 C 的 50 人；同时选 A、B 的 30 人，A、C 的 25 人，B、C 的 20 人；三门都选的 10 人。求至少选一门的人数、一门都不选的人数、恰好选一门的人数、恰好选两门的人数。

**解**：由三集合容斥

`|A∪B∪C| = 70 + 55 + 50 − 30 − 25 − 20 + 10 = 110`

一门都不选 = `120 − 110 = 10`。

**恰好选一门**（用 3.3 公式）：

`N₁ = 70 + 55 + 50 − 2(30 + 25 + 20) + 3×10 = 175 − 150 + 30 = 55`

**恰好选两门**：`S₂ − 3S₃ = (30 + 25 + 20) − 3×10 = 75 − 30 = 45`
（另可用 `|A∪B∪C| − N₁ − N₃ = 110 − 55 − 10 = 45` 验证 ✔）

**答**：至少一门 **110 人**，都不选 **10 人**，恰好一门 **55 人**，恰好两门 **45 人**。

### 例 3（文氏图分块·语言调查）

对某群体调查三门语言，得：会英语 30 人，会日语 20 人，会法语 15 人；英日都会 10 人，英法都会 8 人，日法都会 5 人，三门都会 3 人。求恰好会一门、恰好会两门的人数，并画出七分块。

**解**：中央 `英∩日∩法 = 3`。

| 分块           | 计算                   | 结果 |
| :----------- | :------------------- | :- |
| 只英日（不含法）      | `10 − 3`             | 7  |
| 只英法（不含日）      | `8 − 3`              | 5  |
| 只日法（不含英）      | `5 − 3`              | 2  |
| **只有英语**     | `30 − 7 − 5 − 3`     | 15 |
| **只有日语**     | `20 − 7 − 2 − 3`     | 8  |
| **只有法语**     | `15 − 5 − 2 − 3`     | 5  |
| 恰好一门         | `15 + 8 + 5`         | 28 |
| 恰好两门         | `7 + 5 + 2`          | 14 |
| 三门都           | ——                   | 3  |

**校验**：恰好一门 28 = 公式 `30+20+15 − 2(10+8+5) + 3·3 = 65 − 46 + 9 = 28` ✔

> **技巧**：==先把"中央"和"两两交外圈"填好，单块用"单集合基数 − 该集合的两个外圈 − 中央"倒推==，全程不重不漏。

### 例 4（整除·1–1000）

求 1 ~ 1000 中能被 4 或 6 或 9 整除的整数个数。

**解**：`⌊1000/4⌋ = 250`，`⌊1000/6⌋ = 166`，`⌊1000/9⌋ = 111`。

交叉项（取 lcm）：`4,6 → 12`：`⌊1000/12⌋ = 83`；
`4,9 → 36`：`⌊1000/36⌋ = 27`；`6,9 → 18`：`⌊1000/18⌋ = 55`；
三者 `4,6,9 → 36`：`⌊1000/36⌋ = 27`。

由三集合容斥

`|A∪B∪C| = 250 + 166 + 111 − 83 − 27 − 55 + 27 = 389`

**答**：**389 个**。

> **检查**：`⌊1000/36⌋` 同时出现在"4 与 9 的交"和"三者交"里是正常的——因为 `lcm(4,9) = 36 = lcm(4,6,9)`，被 36 整除的数天然同时满足三个条件。

### 例 5（互素计数·欧拉函数）

求 1 ~ 300 中与 300 互素的整数个数。`300 = 2² × 3 × 5²`。

**解**：与 300 不互素 ⟺ 被 2 或 3 或 5 整除。由例 4 型计算

`|A₂∪A₃∪A₅| = 150 + 100 + 60 − 50 − 30 − 20 + 10 = 220`

故互素个数 = `300 − 220 = 80`。

**验证（欧拉函数公式）**：`φ(300) = 300 × (1 − 1/2)(1 − 1/3)(1 − 1/5) = 300 × 1/2 × 2/3 × 4/5 = 80` ✔

### 例 6（至少/恰好综合）

50 名学生中，看电影的有 30 人，看画展的有 25 人，看话剧的有 20 人；三者都看的有 5 人，三者都不看的 8 人。求恰好看了两部的人数和至少看了两部的人数。

**解**：先求并集：`|A∪B∪C| = 50 − 8 = 42`。

设 `S₂ = x`（两两交之和），则

`42 = 30 + 25 + 20 − x + 5 = 80 − x ⟹ x = 38`

恰好两部 = `S₂ − 3S₃ = 38 − 3×5 = 23`

至少两部 = 恰好两部 + 恰好三部 = `23 + 5 = 28`

（另解：`|A∪B∪C| − N₁`，其中 `N₁ = 75 − 2×38 + 3×5 = 75 − 76 + 15 = 14`，`42 − 14 = 28` ✔）

**答**：恰好两部 **23 人**，至少两部 **28 人**。

## 六、常见易错点速查

| 易错点                        | 正确做法                        |
| :------------------------- | :-------------------------- |
| `\|A∪B\| = \|A\|+\|B\|`    | ==仅当 A∩B=∅ 才成立==            |
| 三集合忘加回中央                   | 中央被减 3 次，必须 ==`+|A∩B∩C|`== |
| 单块填错                       | 减两个两两交后 ==加回中央==            |
| "至少"当成"恰好"                 | 至少=并集；恰好=精确分块                |
| 整除交叉取乘积                    | ==取 lcm，不取乘积==              |
| "都不"直接等于 `0` 或忘记补集         | `= \|E\| − \|A∪B∪C\|`       |
| 符号规律记反                     | ==奇加偶减==，交的集合个数奇数带正          |

> **口诀总纲**：==**加多了要减、减多了要加；边界内外，各算一次。**==

# 参考答案与详细解析

## 第 1 题

`|A∪B| = 28 + 32 − 20 = 40`；都不会 = `45 − 40 = 5`。

**答**：至少会一样 40 人，都不会 5 人。

## 第 2 题

- `|A∪B| = 12 + 9 − 4 = 17`
- `|A△B| = 12 + 9 − 2×4 = 13`
- `|~A∩~B| = |E| − |A∪B| = 20 − 17 = 3`

## 第 3 题

`|A∪B| = 40 + 35 − 15 = 60`；都不选 = `100 − 60 = 40`。

**答**：**40 人**。

## 第 4 题

三集合容斥：

`|A∪B∪C| = 65 + 45 + 42 − 20 − 25 − 15 + 8 = 100`

- 至少订一种：**100 人**
- 一种都不订：`120 − 100 = 20` 人
- 恰好一种：`N₁ = 152 − 2(60) + 3×8 = 152 − 120 + 24 = 56` 人
- 恰好两种：`S₂ − 3S₃ = 60 − 24 = 36` 人

**校验**：`56 + 36 + 8 = 100` ✔（恰好一 + 恰好二 + 恰好三 = 并集）

## 第 5 题

`⌊500/3⌋ = 166`，`⌊500/5⌋ = 100`，`⌊500/7⌋ = 71`；
两两 lcm：`15 → 33`，`21 → 23`，`35 → 14`；三者 lcm `105 → 4`。

`|A∪B∪C| = 166 + 100 + 71 − 33 − 23 − 14 + 4 = 271`

**答**：**271 个**。

## 第 6 题

不互素 ⟺ 被 2 或 3 或 5 整除。

`⌊360/2⌋=180, ⌊360/3⌋=120, ⌊360/5⌋=72`；
`lcm(2,3)=6→60, lcm(2,5)=10→36, lcm(3,5)=15→24`；`lcm=30→12`。

`|A₂∪A₃∪A₅| = 180 + 120 + 72 − 60 − 36 − 24 + 12 = 264`

互素个数 = `360 − 264 = 96`。

**验证**：`φ(360) = 360 × 1/2 × 2/3 × 4/5 = 96` ✔

## 第 7 题

中央 `英∩日∩法 = 4`。

- 只英日：`12 − 4 = 8`
- 只英法：`8 − 4 = 4`
- 只日法：`6 − 4 = 2`
- **只有英语**：`32 − 8 − 4 − 4 = 16`
- 只有日语：`20 − 8 − 2 − 4 = 6`
- 只有法语：`15 − 4 − 2 − 4 = 5`

恰好一门 = `16 + 6 + 5 = 27`。

**答**：只会英语 **16 人**，恰好会一门 **27 人**。

**校验**：`N₁ = 67 − 2(12+8+6) + 3×4 = 67 − 52 + 12 = 27` ✔

## 第 8 题

设全集为 100%（百分比即人数），记 `S₃ = N₃ = 10`。

"至少看过两部"= 恰好两部 + 恰好三部 = `N₂ + N₃ = 55`，故 `N₂ = 45`。

由 `N₂ = S₂ − 3S₃` 反解：`S₂ = N₂ + 3S₃ = 45 + 30 = 75`。

于是

`|A∪B∪C| = S₁ − S₂ + S₃ = (60 + 50 + 45) − 75 + 10 = 90`

一部都没看 = `100 − 90 = 10`。

**校验**：恰好一部 `N₁ = S₁ − 2S₂ + 3S₃ = 155 − 150 + 30 = 35`；`N₁ + N₂ + N₃ = 35 + 45 + 10 = 90` ✔（且各分块非负、不超过全集）。

**答**：一部都没看的人占 **10%**。

> **教学要点**：==计数问题的答案必须落在 `[0, |E|]` 内，且各分块非负==。若算出负值或超出全集，说明已知条件互相冲突——这也是用容斥反查"数据是否合理"的用法。

> **本题关键**：题干给的是"**至少**两部"（`N₂ + N₃`），不是"恰好两部"（`N₂`）。==必须先减去 `N₃` 才能得到 `N₂`，再回代求 `S₂`。=="至少"与"恰好"的一字之差，正是本节最容易失分处。

## 第 9 题

由三集合容斥：

`175 = 100×3 − 150 + |A∩B∩C| = 150 + |A∩B∩C|`

故 `|A∩B∩C| = 25`。

恰好属于一个：`N₁ = S₁ − 2S₂ + 3S₃ = 300 − 2×150 + 3×25 = 300 − 300 + 75 = 75`。

**答**：`|A∩B∩C| = 25`，恰好属于一个集合的元素 **75 个**。

**校验**：恰好两个 = `S₂ − 3S₃ = 150 − 75 = 75`；`N₁ + N₂ + N₃ = 75 + 75 + 25 = 175` ✔

## 附一：容斥与计数速查

**一、核心公式**

| 场景           | 公式                                                                                     |
| :----------- | :------------------------------------------------------------------------------------- |
| 两集合并         | ==`\|A∪B\| = \|A\| + \|B\| − \|A∩B\|`==                                                  |
| 三集合并         | ==`\|A∪B∪C\| = S₁ − S₂ + S₃`==                                                          |
| n 集合并        | ==`\|⋃_{i=1}^{n}A_i\| = S₁ − S₂ + S₃ − … + (−1)^{n−1}Sₙ`==                              |
| 紧凑写法         | `∑_{∅≠S⊆[n]} (−1)^{\|S\|−1} \|⋂_{i∈S}A_i\|`                                           |
| 交集（两集合）      | `\|A∩B\| = \|A\| + \|B\| − \|A∪B\|`                                                      |
| 都不满足（德摩根）    | ==`\|~A₁∩…∩~Aₙ\| = \|E\| − \|A₁∪…∪Aₙ\|`==                                              |
| 对称差          | `\|A△B\| = \|A\| + \|B\| − 2\|A∩B\|`                                                     |
| 恰好一个（三集合）    | `N₁ = S₁ − 2S₂ + 3S₃`                                                                  |
| 恰好两个（三集合）    | `N₂ = S₂ − 3S₃`                                                                        |
| 恰好 k 个（一般）   | `N_k = ∑_{j=k}^{n} (−1)^{j−k} C(j,k) S_j`                                              |
| 整除           | `\|A_d\| = ⌊n/d⌋`；`A_a ∩ A_b = A_{lcm(a,b)}`                                           |
| 欧拉函数         | `φ(n) = n∏(1 − 1/pᵢ)`                                                                  |

其中 `S₁ = ∑_{i}|A_i|`，`S₂ = ∑_{1≤i<j≤n}|A_i∩A_j|`，`S₃ = ∑_{1≤i<j<k≤n}|A_i∩A_j∩A_k|`。

**二、口决与要点**

> - 符号规律：==**奇加偶减**==（交的集合个数为奇 → 正号，为偶 → 负号）。
> - 纠错法则：==**加多了要减、减多了要加**==。
> - 都不满足：==**全集 − 并集**==。
> - 至少两个：==**并集 − 恰好一个**==。
> - 三集合文氏图：==**先填中央 → 再填两两交外圈 → 再倒推单块 → 最后补都不在**==。
> - 整除交叉项：==**取 lcm，不取乘积**==。

**三、计数次数表（证明容斥的工具）**

| 元素恰属 k 个集合 | 在 `S₁ − S₂ + S₃ − …` 中被计次数 | 结果   |
| :--------- | :--------------------- | :--- |
| k = 0      | `C(0,0) − …`           | ==0== |
| k = 1      | `C(1,1)`               | ==1== |
| k = 2      | `C(2,1) − C(2,2)`      | ==1== |
| k = 3      | `C(3,1) − C(3,2) + C(3,3)` | ==1== |
| 一般 k ≥ 1   | `∑_{j=1}^{k}(−1)^{j−1}C(k,j)` | ==1== |

（依据：`∑_{j=0}^{k}(−1)^j C(k,j) = (1−1)^k = 0` ⟹ 上式和为 1。）
