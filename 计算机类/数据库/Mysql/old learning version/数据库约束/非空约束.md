## 1. 定义

1.限制字段**不能存入 NULL 空值**，该列插入、更新时必须填写有效值，不允许留空。

NULL 代表无数据，和空字符串`''`、0 不是一回事

## 2.特点

1. **限制规则**
     
    该字段**禁止存入 NULL 值**，插入、修改数据时必须给该字段赋予**有效值**；
    ==空字符串`''`、数字 0 不属于 NULL，可以正常存入。==
    
2. **默认属性**
    
    数据表字段默认是**允许为空（NULL）**，必须==手动声明`NOT NULL`才开启非空约束。==
    
3. **与主键的关系**
    
    主键约束`PRIMARY KEY`自带非空 + 唯一双重效果，主键列无需额外写`NOT NULL`，强制不能为 null。
    
4. **约束作用范围**
    
    作用于**单列**，==只能单独给某一列设置==，不能多列组合设置非空。
    
5. **修改前提**
    
    给已有表的列追加非空约束前，表里该列**不能存在已有 NULL 数据**，否则语句直接报错，需要先把 NULL 数据填充完毕才能添加约束。
    
6. **插入强制赋值**
    
    插入语句如果省略非空字段的值，数据库直接抛出约束异常，插入失败。
    
7. **可灵活移除**
    
    支持后期通过`ALTER TABLE`语句取消非空约束，改回允许 NULL。

## 3.非空操作

>建表时添加
```sql
CREATE TABLE 表名( 
字段1 类型 NOT NULL, 
字段2 类型, 
字段3 类型,
);
```

>创建表以后修改为非空约束
```sql
ALTER TABLE 表名 MODIFY 字段名 数据类型 NOT NULL;
```

>创建表以后取消非空约束
```sql
ALTER TABLE 表名 MODIFY 字段名 原有数据类型 NULL;
```
