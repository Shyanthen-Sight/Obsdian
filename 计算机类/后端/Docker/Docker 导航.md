## 卡住时先跑这三条

```bash
docker ps -a
docker logs --tail 50 <容器名>
docker inspect -f '{{.State.Status}} {{.State.ExitCode}}' <容器名>
```

状态、日志、实际配置，基本能覆盖“容器起不来”“端口不通”“数据没挂上”这几类问题；具体排查顺序见 [[01-容器|容器]] 和 [[00-网络|网络]]。
